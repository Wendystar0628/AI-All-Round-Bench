# 网页 PV：《壱雫空》

## 1. 目标总览

为乐队 MyGO!!!!! 的歌曲《壱雫空》制作一支 PV，在网页中实时播放。用的是这首歌的前半首，长 81.4 秒，到第一段副歌唱完为止。

这道题的核心工作是视觉设计：画面的构成和层次，人物与文字的排版，动效和节奏，配色和质感。

PV 偏平面设计，靠第一眼的视觉感受取胜。
- 画面里的元素绝大多数和歌词没有直接关系：色块、条纹、网格、几何形、重复的字、标签、贴纸、光斑，都是为了视觉效果。
- 观众没有时间去解读含义，每个画面要让人一眼就觉得好看、有节奏。
- 3D 是辅助：用来做镜头运动、展示少数物件和空间，画风和平面部分保持一致。

第 3 节的分镜表共 36 个镜头。每个镜头按层写：背景、主体、前景装饰、文字，再写动效和色彩。

分镜表里的大小、位置、速度和颜色都是方向，不是要对准的数值，具体取多少由你按画面效果来定。要对准的是歌曲本身的时间点：歌词什么时候唱、第几小节第几拍有什么。

画面里的图像只有题目给的五张角色立绘，其余全部由代码绘制。立绘和其他元素一样，是提供视觉效果的图像：可以裁切、加框、描白边做成贴纸、做成剪影或单色、重复排列。

第 4 节是全片共用的视觉体系。分镜表里没写到的地方，都按第 4 节来做。某个镜头如果有更好的做法，可以换成同等分量的设计，在 `README.md` 里写明。

## 2. 素材与节拍

### 2.1 素材

素材在工作目录的 `素材\` 文件夹里：

### 2.2 节拍

- 每分钟 204 拍，4 拍一小节。第一拍在 0.045 秒，之后每拍 0.294 秒，每小节 1.176 秒。
- 第 n 小节的起点 = 0.045 + (n − 1) × 1.176 秒。分镜表里的“第 n 小节第 k 拍”都按这个算。
- 几乎每句歌词都从上一小节的第 4 拍或拍间弱起进入。

## 3. 分镜表

### 3.1 开场（0–11.81 秒，第 1–10 小节）

**音乐**：第 1 小节是弱起，开头一小段几乎无声。0.92 秒主唱开口，1.22 秒（第 2 小节第 1 拍）是第一下重拍，乐队全部进来。人声唱到约 11.5 秒。

**这一段**：白底为主，用细线、圆、网格立下全片的版式；颜色克制，以天蓝和墨蓝为主。

**镜头 01｜0–1.22 秒（第 1 小节）**
- **背景**：纸白，铺一层很淡的网格。
- **主体**：一根细竖线从画顶往下画出来，一个天蓝的小圆顺着线滑下，越滑越快。
- **前景装饰**：常驻版面层出现，包括四角的角标、一角的时间码、镜头编号，以及一行拉开字距的英文小字 HITOSHIZUKU / MyGO!!!!!。
- **文字**：第一句在画面右侧竖排，明朝体，中等大小。开唱前先以空心描边占位，随唱逐字填实。
- **动效**：
  - 竖线一开始画得很快，快到底时收慢；
  - 角标从角点向两边画出；
  - 英文小字逐个字母打出来。
- **色彩**：纸白、墨蓝，小圆是天蓝。

**镜头 02｜1.22–3.57 秒（第 2–3 小节）**
- **背景**：1.22 秒重拍上，小圆落到底，从落点扩出一组同心圆环。天蓝和白相间的环带一圈圈铺满画面。
- **主体**：第一句歌词定住在右侧。
- **前景装饰**：
  - 画面下部一条横贯的色带，带上一行英文小字从右往左循环滚动，像跑马灯；
  - 画面左半边滑入一组细斜线纹。
- **动效**：
  - 圆环一开始扩得很快，余下的时间慢慢收住，一圈比一圈晚一点；
  - 第 3 小节第 1 拍，整组圆环轻轻一缩一放，跟着重拍；
  - 跑马字一直匀速滚动。
- **色彩**：天蓝、白、墨蓝。

**镜头 03｜3.36–5.67 秒（第 3 小节第 4 拍–第 5 小节）**
- **背景**：浅灰网格纸。
- **主体**：画面分成三栏。
  - 左栏：一张竖长的天蓝卡片，卡片上是灯的全身立绘，描了一圈白边，像一张贴纸。
  - 中栏：第二句歌词，横排大字。
  - 右栏：竖着叠放几个小标签和一条细条码。
- **前景装饰**：卡片的两个角贴着半透明胶带，周围散着几颗四角星芒。
- **文字**：明朝体实心墨蓝，横排；每个词跟着唱，从左往右滑到位。
- **动效**：
  - 三栏从下往上依次滑入，各晚半拍；
  - 卡片入场时稍微转过一点，再弹回摆正；
  - 星芒按拍一闪一闪。
- **色彩**：浅灰、天蓝、墨蓝，星芒白。

**镜头 04｜5.67–9.46 秒（第 5 小节第 4 拍–第 8 小节）**
- **第 6 小节**：
  - 背景：满屏铺着重复的空心英文大字 HITOSHIZUKU，淡天蓝，缓慢横向滚动，字大到上下出框。
  - 主体：画面左边一个圆形取景框，框里是灯的半身；框外绕一圈小字，缓慢旋转。
  - 文字：第三句在画面右侧，竖排实心大字，墨蓝。
- **第 7 小节**：
  - 第 1 拍，背景从白翻成满屏天蓝，字跟着变白。
  - 圆框缩小，一个变成三个，横排成一行，框里是同一张立绘的三种裁切。
- **第 8 小节**：
  - 唱到“一滴”这个词时，这两个字放大到画面中央，其余的字收小、退到一侧。
  - 一组粗细不一的横条纹从画面一侧扫过。
- **动效**：
  - 每个小节的版面变化都落在第 1 拍：先轻微地预备一下，再快速到位。
  - 背景大字和小字圆环一直在缓慢地动，和换版面的快动作形成对比。
- **色彩**：天蓝与白互换，墨蓝的字，“一滴”这两个字是天蓝。

**镜头 05｜9.46–11.81 秒（第 9–10 小节）**
- **背景**：白，网格淡出。上下两条跑马字色带继续滚动。
- **主体**：画面中央一个大的空心圆，沿着圆周从一点画出整圈。
- **前景装饰**：一条横贯画面的细线穿过圆心，线上标着刻度和几个小编号。
- **动效**：
  - 画圆是快进慢收；
  - 第 9 小节第 1 拍，上一个镜头的版面整体往一侧加速滑出；
  - 第 10 小节最后一拍，大圆向内收成一个点，跑马字带同时停住。
- **色彩**：白、天蓝细线、墨蓝小字。

### 3.2 前奏（11.81–18.87 秒，第 11–16 小节）

**音乐**：6 小节器乐，全乐队冲刺。

**这一段**：一小节一个版面，片名一小节，五人各一小节。每个版面都是一张完整的平面海报，层次满、动得快。

**签名转场**：
- 小节交界都用同一个转场：一条斜向的色幕，颜色是下一个人的代表色，从一角进、对角出，一拍走完。
- 色幕一进来就盖住大半，盖满时换画面，再加速离开。
- 五次完全相同。

**小元素**：常驻版面层里有一个小节拍器，按八分音符逐格点亮，颜色随当前的人轮换。

**镜头 06｜11.81–12.99 秒（第 11 小节）：片名**
- **背景**：满屏天蓝，铺着白色斜条纹，条纹缓慢平移。
- **主体**：
  - 中央是一张方形的单曲封套，像唱片封面那样排版：
    - 片名《壱雫空》，“雫”最大；
    - 一把小小的 3D 半透明伞，斜放在片名旁边，伞面干净；
    - 下方是 MyGO!!!!!，五个感叹号分别是五人的代表色。
  - 封套后面露出半张唱片。
- **前景装饰**：
  - 封套一角贴一张小标签，写曲目编号；
  - 封套外绕一圈环形小字 HITOSHIZUKU · MyGO!!!!! ·，持续旋转；
  - 四周散着星芒和小圆点。
- **文字**：“雫”是实心大字，“壱”“空”是空心描边，落位后填实。
- **动效**：
  - 第 1 拍：封套从下方滑入，冲过一点再回到位。
  - 第 2、3、4 拍：片名三个字依次从不同方向滑进封套。唱片同时从封套后面滑出半张，开始旋转。
  - 第 4 拍后半拍：五个感叹号一个接一个落下。
- **色彩**：天蓝、白、墨蓝，加五人的代表色。

**五人的出场**：镜头 07–11 是五个人各自的出场版面，每人一小节。
- 五人共用的只有三样：
  - 每人一小节；
  - 一个大号的罗马字名字，加一个小标签（编号、日文名、乐器）；
  - 一组乐器图形，用自己的代表色。
- 其余都各不相同：构图方向、底色、背景纹样、人物大小、名字的字体处理、人物的显现方式，以及这一小节里的节奏。
- 构图方向：乐奈竖向，爱音斜向，爽世对称加横向，立希横幅，灯居中留白。

**镜头 07｜12.99–14.16 秒（第 12 小节）：要乐奈｜竖向、出框与巨字**
- **背景**：白底，铺一组鲜绿的竖条纹，粗细不一。
- **主体**：
  - 乐奈的上半身从画面右边缘探进来，大半在框外，描白边。
  - 她身后是竖排的空心巨字 RANA，鲜绿，上下都出框。
- **前景装饰**：
  - 六根竖线代表吉他弦，从画顶贯到画底；
  - 两枚黑白棋盘格的小方块贴纸；
  - 一角放小标签：01 · 要楽奈 · Gt.
- **人物的显现**：第 1 拍，弦从左到右依次振动；振到哪，人物就沿着那一条显出来，带着原色。
- **动效**：
  - 第 2 拍，巨字顺着弦的方向从上往下滑到位，比人物慢半拍；
  - 竖条纹一直缓慢地往下滚；
  - 第 3、4 拍再扫一次弦，人物和巨字跟着轻轻一颤。
- **色彩**：白、鲜绿、深灰细线。

**镜头 08｜14.16–15.34 秒（第 13 小节）：千早爱音｜斜向与残影**
- **背景**：满屏珊瑚粉，铺一层白色的半调网点，从一角往对角渐变。
- **主体**：
  - 一条白色的对角色带，从左下斜到右上；
  - 爱音跃起的全身在色带上，身后拖着几个残影。
- **前景装饰**：
  - 吉他琴颈的方向射出几道白色速度线；
  - 几颗白色五角星贴纸；
  - 一角放标签：02 · 千早愛音 · Gt.
- **文字**：名字 ANON 是白色实心粗斜体，沿色带的方向排，压在残影后面。
- **人物的显现**：残影一个接一个落位，由白渐深，最后落下的那一个就是彩色的本人，落在第 3 拍。
- **动效**：速度线每拍射出一组，整个版面顺着色带缓慢漂移，星芒依次弹出。
- **色彩**：珊瑚粉、白。

**镜头 09｜15.34–16.52 秒（第 14 小节）：长崎爽世｜对称与分割**
- **背景**：上下分割，上半白，下半橙黄。白的那半铺着细横线，橙黄的那半铺着同心的细圆弧。
- **主体**：正中一张竖长的卡片，爽世在卡片里，站在分割线上；她的倒影落进下半的橙黄色块里。
- **前景装饰**：
  - 四根贝斯弦是四条粗横线，横穿画面，从卡片后面经过；
  - 卡片两侧对称地各放一列小圆点和刻度；
  - 一角放标签：03 · 長崎そよ · Ba.
- **文字**：SOYO 用空心的细衬线小字，竖排在卡片一侧。
- **人物的显现**：卡片从中线向上下展开，展开时人已经是彩色的；倒影晚半拍才浮现。
- **动效**：
  - 四条横线每拍一起轻轻下沉，再回弹；
  - 这是五个出场里动得最少的一个，所有动作都对称地同时发生。
- **色彩**：白、橙黄、暖灰。

**镜头 10｜16.52–17.70 秒（第 15 小节）：椎名立希｜横幅与暗底**
- **背景**：深靛紫，铺一层细网格和几组大小不一的同心圆环线。
- **主体**：立希和整套鼓的横幅立绘铺满画面下部，暗着，只有鼓圈和镲片的边缘亮着白色高光。
- **前景装饰**：
  - 画面上方一排小方块，按八分音符逐个点亮；
  - 一角放标签：04 · 椎名立希 · Dr.
- **文字**：TAKI 是白色的实心粗无衬线，压在画面上方一角，被一道斜光切开。
- **人物的显现**：
  - 第 1 拍鼓点上，底鼓的鼓面打开一扇圆窗，窗里是彩色的局部：鼓棒和双手；
  - 第 3 拍，圆窗扩满整个画面，扩到哪里，哪里就亮成彩色。
- **动效**：每拍从圆窗向外扩一圈细环；镲片的高光按八分音符闪烁。
- **色彩**：深靛紫、白、靛紫。

**镜头 11｜17.70–18.87 秒（第 16 小节）：高松灯｜居中留白**
- **背景**：极简的白，什么纹样都不铺。
- **主体**：一条天蓝的声波线横贯画面，灯的全身很小，站在声波线中央。
- **前景装饰**：一颗小星芒在她头顶；一角放标签：05 · 高松燈 · Vo.
- **文字**：TOMORI 是极小的实心字，拉开字距，排在声波线下方。
- **人物的显现**：声波线从左往右画过去，到中央时顺势往上勾出她的轮廓，再填上颜色。
- **动效**：
  - 声波线随拍起伏，经过她脚下时变平；
  - 第 4 拍，全部收成画面中央的一个点。
- **色彩**：白、天蓝。

### 3.3 主歌（18.87–36.52 秒，第 17–31 小节）

**音乐**：22.89 秒和 32.39 秒两句和声，32.39 正好在第 28 小节第 3 拍。第 31 小节（35.34–36.52 秒）鼓和贝斯抽空，35.39 秒有一下高频重音。

**这一段**：浅色、通透：半透明的面板、细线、柔和的光斑。字小而精致，版面一小节或两小节换一次，每个版面里都有持续的小动作。

**镜头 12｜18.87–22.40 秒（第 17–19 小节）**
- **背景**：浅天蓝渐变，飘着几个柔和的大光斑；一组极细的斜线纹缓慢平移。
- **主体**：
  - 五张竖长的半透明卡片并排，像一叠亚克力卡；
  - 每张卡片带一点代表色，里面是对应成员的半身剪影；
  - 只有中间那张，也就是灯的那张，是彩色立绘。
- **前景装饰**：每张卡片顶上一个小编号和一个小圆点；画面下沿是一条细刻度尺。
- **文字**：18.86 秒这一句是细小的实心字，横排在卡片下方，墨蓝。
- **动效**：
  - 第 17 小节：五张卡片从上方依次落下，按八分音符一张接一张，落到位时轻轻回弹；
  - 第 18 小节：整排卡片向左移一格，最左边那张从画面滑出，又从右边补进来，像转盘；
  - 第 19 小节：中间那张放大到半个画面，其他卡片退到后面变淡。
- **色彩**：浅天蓝、白，五种代表色都降了饱和度。

**镜头 13｜22.40–24.75 秒（第 20–21 小节）**
- **背景**：天蓝渐变，飘着散景式的柔和圆点。
- **主体**：四块磨砂质感的半透明面板，错落地叠在一起，里面分别是另外四人的剪影，各是自己的代表色。
- **前景装饰**：每块面板角上有一个小标签，写名字的首字母；几道细光线斜穿过面板。
- **文字**：22.89 秒的和声，用窄而宽字距的无衬线小字分写在四块面板上，各是那块面板的代表色，从磨砂后面透出来。

**镜头 34｜74.17–78.87 秒（第 64–67 小节）**

**镜头 35｜78.87–79.60 秒（第 68 小节前半）**

## 4. 全片的视觉体系

### 4.1 风格

- **偏平面设计的动态排版 PV**：主体是色块、线条、几何形、文字和立绘卡片的组合，平涂为主，清爽明亮。
- **3D 是辅助**：三维的空间只出现在镜头 23–26 和 34，负责镜头运动和板块空间，画风保持平涂加描边。
- **伞是 3D 建模的半透明伞**：凡是出现伞的镜头（06、14、20、31），伞都是建模出来的立体物件，像透明的塑料伞：
  - 伞面半透明，透得出后面的画面和颜色，边缘和褶线处稍亮，受光一侧有高光，透过伞面的背景有轻微的折射；
  - 伞骨、伞柄、伞尖、伞面分片的折线都看得清；
  - 带代表色的伞，颜色淡淡地染在伞面上，仍然透光；
  - 雨中的镜头（14、20）伞面挂雨滴，有聚、有滑、有滴落；副歌（31）只残留几颗被阳光照亮的雨滴；片名（06）伞面干净。
  - 伞和平面的画面合成在一起，周围的元素照旧是平面的。
- **其余借用的现实元素要几何化**：雨、路面、云这类现实里的东西，画成短划线、条纹、圆角形这类图形，和整体画风统一。
- **不把全片的视觉重心绑在某一个元素上**：每个镜头的主角可以是文字、人物、几何形、色块，也可以是三维空间，在全片里轮换。
- **一段一种气质**：

| 段落 | 气质 |
|---|---|
| 开场 | 白底、细线和圆，克制 |
| 前奏 | 五张风格各异的平面海报，层次满 |
| 主歌 | 浅色、通透，半透明面板和细线 |
| 预副歌前半 | 深墨蓝底，条纹、标线、色斑越来越满 |
| 预副歌后半 | 三维的板块空间 |
| 副歌 | 晴空蓝、阳光黄和五色，最亮最满 |

### 4.2 元素

任何内容都可以成为 PV 画面里的元素，提供视觉效果。画面里的大部分元素都和歌词没有直接关系。

| 类型 | 例子 |
|---|---|
| 几何与图形 | 点、线、圆、圆环、方格、网格、条纹、斜线纹、放射线、半调网点、棋盘格、圆角形、箭头 |
| 文字 | 歌词、重复铺开的空心大字、跑马字带、环形小字、英文装饰词、编号、标签、刻度、时间码 |
| 色彩 | 整屏色块、渐变、色幕、彩虹色带、光斑 |
| 装饰 | 星芒、五角星贴纸、胶带、小圆点、条码、彩色纸屑、名牌 |
| 画框与容器 | 卡片、圆框、胶片条、唱片、单曲封套、拍立得、播放器界面、磨砂面板、竖缝 |
| 界面语言 | 胶囊形标签、箭头、播放键、进度条、波形、勾选框、页码 |
| 人物 | 五张立绘：加框、描白边做成贴纸、剪影、单色、重复、局部裁切 |
| 意象 | 3D 半透明伞和伞上的雨滴、短划线的雨、同心圆、晴空和阳光 |

每种元素都有设计空间：
- 大小，以及大小之间的对比；
- 实心或空心；
- 放在前景还是背景；
- 横向或竖向；
- 疏或密；
- 单个或重复。

一个版面里通常同时有背景纹样、主体、前景装饰和文字几层。

### 4.3 版式

- **网格**：全片用同一套网格和页边。常驻版面层沿页边排，主体元素对齐网格；斜构图和出框是有意打破网格，要和对齐的部分形成对比。
- **版式原型**：
  - 原型有八种：满版、上下或左右分割、三栏、居中留白、卡片阵列、画中画、对称、斜构图。
  - 相邻两个版面换用不同的原型；同一种原型隔一段时间再出现时，换一种配色或画框。
- **字号阶梯**：
  - 分巨字、大字、正文、小字、注脚几档，相邻两档之间的差距要大。
  - 一个版面里通常只用其中两三档，主次一眼分清。

### 4.4 人物

- 立绘和其他元素一样，是提供视觉效果的图像，不和场景里的现实物件发生关系。
- 用法：加框、描白边做成贴纸、做成剪影或单色、重复排列、局部裁切（手、乐器、半身），以及放进卡片和圆框。
- 不做脸部特写。

### 4.5 文字

- **字体**：
  - 主唱的歌词用明朝体，是全片的主要字体；
  - 少数需要分量的词用粗黑体；
  - 和声用窄而宽字距的无衬线小字，配和声成员的代表色。它和主唱在字体、字号、位置、颜色、容器里至少差出三项；
  - 装饰小字用拉开字距的英文无衬线；
  - 歌词用日文原文，在 1920×1080 下清晰可读。
- **设计手段**：每一句歌词都是一次版面设计。相邻的两句换用不同的组合。

| 手段 | 做法 |
|---|---|
| 大小 | 巨字、大字、正文、小字、极小的注脚，一个版面里拉开对比 |
| 实心和空心 | 空心描边的字轻而透，实心的字重而定；可以先空心，唱到时填实 |
| 横排和竖排 | 竖排安静，横排利落，两种可以在一个版面里交错 |
| 前景和背景 | 字压在人物和图形前面；或者铺在后面，成为底纹、巨字墙、重复的字 |
| 字距、行距、对齐 | 拉开或收紧；居中、靠边或错落 |
| 拆字、叠字、重复 | 把一句拆成几块分开放，或者同一个词叠几层 |
| 和其他元素组合 | 字沿着线、弧、圆环走；字放进画框；字和图形互相遮挡 |

- **跟唱**：一句开唱前，整句先以空心描边占好位置；唱到哪个字，哪个字填实；唱完停留到能读清，再随版面退场。任何时刻，画面上只有正在唱的那个词是热点。

### 4.6 动效

动效是视觉设计里的动效，目的是把动感和节奏表现出来，不为讲含义：
- **缓动**：入场快、收得慢，到位时可以稍微冲过再回弹；出场加速，在最快的那一帧切走。
- **预备和跟随**：大动作前先有一个小的反向预备，动完后跟着有一点余波。
- **错落**：一组元素依次入场，前后错开一点，不一起到。
- **层次**：
  - 大动作，比如换版面、镜头冲击、整屏色块翻转，落在小节第 1 拍和段落交界；
  - 中等动作，比如卡片换位、字滑入，落在拍上；
  - 小动作，比如星芒闪烁、节拍器、短划线，落在八分音符上；
  - 背景里一直有缓慢的循环运动：跑马字、旋转的圆环、平移的条纹，和快动作形成对比。
- **遮罩和揭开**：条纹扫过、圆形打开、竖缝拉开、色幕盖过，都可以用来换画面或揭开元素。
- **配合**：每个动作都和画面里的其他元素配合，同方向、同节拍，或者一前一后错开。
- **闪白**：先压暗，亮度越来越快地升高，全白只停一帧，再迅速退去；退去时新画面已经在光里。

### 4.7 配色与质感

- **配色**：每一段一套配色，段与段之间拉开明暗对比，副歌的亮靠预副歌的暗衬出来。

| 段落 | 配色 |
|---|---|
| 开场 | 纸白、天蓝、墨蓝，克制 |
| 前奏 | 每人一套：白配鲜绿、满屏珊瑚粉、白配橙黄、深靛紫、极简白 |
| 主歌 | 浅天蓝、白、半透明，五种代表色都降了饱和度 |
| 预副歌 | 深墨蓝作底，白色的图形，代表色在深底上一种一种亮起来 |
| 副歌 | 饱和的晴空蓝、阳光黄、白，五种代表色全亮 |

- 五人的代表色用在属于这个人的卡片、色块、伞面和边缘光上。
- 每个版面里，大面积的颜色只有一两种，代表色只做点缀；只有前奏五人各自的版面和副歌，代表色才铺成大色块。
- **质感**：
  - 全片以平涂为主，压一层极细的颗粒；
  - 半调网点、细线纹这类印刷感的纹理可以按段落使用；
  - 不做写实的材质。

### 4.8 转场

| 转场 | 用在 |
|---|---|
| 收成一个点，再从点长出下一场 | 镜头 05、11、16、27 |
| 前奏的签名色幕，一拍走完，五次相同 | 前奏 |
| 收成一条缝，再从缝里展开 | 镜头 19→20、30→31 |
| 从平面拉开，原来是三维空间里的一块板 | 镜头 23 |
| 像素块成倍增加直到盖满 | 镜头 26 |
| 闪白 | 镜头 28→29 |
| 旋涡 | 镜头 32→33 |
| 正拍前一帧先闪下一个版面的主色 | 副歌各版面之间 |

### 4.9 节奏

- 动作稍早于拍起步，在拍上到位、定住。
- 对拍分三层：
  - 版面跟乐句和小节换，大版面一小节或两拍一换；
  - 歌词跟唱的音节出字；
  - 小元素跟拍或八分音符。
- 镜头的缓慢漂移不跟拍。
- 每次推高之前，画面先把动作收住，下一拍再一次放满。分镜里的收住点：镜头 05、11 的第 4 拍、17 的第 1–2 拍、19、22、27、28。

## 6. 播放页

- 打开作品即进入播放页，PV 占满画面主体，画面比例 16:9，播放流畅。
- 首次播放需要一次点击，这是浏览器对自动播放声音的要求。
- 底部有播放控制条：播放、暂停、拖动进度、显示当前镜头号。控制条不遮挡画面主体，鼠标移开后可以隐藏。
- 播放时音轨和画面同步。拖动到任意时刻，画面和音轨立即是那一刻的样子；同一时刻的画面总是相同。

## 7. 视频导出

作品提供以下固定接口：

```js
window.videoExport.runs                        // ['pv']
await window.videoExport.begin('pv', { fps })  // 回到开头，返回 { frames }，总帧数
await window.videoExport.frame(i)              // i 从 0 起依次调用；完成时第 i 帧已完整显示在页面上
window.videoExport.end()                       // 回到正常的播放页
```

- `pv` 是整支 PV，从 0 秒到音轨结束，画面里不出现播放控制条。
- `begin` 负责回到开头并准备好显示，按调用方传入的 `fps` 返回 `frames`，即音轨时长乘以 `fps` 向上取整。支持预览的 3 帧/秒和正式导出的 60 帧/秒，片子的时长与速度不随帧率变化。
- 进入导出模式后：
  - 片中时间只由 `frame(i)` 推进，不播放声音，正常播放也不再推进画面；
  - 第 `i` 帧对应音轨的 `i / fps` 秒，不依赖真实时间，机器快慢不影响结果；
  - `frame(i)` 返回前画面已更新到这一时刻，调用完成后由调用方截图。
- 音轨由调用方按第 0 帧对齐合成，作品不用提供声音。
- 分辨率由调用方设置的窗口大小决定，作品要能适应，最高可能到 3840×2160。
- 这个接口不需要导出按钮，也不用交付视频文件。在 Chrome 中以本地文件方式打开作品时，接口也要可用。

## 8. 交付与运行环境

1. 交付一个网页项目，入口文件是根目录下的 `index.html`。在 Chrome 中直接双击打开（以本地文件方式，不经过网页服务器）就能完整运行。以本地文件方式打开时，Chrome 有下面这些限制，作品要在这些限制下正常工作：
   - 以文件引入的模块脚本、用 fetch 或 XHR 读取本地文件、从文件创建的 Worker，都会被拦截；普通 `<script src>` 和内联脚本不受影响。
   - 本地图片可以显示，也可以画进 2D 画布，但画过之后读不了画布的像素，也不能作为 WebGL 纹理上传。
   - `<audio>` 可以直接播放本地的音频文件。
2. 本机装有多种中文、日文、英文字体，可以自行挑选合适的使用。
3. 本题只做 PC 端，不考虑手机和平板。
4. 环境接入了浏览器 MCP，用的是无窗口的本机 Google Chrome 和显卡，可以随时用它打开、操作作品并截图检查。
5. 开发期间如果需要启动本地网页服务器，使用开场消息给出的端口。

## 9. 规定
