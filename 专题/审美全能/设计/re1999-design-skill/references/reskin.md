# 子主题换皮

一句话：**不是用自己的画风去画这个题材，而是借这个题材所在年代的印刷物和媒介，来包装自己的内容。** 骨架锁死，只换皮。

母版（不变的东西）和皮（变的东西）的清单见 `logic-and-taste.md` 第 2、3 节。这份文件讲怎么一步步换。

---

## 1. 换皮的三档强度

| 档 | 对象 | 换什么 |
|---|---|---|
| 全换 | 主内容（一个版本、一道题、一个章节） | 标题字、主色相、明暗基调、主材质、画法、母题、代表意象、开场媒介、转场物件、故事内命名 |
| 只换色 | 常驻栏目（每一段都会出现的固定入口、横条） | 只换底色，字和图形不动 |
| 不换 | 系统部件（按钮、网格、价签、进度、字幕） | 什么都不换；最多把主按钮和小图标染成这一段的强调色 |

**最小的换皮样本**是一根信息条：宽高比、分隔线位置、圆角全部锁死，换的只有三处——底色、边（直边、撕边、金边、描边）、两端的角落母题。母题只在条的两端，不进入文字区。

---

## 2. 方法：十一步

0. **先冻结母版和系列常量。** 字标、异象、母版底景、强调色、颗粒规矩、组件几何、命名规则——全部写死（第 7 节），后面每一步都不碰。
1. **定题材三元组：一个地方 + 一个年代 + 一种艺术流派或媒介。** 再挂一个文学、音乐、电影或历史的典故做副标题。例如“港口 + 1950 年代 + 工业纪录片”“温室 + 19 世纪末 + 植物学图鉴”。三元组越具体，皮越像“从那个年代穿越来的一件真东西”。
2. **定片种。** 这一段是一部什么片：悬疑、纪录、歌剧、公路、实验短片、街机、动画片、肖像展。片种决定海报的格式和开场的节奏。
3. **定原生媒介。** 这个年代的观众是通过什么东西看到这个题材的：一块表盘、一张地图、一台显像管电视、一扇旧电脑窗口、一张蓝图、一盘铅字、一张赛璐珞片。开场就从这个媒介进入，镜头推进媒介里的世界；静止的介绍页上，媒介留下一点痕迹（底纹里的方格纸、画面边上的屏幕圆角、远景里的地图等高线）。
4. **定故事内词表。** 进入按钮是哪个动作；看点列表是哪份文件；资料区是哪个地点；一到三行题记，用故事里一份文件或一条广播的口吻。
5. **定色板（3 + 1）和明暗基调。** 从这个年代、这个地方的真实材料里取一个地色、两个邻近的中性色，再加一个强调色；材料决定这一段用暗底、亮底还是中等明度的底。步骤见 `color.md` 第 6 节。
6. **定标题字。** 查下面第 4 节的年代表选字体类型，按“主词 1.0 / 次级 0.35 / 微型 0.1 + 一个徽记 + 一种字面材质 + 一团暗底”组装；中文片名用宋体，字号为英文主词的 0.35–0.5。中国题材则中文书法升为主角。
7. **定画法、母题和材质。** 画法一种（`imagery.md` 第 3 节）；母题 1–3 个，从这个题材的文物里取，只放在标题徽记、组件两端、卡片四角、分隔条、按钮装饰；主材质一种，贯穿这一段。
8. **做代表意象。** 一件物件，带第二眼（共生图形、尺度错位、功能错位，三选一）。再把系列的异象放进这个世界的环境里一次。
9. **套进骨架，回染组件。** 内容放进锁死的槽位；固定组件只染强调色（图标、标签条、按钮装饰），不换形。
10. **统一调色。** 这一段里引用的装饰性画面，往主色相上调（渐变映射或同色柔光 15–30%）。展示的作品本身不调。

## 3. 换皮参数卡

每个子主题填一张，填完就是这一段的设计说明。

| 字段 | 填法 |
|---|---|
| 三元组 | 地方 + 年代 + 流派或媒介 |
| 典故或副标题 | 一个文学、音乐、电影、历史典故 |
| 片种 | — |
| 原生媒介 | 开场：一种年代媒介，以及镜头怎么进去；静帧：它留下的痕迹 |
| 明暗基调 | 暗底 / 亮底 / 中等明度 |
| 地 / 中性 / 主色相 / 强调 | 四个色值，写明强调色给谁用 |
| 画法 | 平面水粉 / 剪纸层叠 / 版画线刻 / 剪影加一种红 / 拼贴 / 三维小景 |
| 主材质 | 一种 |
| 母题 | 1–3 个，写明放在哪里 |
| 标题字类型 | 年代表里的一类 + 本机能用的字体 |
| 故事内命名 | 进入动作 / 看点文件 / 资料地点 |
| 题记 | 1–3 句（字放不下时可以不放） |
| 代表意象 | 第一眼是什么（2–3 个识别特征）；第二眼是什么；用哪种第二眼 |
| 精确的错误 | 放在标题上的哪一处 |
| 异象在这里的形态 | 放在环境里的哪一处 |
| 转场物件 | 一到两种 |

**“数字时代以前的对应物”。** 题材本身是数字的东西（像素、体素、网页、3D 模型）时，往前找它在纸和物件上的祖先，再从那里取皮：体素 ← 马赛克、十字绣、积木、等距方格纸；像素字 ← 点阵打印、霓虹灯管；网页 ← 报纸版面、目录卡片；3D 模型 ← 石膏模型、建筑沙盘、蓝图；字体 ← 铅字、木活字、手写招牌。

## 5. 推导示例

下面四个示例演示方法怎么走。它们是推导的示范，不是定稿：真正做的时候，从第 1 步自己重新走一遍。

### 5.1 玻璃温室里的石膏白模

| 字段 | 推导 |
|---|---|
| 三元组 | 铁艺玻璃温室 + 19 世纪末 + 植物学图鉴与石膏写生 |
| 典故 | 一本植物图鉴的扉页，或一间画室的静物课 |
| 片种 | 静物纪录片 |
| 原生媒介 | 一页铜版画植物图鉴：镜头从图鉴的线描推进去，线描一根根变成玻璃的铁框，纸色变成天光；静帧里留下几根很淡的结构线 |
| 明暗基调 | 亮底（材料本身就是白的） |
| 色板 | 纸 `#E6E2D9`｜中性 `#B9B6AE`、`#6E6A62`｜主色相：玻璃里透出的灰绿 `#A9B3A2`｜强调：陶土 `#A65A3A`，只给一只花盆和一枚印章｜墨 `#2B2723` |
| 画法 | 三维聚光静物（石膏的明暗本身就是看点） |
| 主材质 | 石膏的哑光 + 图鉴纸 |
| 母题 | 测光圆（灰度渐变圆）、明暗交界线、铁艺拱 |
| 标题字 | 高反差 Didone 大写 + 植物拉丁学名式的斜体（Playfair Display + Italic）；中文宋体 |
| 故事内命名 | 进入：“开灯”；看点：“布光记录”；资料区：“标本柜” |
| 题记 | “光从北窗进来，正好落在第三个石膏球上。” |
| 代表意象 | 一只玻璃罩扣着一个石膏球；第二眼（功能错位）：罩子的轮廓是一只灯泡，石膏球就是灯丝 |
| 转场物件 | 一张描图纸从上面盖下来；一道光从左向右扫过 |

### 5.2 雨夜港口的巨型机械

| 字段 | 推导 |
|---|---|
| 三元组 | 港口 + 1950 年代 + 工业纪录片与工程蓝图 |

| 画法 | 版画线刻（雨和钢板都用线排出来） |
| 主材质 | 蓝图格（只在开场）+ 湿钢板 |
| 母题 | 尺寸标注线、铆钉、45° 警示斜纹 |

| 题记 | “凌晨两点，吊臂还亮着。” |
| 代表意象 | 一枚巨大的螺栓立在码头上；第二眼（尺度错位）：它的影子是一座灯塔 |
| 转场物件 | 蓝图卷起；探照灯的光束扫过画面 |

### 5.4 字体与标志

| 字段 | 推导 |
|---|---|
| 三元组 | 印刷车间 + 19 世纪末 + 木活字与校样 |
| 典故 | 一张付印前的校样 |
| 片种 | 车间纪录片 |
| 原生媒介 | 排字盘：镜头俯拍一盘倒着的铅字，一只手拣字、压印、揭纸，纸上出现正着的字 |

| 母题 | 铅字块、校对符号、十字对位线 |
| 标题字 | 木活字粗衬线（Abril Fatface / DM Serif Display）+ 校对红笔批注（Caveat）；中文用寒蝉活宋体 |
| 故事内命名 | 进入：“付印”；看点：“校样”；资料区：“排字房” |
| 题记 | “字要先反着排，印出来才是正的。” |
| 代表意象 | 一个巨大的铅字块；第二眼（功能错位）：它反着的字面在灯下投出一个正着的影子——“逆”在这里是题材本身 |
| 转场物件 | 压印机落下；一张纸被揭起 |

## 6. 换皮时最容易丢掉主风格的地方

- **把中文也换成题材字体。** 英文可以穿任何年代的戏服，中文要稳住：除了中国题材的书法，中文一律宋体。两种语言都换了，系列感就没了。
- **换皮时顺手改了槽位。** 新题材想要一个特别的版式，于是把进入按钮挪到左边、把看点挪到下面。观众每一段都要重新找东西，系列感也没了。版式的变化只允许发生在标题簇的位置上。
- **一段里换了两种材质或两种画法。** 这一张金箔、那一张霜；这一张剪纸、那一张三维。主材质和画法一段一种。
- **母题进了正文区。** 齿轮、云纹、蝙蝠只在边上、角上、两端；一旦爬进列表和正文，就成了壁纸。
- **强调色多了一个。** 新题材的颜色很好看，于是锈橙和它并排出现。题材色只能接替锈橙，不能和它同框。
- **代表意象画成了插图。** 把题材里的设施、人物、道具全画上去，就成了一张说明图。意象只要一件东西加一个第二眼：照实画是“展示”，第二眼才是“表达”。
- **意象画成了图标。** 平滑渐变、等粗的线、刀切的边、没有影子——它会像一个应用图标。按 `imagery.md` 第 4 节让它“做出来”。
- **皮太重压住了内容。** 换皮是包装：子主题越花，内容越要干净。真正要读的那几行字永远是母版的宋体，不加材质。

## 7. 系列常量：开工前先定的五样

一个系列（一部片、一个站）开工前，先把下面五样定下来，写进母版。之后每一段换皮都不碰它们。

| 常量 | 怎么定 | 分寸 |
|---|---|---|
| 字标 | 一个高反差的中文名 + 一根短发丝线 + 一行字距极开的英文；只给它一处“被截断”的签名笔画（一笔换成双斜线、一个字母镜像） | 视频里宽约画宽 8–13%（海报上 15–22%），放左上（离边 44px）；颜色可以随段变，形状不变 |
| 异象 | 系列主题物 + 一条被反过来的规律或一个放错的位置（`imagery.md` 第 7 节） | 小、安静、每个世界一次，放在环境里 |
| 母版底景 | 一个中性的“零点”画面：暗室里一束顶光，或一张星图底，或一个空舞台。每段之间回到它 1–2 秒 | 它是全片唯一不换皮的画面 |
| 强调色 | 锈橙族，或系列自己的一种暖色（同样压到 C\* 40–60） | 全片只有这一个；题材色只能接替它 |
| 口吻 | 系列把自己当成什么：一场电影节、一本图册、一个天文台的观测日志 | 决定所有按钮、标题、看点的说法 |
