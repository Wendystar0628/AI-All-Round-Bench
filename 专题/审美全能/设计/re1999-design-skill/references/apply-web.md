# 应用到网页

这份文件把这套语言落到一个展示类网站上：首页、按条目的详情页、按作者或类别的索引页，以及下载、筛选、图片浏览这些常见功能。桌面优先，宽 1280–1920。

一个展示站在这套语言里是一本**电影节的节目册**或一本**展览图录**：首页是海报，详情页是展签和图版，索引页是卡片盒，下载是一张取件票。

---

## 1. 页面底与字体

- **底：** 母版底用炭灰 `#242423`，在页首或某一屏的一角放一团暖棕光晕（`texture-kit.css` 的 `.re-glow`）；长文阅读区可以换成纸 `#EAE8E1`。首屏和每个条目的页首是一张满版的画（静态图），暗处有场景，不用线条填（`imagery.md` 第 1 节）。全站一层颗粒（`.re-grain`，平整处起伏 2–4 级），固定在视口上、不随滚动重绘。
- **不用纯黑纯白：** 最深 `#0C0D0C`，最亮的字 `#E6E2DD`，纸 `#E8E2D8`。
- **字体只用开源授权的：** 站酷小薇（大标题，加竖笔）、思源宋体（或 Noto Serif SC）、Playfair Display、Cormorant Garamond、Source Serif 4、Great Vibes、Oswald、Courier Prime（见 `typography.md`）。
- **字体自托管并子集化：** 中文字体按站内实际用到的字做子集（WOFF2）：站酷小薇只包含标题里出现的字；正文字重按常用字表加站内用字。`font-display: swap`，回退栈写到 `"Noto Serif SC", "Songti SC", serif`。不要把整套思源宋体原文件放上去。
- **大标题的竖笔加粗**在网页上同样用 SVG 滤镜（`typography.md` 第 2 节）；标题字号随视口变时，按字号的 0.018 倍取一个最接近的滤镜（准备 1.5px、2px、2.5px、3px 四个就够）。
- **斜体只用 Playfair Display Italic。** 其余衬线体没有真斜体，写 `italic` 会得到假斜体。

```css
@font-face{font-family:"Source Han Serif CN";src:url(fonts/shs-cn-900-subset.woff2) format("woff2");
  font-weight:900;font-display:swap;}
body{background:var(--re-char);color:var(--re-text);font:400 17px/1.85 var(--re-font-song);
  -webkit-font-smoothing:antialiased;}
```

## 2. 版式

- **栅格：** 12 栏，栏距 24px，左右页边 `max(32px, 3.9vw)`，内容最宽 1680px。标题簇和图像故意跨栏错位：标题占 1–5 栏、图像占 4–12 栏，两者重叠一栏，让图压住字的一角，或者字压住图的一角。
- **两极字号：** 正文 17px（中文 16–18px）；展示字 `clamp(64px, 7vw, 132px)`；中间只有名字 24px 和标题 `clamp(36px, 3.2vw, 56px)` 两档。一屏不超过四档。
- **留白：** 区块之间 120–200px；区块内部行距宽。一屏只有一处密的地方（约五分之一面积），其余是大块的暗或纸。
- **中英：** 导航中文 18px 配英文 12px（3:2），英文字重更细（Oswald 300 或 Cormorant 500），颜色更暗（`#BBA893`）。

## 3. 页面类型

### 3.1 首页：一张海报

- 首屏是一张海报：满版的主视觉（静态图），标题簇住进画面的暗处，宽 ≤35%；片名是拉开字距的大写或中文主角排法（`typography.md` 第 9 节）；一列演职员表式的小字写真实的信息（条目数、作者数、日期）；底部一行极小的拉开字距的字。
- 首屏只有一颗主按钮（锈橙实心，或一张票根）。
- 往下：一面海报墙或书封墙展示所有条目（每张卡一个编号、一个名字、一行小字），然后是按作者或类别的入口，最后是一段关于这个展的短文。
- 页首导航不是一条横栏：字标在左上，几个入口贴右上，每个入口中文加下挂英文；当前项是外框菱形套实心橙菱形。

### 3.2 条目详情页：一张展签加一组图版

- 页首是这个条目的“介绍页”：槽位和入场顺序照 `apply-video.md` 第 4 节，换成网页的尺寸。条目自己的皮（标题字、主色相、母题）只用在页首和分隔条上，正文区回到母版。
- 正文：主要内容一段（宋体 17px，行距 1.85，栏宽约 38 个汉字），看点列表 `✦ … ≫`。
- 作品图版：每张图一个画框（单圆角框 + 偏移的细线框，或蛋形裁切 + 轨道线 + 网点），图下一条展签（编号、名称、作者、媒介）。图片不加滤镜、不加颗粒、不调色。
- 侧边或页底一张“取件票”：下载入口（见第 5 节）。

### 3.3 索引页（按作者、按类别）：一个卡片盒

- 一排竖卡（约 3:7，圆角 6–8px），左上一面分类色的燕尾小旗，右上一枚回形针线描，底部 1/4 一层从透明到 `#A66533` 的渐变，最底下名字（宋体）和下挂英文。
- 卡片网格可以规整；网格之外的标题、筛选、说明按偏置构图摆。
- 背景一行字距极大的英文水印（`INDEX`、`ARCHIVE`），4–8% 不透明度，被网格压住。

## 4. 组件到网页的写法

| 部件 | 网页写法 |
|---|---|
| 主按钮 | `#AE5228` 实心直角（圆角 2px），白色宋体 16px 600，字下英文 10px、字距 .3em、60% 不透明；右上角两个 6px 细线倒三角；高 40–44px。悬停 0.3s 亮一档并右移 4px，不放大 |
| 次按钮 | `#FBF8F2` 实心直角，`#2B2723` 字 |
| 文字链 | `#DE6B34` + ` »`；悬停时下面画出一条 1px 线（0.3s，从左到右） |
| 导航当前项 | 外框菱形套实心橙菱形 + 橙字；或橙字 + 2px 亮橙下划线 + 字后一小块网点 |
| 筛选 | 档案柜索引签：一排小纸签（`#E8E2D8`，转 0–2°），选中的签是锈橙底；或者 ◇ ◎ △ 这类几何前缀的文字页签 |
| 分页 | `6 / 290` 式的衬线数字，左右两个细线 `‹ ›` |
| 标签 | 描边椭圆里一个斜体词；新 = 红方块；限时 = 绿描边椭圆 |
| 列表 | 无底色，细横线分行，左名右值，衬线数字 |
| 提示 | 纸条吐司，右上角，200ms 进、2–3s 停、100ms 出 |
| 确认 | 横贯视口的一条纸带（`#F2E9E4`，高约 13vh），背景模糊 8px、压暗到 40%；230ms 展开，70ms 收起 |
| 图片放大 | 背景压暗到 10% 并模糊；图在中央按原比例显示，下方一条展签；左右 `‹ ›` 细线箭头；关闭是细线 `×`。打开 220ms（从 96% 放大到 100% + 淡入），关闭 80ms 淡出 |
| 页脚 | 一行拉开字距的小字 + 一枚小字标 + 版权行；像一张海报最底下的那一行 |

## 5. 下载：一张取件票

下载入口做成一张票根（`assets/svg/ticket.svg` 的结构）：

- 票面：左缘一条该条目主色的色条；斜体大编号 `No. 07`；条目名（宋体）；一行微字写文件格式和大小（`HTML · 2.4 MB`、`ZIP · 18 MB`）。
- 票根（打孔线右侧）：动作“取件 / DOWNLOAD”，锈橙。
- 悬停：整张票转正（从 −1° 到 0°）并向上 2px，0.3s；票根一侧亮一档。
- 点击：票根沿打孔线轻轻错开 2–3px（像被撕下一点），0.2s，然后开始下载。
- 不可下载的条目：票面压暗、铺一层 45° 细斜线，票根写“仅展映 / SCREENING ONLY”。

文案上：主标签必须一看就懂（“下载”），故事式的说法（“取件”）只放在下挂的小字或票根上。

## 6. 动效

| 场合 | 值 |
|---|---|
| 滚动入场 | 透明度 0→1 + 位移 40px，0.6s，`ease`；同一组元素间隔 0.08s；只在第一次进入视口时播放 |
| 页首入场 | 主视觉 0.8s 从 104% 缩到 100% 并淡入；标题晚 0.3s 从虚到实（模糊 8px→0）；其余 0.4s 淡入 |
| 悬停 | 0.3s；放大不超过 1.05，或右移 4–10px |
| 循环 | 呼吸周期 ≥1.5s（亮度 100%→60%→100%）；慢转的物件 60s / 圈 |
| 光标 | 可选：一个直径 20–50px 的细线圆环跟随，悬停可点的东西时收小，透明度 0.5→0 渐隐 |
| 页面切换 | 当前页 0.15s 淡暗，新页 0.3s 淡入，不做整页滑动 |
| 减少动态效果 | 系统打开时，全部入场和循环关掉，只保留 0.15s 的透明度变化 |

不用视差滚动的多层大图、不用滚动劫持、不用整页翻转。网页上的“电影感”来自静止的构图和停住，不来自动个不停。

## 7. 纹理与性能

- 颗粒：`.re-grain`（内联在 CSS 里的 256px 高反差噪声瓦片），`position: fixed` 的一层，`mix-blend-mode: soft-light`，不透明度约 16%（暗底）；纸面区用 `.re-grain--paper`。不要用全屏 canvas 每帧重绘。
- 网点、断线、点线、暗角、光晕：全部用 CSS 渐变（`texture-kit.css`）。
- 纸：CSS `.re-paper`，或用 `ReTexture.paper()` 生成一张 1024px 的贴图存成图片。
- SVG 装饰内联，需要换色时设置 `--re-orn-*` 变量。
- 本地 `file://` 打开时，CSS 遮罩引用外部 SVG 会被浏览器拦下：遮罩一律写成内联 data URI（`.re-torn-bottom` 就是这样写的）。

---

## 8. 可读性

- 正文：`#E6E2DD` 压 `#242423`（12:1）；纸上 `#2B2723` 压 `#E8E2D8`（11.5:1）。
- 次文字：`#BDB3AA`（7.5:1）；说明 `#8F8A85`（4.5:1）只给 14px 以上、非必读的字。
- 英文注脚即使只是“纹理”，也要 ≥11px、对比 ≥4.5:1；拿不准时用 `#BBA893`。
- 暗底上不写小号红字；提醒用红方块配暖白字。
- 焦点框看得见：2px 锈橙描边、2px 偏移。
- 可点区域至少 32px 高；当前项除了颜色，还靠菱形、下划线和 `aria-current` 区分。

## 9. 网页上容易走样的地方

- **把画册做成后台：** 一格一格的深色卡片、圆角加投影、八级字号——每一样都是网页框架的默认值，加在一起就不再是“一本图录”。
- **每个区块都加框：** 区块之间用留白和一条断线隔开，不用框。
- **首屏塞满按钮：** 首屏只有一颗主按钮，其余入口贴边。
- **给展示的图加滤镜：** 统一感用框、底、展签来做，不改作品。
- **把故事式文案当主标签：** 观众要一眼看懂按钮做什么；故事的口吻放在下挂的小字里。
