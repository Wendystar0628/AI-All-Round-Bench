# 动效与视频语言

一句话：**先空一下，再一下子出来，然后久久不动。** 入场快、停留长、退场短；没有回弹，没有弹性过冲；最大的冲击来自“静 → 响”。

缓动与时长也写在 `assets/tokens.css`（`--re-ease-*`、`--re-t-*`）。

---

## 1. 原则

1. **先给一个空的形状，再填内容。** 弹窗先出现一张空白的纸，再显字；提示先出现一条细线，再展开成纸带；胜利先画出一个细线三角，再亮起来、再出字；揭晓先给三角、星、徽章这些抽象符号，人最后才出来。
2. **快入，长停，短出。** 入场用指数减速落定；停留是动效的主体，常常是入场的 3–6 倍；退场 70–150ms 淡掉，或者干脆硬切。
3. **不回弹。** 任何缓动都不越过终点再弹回来。弹簧、果冻、橡皮筋都不属于这套语言。
4. **“在动”比“动得多”重要。** 幅度小、速度慢：页面淡入只位移 32–48px；呼吸周期 1.5 秒以上；旋转的东西几十秒一圈。
5. **字不跟着画面推。** 画面在慢慢推近时，字卡锁死不动，或者反向极慢地拉远。
6. **闪光、粒子、色散只给仪式时刻。** 揭晓、登场、胜利这种“这一刻和别的时刻不一样”的瞬间才用。日常切换只用淡入和短位移。
7. **转场用题材里的一件物件，技术转场只放在节点上。** 层级越高的转场越“空”：段落之间是黑场和静音，条目之间才是物件擦屏。
8. **最大的冲击来自先清空。** 每一次揭晓之前，画面和声音一起先空 0.3–2 秒。

## 2. 缓动

| 名字 | 曲线 | 用在 |
|---|---|---|
| land（落定） | `cubic-bezier(0.16, 1, 0.3, 1)` | 一切“进来然后停住”：大字从 4 倍缩回、插画推入停稳、卡片飞入减速、布景就位 |
| sway（两段式） | `cubic-bezier(0.65, 0, 0.35, 1)` | 先慢、中间快、最后慢：字块缩小下移让出画面、镜头运动的起止 |
| exit（退场） | `cubic-bezier(0.4, 0, 1, 1)` 或线性 | 70–150ms 的淡出和撤走 |
| web | CSS 默认 `ease` | 网页滚动入场、悬停 |
| drift（漂移） | `linear` | 镜头慢推、轨道上的小行星、印章旋转、纸飞机和鸟群漂移 |

**大字缩回的精确形状**是纯指数衰减：超出 1 倍的部分每 0.1 秒剩下约 63%，时间常数约 0.22 秒，约 1.1–1.25 秒落定到 1% 以内。逐帧渲染时直接用公式：

```js
// t 为入场后的秒数；from 为起始倍数（章节卡用 4）
const scale = 1 + (from - 1) * Math.exp(-t / 0.22);
const blur  = 14 * Math.exp(-t / 0.12);   // 虚焦比缩放先收干净
```

## 3. 时长表

| 动效 | 时长 | 做法 |
|---|---|---|
| 片头标题卡 | 约 7s | 黑场 1.0s → 字组线性淡入 2.4s（不缩放、不位移）→ 停 3.6s；全片最慢的一次出现 |
| 纸面弹窗打开 | 200–230ms | 空白纸（一角卷起）约 100ms 压平并伸展到最终宽度 → 内容约 80ms 淡入 |
| 通栏提示展开 | 约 230ms | 中线处一条约终高 1/3 的半透明纸带 → 100ms 上下展开到全高 → 标题从小到大淡入 → 问句与按钮依次显出 |
| 弹窗、提示关闭 | 70–100ms | 整体淡出，背景同步恢复；不卷角、不收回 |
| 页面切换（界面内） | 250–500ms | 暗下约 150–250ms → 新内容从约 30% 不透明度淡入并带一点横向位移 |
| 主界面进场 | 约 200ms 一串 | 先切到没有界面的场景，再在约 6 帧内依次出现：右栏 → 左栏与顶栏 |
| 插画推入 | 约 0.5s | 带一点运动模糊推进来，停稳；标题晚约 0.3s 出现；其余槽位再 0.3–0.5s 淡入 |
| 网页入场 | 0.5–0.8s | 透明度 0→1，同时位移 32–48px，`ease`；左右切换 0.8s；悬停 0.3s |
| 悬停 | 0.3s | 放大到 1.05–1.1 倍，或右移 5–10px；翻页箭头悬停左右各挪 5px |
| 吐司 | 进 200ms，停 2–3s，出 100ms | 右上角 |
| 星逐颗点亮 | 每颗间隔 0.15s | 从左到右；每颗先是一团暖光，0.1s 后收成星 |
| 逐字打出 | 中文约 0.1s / 字；英文约 0.25s / 词 | 每个字自带一点虚化，从虚到实 |
| 乱码解码 | 约 0.5s | 字符随机跳，最后定格（打字机或终端题材） |
| 线条画出 | 0.6–1.0s | 轨道、刻度、下划线、笔画；线性或 land |
| 呼吸循环 | ≥1.5s 一个周期 | 亮度 100%→50%→100% 或缩放 1→1.01→1 |
| 慢旋转 | 唱片约 60s / 圈，印章约 20s / 圈 | 匀速 |

## 4. 进场与退场的几种动作

| 动作 | 怎么做 | 适合 |
|---|---|---|
| 推入停稳 | 从 105–108% 的大小、带轻微运动模糊推到 100%，0.5s，land | 主视觉、插画、场景 |
| 淡入加短位移 | 透明度 0→1 + 位移 32–48px，0.5–0.8s | 网页、列表、看点 |
| 先空形再填 | 空纸 → 内容；细线 → 纸带；线框三角 → 光三角 → 字 | 弹窗、提示、徽记 |
| 从虚到实 | 模糊 8–14px → 0，同时透明度 0→1，0.3s | 名字、标题 |
| 大字缩回 | 从 4 倍、虚焦、出画的状态以指数衰减缩回原大小 | 章节卡（全片唯一的强入场） |
| 从左到右显现 | 用一条矩形遮罩从左向右扫开，0.4s | 日期、定档字、一行重要的字 |
| 笔画生长 | 先长出字标里最有辨识度的那一笔（例如几道斜线，0.6s），再长成整组字（1.0s） | 落版的字标 |
| 布景就位 | 画框、伸进来的手、前景植物从四周滑入，0.6–0.8s，land；和标题同时 | 章节卡 |
| 慢淡入 | 线性，2–2.5s，什么都不动 | 片头标题卡、片尾的字标——越重要的字出现得越慢 |
| 硬切进入 | 0 帧，直接出现 | 场景之间、黑场之后 |

**退场：** 70–150ms 的淡出，或者硬切。字卡退场 0.15s；布景 0.15s 撤走后硬切到下一个画面。不要让退场比入场还慢，也不要倒放入场动画当退场。

## 5. 揭晓的仪式

一次重要的揭晓（登场、获得、完成），拆成 3–5 个抽象步骤，每步不超过 1.3 秒，人或作品最后才出现。

1. **待机：** 一个实景空镜（雾、水面、一件有象征意义的旧物），给一个很轻的提示。
2. **物件发光：** 0.9s 亮度升到峰值。颜色预告结果；越特别的结果越**早**变色，而不是越亮。
3. **闪白：** 0.5s，暖白过曝，夹一点棱镜彩虹光、半调网点三角、几根细金线、几个外文字母，然后在约 2.5s 里慢慢冷却。
4. **印章字牌：** 圆环 + 转角方框 + 三行古典大写，淡入 0.3s、停 1.5s、转出 0.3s。
5. **硬切黑场：** 亮度一帧内掉到几乎为零。
6. **抽象序列：** 镜头穿过一个线框三角（0.7s）→ 星逐颗点燃（1.0s，间隔 0.15s）→ 一道横向光斑扫过（0.7s）→ 属性徽章从一角旋进中央再远去（1.3s）。
7. **黑 0.3s。**
8. **登场：** 主体在一团暖白辉光里出现，辉光 0.2s 冲到峰值、0.5s 退到身后的红日，然后停住——这一刻就是登场舞台（`layout.md` 3.4）。
9. **回到汇总：** 一道斜的光线划过（0.3–0.4s），结果卡片从画外飞进一个倾斜约 5° 的透视平面，0.5s；先是白票，0.3s 后露出色条，0.4s 后以颗粒噪点溶解成内容。

分寸：整段可以 4–10 秒，但每一步都短；分量在第 8 步的那一下“停住”。

## 6. 转场

### 6.1 按层级分

| 层级 | 做法 | 时长 |
|---|---|---|
| 段落（两大段之间） | 硬切到黑 + 声音同时降到几乎无声（−50dB 以下），下一段从一个强拍进 | 黑 1–2s |
| 章节（一组条目的开头） | 淡黑 0.5s → **一帧**纯色闪（约 33ms，常用暗红）→ 大字从 4 倍缩回 | 全卡约 3s |
| 条目（同一段里的一项到下一项） | 物件擦屏、闪白、撕纸、烟雾或墨团 | 0.2–0.6s |
| 镜头（同一条目里） | 硬切，或一道柔边光从左向右扫开 | 0–0.6s |

**层级越高，转场越“空”**：段落之间什么都不放，只有黑和静；条目之间才有物件。反过来做（段落之间用花哨的物件、镜头之间用黑场）层级就乱了。

### 6.2 物件转场目录

转场就是题材里的一件物件。按题材选，同一部片里相邻两次条目转场不用同一种物件。

| 物件或手法 | 做法 | 时长 |
|---|---|---|
| 信封、纸张横穿 | 一件物件从画外快速滑入（约 0.12s）盖住画面，然后慢慢漂走，露出下一场 | 0.3–0.5s |
| 水晶球、玻璃泡 | 下一场景装在球里横移进来，球放大到满屏 | 0.5s |
| 撕纸、锯齿裂口 | 白色锯齿边从一侧撕开，露出下一场 | 约 0.2s |
| 烟雾、墨团 | 粉色烟雾或一团墨涌满画面，停 0.3s 后切 | 0.3–0.6s |
| 红色竖条擦除 | 一条主题色竖条横扫过去 | 约 0.3s |
| 聚光圈 | 黑场里一个圆形聚光收拢或打开 | 0.4–0.6s |
| 年份滚动 | 黑 0.3s → 白底细网格淡起 0.2s → 一个年份数字随机滚动（约 12 个值 / 秒，0.7s）→ 落在目标年份停 0.15s → 虚化退场 → 白 0.25s → 新场景淡入 0.4s | 约 2.1s |
| 穿云推镜 | 加速推进 0.35s → 白云径向模糊 0.6s → 减速推出 0.9s；界面文字在白场里更新 | 约 2s |
| 雾气遮罩 | 进 1.4s（缓入）→ 全白雾停 0.7s → 散 0.9s（缓出） | 约 3s |
| 线条成网格 | 白细线随机交叉，然后理顺成横竖网格，中间一颗光球，最后放射状模糊揭开 | 1.3s + 0.2s + 0.5s |
| 连线成字 | 画面里的线段从乱到齐重新连接，拼成一个单词 | 每段约 0.17s，组字 3s，停 1.5s |
| 媒介穿越 | 镜头推进一块表盘、一个旧电脑窗口、一台显像管电视、一个取景器、一个放映框，画面填满时换成里面的世界 | 0.5–1.5s |
| 图形匹配 | 同一个形状接同一个形状：圆盘 → 月亮 → 表盘；三角光束 → 山 | 0 帧，或叠化 6–8 帧 |
| 地平线分屏擦 | 镜头上摇，画面里的水面或天际线变成黑白分界，锚点物件保持不动 | 约 0.4s |
| 前景擦过 | 前景的人或物从镜头前走过，变成全黑，再露出下一场 | 0.3–2s |
| 双重曝光 | 一个大的半透明剪影叠在下一场的场景上 | 约 2s |
| 黑场里的一句话 | 画面切到黑，只留一行字幕或一句台词，停一会儿再出下一场 | 0.5–5s |
| 片名拆成字卡 | 片名拆成两三张大字卡，和画面一张一张交替剪 | 每张 0.5–1s |
| 负片闪 | 整屏反相成白底黑剪影 | 1–2 帧，只给冲击 |

### 6.3 一镜到底

连续运镜的段落（片头、一串条目的串场）几乎不硬切：一部 3 分多钟的平面图形片可以只有十来个切点，镜头中位时长约 8 秒。做法：

- **一个锚点物件始终在画面里**（一艘潜艇、一只怀表、一颗星），镜头上摇、横移、推拉时它不动或只做小的位移。
- **画面里的分界线变成擦屏边**：地平线、光束的边、书页的边、一道撕口。镜头一动，这条线扫过画面，线的另一侧就是下一场。
- **形状变形接形状**：一个圆从表盘变成月亮再变成一枚硬币。
- 全片只用黑、白、灰加一种暗红时，这种连接最容易成立：没有颜色的跳变来提醒观众“换场了”。

### 6.4 什么时候不用转场

- 同一场景里的镜头之间：硬切。
- 揭晓之前：不要转场，要黑场。
- 字卡停住的时候：什么都不要动，连镜头也锁住。

## 7. 镜头运动

| 场合 | 推拉 | 横移 | 其他 |
|---|---|---|---|
| 叙事、欣赏画面 | 慢推 1.5–2.5% / 秒 | 约 1% 画宽 / 秒 | 起止各 0.5s 缓入缓出，中段匀速；每 2–4 秒换一次方向或景别 |
| 字卡停留 | 锁死，或拉远 0.2–1.7% / 秒 | 0–0.9% 画宽 / 秒 | 字不跟着画面推 |
| 名字卡停留 | 几乎锁死（−0.03% / 秒） | −0.2% 画宽 / 秒 | — |
| 定档卡、片尾 | 拉远约 1.5% / 秒，停 6 秒以上 | 约 0.9% 画宽 / 秒 | — |
| 活照片（循环背景） | 0 | 0 | 镜头完全不动，只有雨滴、闪电、呼吸、发丝在动 |

**纵深不靠真三维，靠三层：** 前景遮挡物（虚化、偏暗，从画面一角伸进来）、主体（清楚）、远景（虚化、偏亮、偏冷）。三层的视差速度约 1.6 : 1 : 0.4。

**镜头语言：** 极端特写和大远景直接交替（眼睛接城市俯瞰）；低角度仰拍高楼；斜构图（5–12° 的荷兰角）；从云层上方慢慢下降到城市；俯拍一件东西从手里落下。动作段落可以大幅运镜，但叙事和欣赏段落不手持、不甩镜、不做三维旋转的字。

## 8. 节奏与卡点

- **两种剪法：** 叙事段落跟着台词剪，不追鼓点（镜头 2–4 秒）；展示、音乐、角色段落卡点。
- **切点比强拍早约一拍。** 先切到新画面，让强拍落在新画面上（例如 140 BPM 的一小节是 1.71 秒，切点比每小节的第一拍早约 0.45 秒）。蒙太奇段落每小节切一刀。
- **欣赏向的展示段，** 镜头时长 4–8 秒，切点落在小节线上；连贯运镜的片头只在小节线上做“方向变化”，不做硬切。
- **揭晓压在静音后的第一个强音上。** 揭晓前留 0.3–1 秒的声音凹陷（音量先下沉一截再起），揭晓的闪白、字、星落在那个起音上。
- **快慢的完整形状：** 慢开场（长镜头 + 黑场留白）→ 中段 2–4 秒一个镜头 → 蒙太奇按小节剪 → 高潮 0.1–0.3 秒的闪切 → 静音黑场 1.5–2 秒 → 落版长停。
- **画风切换本身就是段落标记：** 从厚涂切到平涂网点、从暖褐写实切到青粉双色调，观众就知道进了另一段。

## 9. 字卡

### 9.0 片头标题卡（品牌出场）

- 黑场 1.0s，几乎无声 → 字组（片名、短线、一行拉开字距的英文）一起线性淡入 2.4s，不缩放、不位移、不模糊 → 停 3.6s；停的时候镜头以 −0.2%/s 极慢地拉远，或者完全不动。
- 如果有一行套着椭圆轨道的短句：轨道在字组淡入到一半时从左向右画出来（0.8s，线性），小圆点最后落定。
- 退场：淡出 0.4s 到黑，或者被下一段的第一个画面硬切掉。
- 版式见 `typography.md` 9.9。这一张卡不闪、不缩放、不用色闪——它的分量来自慢和空。

### 9.1 章节卡（全片唯一的强入场）

| 时刻 | 发生什么 |
|---|---|
| 0–0.5s | 上一个画面淡到黑 |
| 0.5s | **一帧**纯色闪（约 33ms），暗红约占画面 2/3 |
| 0.53s 起 | 标题以约 4 倍大小、虚焦、出画的状态出现，按指数衰减缩回原大小（τ≈0.22s，约 1.1s 落定）；同时布景从四周就位（画框、伸进来的手、前景植物），0.6–0.8s，land |
| 约 1.6–3.5s | 停约 1.9s，只有很小的动作（手指微动、叶子轻摆） |
| 约 3.5s | 布景 0.15s 撤走，硬切到下一个画面 |

字的层级：小字标居中在约 15% 高处 → 中文标题（粗宋，压在一张白纸签上，下面一条主题色笔刷下划线，字高约画面区 9%）→ 英文标题（题材字体，两行，合计字高约画面区 23%）→ 一段全大写、字距拉开的引文小字（字高约 1%）。字的周围点两颗四角星。

章节卡的**布景整部片复用**，换的只是字。

```css
@keyframes re-chapter-land {
  0%   { transform: scale(4); filter: blur(14px); opacity: 0; }
  6%   { opacity: 1; }
```

### 9.2 名字卡（登场）

- 白闪 0.2–0.3s（落在一个起音上）→ 一条线上的星从左到右依次点亮（0.3s 内）→ 名字从虚到实 0.3s → 停 4–6s，镜头几乎锁死。
- 构图：主色圆盘直径约画面区高的 70%，圆心约在 (22%W, 39%H)，人站在圆前；名字（宋体，字高约画面区 12.6%）放在约 (54%W, 41%H)；名字上方一枚小徽章（菱形里套四角星）；名字下面一排星串在一条细线上，线的末端一个小图标；名字背后压一层描边大字（英文名）作底纹；一侧竖排小字（身份）；一角一笔主题色手写签名。

### 9.3 片中标题

- 拿掉画面，只留暗色纹理底；一群物件（羽毛、纸片、碎片）从下往上爆开，中间是很小的标题（宽约 19%W）。
- 整个过程落在一个强拍上，强拍前约 1 秒有一个小的音量凹陷。
- 停 2.5s；物件散开，画面淡黑；一道柔边光从左向右扫开（约 0.6s），露出下一场。
- **字本身不动，动的是周围的物件。**

### 9.4 定档卡、片尾卡

**一段式：** 硬切到黑，黑场 1.7s 几乎无声 → 主视觉 0.3s 淡入并轻微缩放落位 → 日期从左到右显现 0.4s → 停 6s 以上，期间画面以约 1.65% / 秒慢慢拉远。
版式：大日期（高反差细衬线，字高约画面区 11.8%）+ 一行粗宋（字高约 16.5%，以一道斜线收尾）+ 一行浅色衬线小字半压在数字上作底纹 + 一行小副标（2.8%）+ 一行锈橙小字（3.3%，左右各一段细线加 ✦）。文字块重心约在 74%H、40–58%W；字标在左上；右上一个极小的系列标。

**两段式：** 压暗的背景 0.4s 淡入（平均亮度从约 2 升到约 21）→ 巨大的日期从虚到实 0.3s、同时放大约 10% 落定 → 一行字逐字打出 0.33s → 整体停 0.6s → 文字整块缩到 56% 并下移到画面下部，0.73s，sway 曲线 → 同时背景亮度提高到约 2.5 倍，0.8s。核心是：**先让字独占画面，再把字收到一角，把画面让给主视觉。**

### 9.5 信息页（介绍页）

- 一张满版的画，字住在画面更暗的那一边；文字栏约 30–35%W，主体落在另一侧（版式见 `layout.md` 3.5）。
- 入场顺序：底图推入停稳（0.5s）→ 标题 0.3s 后出现（中文从虚到实，背后英文片名淡入）→ 日期行与看点列表逐行淡入并右移 24px，行间隔 0.1s → 图像卡片从画外飞入、倾斜约 5° 落定 → 角标最后淡入。
- 看点列表的四角星在行出现时先闪一下（0.15s 的暖光）。
- 停留期间镜头锁死，只有图像那一侧极慢地推（≤1% / 秒）。

### 9.6 卖点字卡、片头演职员字卡

- 卖点字卡：黑底 + 麻布或印刷底纹 + 一个暗红褐色的巨大窄体英文词铺满画面作底纹 + 正中一行做旧印刷感的粗宋（字距约 0.55em，横跨约 80%W）。
- 片头演职员字卡（复古片头）：在一个场景上逐条打出“领衔主演 / 名字”，粗白字，下面配小号英文；或者索尔·巴斯式：只用黑、白、主题红三色，每个镜头一个剪纸剪影配一组窄体大写人名，人名里一个字母单独染红，每个画面 2–6 秒。

### 9.7 年份字卡

细衬线年份（数字高约画高 7%）放在右下三分之一，下面一根向左伸出的发丝线；淡入 0.6s，停到镜头结束。

### 9.8 出品标识与落版

- 出品标识：每块淡入 0.4–0.6s、停 1–1.8s、淡出 0.4–0.6s，块与块之间 0.3s 黑。
- 落版：字标先长出它最有辨识度的那个部件（几道斜线、一个圆），约 0.6s；然后其余笔画长成整组字，约 1.0s；停 2.5s；淡出 0.3s。不另加粒子和光效。

## 10. 胶片感处理

所有叙事和欣赏段落统一一套处理，平面图形段可以更重：

| 处理 | 数值 | 怎么做 |
|---|---|---|
| 宽银幕 | 2.35:1，1080p 上下各 132px | 黑边 `#0C0D0C`，里面只放刻度尺进度条；字幕不进黑边 |
| 影调 | 画面黑位约 10/255，白位约 215/255 | 输出 = 10 + 输入 × 205/255，再加一条轻 S 曲线；只作用在画面层，字和部件叠在调色之后 |
| 饱和度 | 乘 0.7 左右 | 调色或 `saturate(.7)` |
| 暗角 | 四角亮度为画面中央同一种底色处的 0.4–0.6 | 径向渐变正片叠底 |
| 强调色面积 | ≤5% | 构图时控制（登场舞台的“日”除外） |
| 柔光晕 | 亮部向外渗暖光 | 取亮部 → 模糊约 1% 画宽 → 染暖（`#FFD2A8`）→ 滤色叠加 20–30% |
| 色散 | 红青错开 1–1.5px | 只在闪白、特写、冲击的瞬间 |
| 颗粒 | 界面与字卡 2–4 级起伏，平面段 4–8 级 | 三维与绘画画面不加，靠景深和前景遮挡（`ornament-texture.md` 3.1） |
| 划痕尘点 | 每帧 0–2 根划痕、0–5 粒尘，各活 1–3 帧 | 只给平面图形段和年代字卡 |
| 漏光 | 一侧橙红光，滤色 | 一段只出现一次 |

**冷暗场里放一小块暖光**，是这套处理最典型的一张画：蓝灰雨夜里一辆红色的车、一盏琥珀色的灯。

**展示他人作品时不加这套处理到作品身上。** 作品是被拍的“展品”：胶片感可以加在作品外面（黑边、暗角在框外、颗粒在底上），作品本身的颜色和清晰度不动。

## 11. 片子的结构

- **开场的四种做法。** ① 冷开场：直接切进一个极端特写（一只眼睛、一件物件），静止 2 秒再慢推；② 先声后画：黑场里先出一句台词或一个声音，再淡入画面；③ 先戏后标：先放 5–6 秒的画面，再插片头标题卡；④ 标志就在第一个镜头里：从云层上方慢慢降下来，片名浮在云上停 6 秒以上。一部片只选一种。
- **母版 + 条目子风格。** 章节卡的布景、字标位置、角标、字幕位置全片统一，这是母版；每个条目的字体性格、底景和转场物件跟着条目的主题走，这是子风格。
- **清口底景。** 条目之间回到同一个中性底景 1–2 秒（暗室里一束顶光、一张星图底、一个灰色的空舞台），给眼睛“清口”，然后进入下一个条目的专属画风。
- **两幕。** 一部较长的片可以分成两幕：第一幕卖情绪（电影语言、宽银幕、跟着台词或音乐的情绪剪），第二幕交代信息（节目包装、章节卡、背景音乐不断）。两幕之间用 1–2 秒“黑 + 静音”切开，观众会明确感到换了一种节目。
- **一部片只有一种强入场。** 章节卡的“色闪 + 大字缩回”只给章节，其他地方不用，才能保住它的分量。

## 12. 待机与循环（活照片）

需要一个画面停留很久时（背景、介绍页、人物站立），不用镜头运动，用“活照片”：

- 镜头完全不动，前景、主体、远景三层叠在一起。
- 只有很小的东西在动：雨滴滑落、窗外闪一下电、人物呼吸（缩放 1.000→1.008，周期 4–6 秒，正弦）、发丝和衣角摆 1–2px、灰尘或光点以 6–12px / 秒向上飘、灯光以不规则的间隔闪 ±3%。
- 一件仪器在慢转：唱片约 60 秒一圈，轨道上的小行星 20–60 秒一圈。
- 一块辉光管或翻牌数字偶尔乱跳一下再停住（每 8–15 秒一次，跳 0.3 秒）。

## 13. 声音和画面

- 揭晓之前声音和画面一起清空；揭晓落在静音后的第一个起音上。
- 界面声是实物的声音：翻纸、放映机转动、胶片放完的闷响、打字机、印章盖下。
- 大段落之间的黑场里声音降到几乎无声，不要用一个“嗖”的音效填。

## 14. 动效上常见的走样，以及为什么

- **弹跳与回弹：** 它让东西显得轻、像玩具；这套语言里的东西是纸、金属、玻璃，有分量，落下就停。
- **每个转场都闪白：** 闪白是“这一刻不一样”的标记，处处都闪，就没有一刻不一样。
- **满屏粒子：** 粒子会把画面变成“特效”；这里的粒子只围在标题周围、有方向（向上飘），而且只在仪式时刻出现。
- **字跟着画面一起推：** 字一动，就读不清；也失去了“字是贴在镜头前的一张卡”的感觉。
- **入场和退场一样长：** 退场拖长，观众的注意力会被拉回已经结束的东西上。
- **三维旋转的大字：** 它属于电视包装和游戏广告，不属于电影片头。字的动作只有缩放、从虚到实、遮罩显现、逐字打出、慢淡入。
- **停留时所有东西都在飘：** 为了“有动感”，让背景、星、线、字一起缓缓浮动，画面就成了屏保。停留时只留一两样东西在动（一缕烟、一颗轨道上的小行星、一盏闪了一下的灯），其余锁死。
- **所有东西同时到：** 画、标题、看点、按钮在同一帧一起出现，就没有了“先空一下，再一下子出来”。顺序是：画先于字，抽象先于具象，主角先于配角，每一步隔 0.1–0.3s。
