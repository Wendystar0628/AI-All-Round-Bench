# 排版与构图

一句话：**画铺满，字贴边或住进画的暗处；一屏只有一个图形主角，其余都小。**

坐标一律写成画面宽（W）、高（H）的百分比，16:9 画布。

---

## 1. 画幅、边距、安全区

| 项目 | 数值 |
|---|---|
| 母版画布 | 16:9（1920×1080） |
| 叙事、欣赏、片头段落 | 2.35:1 宽银幕：16:9 上下各留 12.2% 黑边（1080p 下 132px），画面区 1920×816。黑边用 `#0C0D0C` |
| 黑边里放什么 | 只放底部的刻度尺进度条（见 `apply-video.md`）。字幕、演职员表、字标都放在画面区里 |
| 图标与角标贴边 | 2.3%W（44px）——左上的字标、返回、主页图标，角落的小字标。宽银幕段落里按画面区的边算 |
| 正文与按钮离边 | 3.9%W（75px） |
| 海报与公告的边距 | 3–5%W；字标宽约 15–22%W，放在左上或右上 |
| 字幕 | 在画面区里面，离画面区下沿约 3%；不放进黑边 |
| 超宽背景 | 背景画按 2.4:1 准备，界面按 16:9 排；多出来的两侧只露背景 |

---

## 2. 母版骨架：四边槽位 + 一个会走动的标题簇

这是这套语言最稳定的版式。所有主内容页（活动页、介绍页、主题页）都是它的变体。

| 槽位 | 位置 | 放什么 |
|---|---|---|
| 右上 | 74–96%W，2–7%H | 两三个固定入口或品牌：细线圆形图标 + 中文 + 英文微字 |
| 右栏 | 78–96%W，25–70%H | 一列信息条（看点、任务、商店）：每条左边一张撕边小照片或小图标，右边中文 + 进度数字 |
| 右下 | 72–96%W，66–95%H | 进入按钮或一张票根。文案是故事里的一个动作 |
| 左列或底排 | 左列 2–20%W、15–95%H；或底排 82–95%H | 子项列表：小图标 + 中文名 + 英文微字 |
| 标题簇 | **不固定**：放在画面的暗处，宽度 ≤35%W | 题材字标题 → 中文片名 → 一个状态小标签 → 一行倒计时或编号 → 一到三行题记 |
| 中央 | 约 50–60% 的面积 | 只放画（插画、意象、主体），不放任何界面框 |

**标题簇跟着画走。** 主体在右，标题簇就在左上；主体靠左，标题簇移到右侧；画面上半满，标题簇横铺在底部；画面是竖长的书法或一根柱子，标题簇可以竖排压在中线上。规则只有一条：**标题永远放在主体让出来的那一边。**

**骨架要锁死。** 拿掉标题字和颜色以后，所有主内容页的骨架应该完全一样。观众每次都在同一个位置找到“进入”、在同一个位置找到“看点”，新鲜感全部来自皮。

**这套槽位只管“界面页”。** 片头标题卡、登场舞台、章节字卡、落版这些仪式画面不用槽位，它们居中对称（第 4 节）。“中间 40–60% 不放界面”说的是槽位页；仪式画面的中线上本来就是主体和字。

## 3. 几种典型版式

### 3.1 横幅：左三分之一字，右三分之二画

用在入口卡、公告条、横向海报（宽高比 2.3:1 到 5.7:1）。

| 元素 | 位置 |
|---|---|
| 小上标（栏目名或系列名，字距拉开） | 8–20%H，从 3–15%W 起 |
| 标题字 | 3–55%W，20–75%H |
| 底部一行固定信息（基线） | 86–92%H，左边距 4–6%W |
| 主体 | 45–100%W，脸或重心落在 55–85%W |
| 左右交界 | 一段暗色渐变，不用硬边 |

左半边整体压暗：左半平均亮度约 0.32，右半约 0.41。主体脸朝左时，整套镜像到右边。

### 3.2 竖海报：一个意象 + 片名放在空处 + 演职员表

用在版本海报、题目海报、片头里的海报帧（9:16 或 3:4）。

- 画面中心是**一个**超现实的单一意象（物件变场景、字母变建筑、人脸变山），约占画面中间一半。角色要么缩成剪影或小人，要么不出现。
- 品牌字标在左上：左边距约 5%W，上边距 2–6%H，宽约 18–20%W。
- 片名放在画面的空处：大写字高约为海报宽的 8–9%。可以在上三分之一、下三分之一、侧边竖叠。
- 演职员表：一列 `STARRING` 加 4–8 个名字，字高约为海报宽的 1.4–1.5%，行距为字高的 2 倍，`STARRING` 字距 +300 以上。
- 底部微字：约 94%H，宽约 30%W，居中。

### 3.3 人物海报：圆盘 + 人 + 名字压在下四分之一

- 背景大圆盘：直径为画宽的 0.55–0.76，压在人物上半身后面，纵向约 4–56%H；它是一盏光，人物的影子落在上面（`imagery.md` 第 2 节）。
- 名字：水平居中，顶端在约 78%H，字高为画高的 5.6–8.4%，宽为画宽的 48–78%。
- 底部微字在约 94%H。
- 一条 1px 的轨道线从画外绕进来、在人物身后穿过，再从另一边出去。

### 3.4 登场舞台：中心圆 + 身后大词 + 下方三层

| 元素 | 位置 |
|---|---|
| 红日 | 正圆，中心 (50%W, 45%H)，直径为画高的 58–64%，下沿被暗角吃掉一截 |
| 光锥 | 两道从画外斜下来的顶光，在圆的上缘交叠 |
| 大词 | 宽约 45–55%W，垂直中心 40–45%H，被主体挡住中间（做法见 `typography.md` 9.3） |
| 名字 | 约 68%H，下面一条两端渐隐的发丝线 |
| 星 | 75–80%H，星高约 5%H，相切横排 |
| 双语台词 | 中文约 86%H，外语约 90%H |
| 右上 | 一枚属性徽章，从徽章下面拉一条竖向虚线到约 76%H，以一个 × 收尾 |
| 左缘 | 一列极小的字母和符号竖排，像刻度 |

这种版式是对称的，因为它是仪式。

### 3.5 信息页（介绍页）：一张满版的画，字住在画的暗处

用在介绍页、活动说明、玩法说明。

- **画是满版的。** 意象不是放在一块空底上的一件东西，而是一张铺满全屏的画：同一个场景从右边延伸到左边，左边那部分更暗、更虚、细节更少，字就写在这片暗处（主体在左时整套镜像）。
- 文字栏约占 30–35%W（从约 6%W 到 40%W），主体落在 50–85%W。
- 中文标题两行粗宋或一行高反差宋，合计字高约画面区的 20%；标题背后可以叠一层大号英文片名，低不透明度。
- 标题下一到三行：日期或类别行（行首 ◆）、列点看点、奖励或数量（斜体 `×14`）。
- 列点格式：`✦ 看点一句话 ≫`，行首四角星、行尾双箭头、下面一条只到字尾的细下划线。三条为宜，不超过四条。
- 图像也可以是倾斜约 5° 的两三张卡片，描一圈主题色细边并微微发光。
- 左上字标离边 44px；右上角一个极小的系列标 `◆◆ 系列名`，字高约 1.4%。
- **这里的标题不必和主体重叠。** 标题簇住在画面的暗处，和主体左右分开是对的；“标题和主体要发生遮挡”说的是海报、舞台和人物卡里横在主体身后的大词。

**字量的上限（1080p 视频）。** 说明一到两句，每行不超过 20 个字（30px），最多两行；看点三条，每条不超过 14 个字（28px），一条一行。放不下时按这个顺序让：
1. 先改写，把句子写短；
2. 再把看点从四条减到三条；
3. 再把说明从两句减到一句；
4. 字号不往下缩（正文不低于 28px），也不把文字栏加宽到 35%W 以上。

**同一个编号一屏最多出现两次**：标题簇里一次，底部刻度尺上一次。右上的系列标只写系列名，票根上不再写编号。

### 3.6 档案页：左菜单 · 中主体 · 右展签

- 左侧竖排 4–6 项菜单，菱形做列点，选中项是外框菱形套实心橙菱形加橙字。
- 中间主体，背后一个细线矩形画框、一个锈红的光圈、几个巨大衬线字母的碎片。
- 右侧一块展签：首字母放大的名字（首字母高约其余字母的 1.6 倍），一段美术馆口吻的介绍，下面一个“羁绊 0%”式的小数据条。
- 左下或右下竖排几个字段（媒介、年代、尺寸），菱形列点。

### 3.7 通栏：横贯全屏的一条纸带

用在二次确认、阶段提示、重要通知。

- 纸带横贯全屏，高约屏高 13%（确认）到 28–30%（含图示的提示），左右边缘可以渐隐。
- 背景模糊约 8px 并压暗到约 40%。
- 纸带上方居中写标题（“提 示”，字距 0.5em），上面一个小 `^`，下面一个括号形托着极小的英文。
- 纸带里一行宋体问句，关键词和数字染锈红。
- 纸带下方并排两颗按钮：白色次按钮在左，锈橙主按钮在右。

### 3.8 海报墙、书封墙、票根排（汇总页）

- 一排竖版海报或书封，卡间距约卡宽的 20%，每张下面一行衬线片名。
- 顶部或背后一行极淡、字距极大的大写字作水印，被卡片压住。
- 底部一条图标页签栏：每个页签是多色几何线图标 + 宋体名；选中项一条橙下划线 + 一笔橙色手写叠在字后。
- 一组结果可以摆在倾斜约 5° 的透视平面上，像桌上的一叠卡；四周印几个表格标签和竖排符号，像一张盖了戳的档案表。

## 4. 对称、偏置，和构图在说什么

- **默认偏置。** 主体偏一侧，字在另一侧；版面的重心落在下三分线附近、略偏左（定档卡的文字块重心约在 74%H、40–58%W）。
- **对称只给仪式。** 片头标题卡、字标落版、登场舞台、横贯全屏的提示、章节字卡、成就弹窗是居中对称的。一屏对称，说明这一刻是“仪式”；如果每一屏都对称，就没有仪式了。
- **对称里放一个偏差。** 对称构图里留一处不对称（星排在一侧、一条竖虚线只在右边），对称就不死板。
- **构图本身表达意思。** 对称是秩序，也像牢笼；对角切割、上重下轻是坠落和失衡；三个人各装在一个形状里（柱子、画框、齿轮）是三条线索；一个极小的人站在一件巨物脚下是渺小。先想这一屏要说什么，再挑构图。
- **倾斜：** 纸片 1–5°，票根约 1°，标题牌约 −4°，结果网格 5° 透视。文字本身永远水平、清晰；倾斜的是纸，不是字。

## 5. 文字直接压在画上

这套语言里几乎没有文字底板。字压在画上靠下面三件事保证可读，按顺序用：

1. **让字所在的那一半自然更暗。** 构图时就把暗部留给字：字那边比主体那边暗约 25%、细节更少。
2. **在字后面局部垫一团暗色污渍或一块网点。** 污渍是几团模糊的近黑径向渐变（不透明度 35–60%），边缘完全化开；网点块只比底色亮 10–20%。它们看起来是画的一部分，不是一块板。
3. **很淡的同色外发光。** 字的外发光用字自己的颜色或主题色，模糊半径约字高的 0.2，不透明度 20–40%。

三样都不够时，才在底部加一层从透明到暗（`#171111`）的渐变，像剧情对白那样。仍然不用带边的框。

## 6. 遮挡与层叠

一张有层次的画面，从后到前是：

**背景水印字 → 远景与暗纹 → 大圆（光）或光晕 → 拉开字距的大词 → 主体 → 前景虚化的遮挡物 → 暗角与颗粒 → 中文标题 → 签名笔画**

前景遮挡物属于画，压在主体上、不压在要读的字上；颗粒也在字的下面，要读的字永远干净。

- **大词和主体一定发生遮挡。** 舞台、海报、人物卡里横在主体身后的大词，被主体挡住中间 1/4–1/3 的字母；中文标题不被挡。不要把大词放在主体旁边、两者不接触。
- **信息页的标题簇不在此列**：它住在画的暗处，和主体左右分开（3.5）。
- **没有主体的画面不硬做遮挡**：片头标题卡只有字和一件小物，不为了“遮挡”去加一个大词。
- **前景遮挡物**（虚化的植物剪影、窗框、花瓣、帘子边）放在画面一角，偏暗，制造纵深。纵深靠前景遮挡和景深，不靠真三维。
- **大字的一部分出血。** 背景水印字和巨号编号常被画面边缘裁掉一截，这让画面显得比画框更大。

## 7. 信息层级与疏密

**五层，越往下越淡：**

1. 场景或主体（满屏，最饱和）
2. 巨型标题（页面名或人名，常带中英两层）
3. 主操作（唯一的锈橙块，或一张纸卡）
4. 数据（小号衬线，`#BDB3AA` / `#C3C2C1`）
5. 装饰（发丝线、轨道椭圆、水印字，不透明度 4–20%）

**疏密 8:2。** 一屏一半的细节集中在 11–20% 的面积里，80% 的细节在不到一半的面积里，其余是大块的暗或纸。载入页、片头标题卡这类黑场页更极端：80% 的细节只占约 10% 的面积，95% 以上的像素接近黑。

**主视觉只回答三个问题：** 是谁（或是什么）、有多特别、什么时候。规则、概率、说明一律藏到第二层：缩成斜体小字、收进“详情”、折进“▸”展开项。观众扫一眼只读到标题；停下来看，才读到下一层。

**标签贴着它说的东西。** 名牌、编号、看点贴在各自的主体旁边，而不是集中成一张表；一组东西一起出场时，每样东西带着自己的小标签。

## 8. 留白与间距

- **留白是“暗部留白”。** 不是把背景挖空成一块纯色，而是让那一半更暗、更虚、细节更少。照着做时，不要把背景擦干净，要压暗它。
- 槽位页的屏宽中间 40–60% 不放界面；界面只贴四边：上约 7%，右约 20%，下约 18%，左约 20%。
- 标题簇宽度不超过 35%W。
- **间距跟着字号走。** 一行小字和它上面的大标题之间，空出约小字字号的 1.5–2 倍；两个大块之间，空出约大块字号的 0.5–0.8 倍；同一组里的小字之间，只空约 0.5 倍字号。越大的东西之间空得越多，所以一组字看起来是一块，几组之间分得开。
- 信息区内部，行与行之间留约 1.5–2 个字高的空；任何面板离屏幕边至少 44px（2.3%W）。
- 暗底页面里，文字和线一共只占约 10–15% 的面积。

## 9. 栅格

这套语言不是靠网格出秩序，而是靠**锁死的槽位**和**共基线**。

- 视频画面：不用可见的网格；按第 2 节的槽位坐标放。
- 网页：12 栏，栏距 24px，左右页边 `max(32px, 3.9vw)`；内容最宽 1680px。标题簇和图像故意跨栏错位（例如标题占第 1–5 栏，图像占第 4–12 栏，两者重叠一栏，让图压住字的一角）。
- **共基线：** 大小混排的字（放大的首字母和其余字母、巨号数字和单位、中文和下挂的英文起点）共用一条基线或左对齐于同一条竖线。
- **槽位固定、内容随动：** 卡片网格本身可以规整（人物列表是 6 列竖卡），但网格之外的标题、说明、装饰都按偏置构图摆。

## 10. 版式上常见的走样

- **一格一格的深色模块。** 把信息分进等大的深色方块、每块一个小标题加数据，颜色一点没变也不像了。因为模块网格是通用科幻面板的结构，和“一件旧物”的结构冲突。需要分区时，用一张纸、一条断线、一个刻度，而不是一个盒子。
- **物件浮在空底上。** 一个没有影子的物件摆在一块平的深色渐变中央，四周用线条填满。它像幻灯片里的一张贴图，不像一个地方。
- **大词和主体并排。** 两者不接触，画面只有左右没有前后。
- **满屏散落的入口。** 入口要收进边栏，中间留给画。
- **每个元素都加框。** 框只在一个地方出现：要把几个次要角色归成一组时，用一个拱窗形的框。
- **把说明文字放在第一层。** 一旦规则和标题抢第一眼，主视觉就变成了公告。
- **把一组条目排成一圈带编号的图形。** 十几个条目各配一颗星、一个编号，排成轨道或放射状，就成了信息图；条目多时收进演职员表块或一面海报墙。
