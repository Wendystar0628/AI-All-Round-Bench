# 界面部件范式

一句话：**每个部件都是一件旧物的局部。** 按钮是一张印出来的票，卡片是一张纸，进度是一把尺，标签是一个印章，对话框是一条纸带。

尺寸按 1080p 视频给出；网页按约 0.55 倍取整（例如按钮高 44px → 网页 40px，字 28px → 16px）。颜色见 `color.md`，符号与纹理见 `ornament-texture.md`。

---

## 1. 标题

### 1.1 页面大标题

- 中文巨字（思源宋体 700，60–72px；更大时换高反差宋，见 `typography.md` 第 2 节）+ 一层英文：字距拉开的小号大写，或斜体短语。
- 背后一个字距极大的英文水印（页面名，如 `ARCHIVE`、`GALLERY`），不透明度 4–8%，常被屏幕边裁掉。
- 首字可以放大 1.3–1.6 倍；或在首字后压一个锈色圆。
- 没有底板、没有下划线、没有图标前缀。

### 1.2 小节标题

宋体骆驼色 + 短竖线 + 英文微型大写 + 尾部断开的发丝线（写法见 `typography.md` 9.11）。

### 1.3 字卡标题

章节字卡、名字卡、定档卡各有固定排法，见 `motion-video.md` 第 9 节。

## 2. 按钮

按钮几乎不用圆角胶囊。**主次靠“橙对白”区分，不靠大小区分。** 每颗按钮至少带一个“印刷记号”（小三角、点阵、迷宫纹），让它像一张印出来的票，而不是一块平涂色。

| 类型 | 长相 | 尺寸 |
|---|---|---|
| 主按钮 | 锈橙实心直角矩形（视频 `#C25E30`，网页 `#AE5228`），圆角 0–2px；白色宋体字，字下一行极小的英文大写（CONFIRM），约 0.32 倍中文字高、字距 0.3em、50% 不透明度；右上角一到两个细线倒三角 `▽▽`；左半边一层 6–10% 白的迷宫细线；右下角 3×2 小点阵；一层很轻的投影 | 高约屏高 4%（44px），字 28px，左右内边距约 1.6 倍字高 |
| 次按钮 | 同结构的近白矩形（`#FBF8F2`），深色字 `#2B2723`，只有一个 `▽` | 同上 |
| 加号块 | 贴在纸卡右侧的锈橙方块，里面一个几乎顶到边的黑色细十字，块内同样有淡迷宫纹和点阵 | 方块宽约纸卡宽的 0.4 |
| 纸卡按钮 | 整张纸卡就是按钮：宋体标题 + 下挂英文 + 纸面上淡淡的线描（波浪、多边形）+ 右下一个数值 | — |
| 圆形印章钮 | 一个圆，衬线字，外面一圈细线或环形小字；可以是锈橙颗粒实心圆 + 一条倾斜轨道 + 一颗小行星 | 直径约 96–170px |
| 笔刷钮 | 一抹灰色毛笔刷痕当底，上面写字 | — |
| 撕纸钮 | 一条撕边纸 + 一块网点 + 一个锈橙圆 | — |
| 菱形图标钮 | 45° 方块细描边，里面一个线图标 | 约 48px |
| 文字链 | 锈橙字 + `»`（“去看看 »”），背后可以垫一小块网点 | — |
| 票根钮 | 一张小票根：打孔虚线 + 半圆缺口，右侧票根上写动作 | 整张转约 1° |

**一组里只有一颗主按钮。** 有章节色或题材色时，主按钮换成那个颜色，锈橙退到别处的小字上，不并排出现两种强调色的按钮。

**文案：** 写动作，最好是故事里的动作（“开映”“入座”“翻开”），中文下面挂英文（START、ENTER、OPEN）。

**状态：** 悬停时整块亮一档（视频不需要）；按下时向下 1px、投影消失；禁用时整块压暗到 40% 并铺一层 45° 的细斜线。

## 3. 卡片

这套语言里的“卡片”是一张纸或一件实物，不是一块带圆角和投影的面板。

| 卡 | 长相 | 用法 |
|---|---|---|
| 纸卡 | 暖白纸 `#E8E2D8`，一角渗桃色，0–4px 圆角，可以转 1–3°；标题深色宋体 `#3B3A36`，说明灰 `#827E77` | 养成项、看点、说明 |
| 竖卡 | 约 3:7 的竖长条，圆角 6–8px；左上一面底边开叉的燕尾小旗（属性色），右上一枚回形针线描；底部 1/4 叠一层从透明到 `#A66533` 的渐变和几颗光点；最底一排 5 段短横表示等级 | 人物、作品的列表 |
| 海报卡 | 一张真正排过版的竖海报：片名、标语、档期、演职员表小字；下面一行衬线片名 | 章节、汇总页的每一项 |
| 拱顶卡 | 顶部是半圆拱（墓碑、教堂窗形） | 技能、作品缩略图 |
| 展签 | 字段标签 + 值，菱形列点，美术馆口吻 | 资料、档案 |
| 票根 | 见 `ornament-texture.md` 2.9 | 入口、下载 |
| 胶片格 | 深色胶片上的一格，左上斜体编号；选中时橙色取景框四角 | 分集、序列 |
| 拍立得 | 白边，底边更宽，底边上一笔手写签名和一行小字 | 人物、纪念 |
| 证件照 | 齿孔边的小方框 | 头像 |
| 唱片封套 | 灰纸上一张黑胶 + 打字机编号 + 巨大宋体名 | 资源、合集 |

**选中：** 2px 红橙描边，或者橙色取景框四角，或者整张纸亮一档。不用发光。

**卡片之间：** 不用闭合的边框分隔，靠间距（约卡宽的 20%）和一条低对比的断线。

## 4. 页签与导航

| 类型 | 未选 | 选中 |
|---|---|---|
| 文字页签 | 灰字 `#707070` | 橙字 `#DE6831` + 1–2px 亮橙下划线（最亮处 `#FF7D43`）+ 字后一小块网点 + 下方一个实心小倒三角 ▼ |
| 色块页签 | 只有灰字 | 整块锈橙底 + 白字 |
| 符号页签 | ◇ / ◎ / △ 做前缀区分类别 | 同文字页签 |
| 图标页签栏 | 多色几何线图标 + 宋体名 | 橙色下划线 + 一笔橙色手写叠在字后 |
| 菱形导航 | 灰色实心小菱形 + 灰字 | 外框菱形套实心橙菱形 + 橙字 + 极小的英文 |

页签之间用 1px、约 40% 高的竖线隔开。

**左上固定三件：** ◁ 返回（约 48px，离左边 44px、离上边 44px）、▣ 主页（右边隔约 100px）、◇! 说明。所有子页面位置不变。

## 5. 标签、角标、提醒

| 意思 | 长相 |
|---|---|
| 有新东西 | 12–16px 红色**小方块** `#CB4438`，贴在入口右上角 |
| 新 | 红底白色斜体 “New” |
| 限时 | 绿色 1.5px 描边椭圆 + 沙漏 + 斜体数字（`⌛5d`，字 `#96D084`） |
| 折扣 | 同一个绿色描边椭圆，里面 `-20%`，压在卡角 |
| 通用印章标签 | 描边椭圆里写一个斜体词（Style、Bond、SALE）。圆和椭圆是这套语言里的“章” |
| 丝带 | 两端开缺口的暗棕条，用在评级、称号 |
| 已领取 | “已领取 / CLAIMED”两行字 + 一个细线勾，像盖上去的章 |
| 限定 | 贴在标题旁的一个小章（形状随场合换） |
| 分类 | 底边斜切的竖旗，分类色底 + 白色符号（`flag-tag.svg`） |

## 6. 列表

- **没有卡片底**，只有一根低对比的细横线分行。
- 行内“左标题、右数值”两端对齐；数值用衬线数字。
- 行首：`01/` 编号、◆ 菱形或 ✦ 四角星，三选一，一个列表只用一种。
- 行尾可选 `≫`，表示能展开或前往。
- 行距约 1.5–2 个字高。
- 记录行（对话记录、历史）：一个圆形小播放钮 + 人名 + 冒号 + 内容，三列对齐。
- 表格：只用细横线分行，不用竖线；表头底色比表身略深一档。

**看点列表（介绍页用）：** `✦ 一句话看点 ≫`，行首四角星、行尾双箭头、下面一条细下划线（只到字尾，不到行尾）。三条最好，最多四条。每条一句话，不超过一行（视频里不超过 14 个字）。

## 7. 进度

每一种进度都和它的意思对应，不用同一根通用进度条。

| 场合 | 长相 |
|---|---|
| 载入 | 已完成的一段是 4–5px 实线，越靠近头部越亮（从 30% 白渐变到 95% 白）；头部前方约 10px 一颗单独的亮点；没走到的部分是点线（2px 点、6px 间距、20% 白） |
| 序列、章节、关卡 | 刻度尺：一根全宽细线带小刻度，当前位置一个 ◎ 定位环加 `编号/ 名称`，前面的项更小、更暗，旁边一颗带长芒的小星（`ruler.svg`） |
| 经验、信任 | 3px 细线（红 `#C35237` 或绿 `#5A823E`），右上角 `1120/1680`，旁边一个绿色 `+120` |
| 阶段（如 12 步） | 一排 12 个橙色小圆点，亮的实心、没到的空心 |
| 等级（如 5 级） | 5 段短横，亮的白、暗的灰 |
| 音量、热度 | 一排电平格（VU 表），从左到右绿到橙 |
| 血量、耐久 | 平行四边形细条，右端斜切 |
| 地点完成度 | 一个圆形徽章，旁边写百分比 |

## 8. 数字

- 分子大、分母 0.55 倍：`60/₆₀`。任务里的 `2/2`，分子是巨大的衬线数字。
- `Lv.` 为数字的 0.55 倍，共基线。
- 数量用乘号：`×300`（斜体）。
- 编号：`2ND 14`、`13/`、`EP. 01`（斜体）。
- 大数值（总计、记录）：斜体衬线大字，上面一个锈橙小词（`TOTAL`、`NEW RECORD`）。
- 年份字卡：细衬线 `1929`，在右下三分之一，下面一根向左伸出的发丝线。
- 数字不要染红做提醒（暗底上的小红字很难读）；用暖白数字配一个红方块。

## 9. 对话框与提示

四种，各有固定用途。**弹窗不是居中的圆角小卡片。**

### 9.1 纸面弹窗（购买、说明、规则、记录、选择）

- 一张暖白纸（`#E8E2D8`），一个角渗桃色；右上角一个细线 ×（可以是锈色）。
- 标题：宋体 + 极小英文 + 一根断开的发丝线。
- 物品展示：放在一个桃色圆 + 一圈细轨道圆 + 一颗四角星前面。
- 左侧页签做成一张张浅色纸片，选中那张变成锈橙并带 `>`。
- 表格只用细横线。
- 数量步进器：`MIN [−] 1 [+] MAX` 一排小方块，下面锈橙的“确认”。
- 动效：先出现一张空白的纸（一个角向上卷起），约 100ms 压平并伸展到最终宽度，再约 80ms 让内容淡入；合计 200–230ms。关闭：70–100ms 整体淡出，不卷角。

### 9.2 通栏提示（二次确认）

- 横贯全屏的一条纸带（`#F2E9E4`），高约屏高 13%；背景模糊约 8px 并压暗到约 40%。
- 纸带上方：“提 示”（宋体，字距 0.5em），上面一个小 `^`，下面一个括号形托着极小的 `NOTICE`。
- 纸带里一行宋体问句，关键词和数字染锈红（纸上用 `#A64A26`）。
- 纸带下方：左“取消 CANCEL”白钮，右“确认 CONFIRM”锈橙钮。
- 动效：先在屏幕中线出现一条约终高 1/3 的半透明纸带，100ms 内上下展开到全高、变不透明，标题从小到大淡入，再依次显出问句和按钮；合计约 230ms。关闭：约 70ms 全部同时淡出，背景同步恢复清晰。

### 9.3 深色信息面板（战斗信息、特殊说明、类型对照）

- 近黑半透明（`#0D0C0F`，约 90%）。
- 小节标题骆驼色宋体（`#B59070`–`#CDA17B`）+ 竖线 + 小号英文大写 + 断成三截的细线。
- 网格用 1px 线分格；标题可以写成 `—◆ 类型对照 ◆—`。
- 关键词用【】括起并染金橙，菱形 ◆ 做列点。

### 9.4 纸条吐司（成就、解锁、提示）

- 一小条浅纸（`#EBDFDA`），左边一个红色描边圆 `!`，衬线字，关键词染锈红（`#BE523F`）。
- 或一个暗色胶囊 + 一枚小勋章 + 灰色小字 + 锈橙标题。
- 位置：右上角；出现 200ms，停 2–3 秒，消失 100ms。

### 9.5 详情浮层

点开某一项后才出现的说明，用浅灰纸条（宋体，数字染锈红）或深色面板，贴在被点的东西旁边，不遮主体。

## 10. 字幕与对白

**没有对话框。** 底部只有一层由透明到暗（`#171111`）的渐变，字直接写在画面上。

- 人名：衬线，约 44px，暖灰 `#B8AEA9`。
- 人名下一根 2px、只比底亮约 15 级的分隔线，精确地断成三截：`62 | 缺口 18 | 1021 | 缺口 18 | 74`，整体约屏宽 62%，居中。
- 正文：约 32px，`#E6E2E1`，左起约 21.5%W。
- 右下角一个小 `▽` 表示继续。
- 头像：主角用菱形相框，其他人用方形细框（证件照式），没有头像时只有名字。
- 右上角 `AUTO ▷` `SKIP ▷|` 一类的控制用细窄的无衬线大写（`#D4C4B6`）。
- 画面里的旁白或无人名的字幕居中，不写人名，也不加线。
- 双语字幕：上中文宋体，下英文衬线，无底框，中文约画面区高 2.7%、英文约 1.9%，两行间隔约 7px（480p 的比例，按高度换算）。

## 11. 头像与相框

- 主角：菱形（45° 方形）相框。
- 其他人：方形细框，像证件照；或齿孔边的小方框。
- 回忆：整个画面装进一张泛黄旧照片：圆角暗框 + 深暗角 + 棕褐偏色 + 灰尘点。
- 作品缩略图：蛋形裁切（竖长的圆角椭圆）+ 一条从一侧穿过的 1px 锈色轨道线 + 另一侧一片渐隐的网点；或者单圆角框 + 一圈偏移 8–12px 的细线框。

---

## 12. 载入页

- 满屏一张降饱和、偏灰绿的插画，**或**近黑底中央一件很小的旧物（电视、磁带、沙漏）。
- 左下一个百科词条：标题约 48px 衬线 + 断开的下划线 + 两行定义（这一页的“知识”）。
- 底部约 125px 的近黑带；进度条压在黑带上沿（见第 7 节“载入”）；黑带中央两行状态小字。
- 字只有四处左右。词条的口吻是百科全书，不是“小贴士”。

## 13. 新部件怎么推

遇到这里没有的部件时，按顺序问：

1. **它在 1900–1999 年的现实里是什么东西？** 日程 → 台历；数据 → 展签；进度 → 刻度尺或电平表；章节 → 海报；分集 → 胶片格；消息 → 带邮戳的信；收藏 → 回形针；下载 → 取件单或票根；筛选 → 档案柜的索引签；排序 → 卡片盒的分隔卡。
2. **取那件东西的哪一个局部？** 部件只取一个局部（票根的打孔线、展签的字段、台历的线圈），不是把整件东西画出来。
3. **套上母版：** 宋体 + 下挂英文、锈橙只给一个状态、1px 断线、一个印刷记号。
4. **动起来像那件东西：** 纸落下、纸带展开、票根撕开、印章盖下、指针转到位——动作短（200–300ms），不回弹。
