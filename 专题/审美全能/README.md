# AI审美全能

测试专题「AI审美全能」的题目。网址标识为 `aesthetics`，上线后在总站的 `/aesthetics/` 下。

本专题不打分：没有评分指南、评分员和成绩表，只展示各模型的作品，由观众自己比较。

类别：创意网页设计、卡通渲染（三渲二）、PV设计、硬表面建模、大型场景建模、体素建模、SVG动画、白模渲染、字体与Logo设计、游戏UI设计。

- `专题.json`：专题清单，写明类别、题组和每道题的属性（限时、交付物、作答资源）。评法是展示（`evaluation.kind: showcase`），测试时长按实际作答时长计（`costs.hours: measured`）。
- `参测.json`：参测型号与所用智能体、推理强度。
- `题面\<类别>\<题名>.md`：题面；同名文件夹放交给受测模型的公开材料。
- `展示文案.json`：10 个创作方向按展示顺序的中英文案（点题短语、主要内容、看点）和点评评委，视频的题目介绍页和网站的题目页共用；格式写在文件开头的 `format`。

## 测法与时长规则

- 测法是平台的限时智能体作答（题目字段 `test_method: timed_agent_workspace`）。作答流程、叫回与交卷、隔离和共同规定见[平台说明](../../README.md#通用测试形式)。
- 时长规则写在 `专题.json` 的题目字段：`minutes` 是最长作答分钟，`min_minutes` 是最短作答分钟。累计作答未满最短时长时，每轮结束都叫回继续；满了之后，模型一轮正常结束即交卷；到最长时长强制交卷。
- 端口写在题目字段 `answer_resources.ports`：作答时由平台分配，写在开场提示里，题面不写死端口。
- 开场和续做的文字、叫回语在本机配置 `orchestrator\topics\aesthetics\`，不在本目录。
- 作答关闭后不评分，作品只导出素材展示。
