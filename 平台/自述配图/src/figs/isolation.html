Isolation

公平与隔离Fairness and isolation

作答和评分在同一台机器上，用两个 Windows 账户分开；挡住受测会话的是系统权限，不是一句嘱咐。Answering and grading share one machine but run under two Windows accounts; what holds a tested session back is system permissions, not a request.

受测账户Tested account

专用的普通账户，不在管理员组a dedicated standard account, not an admin
单独登录Own logon每个会话一次登录，进程权限收紧到这次登录each session is a separate logon; its processes are bound to it
作业对象Job object会话的全部进程都在里面，到时一并结束holds every process of the session; all end at time
作答目录Work folder按专题、型号、题分开，只放本题题面和材料per topic, model and task; only this task's files
智能体Agent不开沙箱和审批，能做什么由账户权限决定no sandbox or approvals; the account decides what it can do
同时作答的每个会话各有一套，彼此结束不了对方的进程every concurrent session gets its own set and cannot end another's processes

管理员账户Admin account

题库仓库Repository题面原件、评分指南、参考答案、隐藏数据和测评程序original statements, grading guides, reference answers, hidden data, benchmark code

记忆清空Memory wiped

开测前清空受测账户里智能体的记忆，作答时关闭自动记忆

Agent memories in the tested account are cleared before testing; auto-memory is off

同一套浏览器Same browser

都接 chrome-devtools-mcp：本机无窗口 Chrome，用显卡，每次独立的临时用户目录

All use chrome-devtools-mcp: local headless Chrome on the GPU, a fresh temp profile each time

专用端口Own ports

要起本地服务器或调试端口的题，平台给每个会话分配专用端口，同题并行也不冲突

Tasks needing a local server or debug port get ports per session, so parallel runs never collide

占机互斥Machine claims

独占整机的题作答时不开别的作答；需要安静机器的题作答时不评分

No other answering beside a whole-machine task; no grading while a quiet-machine task runs
