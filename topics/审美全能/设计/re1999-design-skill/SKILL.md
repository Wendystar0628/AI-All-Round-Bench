# 1999 设计语言（re1999-design）

这份 skill 教你做出“一看就是那个味道”的原创设计：不用它的任何素材，只用它的想法、比例、色值、字和动作。它只讲这套设计语言本身；项目自己的主题怎么接进来，由项目的设计决定（开工前先定的系列常量见 `references/reskin.md` 第 7 节）。

> **一句话：把每一件信息做成二十世纪的一件印刷品或旧物，再用老电影的光去拍它。**

---

## 底层逻辑：七条

1. **先有物，后有界面。** 每一条信息先问“它在 1900–1999 年的现实里是什么东西”：入口是门票，进度是刻度尺，档案是美术馆展签，章节是电影海报，分集是一格胶片，消息是盖了邮戳的信。按钮和面板只取那件东西的一个局部（票根、索引签、刻度）。
2. **骨架锁死，只换皮。** 槽位、字体系统、组件几何、颗粒规矩、命名规则从头到尾不动；每个子主题只换标题字的“时代戏服”、一个主色相、一种材质、一种画法、一到三个母题、一个有第二眼的意象。换皮靠借那个年代真实的印刷物和媒介，而不是用自己的画风去画题材。
3. **暗而有物，暖而不亮。** 八成以上是近中性的低色度颜色；暗部带色相（藏青黑、墨绿黑、棕黑），从不是 `#000`，而且暗里看得出墙、窗、光和影；最亮处是象牙和奶白，从不是冷白；只有一口锈橙，占一屏不到 5%。
4. **中文给人读，英文当纹理。** 中文全部宋体，大标题用细横粗竖的高反差宋；英文换着性格（Didone、书籍衬线、签名草书、细窄大写），要么比中文小一半，要么大到变成背景，从不同大并排。
5. **字比画轻，装饰止于一圆一线一星。** 线是 1px、很淡、末端断开；装饰只长在标题、边、角和按钮角上，不拿来填暗部；一到要读的地方，装饰全部撤掉。
6. **一件做出来的物件，一处精确的错误，一个第二眼。** 每一屏有一件被光照着、影子落在别处、带点画明暗和材质的物件；标题上放一处“逆转”的签名（一个镜像字母、一笔被双斜线截断）；主体上放一个第二眼（手同时是雪原）。其余全部端正。
7. **先空一下，再一下子出来，然后久久不动。** 揭晓前先黑、先静；入场指数减速、不回弹；停留是动效的主体；退场 70–150ms 或硬切；最重要的字出现得最慢。

## 一页总纲

### 不变的（母版）和变的（皮）

| 母版：全程不动 | 皮：每个子主题换一套 |
|---|---|
| 带色相的近黑 / 炭灰底，暖白纸；暗里有场景 | 一个主色相，整片往它上面调；明暗基调（暗底、亮底或中等明度） |
| 一口锈橙（`#B55829` / `#C25E30`） | 题材色可以接替锈橙，但不和它并排 |
| 中文宋体（大标题高反差宋）；西文 Didone + 书籍衬线 | 英文标题字穿那个年代的“戏服” |
| 1px 断线、四角星、斜线、菱形、轨道 | 1–3 个母题，只放在标题徽记、组件两端、卡片四角 |
| 槽位与组件几何 | 一种主材质（金箔、霜、墨、蓝图格、网点、马赛克……） |
| 颗粒按媒介定的一套规矩 | 一种画法（平面水粉、剪纸、版画线刻、剪影、拼贴、三维小景） |
| 电影框架：片名、档期、演职员表、黑场 | 一个有第二眼的代表意象；开场的媒介、转场的物件 |
| 故事内命名（入口是动作、列表是文件） | 这一段的词表与题记 |
| 一个贯穿全系列的超现实异象，每个世界出现一次 | 异象在这个世界里的形态 |

### 关键数字

| 项 | 数值 |
|---|---|
| 画幅 | 母版 16:9；叙事、欣赏、片头段落 2.35:1（1080p 上下各 132px 黑边，`#0C0D0C`，只放进度尺） |
| 边距 | 图标和字标贴边 44px（2.3%W）；正文与按钮 75px（3.9%W） |
| 中央留画 | 槽位页屏宽中间 40–60% 不放界面；标题簇 ≤35%W，放在主体让出的暗处；仪式画面居中对称 |
| 平均亮度 | 黑场类 2–8%；仪式暗场 8–15%；有景的暗（界面、介绍页）15–30%；满版画面 25–45%；纸面 70–85% |
| 色度 | 近中性（Lab C\* < 15）像素：界面与暗场 ≥80%，主题画面 ≥50%；鲜艳（C\* ≥ 35）：界面 ≤5%、登场舞台 ≤12%、主题画面 ≤15% |
| 影调 | 画面黑位约 10/255、白位约 215/255（字和星用令牌色，可到 240）；近白 ≤2%；最亮处 R 比 B 高 10–40；四角亮度为中央同种底色的 0.4–0.6 |
| 颗粒 | 平整处起伏：界面与字卡 2–4 级；平面图形段、海报式意象 4–8 级；三维、绘画、展示的作品 0 |
| 字号 | 两极：展示字与正文 4–7 : 1；标题与微型字 5–8 : 1；一屏最多四档 |
| 中英比（按字号） | 按钮下英文 0.3；纸卡 0.55；第二声部：斜体短语 0.45–0.5（不透明度 35–50%），大写关键词 0.55–0.65、宽度 ≤ 中文行 60%；中文片名为英文主词的 0.35–0.5 |
| 放大 | 中文只放大首字（1.3–1.6 倍）或末字（1.5–1.8 倍并下沉）；西文首字母 1.75–2.4 倍，共基线 |
| 字距 | 身后大词 0.4–0.5em；当线用的英文 1.5–2.6 倍字高；中文大标题 0；作副标的中文 0.2–0.5em |
| 行距 | 中文正文 1.8–1.85；英文 1.5–1.6；演职员表 2.0 |
| 线 | 1–2px；只比底亮 10–15 级；三截线 62｜18｜1021｜18｜74 |
| 倾斜 | 纸片 1–5°；标题牌 −4°；结果网格 5° 透视 |
| 疏密 | 8:2——一屏一半的细节在约五分之一的面积里 |
| 动效 | 落定 `cubic-bezier(0.16,1,0.3,1)`；大字从 4 倍缩回 τ≈0.22s、约 1.1s；片头标题卡线性淡入 2.4s；弹窗开 200–230ms、关 70–100ms；网页入场 0.5–0.8s、位移 32–48px |
| 镜头 | 叙事慢推 1.5–2.5%/s + 横移约 1%W/s；字卡锁死或拉远 0.2–1.7%/s |
| 节奏 | 叙事跟台词；展示镜头 4–8s、切点比强拍早约一拍；揭晓前 0.3–1s 声音凹陷；段落之间黑场静音 1–2s |

### 字体速查（全部本机已装，开源）

中文大标题 **站酷小薇 + 竖笔加粗**（高反差宋）· 中文主力 **思源宋体 CN**（700 页面标题 / 600 标签 / 400 正文；900 只给金属字和铅字卡）· 铅字感 **寒蝉活宋体** · 引文 **霞鹜新致宋** · 题记 **朱雀仿宋** · 西文标题与斜体 **Playfair Display** · 巨号数字 **DM Serif Display** · 拉开字距的古典大写 **Cormorant Garamond** · 英文正文 **Source Serif 4** · 签名 **Great Vibes** · 系统微型大写 **Oswald 300** · 打字机 **Courier Prime** · 像素 **Ark Pixel**。斜体只用 Playfair Display。中文不用黑体。详见 `references/typography.md`。

### 色值速查

炭灰底 `#242423` · 深底 `#141514` · 黑场与黑边 `#0C0D0C` · 暖光晕 `#654838` · 纸 `#E8E2D8` · 字 `#E6E2DD` / `#BDB3AA` / `#8F8A85` · 象牙 `#E9DCCD` · 标题渐变 `#F2ECE2 → #E2D3B8` · 沙色英文 `#BBA893` · 锈橙 `#B55829` · 主按钮 `#C25E30`（网页 `#AE5228`）· 选中 `#DE6B34` · 红日 `#A63A39 → #8F3433` · 铜金大词 `#90744E` · 星 `#F0EADF` · 石油青 `#2F4552`。详见 `references/color.md`。

## 怎么开工

1. 读 `references/logic-and-taste.md` 的“分寸”一节和 `references/imagery.md` 的第 1–4 节。前者决定做出来是“那个味道”还是“像的仿作”，后者决定画面是“一个地方”还是“一张幻灯片”。
2. 先定系列常量（`references/reskin.md` 第 7 节），再为每个子主题填一张换皮参数卡（同一文件第 3 节）。
3. 引入 `assets/tokens.css`、`assets/textures/texture-kit.css`（颗粒瓦片已内联，复制就能用）；需要点画渐变、颗粒、竖笔加粗、粗糙边时用 `assets/textures/texture-kit.js`；装饰从 `assets/svg/` 取。
4. 先画画面（场景、光、物件），再排字，最后加装饰；版式按 `references/layout.md` 的槽位放，部件按 `references/components.md`，动作按 `references/motion-video.md`。
5. 做视频看 `references/apply-video.md`，做网页看 `references/apply-web.md`。
6. 打开 `templates/specimen.html` 对照：令牌、字体、装饰、纹理、标题排法、介绍页、片头标题卡、分寸对照和换皮都在上面（`?p=1` 到 `?p=11` 单独看每一张）。
