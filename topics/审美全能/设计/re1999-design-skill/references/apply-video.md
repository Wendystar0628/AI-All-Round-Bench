# 应用到视频

这份文件把前面的语言落到一部“展示片”的各个段落上：开场、汇总、介绍页、人物登场、讲话与字幕、作品展示、进度条、落版。数值按 1920×1080、30 或 60fps。

一部展示片在这套语言里是一场**电影节**：每一项内容是一部参展片，有自己的海报、片头和展签；整场有统一的节目包装。

---

## 1. 整片的骨架

- **母版 + 子风格。** 全片统一的：字标位置、角标、字幕位置、进度条、章节卡的布景、介绍页的槽位、字体、颗粒规矩、宽银幕。每一项内容自己换的：标题字、主色相、明暗基调、主材质、画法、母题、代表意象、开场媒介、转场物件（方法见 `reskin.md`）。
- **底色怎么连贯。** 母版页——汇总页、评委登场、点评、清口底景——固定用同一种暗底。每一项的介绍页和意象按自己的材料定底：可以是暗底，也可以是亮底或中等明度（雪、纸、海、正午）。亮的一段夹在两个暗的母版页之间，本身就是段落标记。
- **层级与转场对应。** 大段落之间用黑场加静音；每一项内容开头用章节卡（全片唯一的强入场）；同一项内部的镜头之间硬切或柔扫。
- **清口底景。** 一项内容结束、下一项开始之前，回到同一个中性底景 1–2 秒（暗室里一束顶光、一张星图底、一个空舞台）。它让每一项的子风格都从同一个“零点”出发，观众不会被上一项的颜色带着走。
- **节奏是欣赏的节奏。** 展示段的镜头 4–8 秒，切点落在小节线上；停留比运动多。没有比分、没有倒计时的片子，更要靠“停住”给分量。

---

## 2. 开场

开场分两部分：一个起手页，然后一段连续运镜的动画，把各个方向依次走一遍。

### 2.1 起手页

起手页是全片最安静的一屏：宽银幕，近黑，正中一组字，95% 的画面是黑。它的分量来自慢和空，而不是来自东西多。

**落定的画面**（版式细节见 `typography.md` 9.9、9.10）：

- **宽银幕**：2.35:1，黑边 `#0C0D0C`，黑边里什么都不放（这一段不显示进度条）。
- **一件小物**：画面里只有一件发光或被照亮的小东西（一颗长芒星、一盏灯、一枚印章），宽不超过画宽 8%，放在字组上方或下方的中线上。它是这一屏唯一的“图”；它也可以就是系列的异象，让异象在全片第一次露面。
- **片名**：高反差宋，居中，宽约画宽 27–35%，暖白。下面一根短发丝线、一行字距极开的英文。
- **交代“有哪些内容”**：用一块演职员表式的小字（`typography.md` 9.10）——三四行窄体大写或宋体小字挤成一块，按出场顺序写全部条目，用竖线或斜线隔开；或者在一条横贯全幅的细线上，条目名一个一个亮起来。不要给每个条目配一个图形、一个编号排成一圈。
- **字一共五处以内**：片名、英文行、演职员表块、一行日期或标语、角落里极小的出品字。
- **不放的东西**：星图、轨道圈套轨道圈、竖排拉丁字、大圆盘、立体的大物件、身后大词。这些属于舞台和海报，放到起手页上就成了信息图。

**出现的过程**：
- 黑场 1.0–1.5 秒，声音也是空的。
- 那件小物先出现：一颗星点亮（0.1 秒的暖光团收成星），或一盏灯亮起。
- 字组线性淡入 2.4 秒，不缩放、不位移。
- 演职员表块在字组之后再淡入，或者条目名按出场顺序逐个亮起（每个 0.15–0.3 秒）。
- 停 3–4 秒，只有那件小物在动（呼吸、慢转）。

### 2.2 连续动画（把各个方向串起来）

- **一镜到底的连接法：** 一个锚点物件始终在画面里（一颗星、一只表、一张纸），镜头横移或下摇；画面里的分界线（地平线、书页边、光束边、一道撕口）扫过画面，变成到下一段的擦屏边。
- **图形匹配：** 上一段的一个形状变成下一段的一个形状（圆盘 → 表盘 → 透镜；方格纸 → 像素 → 窗格）。
- **媒介穿越：** 镜头推进上一段画面里的一块屏、一扇窗、一个取景器，里面就是下一段。
- **每一小段 3–4 拍，每拍 1.5–3 秒，每拍只有一个图形想法**：媒介 → 媒介里的图形 → 推进 → 定格在这个方向的意象和标题上。
- **画法跟着题材换**：每一段用这个方向自己的画法（`imagery.md` 第 3 节），平面手法（剪纸、网点、蓝图线、铅字）和三维手法（微缩沙盘、景深推镜、剖开的娃娃屋）交替；每一段内部只用一种主手法。画法一换，观众就知道进了下一个方向。
- **转场多样但不堆叠：** 相邻两次连接不用同一种手法；一次连接只用一个想法（要么图形匹配，要么分界线擦屏，要么媒介穿越），不在一次连接里叠三种效果。
- **标题在每段只停一下**：定格时这一段的题材字标题出现（0.3 秒从虚到实），停 0.8–1.2 秒，随下一次连接离开。

## 3. 汇总页

一屏展示所有项目。在下面几种里选一种，全片只用这一种：

| 形式 | 做法 |
|---|---|
| 海报墙 | 一排竖版海报卡（每张一个项目的片名、编号、一行演职员表式小字），卡下一行衬线名；背后一行字距极大的大写水印 |
| 书封墙 | 同上，但每张是一本书的封面，书脊一侧有一条色带 |
| 票根排 | 一排斜放的票根，每张一个编号和名字，打孔线一侧是项目的主色 |
| 胶片条 | 一条横跨画面的胶片，每格一个项目的小画面和斜体编号 |
| 天文图 | 项目是图上的节点，金色细线连成一条路线，当前节点是一个新月环包着的巨号数字 |

- 整组可以摆在倾斜约 5° 的透视平面上，像桌上的一叠卡；四周印几个表格标签和竖排符号，像一张盖了戳的档案表。
- 入场：卡片依次从画外飞入，间隔 50–80ms，land 曲线，0.5s 落定；然后镜头锁死停 2–3 秒。
- 每张卡用各自项目的主色相，但卡的版式完全一样——这一屏就是“骨架不变、皮在换”的总预告。

## 4. 介绍页

每一项正式展示之前的一页。主风格是母版，子风格是这一项的皮。

### 4.1 画面

- **一张满版的画。** 代表意象不是放在空底上的一件东西，而是一张铺满全屏的画：同一个场景从右边一直延伸到左边，左边那一片更暗、更虚、细节更少，字就写在那里（`layout.md` 3.5）。场景怎么“有内容”见 `imagery.md` 第 1 节，意象怎么画见第 3、4 节。
- **原生媒介留一点痕迹**：开场是从哪种媒介推进来的，静帧里就留一点它的痕迹——底纹里的方格纸、画面边上的屏幕圆角、远景里的地图等高线。
- **装饰**：一条线（轨道或断线）、一两颗星，其余不加。画里真有一扇拱窗、一个圆，就让它们来当“框”和“圆”。

### 4.2 槽位（16:9）

| 槽位 | 位置 | 放什么 |
|---|---|---|
| 左上 | 离边 44px | 系列字标（很小） |
| 右上 | 74–96%W，2–7%H | 系列小标 `◆◆ 系列名`（不写编号） |
| 标题簇 | 意象让出来的那一边的暗处，宽 ≤35%W | 编号（`07` + 四角星 + 类别小字）→ 题材字标题（英文或中文当图）→ 中文题名（宋体）→ 一行斜体副标或题记（字放不下时省掉） |
| 主要内容 | 标题簇下方 | 一到两句宋体，说清这一项是什么 |
| 看点 | 主要内容下方，或右栏 78–96%W、25–70%H | `✦ 一句话 ≫` 三条，每条下面一条细下划线 |
| 进入 | 右下 72–96%W，78–94%H | 一张票根：票面写这一项的片名，票根写这一项故事里的动作（不再写编号） |
| 中央 | 50–60% 面积 | 代表意象 |
| 底部 | 94–98%H | 进度条（见第 8 节） |

**“进入”在视频里怎么用**：票根是一个动作的预告。介绍页的最后，票根沿打孔线被撕下（0.2 秒，撕下的一半往下落出画），紧接着转场进作品展示——观众“检了票”，就入场了。

### 4.3 入场顺序

原生媒介（0.5–1.5s）→ 推进到意象，停稳（0.5s）→ 标题簇晚 0.3s 出现（编号先，中文从虚到实，英文淡入）→ 看点逐行淡入并右移 24px，间隔 0.1s，每行的四角星先闪一下 → 票根和角标最后淡入（0.3–0.5s）。之后停住，直到这一页结束。

### 4.4 文字

- 主要内容：一到两句，宋体 30–32px，`#E6E2DD`（亮底上 `#2B2723`），每行不超过 20 个字，最多两行。
- 看点：三条，每条一句、不超过 14 个字、一条一行，宋体 28–30px；行首四角星，行尾 `≫`。
- 放不下时：先改写缩短，再减条数，再把说明减成一句；字号不往下缩（`layout.md` 3.5）。
- 英文：标题后面一层大号英文片名作底纹（10–20% 不透明度），或一行斜体短语作第二声部。看点不配英文。
- 编号：一屏最多出现两次（标题簇、刻度尺）。

### 4.5 质地

- 自己画的画面（底、意象）按 `motion-video.md` 第 10 节的曲线调色；字和部件叠在调色之后，用令牌原色。
- 颗粒：平面画法的意象和底加 4–8 级的颗粒；三维小景本身不加，颗粒只加在它外面的底和暗角上。

## 5. 人物登场（几位讲解人或评委集合）

### 5.1 集合

- 几个人同时在场时，**每人在一个形状里**：一个拱窗、一个圆盘、一个画框，三种形状不同但大小相近，错落排开（不排成一条直线，高低差约 5–8%H）。
- 或者每人身后一个光圈（`imagery.md` 第 2 节），颜色取各自的签名色（降到中等色度），人物站在光圈前，影子落在光圈上。
- 背景是同一个中性舞台：暗底、一束顶光、一层只比底亮 3–5% 的三角暗纹。

### 5.2 依次点名

每人轮到时：

1. 其他人压暗到约 45% 亮度并轻微虚化（0.3s）。
2. 轮到的人：一次很短的白闪（0.2s，落在一个起音上）→ 身后的圆盘或形状亮起 → 名字从虚到实（0.3s）→ 名字下面一条两端渐隐的发丝线画出（0.4s）。
3. 名字旁边一枚小徽章（菱形套四角星）；一侧竖排一行极小的身份字；一笔签名色的手写签名横过名字下方。
4. 自我介绍的一句话以字幕出现（见第 6 节），说完停 0.5–1s，换下一位。

### 5.3 站立时的小动作

- **常驻的呼吸：** 缩放 1.000→1.006，周期 4–6 秒，正弦；锚点在脚下（不是中心），这样是“胸口起伏”而不是“整个人在缩放”。
- **说话时：** 每一句开头最多一次很小的动作——向上抬 0.6–1% 画高、或向前倾 0.5–1°，0.25s land 曲线出去，0.4s 回到原位。一句一次，长句也只一次；相邻两句至少隔 2 秒。
- **眨眼（如果立绘分层）：** 每 4–7 秒一次，约 120ms。
- **不做：** 弹跳、抖动、左右摇摆、频繁缩放、夸张的嘴型。人物的分量在于“站得稳”。

## 6. 讲话、点评与字幕

**没有对话框。** 字直接写在画面上，靠底部渐暗保证可读。

| 元素 | 规格 |
|---|---|
| 底部渐暗 | 从约 62%H 开始，由透明到 `#171111` 约 85% |
| 人名 | 衬线或宋体，约 44px，暖灰 `#B8AEA9`；左起约 21.5%W；人名后面可以接一个极小的身份英文 |
| 分隔线 | 人名下一根 2px、只比底亮约 15 级的线，断成三截：62 ｜18 缺口｜ 1021 ｜18 缺口｜ 74（整体约屏宽 62%） |
| 正文 | 宋体 30–32px，`#E6E2DD`，行距 1.7，宽约屏宽 62%（每行约 36 个汉字）；约 100 字的一段是三行 |
| 继续标记 | 右下角一个小 `▽`，说完时出现 |
| 立绘 | 站在画面一侧（左或右三分之一），脚或腰被底部渐暗吃掉一截；人物和正文不重叠 |

**文字和语音同步**，两种做法任选，全片统一：

- **按句：** 每一句在语音开始的同一帧从虚到实（模糊 6px→0，透明度 0→1，0.2s），已经说完的句子保持不动。
- **按字：** 每个字在语音读到它时出现，约 0.06–0.1s / 字，每个字带一点虚化。按字更“活”，但更忙；点评这种安静的内容，按句更合适。

说完以后整段停 0.8–1.5 秒再淡出（0.15s）。字幕不滚动、不翻页；一段超过四行时拆成两屏，两屏之间淡出淡入 0.2s。

## 7. 作品展示

**作品是展品，不是素材。**

- **不改作品：** 不调色、不加颗粒、不加色散、不加暗角、不裁画面。胶片感只加在作品外面：框、底、黑边、角标。
- **按作品原比例完整呈现。** 宽银幕黑边只给叙事和片头段；作品段按作品自己的比例放，四周是展墙或暗底。
- **展签：** 作品旁或作品下方一条极小的展签（像美术馆墙上的标签）：编号、名称、作者（模型名）、媒介，衬线小字，`◆` 分隔。
- **画框：** 单圆角框 + 一圈偏移 8–12px 的细线框；或者蛋形裁切 + 一条从一侧穿过的锈色轨道线 + 另一侧一片渐隐的网点。框是展墙的一部分，不压在作品上。
- **镜头：** 静态作品可以极慢地推（≤1% / 秒）或者完全不动；动态作品原样播放，不叠镜头运动。
- **切换：** 同一项里的作品之间硬切或 0.3s 淡入淡出；不要用物件转场打断作品。
- **作品自带声音时不放配乐**；需要配乐时，讲话段落配乐压低 10–14dB。

## 8. 底部进度条（刻度尺）

| 元素 | 规格 |
|---|---|
| 位置 | 约 96%H（16:9 画面）；宽银幕段落就放在下方黑边里，竖直居中 |
| 主线 | 1px，`rgba(233,220,205,.35)`，从左边距到右边距 |
| 刻度 | 每一项一个大刻度（10px），项与项之间均分小刻度（4px） |
| 已走过 | 主线变亮到 80%，粗 1.2px |
| 当前项 | 一个 ◎ 定位环（外圈直径约 18px、1.3px 线，中心 5px 实心点），锈橙；上方写 `07/ 名称`（编号衬线 18–24px，名称宋体 15–18px）。名称写这一项自己的题名；类别写在介绍页标题簇的编号行里 |
| 之前的项 | 只写编号，字更小、更暗（50%）；紧挨着的前一项旁边一颗带长芒的小星 |
| 之后的项 | 只有刻度，不写字 |
| 动 | 换项时定位环沿线滑到下一个刻度，0.6s，land；当前项内部，已走过的亮线随时间线性生长 |

进度条在介绍页、作品段、点评段一直在；起手页、章节卡、黑场、登场舞台这类仪式画面里隐去（0.3s 淡出），仪式结束后淡回。

## 9. 落版

- 黑场 1–1.5s，声音收住。
- 字标先长出它最有辨识度的那一笔（0.6s），再长成整组字（1.0s）；下方一行拉开字距的小字，从左到右显现（0.4s）。
- 停 2.5s；淡出 0.3s。不加粒子和光效。

---

## 10. 合成层顺序

一帧从下到上：

1. 底色（暗地或纸）
2. 远景、暗纹、光（窗光、光锥、光晕）
3. 圆（一盏光）、轨道、拉开字距的大词
4. 主体或作品（作品在这一层被框起来，之后的层不压到作品上）
5. 前景虚化的遮挡物
6. ——到这里是“画面层”，在这里调色——
7. 暗角
8. 颗粒（按媒介定强度；作品区域和三维画面内不加）
9. 标题、文字、标签（令牌原色，不调色）
10. 签名笔画、四角星
11. 宽银幕黑边、进度条、角标

---

## 11. 声音

- 每次揭晓前留 0.3–1 秒的音量凹陷；揭晓落在之后的第一个强音上。
- 大段落之间的黑场里，声音降到几乎无声。
- 界面声用实物的声音：翻纸、放映机、打字机、印章盖下、撕票。
- 讲话时配乐压低；讲话结束后 0.5s 再把配乐推回来。
