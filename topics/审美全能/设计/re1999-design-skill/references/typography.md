# 字体与文字处理

一句话：**中文全部宋体，负责被读；英文换着性格，负责气质。** 大标题的宋体要“细横粗竖”——横画细到像发丝，竖画粗——它和 Didone 的粗细对比是同一种气质，所以中英放在一起不打架。

字体栈也写在 `assets/tokens.css`（`--re-font-*`）。

---

**两条硬事实：**

- **斜体只用 Playfair Display Italic（或 DM Serif Display Italic）。** EB Garamond、Source Serif 4、Cormorant Garamond、PT Serif、Libre Baskerville 在本机都没有真斜体文件，CSS 写 `font-style: italic` 会得到机械倾斜的假斜体，笔形是错的。
- **中文不用黑体。** 黑体只在 12px 以下的纯数字或版权行里可以出现。任何标题、标签、按钮、正文用黑体，整页都会被拉回现代 App。

**站酷小薇的字库**是 GB2312 的 6763 个常用字。碰到它没有的字（日文汉字、生僻字），那几个字回退到思源宋体 500，同样加竖笔。

**不走浏览器的工具**（PIL、ffmpeg drawtext、Blender）按字体文件找最稳，字体都在 `C:\Windows\Fonts\`：`ZCOOLXiaoWei-Regular.ttf`、`SourceHanSerifCN-{Regular,Medium,SemiBold,Bold,Heavy}.otf`、`PlayfairDisplay-{Regular,Italic,Bold}.ttf`、`DMSerifDisplay-Regular.ttf`、`CormorantGaramond-{Medium,SemiBold}.ttf`、`SourceSerif4[opsz,wght].ttf`、`GreatVibes-Regular（商免）.ttf`、`Oswald-Light.ttf`、`Courier Prime.ttf`、`ZhuqueFangsong-Regular.ttf`、`LXGWNeoZhiSong.ttf`、`ChillHuoSong_F_Regular.otf`。这些工具里 Cormorant 的家族名带字重（“Cormorant Garamond SemiBold”），朱雀仿宋的家族名会被截短，按文件名指定就不会错。

## 2. 高反差宋：大标题的中文怎么做

这套语言的大标题中文，横画细到像发丝，竖画粗，横画末端一个尖的三角字脚。它像 Didone 一样靠粗细对比显得贵，而不是靠粗。

**做法：站酷小薇（本身就是细横、尖脚的宋体），把竖画单独加粗。** 竖画加粗用一次只朝水平方向的膨胀：水平膨胀只让竖画变宽，横画几乎不变，粗细对比就拉开了。

| 字号 | 竖画加宽（左右各） | 说明 |
|---|---|---|
| 80–120px | 1.5–2px | 约 0.018em |
| 120–180px | 2–3px | 约 0.018em |
| 180px 以上 | 字号 × 0.016 | 再粗就开始像粗宋了 |

```html
<!-- 一次注入，整页可用；JS 也可以用 ReTexture.injectFilters() 自动生成 -->
<svg width="0" height="0" style="position:absolute" aria-hidden="true">
  <filter id="re-stem-2" x="-5%" y="-5%" width="110%" height="110%"><feMorphology operator="dilate" radius="2 0"/></filter>
</svg>
<h1 style="font:400 128px/1 'ZCOOL XiaoWei';filter:url(#re-stem-2);
  background:linear-gradient(180deg,#F2ECE2,#E2D3B8);-webkit-background-clip:text;background-clip:text;color:transparent">静物夜曲</h1>
```

Canvas 里做同一件事：同一行字在水平方向错开画几遍（`ReTexture.fillTextStem(ctx, text, x, y, 2)`）。

**填色**：暖白到象牙的竖向轻渐变（`#F2ECE2 → #E2D3B8`），加颗粒；亮底上用墨 `#2B2723`。不用大块金渐变，不加投影和外发光——那是“金属字”的做法，只在需要金属字时用粗宋去做。

> **正反对照。** 刚好：细横粗竖的宋体，暖白，字距 0，最后一个字放大下沉，下面压一行半透明的斜体英文。走样：最粗的宋体刷满金渐变，再加投影。前者像一本书的书名页，后者像一盒月饼。

## 3. 中西文怎么搭

**原则：一个画面只有一种语言“当图”。** 要么英文题材字当图、中文宋体退为副标；要么中文（高反差宋或书法）当图、英文退为注脚。两种语言不抢同一个层级。

英文有五种用法，每次只挑一两种：

| 用法 | 怎么做 | 数值（都按字号比） |
|---|---|---|
| 注脚 | 放在中文下方，左对齐于中文，颜色降一档（暗底 `#BBA893`，纸上 `#6E6860` 或锈色） | 按钮 0.3 倍中文字号；纸卡 0.55 倍；横幅标题 0.22 倍；字距 0.3–0.4em |
| 第二声部 | 一句小写斜体短语，半透明，紧贴在中文下面；再加一个全大写关键词放在右下 | 短语 0.45–0.5 倍中文字号（大写高约汉字字面的 0.4）、不透明度 35–50%；关键词 0.55–0.65 倍（大写高约汉字字面的一半），宽度不超过中文行的 60% |
| 底纹 | 放大到几百像素的英文大词，铺在背景里，常被画面边缘裁掉 | 界面 4–8% 不透明度，海报 10–20%；字距 0.3–1em |
| 一条线 | 字距拉到极开的小号大写，整行当成一根细线用 | 字距 1.5–2.6 倍字高；字高约画面高的 1% |
| 等宽对齐 | 中文一行、英文一行做成完全一样宽，行距很紧 | 两行宽度差 ≤1%；行距约字高的 0.1 |

**“字高”和“字号”**：本文的比例都按**字号**（`font-size`）算。需要按看得见的高度对齐时换算：思源宋体的汉字字面高约 0.93 倍字号，站酷小薇约 0.88 倍；Playfair Display 的大写高 0.71 倍字号，DM Serif Display 0.66 倍，Cormorant Garamond 0.63 倍。

**英文不需要逐字翻译**。它是气氛词：比如中文写“公告”，英文写 `ANNOUNCEMENT`；中文写一行活动说明，英文可以只写 `THE QUIET HOUR`。但它必须和中文说的是同一件事的气氛，不能是随便一串拉丁字母。

**长英文的让位。** 第二声部的大写关键词，宽度不超过中文那一行的 60%。词太长（十个字母以上，或者是两个词）时，按顺序让：先把关键词缩到 0.45 倍字号；还太宽，就只留斜体短语、不放关键词，或者把关键词换成一个更短的词。斜体短语可以比关键词宽，甚至从中文左边伸出去一点，因为它只有 35–50% 的不透明度；不透明的大写英文一旦比中文还宽，就成了“英文当图”。

**中英同大并排是错的。** 两行一样大，读者会以为要读两遍；一大一小或一实一虚，读者才知道“中文在说话，英文在织底”。

### 汉字标题里的拉丁字母和数字

片名里夹着拉丁字母或阿拉伯数字（“X 光”“B 面”“1999 号”）时：

- **字体**：Playfair Display。高反差宋配 Playfair 500–600 并加同样的竖笔；思源宋体 900 配 Playfair 800–900。竖画粗细要和汉字的竖画看起来一样。
- **字号**：配站酷小薇时和中文同字号；配思源宋体时放大到 1.05 倍。这样大写字母的高度约为汉字字面的 0.8，不会显得比汉字还大。
- **基线**：用默认基线，不手动挪。两种字的视觉中线这时自然对齐（汉字的字脚会比字母低一点，这是对的）。
- **间距**：拉丁字母和汉字之间留 0.1em；字母之间按 Playfair 本身的字距，不拉开。
- **数字**：和字母同样处理；日期式的数字（`05/31`）不进汉字行，单独成一行做大数字。

## 4. 字号阶梯

字号的习惯是**两极**：功能字基本一个号，展示字极端放大，中间层级很少。一屏最多四档。

### 4.1 视频（1920×1080）

| 档 | 字号 | 用在 |
|---|---|---|
| 微 | 12–16px（默认 14） | 中文下方的英文、演职员表、角落微字、版权行 |
| 说明 | 22–26px | 说明、次级信息 |
| 正文 | 28–34px（默认 30） | 标签、正文、字幕、对白 |
| 名字 | 40–48px（默认 44） | 人名、小节标题 |
| 标题 | 60–72px（默认 68） | 页面标题、关卡名 |
| 展示 | 96–160px（默认 128） | 片名、大词、日期、巨号编号 |
| 海报 | 片名大写字高约为画面宽的 8–9% | 海报片名 |

字幕和对白：中文字高约为画面区（去掉宽银幕黑边之后）高度的 2.7%，英文约 1.9%，放在画面区里面、离下沿约 3%，不放在黑边里。

### 4.2 网页（桌面 1440–1920）

微 11px ｜ 说明 13px ｜ 正文 17px（中文 16–18px）｜ 名字 24px ｜ 标题 `clamp(36px, 3.2vw, 56px)` ｜ 展示 `clamp(64px, 7vw, 132px)`。导航中文 18px 配英文 12px（3:2），英文字重更细、颜色更暗。

### 4.3 比例（任何尺寸都照这个比，都按字号）

| 关系 | 比例 |
|---|---|
| 相邻两档 | 1 : 1.3–1.4 |
| 展示字 : 正文 | 4–7 : 1 |
| 标题 : 微型字 | 5–8 : 1 |
| 标题字的主词 : 次级词 : 微型字 | 1 : 0.35–0.5 : 0.1–0.2 |
| 海报片名 : 演职员表 | 5.5–6 : 1 |
| 名字 : 副标题（如“— 某某”） | 1 : 0.65 |
| 数字 : 分母、`Lv.`、上限 | 1 : 0.55 |
| 中文首字或关键字放大 | 首字 1.3–1.6 倍；末字 1.5–1.8 倍并下沉 |
| 西文首字母 : 其余字母 | 1.75–2.4 : 1，共用基线 |
| 中文片名 : 英文题材字主词 | 0.35–0.5 : 1 |

## 5. 字距、行距、对齐

- **拉开字距的大写（横在主体身后的大词、印章字、档案标签）**：0.35–0.6em。
- **题材字当主角的主词（logo 化的英文片名）**：按那款字本身的字距，0–0.05em；它靠字形本身说话，不靠拉开。
- **当一条线用的英文**：字距 1.5–2.6 倍字高（例如“S P E C I M E N”）。
- **系统微型大写**：字距 0.2–0.3em。
- **中文大标题**：字距 0，字靠字。
- **作副标的中文**（放在英文题材字下面的中文片名、两三个字的短标签）：拉开到 0.2–0.5em（“提 示”），或用斜线隔字（“即/将/开/映”）。
- **中文正文**：行距 1.8–1.85 倍，段首缩进两字，两端对齐，字距 0–0.02em。
- **英文正文**：行距 1.5–1.6 倍；必要时每行下面一根 1px、10–15% 不透明度的横线，像横格信纸。
- **演职员表**：一行一个名字时，行距为字高的 2 倍，字距约 0.3em；做成一整块“演职员表块”时，用窄体大写，字距 0.08–0.15em，行距 1.3，挤成一块纹理。
- **对齐**：信息区一律左对齐。只有这几样居中：片头标题卡、字标落版、横贯全屏的提示纸带、成就或章节字卡、无人名的字幕和旁白、登场舞台上的名字。
- **加字距后居中**：CSS 和 SVG 都会把最后一个字母后面那份字距算进宽度，居中会偏左半个字距。补一个等于字距的左内边距（`padding-left: .5em`），或者 SVG 里把 x 往右挪半个字距。

## 6. 大小写

- 西文展示字和系统微型字：**全大写**。
- 人名、片名在正文里：首字母大写（Title Case），书籍衬线。
- 第二声部的短语：**小写斜体**（`a nocturne for`、`the belated`）。
- 小型大写混排：首字母放大、其余字母用小一号的大写（`T` `HE STORM` 式），共用基线。
- 一个词里随机几个字母填强调色（票根版式的小节标题）：每个词最多 2–3 个字母，用锈色或浅金。

## 7. 数字

数字是这套语言里的主角之一，它们常常单独成形。

| 用途 | 写法 |
|---|---|
| 日期 | 高反差衬线大数字 + 斜线：`05/31`、`11/14`；起止之间用 `▸`、`—` 或一颗四角星 |
| 年份字卡 | 细衬线年份 `1929` 放在右下三分之一，下面一根向左伸出的发丝线 |
| 编号 | `01/`、`03 ✦`、`No. 0427`、`EP. 01`（斜体）、`2ND 14`（序数缩小上提、编号大） |
| 分数 | 分子大、分母 0.55 倍：`60/₆₀`、`2/2`、`113/113` |
| 等级 | `Lv.` 为数字的 0.55 倍，共基线 |
| 数量 | 用乘号 `×14`（斜体衬线），不用字母 x |
| 卷次、续集 | 罗马数字：`VOL. Ⅲ`、`I / II` |
| 巨号编号 | 小节标题背后压一个淡色斜体巨号 `01`，约 20% 不透明度 |
| 倒计时 | `⏳35天21时`、`5d`、`12h`，斜体，装进绿色描边椭圆 |

数字统一用衬线（Playfair Display 或 DM Serif Display）。等宽的打字机数字只用在编目号、档案号这类“文件”里。

## 8. 符号与标点

- **四角星 ✦**：星级、列点符号、标题两侧点缀、首字母里的亮点。星的竖臂略长于横臂（约 1.15 : 1）。
- **斜线 `/`**：编号（`18/`）、日期、隔字。
- **小菱形 ◆ ◇**：列点、角标、日期行行首。
- **双箭头 `≫` 或 `»`**：列点行尾、文字链（“去看看 »”）。
- **直角引号「」**：框住关键词。英文里也可以直接用（`「NOTICE」`），这是一种一眼可认的口吻。
- **方头括号【】**：说明文字里的术语、活动名，染强调色。
- **`×` 与 `▸`**：数量与展开（“个人属性 ▸”）。
- **感叹号**：广告口吻里可以用两三个（`ENJOY THE SHOW!!`、“开映!!”），像旧报纸广告。正式说明里不用。

## 9. 标题的典型排法

先分清两种标题：

- **标题美术**：一个 logo 化的标题，本身就是画面的主角（片名、海报标题、卡池式标题、片头的大标题）。它可以是几层叠起来的一整块（9.1、9.2、9.8、9.9）。
- **页面上的标题**：介绍页、章节卡、名字卡、小节上的标题。主标题旁边**最多配一个元素**——一道斜线、一段弧、一对四角星、一条下划线，四选一；第二层装饰用底纹英文代替，不用图形。

以下排法覆盖了大多数场合。示例文字都是示意。

### 9.1 中文主角 + 英文第二声部（标题美术，最常用）

- 中文：高反差宋（第 2 节），暖白到象牙的竖向轻渐变加颗粒。
- **放大一个字**：只放大首字或末字，挑那个承载意思的——末字放大 1.5–1.8 倍并下沉（末字的基线比整行低约 0.25 倍常规字号），首字放大 1.3–1.6 倍、站在基线上往上长。意思重心在中间的字上时，一个字都不放大，改用英文关键词去点它。
- 英文第一层：一句小写斜体短语（Playfair Display Italic，0.45–0.5 倍中文字号），35–50% 不透明度。它紧贴在中文下面：顶部和中文字脚重叠约 10–20% 的字面高度，起点和中文第一个字对齐，或者往左伸出半个字。重叠再多，两行就都读不出了。
- 英文第二层：关键词全大写，0.55–0.65 倍中文字号（大写高约汉字字面的一半），宽度不超过中文行的 60%，放在末字下方偏左，顶部被放大的末字压住一点，颜色用主色或沙色。
- 可选：一笔主题色的签名（Great Vibes，70–90% 不透明度，旋转约 −5°），横穿整组字，在最前面。画面里已经有别的“书写”动作（笔尖、手写批注）时不加。
- 可选：最后面一个主题色的巨大首字母或符号当水印，约为中文字号的 3–4 倍，不透明度 8–15%。
- 层级从后到前：水印 → 英文短语 → 主体或意象 → 中文 → 签名。主体可以挡住中文之外的东西，不挡中文。

示意：“迟来的回**信**” ＋ *the belated* ＋ LETTER ＋ 一笔签名 ＋ 背后一个巨大的 L。

### 9.2 英文题材字当主角 + 中文宋体副标（版本式、活动式）

- 英文主词 1.0，次级词 0.35–0.5（常是斜体、小型大写或书写体），微型字 0.1–0.2（外语、编号、口号）。
- 主词字体按题材年代选（见 `reskin.md` 的年代表）；加一个题材徽记（一件物件的剪影）、一种字面材质（金箔、霜、锈、墨、马赛克），字后垫一团暗色污渍。
- 中文片名用宋体，放在英文下方，字号为英文主词的 0.35–0.5，字距放宽到 0.2–0.4em。
- 颜色只用三样：暖白或骨白的高光、深色阴影、一个主题色。
- 两行之间的空隙约为主词字号的 0.5；次级行宽约为主行的 60%。

### 9.3 拉开字距的大词 + 名字 + 星（登场舞台）

- 一个古典大写英文词（Cormorant Garamond 600），放在主体身后，垂直中心约在画高 40–45%。
- **先定宽度，再定字号**：词宽约画宽 45–55%，字距 0.4–0.5em。8 个字母时字号约 0.11–0.13 倍画高（大写字高约 7–8% 画高）；字母更多就缩字距到 0.35em，再不够才缩字号。
- 主体挡住中间 1/4–1/3 的字母，首尾字母露出。
- 颜色：哑光铜金 `#90744E`，左边字母略暗、右边略亮（从左到右的渐变 `#6E5A3F → #B49A6B`）。
- 下方依次：中文名（宋体，约画高 4–5%，在 68% 高处）→ 名字下一条两端渐隐的发丝线 → 一排相切的四角星（星高约名字字高的 1.15–1.4 倍）→ 中文台词（约 86% 高处，`#787979`）→ 外语台词（约 90% 高处，`#555554`）。
- 名字背后可以叠一条较大的金色手写体英文名。

### 9.4 首字放大的地名、关卡名（页面上的标题）

- 一行宋体，首字放大 1.3–1.6 倍（“**钟**表匠的午后”）。
- 上方：编号 `03` + 一颗四角星，前面一个极小的字母代码（4 个字母左右），字号约主字的 0.2。
- 下方：只有一句台词式的引文，不写描述。
- **无框**：文字直接浮在画上，四角压暗。

### 9.5 中英等宽对齐（章节字卡）

- 中文一行（宋体 600–700，或高反差宋）和英文一行（Didone 大写或大小写混排）做成**完全一样宽**，行距只有字号的约 0.1。
- 两侧各点一颗四角星。
- 可以加一点点红青错位（1px 色散），只在这一种字卡上。

### 9.6 宽字距中文压英文巨字（卖点字卡、片头字卡）

- 背景：一个暗红褐色的窄体压缩英文大词，铺满画面，被画面边缘裁掉（10–20% 不透明度或深色低对比）。
- 前景：一行做旧印刷感的粗宋（寒蝉活宋体或思源宋体 900），字距约 0.55em，横跨画宽约 80%。

### 9.7 Didone 首字母放大（网页栏目标题、海报小标）

- 首字母为其余字母的 1.75–2.4 倍，其余用小型大写，共用基线：`T HE STORM`。
- 首字母背后压一个锈色圆（直径约首字母字高的 0.9，不透明度约 50%），圆的一半被字母盖住。
- 可选：最后一个字母做一点横向拖影（这就是这一件的“精确的错误”）。

### 9.8 档案展签（人物、作品、器物的资料）

- 三栏均分的一条信息带：每栏上面是手写斜体的标签（`Birth` `Place` `Century` 一类，Great Vibes 或 Playfair Italic，小而淡），下面是全大写衬线的值（`05/30`、`NEW YORK STATE`、`1930s`）。
- 或者竖排的展签：`◆ Medium` 加一行值、`◆ Dimensions` 加一行尺寸。字段名是衬线大字，值是小一号的衬线，菱形做列点。
- 展签的口吻是美术馆，不是数据库：写“媒介、年代、尺寸、收藏地”，不写“属性 1、属性 2”。

### 9.9 片头标题卡（品牌出场、起手页的落定画面）

全片最安静的一张字卡：黑场正中只有一组字，95% 以上的画面是黑。

- **字组居中**，重心在画面区高度的 36–40%（略高于正中）。
- **片名**：高反差宋，宽约画宽 27–33%（四个字约 128–160px 字号），暖白。
- **片名下**：一根 1px 的短发丝线，宽约画宽 7%，离片名约 0.2 个片名字号。
- **线下**：一行字距极开的大写英文（Oswald 300 或 Cormorant 500），字高约画高 1.9%，字距约 1.7 倍字高，横跨约 18% 画宽。
- **再下面一行**（可选）：一行宋体短句（字高约画高 3–4%），外面套一圈倾斜约 8° 的 1px 椭圆轨道（宽约画宽 26%、高约画高 13%），轨道上停一颗小圆点——这是这张卡唯一的装饰。
- **最下**：出品方一行斜体小字（字高约画高 2.5%）。
- **间距**：上面三样（片名、线、英文）挨得紧，越往下空得越大：从上到下的四段间距约为 1 : 1.3 : 4 : 3.7。
- 字一共不超过五处。没有星图、没有边框、没有编号。

### 9.10 海报式片名 + 演职员表块（起手页要交代“有哪些内容”时）

- 一个大字片名（标题美术），宽约画宽 35–50%。
- 下面一行字距极开的英文标语（像一根线）。
- 再下面一块**演职员表块**：三四行窄体大写挤成的一整块小字（Oswald 300，字高约画高 1.2–1.5%，不透明度 35–50%），写真实的条目名，用竖线或斜线隔开。远看是一块纹理，近看每个名字都读得出。
- 再下面一个年份或日期（衬线，约为演职员表字高的 2 倍）。
- 最下面一根横贯全幅的 1px 锈色线，线上停着一件很小的剪影（一辆车、一盏灯、一颗星）。
- 条目多（十个以上）时，就放进演职员表块，不要一个条目配一个图形、一个编号排成一圈——那是信息图。

### 9.11 小节标题

固定配方：**中文宋体（骆驼色 `#C9A07B` 或暖白）+ 一根短竖线 + 小号英文大写 + 一根向右延伸的发丝线，线尾断成两三小截。**

- 中文 30px（视频）/ 18px（网页）；竖线高度为中文字号的 0.8；英文 12px / 11px，字距 0.26em；发丝线 1px、不透明度 15–22%，长度到容器右边，尾部按“长 82% — 缺口 — 短 6% — 缺口 — 短 3%”断开。
- 可选：标题两边各一根细线和一颗小菱形：`—◆ 小节名 ◆—`。

## 10. 中文标题的四种加工

需要让一行中文标题“像这个品牌”时，在下面四种里选**一种**：

1. **笔画延长线**：把横画向两侧伸出发丝长线，或把撇、捺换成伸出字框的双发丝斜线。做法：在字后面放几根 1px 的横线（SVG `<line>`），位置对齐横画的高度，长度超出字框 20–60%。
2. **首字压圆**：第一个字后面放一个锈色圆盘（直径约字号的 1.1，不透明度 50–70%），首笔叠一片浅色斜切面。
3. **金属填充**：用粗宋，字面是象牙到浅金的竖向渐变，下方一层深色投影偏移 2–3px（只在海报、宣传图这类展示图上）。
4. **收笔换形**：最后一笔换成和题材相关的造型（卷草、触手、齿轮、水波）。这一种最费工，一套片子里只做一两次。

中国题材（新春、武侠、水墨）时，中文可以升格为书法主角，英文退为副标；书法只在中国题材里当主角。

## 11. 文案与命名

文案和字体一样是皮的一部分。

- **故事内命名：** 入口按钮写一个动作（“请入座”“开映”“登船”“翻开第一页”），列表叫一份文件（“放映单”“布光记录”“零件清单”“校样”），资料区是一个地点（“放映室”“暗房”“标本柜”“档案室”），签到是一本刊物，序列用日期或编号。
- **电影化口吻：** 用“上映、首映、开映、敬请期待、STARRING、COMING SOON、演职员表”，不用“上线、开启、活动开始”。
- **题记：** 一段内容可以有一到三行题记诗，口吻是故事里的一份文件或一条广播，比如“灯熄之前，还来得及把最后一页读完”。用仿宋或旧明朝，字号小，行距宽。
- **旁白与引文：** 关卡、地点、展品只配一句台词式的引文，不写描述性的说明文字。
- **演职员表当纹理：** 大量真实可读的小字（演职员表、语言列表、版权行、小字标）铺在角落和底栏，远看是肌理，近看有档案感。
- **广告口吻：** 运营信息如果非出现不可，就写成旧报纸广告的口吻（“本期主演概率提升!!”），而不是手机推送的口吻。
- **按钮下的英文小字：** 每个中文按钮下面缀一行 0.3 倍的英文大写（确认 CONFIRM、取消 CANCEL、提示 NOTICE），统一当“标签”用。
