# 装饰、纹理与材质

一句话：**一圆、一线、一两颗星，再加一种底纹；装饰只长在标题、边缘、角上和按钮的角上，一到需要读的地方就全部撤掉。**

现成的原创元件在 `assets/svg/`，纹理在 `assets/textures/`（`texture-kit.css`、`texture-kit.js`、`noise.svg`）。SVG 的颜色都写成 CSS 变量加默认值（例如 `var(--re-orn-line, #E9DCCD)`）：用 `<img>` 引用时显示默认色；把 SVG 源码内联进页面时，在外层设置 `--re-orn-*` 变量就能换色。

---

## 1. 装饰的总规矩

**预算：一屏一个圆 + 一条线 + 一两颗星 + 一种底纹。** 先分清什么算装饰：

| 算装饰（占预算） | 不算装饰（是部件或画面） |
|---|---|
| 圆盘、光圈、星图、轨道、放射线、刻度圈、印章、邮戳、水印字母、签名花笔、角花、竖排的装饰字、散落的三角、网点块 | 按钮、票根、刻度尺进度条、列表的行首星、页签的下划线、字标；画面里的物件、光、影、暗纹（它们属于画，见 `imagery.md`） |

想再加一件装饰时，先拿掉一件。装饰不能拿来填暗部：暗处要靠场景、光和暗纹（`imagery.md` 第 1 节）。

| 项 | 规矩 |
|---|---|
| 放在哪 | 只在五个地方：标题的徽记、组件的两端、卡片的四角、分隔条、按钮的角。正文、列表、网格、长段说明里一律不放 |
| 线宽 | 1–2px（1080p）。网页 1px |
| 亮度 | 发丝线只比底亮 10–15 级灰；网点只比底色亮 10–20%；装饰整体比正文暗两档以上，永远不和字抢 |
| 形状语言 | 圆（圆盘、轨道、徽章）、直线（发丝线、双斜线、刻度）、四角星、菱形、三角、拱门。弧线、锐角、几何三样一起用 |
| 闭合 | 线要断、框要破：发丝线末端断开；标签文字压在框线上；首字母压在物体上；签名压在标题上 |
| 花饰 | 卷草、铁艺、花朵只在题材需要时出现（新艺术、维多利亚、中式），不是常备件 |
| 实物 | 道具用写实的物件（喇叭、显像管、棋子、唱片、相机），统一做旧偏色；不画扁平图标 |

## 2. 元件库

### 2.1 四角星 ✦ — `star4.svg`、`star4-flare.svg`

- 形：四个尖角、四边内凹，竖臂比横臂长约 1.15 倍。奶白 `#F0EADF`，可带一圈柔光。
- 用法：星级（一排相切的星，星距约等于星宽）；列点符号；标题两侧各一颗；首字母的碗里嵌一颗；画面角落散两三颗。
- 长芒版：中心一颗小星，十字两道发丝光芒（竖长横短，向两端渐隐），中心一团很淡的暖光。用在揭晓、星点亮的瞬间，或一个画面里最重要的那一颗。一屏只有一颗长芒星。
- 分寸：同一屏的装饰四角星不超过 7 颗；一排星级、一串列点、一条轨道上的一串星各算一颗。星比旁边的名字还亮还高时，它就是主角，名字要让位。
- 星本身就是题材时（星空、星图）：大多数星是 1–3px 的点，亮度不一，只有一颗是四角星（`imagery.md` 第 8 节）。

### 2.2 倾斜的椭圆轨道 + 小行星点 — `orbit.svg`

- 形：1px 椭圆，倾斜约 10°，在某一处断开一个缺口（像从主体背后穿过），轨道上停一颗 4px 的实心小圆，外面再套一个 8px 的细圈。
- 用法：绕着标题、名字、圆盘或一件物件；常常一半在前一半在后。
- 变体：虚线椭圆（`stroke-dasharray: 2 6`），表示“轨道”“未完成”。
- 动起来：小行星沿轨道匀速走，一圈 20–60 秒；或者只在揭晓时画出这条线（0.6–1 秒，线性）。

### 2.3 圆盘 / 红日 — `disc-light.svg`、`disc-halftone.svg`

- **大圆是一盏光**（`disc-light.svg`）：主体身后的“日”是打在墙上的一圈光——边缘羽化、表面颗粒、下沿被暗角吃掉一截、主体的影子落在上面。颜色和面积见 `imagery.md` 第 2 节。
- **小圆是一枚色片**（`disc-halftone.svg`）：标题首字后面、栏目首字母后面的小圆，可以是实心锈色，一侧铺一片由大到小渐隐的网点，网点只比圆亮 10–20%。直径为字号的 0.9–1.1。
- 用法：人物海报里大圆直径为画宽的 0.55–0.76；登场舞台里为画高的 58–64%。
- 分寸：一张图一个圆。圆不描边、不加外发光圈。

### 2.4 断开的发丝线 — `hairline-broken.svg`、`.re-hair3`、`.re-hair-tail`

- 三截线（对白、长分隔）：按 `62 | 缺口18 | 1021 | 缺口18 | 74` 的比例，整体约屏宽 62%，居中。
- 尾部断开（小节标题后）：长 82% — 缺口 — 短 6% — 缺口 — 短 3%。
- 两端渐隐（名字下面）：`linear-gradient(90deg, transparent, 线色 20%, 线色 80%, transparent)`。
- 点线只表示“未完成”和“轨道”：载入条没走到的部分、竖向的刻度虚线、轨道椭圆。

### 2.5 双斜线 — `double-slash.svg`

- 形：两条平行的发丝斜线，斜度约 75°，伸出所在字母的基线约 0.22 倍字高。
- 用法：替换一个字母的一笔（R 的右腿、A 的横画），或放在标题旁边当签名点；也可以做日期里的分隔。
- 这是“精确的错误”的一种：一件作品里只用一次。

### 2.6 三角 — `triangle-frame.svg`、`triangles-scatter.svg`

- 线框大三角：外框 1.2px，里面一个同心小三角 0.6px，底边向两侧延伸并在中点断开、放一个小圆环，底边下面一排 4 颗小星。用在“完成”“揭晓”的徽记背后。
- 散落的小三角：实心和线框混用，大小相差 2–3 倍，不透明度 20–30%，随机角度。用在登场舞台和选择页的背景，像飘着的碎片。
- 暗纹：一层由大三角拼成的菱格，只比底色亮 3–5%，偏暖褐。它是暗纹，不占装饰预算。

### 2.7 菱形 — `diamond-nav.svg`

- 列点：实心小菱形 ◆，灰 `#888179`。
- 选中：外框菱形（1.2px，转 8–10° 和内菱形错开）套一个实心橙菱形，配橙字。
- 菱形按钮：45° 的方块，灰色细描边，里面一个线图标。
- 头像：主角用菱形相框，其他人用方形细框。

### 2.8 拱窗 — `arch-frame.svg`

- 形：半圆拱顶的竖长框，双线（外 1.2px，内 0.7px、偏移约 12px），底边外延，拱顶正中一颗小菱形。
- 用法：把一个次要角色或一组作品“装进窗里”；技能卡、作品缩略图的顶部做成拱形（墓碑、教堂窗）。
- 这是唯一常备的“框”。需要把几样东西归成一组时才出现。画面里真的有一扇拱窗时，就让那扇窗来做这件事，不再叠一个线框。

### 2.9 票根 — `ticket.svg`

- 形：奶油纸 `#EFE5D2`，左缘一条色条（锈色或档位色），右边约 27% 处一条打孔虚线，虚线上下各一个半圆缺口（半径约票高 6%），右侧是票根。
- 字：左上 `ADMIT ONE` 一类的微字，中间一个斜体大编号或片名，下面一行 `RETAIN THIS STUB` 微字，票根上写动作。
- 用法：入口、下载、“进入展示”这类一次性的动作。整张转约 1°。

### 2.10 印章 / 徽章 — `seal.svg`、`postmark.svg`

- 印章：外圈 1.2px、内圈 0.7px，两圈之间一圈环形字（拉丁短语、字距 0.32em）；中间两个转了不同角度的方框交叠，正中三行字（古典大写 / 小写斜体 / 罗马数字）。用在揭晓前停 1.5 秒的“字牌”，或页面一角的出品章。
- 邮戳：双圈，圈里两行字（日期、年份），右侧拖四道波浪注销线。用在“消息”“来信”“寄出”。
- 属性徽章：一个图标装在三角或菱形里，外面一圈伪字母组成的环形字，下面一行类型英文，再绕几道椭圆轨道。
- 限定章：贴在标题旁的一个小章，形状随场合换（梅花形、铜牌、圆章），永远很小。
- 动起来：印章慢慢匀速旋转（约 20 秒一圈），或者只在出现时转进来 0.3 秒。

### 2.11 编号牌与巨号编号

- 编号牌：`01/` + 一颗四角星；或 `No.` + 斜体数字；或 `EP. 01`。不加框，就是字。
- 巨号编号：小节标题背后压一个淡色斜体巨号 `01`（约 20% 不透明度，约为小节标题字号的 2.5 倍），被标题压住一半。
- 编目号：打字机粗体 `LP1×L2P` 一类的字母数字串，用在“资源”“档案”这类文件上。

### 2.12 刻度尺 / 时间轴 — `ruler.svg`

- 形：一根贯穿全宽的 1px 细线，小刻度每 1%、大刻度每 10%；已经走过的一段线更亮；当前位置一个 ◎ 定位环（外圈 9px、中心 2.6px 实心点）；前一项旁边一颗带长芒的小星。
- 字：当前项写 `18/ 名称`（衬线，编号大名称小），前面的项字更小、更暗。
- 用法：进度、章节序列、关卡序列。它是“刻度尺式进度条”的原型（见 `components.md`）。

### 2.13 极坐标星图 — `polar-chart.svg`

- 形：几圈同心圆（0.8px，35%），一圈虚线圆，每 15° 一根放射线（0.5px，18%），最外圈每 3° 一个小刻度，沿弧排一行字距很开的拉丁字。
- 用法：一张字卡的底，或一件意象的“底座”。一屏只有一张，整体不透明度不超过 15–30%，不和轨道、放射线、刻度圈叠在一起用。它是天文仪器的线，不是霓虹科幻：细、淡、金或象牙色。
- 宽银幕里：圆心放在画面区里，弧上的拉丁字挪到左右两侧的弧段，不让它落进黑边。
- 变体：把放射线拉长成速度线，配一团很淡的星云色，就有“冲出去”的动势。

### 2.14 胶片格 — `film-strip.svg`

- 形：深色胶片，两侧一列圆角齿孔，中间一格一格的画面，每格左上一个斜体编号 `01`。
- 选中：用橙色的取景框四角标出当前格（`corners.svg`）。
- 用法：分集、作品序列、时间线上的“样片”。

### 2.15 小图标

- 线性图标为主，线宽约 2–3px（1080p），奶白，几何基本形（三角、方、菱、圆）加一个实心小细节。
- 固定三件：返回是一个空心左三角 ◁，主页是方框里套一个实心小方块 ▣，说明是菱形里一个感叹号。
- 主入口图标是**实心奶白剪影**（信封、票据、房子、拖拉机、人像），像橡皮图章，不是线描。
- 关闭：两根交叉的发丝线 ×。
- 货币、道具：写实的三维小物件（硬币、宝石、玻璃雕塑），不画平面图标。

### 2.16 签名笔画 — `swash.svg`

- 一笔主题色的连笔草书，70–90% 不透明度，旋转约 −5°，从标题左下斜穿到右上，尾巴拖成一根更细的发丝线。
- 可以是真名字的签名（Great Vibes 写），也可以是一道没有字的花笔（`swash.svg`）。
- 一组标题只有一笔，而且是可选的。它是最前面的一层，压在所有字上面。

### 2.17 回形针、胶带、撕边照片 — `paperclip.svg`

- 一张照片或一张纸条被回形针或一截半透明胶带固定在另一张纸上，整张转 1–5°。
- 用法：收藏、看点、附件。回形针代替“收藏星标”。

### 2.18 结构线 — `construction.svg`

- 形：几何作图留下的金色发丝线——一个大圆、一个同心的虚线圆、一条水平中线和一条竖直中线、一个压扁的椭圆，线在交点处断开或伸出一点。
- 用法：叠在一件古典或建筑题材的意象上，像设计图纸留下的痕迹（`#C9AA68`，不透明度 50–70%）。它和极坐标星图是同一类东西，两者不同时出现。

## 3. 材质与纹理

材质只铺在“面”上（纸、底、标题字的填充、意象），不铺在要读的字上。每屏最多两种材质（例如一张暗胶片底 + 一张纸）。

### 3.1 颗粒

颗粒的强度用“平整处相邻像素的明暗起伏”来说（0–255 级）：

| 画面 | 起伏 | 做法 |
|---|---|---|
| 界面、介绍页、汇总页、字卡（平涂的底） | 2–4 级 | `.re-grain`（柔光叠加 16%） |
| 纸面 | 3–4 级 | `.re-grain--paper`（正片叠底 4.5%） |
| 平面图形段、海报式意象、片头字卡 | 4–8 级 | `.re-grain--film`（柔光叠加 30%），可以 12fps 轮换 6 张，像胶片在抖 |
| 三维渲染、绘画式画面、展示的作品 | 0 | 不加。它们的质感靠景深、前景遮挡和柔光晕 |
| 纯黑场 | 0–1 级 | 不加，或只给中间那件小物 |

**为什么用柔光叠加而不是叠加（overlay）**：叠加模式的颗粒强度跟着底色亮度走，在近黑底上几乎消失（overlay 7% 在 `#141514` 上只有约 0.1 级的起伏）。柔光叠加配一张高反差的噪声瓦片，在暗底上也看得见，在中灰上自然更明显，正像胶片。

```css
/* texture-kit.css 里的写法：噪声瓦片已内联成 data URI，复制这一个文件就能用 */
.re-grain{position:absolute;inset:-2px;pointer-events:none;
  background:var(--re-noise-tile) 0 0/256px;mix-blend-mode:soft-light;opacity:var(--re-grain,.16)}
```

```js
// Canvas：逐帧可复现的颗粒，视频里用帧号做 seed
ReTexture.applyGrain(ctx, 1920, 1080, { seed: frame, alpha: .2 });          // 暗底约 3 级；平面段 alpha .4；纸面 { blend:'multiply', alpha:.055 }
```

分寸：**100% 下看得见，缩到四分之一看不见。** 起伏在 2–8 级之间时，缩到四分之一自然只剩 0.5–1.5 级，看不出来；缩小以后还能一眼看出颗粒，就太重了。

### 3.2 纸

- 底色用纸色令牌（`#E8E2D8` 等），不用纯白。
- 一角渗桃色：径向渐变，中心 `#E3A78F` 约 50% 不透明度，半径约纸宽 30–42%，向中心淡到透明。只在一个角（或对角两个角）。
- 低频旧渍：十几团很淡的大径向渐变，深的约 4.5% 不透明度、浅的约 6%。
- 纤维：稀疏的短曲线（6–28px），0.5–1px，深色 5–12% 不透明度，少量白色。
- 折痕：一条 1px 亮线贴一条 1px 暗线（`.re-crease`）。
- 对位十字线和铅笔曲线：印刷校样纸上才有，很淡（10–15%）。
- 做法：CSS 用 `.re-paper`（颜色 + 渗色 + 受光 + `::after` 颗粒）；Canvas 用 `ReTexture.paper(w, h, {base, seed})` 生成一张贴图。

分寸：纸要像“一张纸”，而不是“一张纸的照片”。纤维和旧渍加起来，远看应该还是一块干净的暖白。

### 3.3 印刷痕迹

- **网点：** 规则点阵，45° 栅格，点距约画框宽的 1.8%（网页 6–8px），点从大到小渐隐。用在标题下的高亮条、选中页签的字后、画框的一侧、按钮背后、大圆的一角。CSS 用 `.re-halftone`（径向渐变点 + 线性渐变遮罩）；Canvas 用 `ReTexture.halftone()`，能做真正“由大到小”的点。
- **点画渐变：** 大面积的明暗过渡不用平滑渐变，用颗粒散开的过渡带：两色之间 2–3 级色阶，交界处按噪声决定每个点属于哪一级，像丝网和喷枪（`ReTexture.stipple()`）。天空、墙、光柱、物件的明暗都可以这样做。
- **套印错位：** 一个形状或一行字，用第二种颜色错开 1–3px 再印一次（`.re-misreg`）。只在一两处：一个描边三角和灰三角错开几像素，一个警示符号用错开的双线。
- **漏印、磨损：** 标题字面上局部擦掉一点（用噪声遮罩把字面挖掉 5–10%），像铅字没吃满墨。

### 3.4 胶片

| 痕迹 | 数值与做法 |
|---|---|
| 宽银幕黑边 | 16:9 上下各 12.2%，`#0C0D0C`（`.re-letterbox`） |
| 暗角 | 四角亮度为画面中央同一种底色处的 0.4–0.6（`.re-vignette`） |
| 柔光晕 | 亮部向外渗暖光：字用 `.re-halation`；画面用“复制亮部 → 模糊约 1% 画宽 → 暖色 → 滤色叠加 20–30%” |
| 色散 | 红青错开 1–1.5px（`.re-chroma`），**只在**闪白、特写、冲击的瞬间和章节字卡的标题上 |
| 划痕与尘点 | 一帧里 0–2 根竖划痕、0–5 粒尘，各自只活 1–3 帧（`ReTexture.filmDamage(ctx, w, h, frame)`）。只给平面图形段和年代字卡 |
| 漏光 | 画面一侧一团橙红光，滤色叠加（`.re-leak`）。一段只出现一次 |
| 一拍二 | 平面图形段的纹理按 12fps 换帧，主体动画仍是全帧率 |

### 3.5 撕边、剪纸与拼贴

- 撕边：纸的边缘不规则地起伏，边上露出一条更白的纤维带（`torn-edge.svg`；CSS 用 `.re-torn-bottom` 遮罩）。
- 粗糙边：剪影和剪纸的轮廓加 0.5–1.5px 的不规则位移，像手剪的（SVG 滤镜 `re-rough`，由 `ReTexture.injectFilters()` 注入）。字和细线不加。
- 剪纸投影：每层纸朝光的反方向投影，偏移 4–10px、模糊 6–14px、不透明度 35–55%，影子用更深的底色而不是黑。
- 拼贴：照片、证件、信封、标签统一去色压暗，整块略微旋转，用回形针或胶带固定。
- 用法：任务条的边、入口按钮的底纸、转场时被撕开的画面、剪纸层叠的意象。

### 3.6 暗底污渍（标题后面）

几团模糊的近黑径向渐变（不透明度 35–60%，`.re-smudge`），垫在标题字后面，让字压在画上也读得清。它取代了文字底板和描边。

### 3.7 子主题材质（只在对应题材里用）

| 材质 | 做法 |
|---|---|
| 金箔 | 字面浅金渐变 + 细密划痕 + 局部更亮的反光斑；大面积金必须配密纹理，只配黑 |
| 锈与血 | 字面压暗红褐色斑，边缘一两滴 |
| 霜 | 冷白字面 + 边缘细碎的白色晶体噪点 |
| 墨 | 字后一团化开的墨，带飞白 |
| 蓝图格 | 深蓝或深灰底上 1px 网格（大格 10 等分小格），白线 15–25% |
| 显像管 | 扫描线（`.re-scanline`）+ 屏幕圆角 + 轻微桶形畸变 |
| 马赛克 | 字或面由 4–8px 的小方砖拼成，砖缝 1px 暗线，每块砖的明度随机差 3–6% |
| 镭射 | 斜向一条彩虹反光，只在“特别”的卡面上 |
| 混凝土 | 灰色噪声 + 几块更深的斑 + 模板喷字 |

## 4. 材质的分寸

- 颗粒按媒介定（3.1）；其余材质只上在展示性的元素上（标题字、底图、边、意象）。
- 要读的字永远干净：正文、说明、数字不加材质、不加颗粒遮罩、不加色散。
- 撕边、墨点、划痕都在**边缘**，并且受控：一条边撕，三条边齐。
- 一种材质贯穿一整段：这一段选了金箔，就是字面、条带、长图都用金箔；不要这张金箔、那张霜。
- 判断有没有过头：把画面缩小到原来的四分之一看——此时材质应该消失，只剩形状和颜色。如果缩小后还能一眼看出“脏”“旧”“噪”，就过了。
