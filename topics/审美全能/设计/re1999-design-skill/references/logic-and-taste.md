# 底层逻辑与 taste

一句话：**把每一件信息做成二十世纪的一件印刷品或旧物，再用老电影的光去拍它。** 界面本身只给“暗底或纸面 + 一种锈橙”，颜色和戏剧性都让给画面。

这份文件讲它怎么想、什么不变、什么变，以及最难的部分：分寸。其余文件讲具体做法。

---

## 1. 它每次怎么想

每做一屏、一张海报、一段动画，按这个顺序想。顺序本身就是这套语言的一部分：先有物和片，后有界面和装饰。

1. **这是一部什么片？** 每一段内容都当成一部片子来发行：有片名、有档期、有演员表、有片头、有落版。先定片种（悬疑、歌剧、公路、纪录、实验短片、动画、街机……）。片种决定海报格式、开场节奏和英文字体的性格。
2. **这条信息在 1900–1999 年的现实里是什么东西？** 任务是一张纸条，入口是一张门票，日程是一本线圈台历，进度是一把刻度尺或一排电平格，档案是一张美术馆展签，章节是一张电影海报，分集是一格胶片，消息是一封盖了邮戳的信，资源是一张唱片和它的编目号。按钮和面板是那件东西的**局部**（票根、邮票、索引签、刻度、唱片标签），不是通用的矩形。
3. **画面上的“一件东西”是什么？** 每一屏都有一件被光照着的物件，它就是这一屏的主角（画法见 `imagery.md`）。没有物件的屏，至少要有一个有光的空间。
4. **哪一处是怪的？** 每一件作品只放一处“精确的错误”：一个镜像字母、一笔被双斜线截断并伸出基线、一个字母的横向拖影、一角像素溶解。其余部分全部端正。
5. **暗留在哪？** 偏置的画面，决定哪一半是“暗部留白”，标题和信息住进那一半：那一半压暗约 25%、虚化、减少细节，但仍是同一个场景。居中对称的仪式画面，暗在四周，主体和字都在中线上。
6. **排字。** 先定一个绝对的主角：一个拉开字距的大词、一个巨号数字或一行高反差宋体。其余字都小，小到像纹理。中文宋体负责被读，英文负责气质。
7. **加一圆、一线、一两颗星**，再加一种底纹。圆是一盏光（红日、圆盘），线是 1px 的轨道或断线，星是四角星。部件（按钮、进度尺、列表符号）不算在里面，星图、水印字母、印章、放射线都算。
8. **删一件装饰。** 加完以后拿掉一件装饰再看。多数时候拿掉以后更好，那就不放回去。只删装饰；骨架（字标、标题、进度尺、遮挡关系）不在这一步里删。

## 2. 什么不变：母版

这些东西从第一屏到最后一屏都不动。正因为它们不动，每一段换皮之后仍然一眼认得出是同一个系列。

| 不变的东西 | 具体做法 |
|---|---|
| 底的倾向 | 带色相的近黑（藏青黑、墨绿黑、棕黑）或中性炭灰，配暖白纸；暗里有场景、光或暗纹。没有 `#000`，没有大面积 `#FFF` |
| 强调 | 一种锈橙（`#B55829` / `#C25E30`）。某一段有自己的题材色时，题材色接替锈橙的位置，两者不并排 |
| 字 | 中文全部宋体：大标题用高反差宋（细横粗竖），正文和标签用思源宋体；西文标题用高反差 Didone，正文用书籍衬线；签名用一笔草书；系统小字用细的窄体大写 |
| 线与符号 | 1px、比底亮 10–15 级灰、末端断开的发丝线；四角星 ✦；斜线 `/`；小菱形 ◆；倾斜的椭圆轨道加一颗小圆点 |
| 组件几何 | 槽位、按钮、纸卡、通栏、刻度尺的比例和位置锁死。换皮只换底色、边、角落母题 |
| 质地 | 颗粒按媒介定，全片同一套规矩：界面、字卡和平涂的底 2–4 级，平面图形段和海报式意象 4–8 级，三维渲染、绘画式画面和展示的作品不加（数值见 `ornament-texture.md` 3.1） |
| 电影框架 | 片名、档期、STARRING 式演职员表、片头、黑场、落版 |
| 命名 | 入口是一个动作，列表是一份文件，资料区是一个地点，序列用日期或编号 |
| 异象常量 | 一个贯穿全系列的超现实母题，每个子主题的世界里出现一次（`imagery.md` 第 7 节） |
| 留白 | 槽位式的页面，中间 40–60% 留给画，界面贴着四边 |

## 3. 什么变：皮

每个子主题（一个版本、一道题、一个章节）只换下面这几样，而且一次全部换掉：

- **标题字的“时代戏服”**：按题材所在年代、地域、媒介，模仿那个时代的招牌、片头、海报或印刷品上的字。
- **一个主色相**：并把这一段里所有引用的画面都往这个色相上调。
- **一种主材质**：金箔、锈、霜、墨、撕纸、蓝图格、网点……贯穿这一段的标题字、底图和条带。
- **一种画法**：平面水粉、剪纸层叠、版画线刻、剪影加一种红、拼贴、三维小景，按题材的年代选（`imagery.md` 第 3 节）。
- **1–3 个母题**：只放在标题徽记、组件两端、卡片四角、分隔条、按钮装饰这五个地方。
- **一个有第二眼的代表意象**：手同时是雪原，苹果皮剥开是纸，字母 T 同时是一把直尺。
- **开场的媒介和转场物件**：怀表钟面、旧电脑窗口、显像管电视、地图、棋盘……
- **故事里的词表**：入口按钮写什么动作，列表叫什么文件。

换的强度分三档：主内容全换（上面全部）；常驻栏目只换底色；系统部件（按钮、网格、价签、进度、字幕）不换。

## 4. 分寸：做到哪一步刚好，再多一步就俗了

这是这套语言最难学的部分。每一条都写成“刚好 / 再多一步 / 为什么”。

**暗。** 刚好：暗里有东西——一面看得出材质的墙、一道窗光、地上的影子、一个前景的剪影，界面页的平均亮度 15–30%。再多一步：把底刷成平的 `#0A0A0A`，或者用同心圆和放射线把暗处画满。为什么：平黑底没有空间也没有温度，立刻像一个奢侈品网站；线条填满的暗像仪表盘。暗要靠场景、光、暗纹来“有内容”（`imagery.md` 第 1 节）。唯一例外是黑场和片头标题卡：它们可以几乎全黑，但画面上只放一件小物和极少的字。

**亮。** 刚好：每屏有一处很亮的点（一张纸、一盏灯、一行字），近白像素只占 1–2%。再多一步：整屏提亮到中灰。为什么：亮暗跨度一缩，画面就“发灰”，看上去便宜。低长调的意思是整体暗、但最亮处真的亮。

**高光的颜色。** 刚好：最亮处是奶白、象牙或浅金（偏暖，R 比 B 高 10–40）。再多一步：最亮处是冷白 `#FFFFFF`。为什么：同样一张蓝色海报，高光一冷，立刻显得数码、廉价；高光是暖的，蓝也显得像旧纸上印出来的蓝。

**圆。** 刚好：圆是一盏打在墙上的光，边缘羽化，下沿被暗角吃掉一截，主体的影子落在上面。再多一步：一张边缘锐利、颜色鲜亮、浮在最前面的圆片，外面再加一圈发光。为什么：锐利的色片读作“图标”，光圈读作“舞台”。

**强调色。** 刚好：一屏里只有一个锈橙实心块（主按钮或一张票根）加一条选中下划线，面积不超过 5%。再多一步：再加一个暖色块，或者把信息字也染成强调色。为什么：强调色是全屏唯一会“叫”的东西，两个东西同时叫，就谁也听不见。

**金。** 刚好：金只上在细线、星、数字、首字母上。要整张用金时，必须在金上铺满密纹理（雕花、木纹、网点）把金属的光压下去，并且只配黑。再多一步：金色描边按钮、金色信息字、大块平涂金渐变。为什么：金多一处就开始像奖杯和礼盒。

**标题字的重量。** 刚好：大标题用高反差宋——横画细到像发丝，竖画粗，三角形的字脚很尖，填色是暖白到象牙的轻渐变。再多一步：用最粗的宋体，再刷上大块金渐变和投影。为什么：粗而亮的金字是“国潮礼盒”和手游开屏的语言；1999 的标题靠细横和留白显得贵，重量只在竖画上。

**装饰。** 刚好：一个圆、一条 1px 线、一两颗星，再加一种底纹。再多一步：星图、轨道、放射线、印章、水印字母、角花同时上。为什么：每多一种装饰，标题就少一分重量。装饰的作用是让主角显得更孤独，不是让画面显得更满。

**线。** 刚好：1px，只比底亮 10–15 级灰，末端断成“长—短—短”。再多一步：闭合的矩形框、2px 以上的强调色描边。为什么：断开的线像书籍里的装饰线，有呼吸；闭合的框把东西关起来，像表单。

**颗粒。** 刚好：100% 下看得见，平整处明暗起伏 2–4 级；缩到四分之一就看不出来。再多一步：一眼就能看出“做了旧”，或者满屏划痕和污渍。为什么：复古感来自物件的形状和材质，不来自弄脏。脏是滤镜，物件才是设计。

**渐变。** 刚好：大面积的明暗过渡用点画（颗粒散开的过渡带），像丝网和喷枪。再多一步：处处是平滑的数码渐变，再加柔光。为什么：平滑渐变是屏幕的质感，点画是印刷的质感。

**字量。** 刚好：一个载入页只有四处字——角落一行极小的字、一行标题加一行斜体副标、一行提示、角落一枚字标。再多一步：再加面包屑、编号、眉标、记录号、进度计数、引文、竖排字。为什么：字一多，“一件静物”就变成了“一个后台”。每加一处字都要问：拿掉它，观众会少知道什么？同一个编号在一屏里最多出现两次。

**字号。** 刚好：功能字基本一个号，展示字极端放大，两者差 5–8 倍，中间层级很少，一屏不超过四档。再多一步：八级字号阶梯一级一级排下来。为什么：两极的字号像印刷品；均匀的阶梯像网页。

**间距。** 刚好：间距跟着两边的东西走——大东西之间留大空，小东西之间留小空（标题和一行小字之间的空，约为那行小字字高的 1.5–2 倍；两个大块之间的空，约为大块字高的 0.5–0.8 倍）。再多一步：所有元素之间用同一个间距。为什么：等距让每样东西一样重，画面就没有主次。

**英文。** 刚好：英文要么比中文小一半（注脚），要么大到变成背景（底纹）。再多一步：中英两行同样大、并排放。为什么：同大并列是说明书；一大一小或一实一虚，才是“中文在说话，英文在织底”。

**遮挡。** 刚好：主体和身后的大词重叠时，主体挡住中间 1/4 到 1/3 的字母，首尾字母露出来。再多一步：挡掉首字母，或者大词和主体隔开、互不接触。为什么：不接触，字和图是两张贴纸；挡掉首尾，词就读不出了。挡中间，词还在，层次也出来了。信息页“左文右图”的标题簇是例外：它住在画面的暗部里，不必和主体重叠。

**倾斜。** 刚好：纸片转 1–5°，标题牌转 −4° 左右，结果网格摆在 5° 的透视平面上。再多一步：10° 以上的乱转。为什么：小角度读作“放在桌上的一张纸”；大角度读作“散了一地”。

**怪。** 刚好：一处镜像字母或一笔被截断。再多一步：满屏故障、错位、雪花。为什么：一处“精确的错误”是签名；满屏错误是赛博风格，跟这套语言是两回事。

**比喻。** 刚好：一个有第二眼的图形，第一眼是一样东西，第二眼是另一样。再多一步：同一张图里堆三个比喻，或者把题材里的东西全画上去。为什么：一个双关让人多看几眼；三个双关让人放弃看懂；照实画全是“展示”，不是“表达”。

**构图。** 刚好：构图本身在说话——对称是秩序（也像牢笼），对角切割、上重下轻是坠落，三个人各在一个形状里是三条线索。再多一步：所有画面都用同一个“左字右图”。为什么：同一个构图反复出现，画面就只剩信息，不再有情绪。

**动。** 刚好：插画带一点运动模糊推进来，约 0.5 秒停稳，标题晚 0.3 秒出现，然后久久不动。再多一步：弹跳、回弹、果冻、持续旋转的大物体。为什么：这套语言的动作是“先空一下，再一下子出来，然后久久不动”，所有分量都在那个停住的瞬间。

**闪光。** 刚好：整段只在揭晓的那一刻闪一次。再多一步：每个转场都闪白、都加粒子。为什么：闪光是用来标记“这一刻和别的时刻不一样”的；处处都闪，就没有一刻不一样。

**文案。** 刚好：像故事里的一张票、一份文件、一条广播：“请于开映前入座”“读完这一页可领取”。再多一步：运营腔，“限时！速来！”。为什么：口吻也是皮的一部分，运营腔会把整件旧物拉回手机通知栏。

## 5. 把几个说不清的词拆成做法

**“高级”** 来自六件事：① 字是衬线和宋体，大标题细横粗竖，有阅读感；② 线细、淡、断开；③ 纸和底有颗粒和纤维，远看平、近看有；④ 只有一种橙；⑤ 东西都像真物件（邮戳、票根、展签），不是图标；⑥ 高光是暖的，暗部有内容。

**“复古”** 来自三件事：年代物件（老电脑、合成器、点唱机、台历、飞艇、怀表）；印刷工艺的痕迹（网点、点画渐变、套印错位、对位十字线、撕边、折痕）；胶片的痕迹（暗角、只在边缘的划痕、年份字卡）。不是做旧滤镜。

**“电影感”** 来自：2.35:1 宽银幕黑边；两端都收进去的影调（黑位约 10/255，画面白位约 215/255）；重暗角；前景遮挡加景深；镜头一直在极慢地推；剪辑先静后响。

**“精致感”** 来自：夸张的大面积对极细的点和线（一大块剪影旁边放一根 1px 的线和一颗小星）；疏密 8:2，一屏的细节集中在约五分之一的面积里，其余是大块的暗或纸。

**“有味道”** 来自：每一个名字都在故事里（商店是一个地点，任务是一份文件），每一个数字都有一个格式（`01/`、`×14`、`05/31`），每一个英文词都不是翻译而是气氛。

**“做出来的”而不是“画出来的”** 来自：一个主光和落在别处的影子；点画渐变；不完全光滑的轮廓；表面材质；三五个色阶（`imagery.md` 第 4 节）。

## 6. 偏爱与回避

**偏爱**

- 暗而带色相的底，暗里有墙、窗、光；暖白或浅金的字。
- 衬线字：高反差宋体、Garamond、Didone、罗马碑刻大写。
- 二十世纪的印刷物和办公用品：车票、行李牌、档案表、印章、打字机字、报纸广告的口吻。
- 古典与天文仪器的元素：柱廊、拱窗、罗马大写、星图、轨道、刻度。
- 一个象征物件压住一整张图，而不是一群人摆拍。
- 克制的光：大部分画面是暗的，只有一个光源，只有一次闪光是亮的。
- 直角、细线框、45° 菱形、三角；徽章、计时、等级则用圆和椭圆——弧线、锐角、几何三样一起用。

**回避**（每一条都是因为它属于另一种语言）

- 圆角卡片一张叠一张的手游面板：它是通用界面的语言，不是旧物的语言。弹窗用横贯全屏的纸带，面板用一张纸。
- 文字底板：字直接压在画上，靠暗部、局部污渍或网点块来保证可读。
- 粗描边、粗投影的卡通字；最粗的宋体刷金：这里的标题靠细横和材质出层次。
- 玻璃拟态、发光描边、渐变按钮、金属倒角：它们属于科技产品。
- 科幻 HUD、扁平插画图标、霓虹星空：这里的图标是实物剪影或几何线描，星空是天文图册。
- 矢量图标式的意象：平滑渐变、处处等粗的线、刀切一样齐的边。
- 用线条填满暗部：星图、放射线、轨道、刻度一起铺满背景。
- 中文黑体当标题或正文：黑体会把整页拉回到现代 App。
- 满屏粒子：粒子只围在标题周围，并且有方向（向上飘）。

## 7. 正反对照的小例子

**一张载入页。** 刚好：近黑底的正中放一台很小的旧电视，屏里是一张泛黄的照片；电视背后露出半个锈色圆；下面一行衬线标题、一行斜体副标；左右各一根细线向两边伸出去；右下角一枚极小的字标。97% 的像素接近黑，但这一屏有一件“东西”。走样：同样的近黑底，正中换成一个线框拱门加四角取景框，再补上面包屑、记录号、进度计数、引文和竖排字——每一件都“对”，加在一起就成了系统后台。差别在于：前者有一件真物件和四处字，后者没有物件、有十几处字。

**一张片头标题卡。** 刚好：黑场里正中一行高反差宋体片名，下面一根短发丝线、一行字距极开的英文，再下面一小块演职员表式的小字，最底下一根横贯全幅的细线，线上停着一件很小的剪影。字一共五处，画面 95% 是黑。走样：片名、副标题、标语、十一个带编号的星、一张星图、两侧竖排拉丁字、一个大圆盘和一颗立体的星同时出现。差别：前者像电影开场的那一秒，安静到让人等；后者像一张信息图，所有东西都在第一秒交代完了。

**一页介绍页。** 刚好：一张满版的画——画室的北窗、窗光里的石膏球、地上的影子——标题和看点住在画面左边那面更暗的墙上。走样：一块平的深色渐变，右边浮着一个没有影子的物件，四周用星图、光芒线和轨道圈填满，左边一列字。差别：前者是“走进一个地方，读墙上的展签”；后者是“看一张幻灯片”。

**一张蓝色海报。** 刚好：顶部三分之一是一大块近黑，蓝色的五线谱纸带从下往上汇成一座塔，塔尖上停着一艘极小的船；亮部仍是奶金；字只有手写体片名、一枚小字标、一行演员表。走样：整张提亮成灰蓝，最暗处只到中灰，亮部变成冷白，谱带均匀地铺满画面，再加三块时间地点信息和一行竖排大标题。差别在于：大块的暗、暖的高光、一大一小的尺度反差、克制的字量——四样少了任何一样，都会掉价。

**一颗主按钮。** 刚好：实心锈橙直角矩形，白色宋体字，字下一行极小的英文大写，右上角两个细线小三角，左半边一层几乎看不见的迷宫细线，右下角 3×2 个小点。走样：圆角胶囊、上下渐变、外发光。差别在于：前者像一张印出来的票，后者像一颗糖。

**一个人物介绍页。** 刚好：人物站在场景里，身后一个锈红的光圈，左侧竖排几项菜单（选中项是外框菱形套实心橙菱形），右侧一块展签：“媒介 / 年代 / 尺寸 / 收藏地”。走样：把同样的信息放进一格一格的深色模块，每格一个小标题加数据。颜色一点没变，却立刻像别的游戏——因为“模块网格”本身就是通用科幻面板的语言，和“一件旧物”冲突。

**一个标题和一个人。** 刚好：一个拉开字距的大写词横在人物身后，人物挡住中间两三个字母，首尾字母露在两边。走样：标题放在人物旁边，两者互不接触。差别在于：前者有前后，后者只有左右。

**一次转场。** 刚好：两大段之间黑场 1.5 秒，声音同时降到几乎无声，然后在第一个强拍上出新画面。条目之间用题材里的物件擦过去（一封信、一张纸、一团烟）。走样：每个转场都闪白、都加光效。差别在于：前者让观众知道“现在换了一种节目”，后者让观众一直处在“好像有什么事”的状态，最后什么都不重要了。
