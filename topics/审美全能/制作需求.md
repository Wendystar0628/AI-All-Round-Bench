# 审美全能：设计调研、视频模板与网站的制作需求

用户 2026-11-24 提出。第一至四节是用户的要求，照原意整理；第五节是指挥补的默认做法，用户没说的地方先按它做，可改；第六节是等用户后续提供的东西。各阶段的设计者和实现者都以本文为准。

## 一、总要求

- **顺序**：先调研《重返未来：1999》的美术风格并写成设计 skill，再做视频模板，再做网站。
- **分工**：这些工作都派给 Opus，推理强度 max。
- **风格**：全片设计风格保持连贯。本项目的核心主题依旧是星辰；主题色和辅助色根据 1999 的调研结果来定；按 1999 的 skill 结合星辰主题来设计。
- **定位**：本项目不打分排名，不计时计费，各种对比都没有了，更偏欣赏。视频模板的节奏和十项全能要有变化。

## 二、1999 美术调研与设计 skill

- **调研范围**：各种卡池界面、活动界面、功能界面，官方视频、官方设计，以及社区中能找到的各种素材。
- **要提炼的内容**：1999 设计的底层逻辑、常用技巧、美学倾向，以及一些比较玄乎的 taste；配色、字体、动效、排版都要研究。
- **用途**：作为新视频模板的设计方向。
- **产出**：一个详细的 skill，可以由多个文件组成。skill 多写设计相关的内容；审计、检查、证据、来源这些都不要。

## 三、视频模板

### 3.1 全片流程

片头 → 选手登场 → 三位评委集合登场并自我介绍 → 按顺序逐题展示（11-25 用户定：删掉题目汇总页，选手登场之后直接进评委登场）。每道题依次是：题目介绍页 → 作品展示 → 评委点评。全片有底部进度条。

- 底部进度条上要显示各题的文字简称（用户 11-24 定），能简称的简称：PV、卡通渲染、白模渲染、网页设计、大型建模、SVG动画、体素建模、硬表面、游戏UI、Logo设计。

- 选手登场要有：片是按型号出的，这一段交代型号名（带推理强度）、厂商和立绘。
- 没有「选手收尾」这一段。
- **段落之间要连贯**（用户 11-24 定）：视觉观感上要连贯，段落之间不用黑场过渡。片头 → 选手登场 → 评委登场 → 第一题，以及最后一题 → 落版，都用连贯的转场接上。第一版每个段落之间各有 1.5 秒黑场，作废。

### 3.2 片头

- **总长控制在 30 秒之内**（用户 11-24 看了第一版分镜后定）。像十项全能的片头那样做概念性示意：每个方向一个概念画面，快切、一闪而过，方向名读得出来；不是把作品内容缓慢地展示出来。第一版 74 秒、每个方向 4.8 秒的一镜到底作废。
- 先是一个起手页动画，展示各个主题。不要套用十项全能的时钟模板。
- 再做一段展示各个方向题目的连续动画：
  - 使用连贯的运镜和动效设计；
  - 每个小段的设计都契合实际题目的主题，运用各种平面设计和三维设计的手法来设计和组织；
  - 片段之间的转场方式不要单一。为了更好地衔接，用多元化但不刻意堆叠的转场技巧，最好根据主题做创意转场设计，而不是套用普通模板。
- **片头曲**：依旧由 Opus 来做（和十项全能一样自己作曲、用程序合成）。

### 3.3 展示顺序

PV设计、卡通渲染、白模渲染、创意网页设计、大型场景建模、SVG动画、体素建模、硬表面建模、游戏UI设计、字体与Logo设计。

（用户 11-24 删掉了立绘设计这道题，现在共十个方向；11-25 把 PV设计和卡通渲染的展示顺序对调，PV设计排第一。）

（用户 11-24 把「MV制作」改名「PV设计」，题名《壱雫空》PV，简称 PV；类别 key `promo-video`，题 key `mygo-pv`。）

（用户 11-24 调整过一次：卡通渲染的秋庭观星画室和 SVG动画的鹈鹕互换了位置，秋庭排第一，鹈鹕排第六。）

其中两道题的题面用户后续再设计，但主题已经有了，可以先做相关设计：

- 字体与Logo设计：二次元游戏 Logo。

### 3.4 题目介绍页

- 每题正式展示前有一个介绍页面。
- 主风格按 1999 的 skill 设计风格做，子风格按题目主题来。
- 内容是说明主要内容，加上列点说明看点。
- 除了文字，也要有相关的意象设计：设计一个承载本题主旨的代表性设计元素。用 2D 还是 3D、怎么表现，都由设计者自行发挥。
- 视频模板里也要考虑使用和 1999 风格契合的各种 SVG 元素、纹理材质等设计。

### 3.5 点评环节

- 每道题结束后没有打分环节，有点评环节。
- 一共三位评委 AI，每道题只有一位点评：

  | 评委 | 点评的题目类别 |
  |---|---|
  | GPT 6.2 Sol | 白模渲染、大型场景建模、硬表面建模 |
  | Claude Opus 5.5 | PV设计、SVG动画、创意网页设计、卡通渲染 |
  | Gemini Neon | 体素建模、游戏UI设计、字体与Logo设计 |

- 评委除了文本点评，还要展示立绘和 TTS 语音。
- 评语不超过 100 字。TTS 语音和文本同步出现。
- 评语的写法（用户 11-24 定）：不能是纯感受类的，主要对技术进行评价，公正地指出优缺点；最后再简要做主观赏析。
- 评语还要有分析（用户 11-24 看样片后定）：除了描述，还要选这件作品最主要的技术层面的内容进行分析，仍然不超过 100 字。
- 评委说话的时候可以加入一些立绘说话的小动作，但不要夸张，也不要频繁使用。

### 3.6 评委登场与人设

- **登场位置**：在题目开始前、题目讲解后，三位评委的立绘集合登场，轮流做简短的一句话自我介绍。
- **登场动画**（用户 11-24 定）：要一段连贯的出场动画，做风格化的人物排版，三位评委各自的排版风格由各自的人设决定，彼此之间转场连贯。
- **人设**：
  - GPT：理性、严谨、卓识远见的形象。
  - Claude：沉稳、安静、博识、温暖的形象。
  - Gemini：元气、活泼、具有活人感的猫娘形象。
- **文本写法**：自我介绍和评语主要关注创作内容，同时要写成符合各自人设的口吻。
- **音色**：三位评委的 TTS 音色要和人设对得上。TTS 用本地的 Qwen TTS，它要放在本项目下面，不要丢在别处。音色先由指挥调一个气质大致相符的，有问题用户后续会改。
- **评委立绘**：暂时用现有的 GPT、Claude、Gemini 三张（`videos/model_character/transparent/` 的 `gpt.png`、`claude.png`、`gemini.png`）。

## 四、网站

- **风格**：和视频风格保持一致。本网站是展示类网站。
- **页面**：一个首页；按题目展示的页面，一题一页；按模型展示的页面。要有展示类网站各种常见的功能，以及设计者认为有助于交互的功能。
- **首页不滚动**（用户 11-24 定）：首页一屏放下，不加滚动；把导航栏做清晰，需要的内容放进子页。
- **下载**：
  - 除了白模渲染和 PV设计不提供下载，其他题目都提供模型的作答下载；
  - 观众下载到的是单个文件或者压缩包，比如网页设计要打包成单个 html；
  - 不提供一键下载功能，只有每题分别下载；
  - 下载包最好让国内下载不太卡。
- **展示内容**：不支持在线浏览作品，GitHub 网页服务器带不动。只展示静态图片，静态图片从模型的设计作品里截取。

## 五、指挥补充的默认做法

用户没有说到的地方，先按下面做。

1. **片尾**：不做和选手有关的收尾。最后一题点评结束后，只接一个很短的落版（专题标志），让片子有个结束。
2. **片头曲怎么做**：用引擎现成的作曲与合成工具（`videos/engine/music/engine.py`，十项全能的做法见 `videos/topics/decathlon/music/`）。画面和曲子一起设计，片头的时间点做成一张可调的节拍表。`videos/topics/aesthetics/` 里那首《ハッピーシンセサイザ》翻唱不是片头曲，不要动它。
3. **正片配乐到位之前**：模板先按没有配乐来做和测试。自带声音的作品段不放配乐（用户 11-24 已定）；评委说话时配乐压低。
4. **片子里没有作品的题**：自动跳过，比如题面还没出的 PV设计和字体与Logo设计。片头的连续动画和进度星座仍然展示全部 10 个方向。
5. **评语由谁写**：由三位评委对应的真实模型来写。GPT 6.2 Sol 用 `sol_exec.py`，Claude Opus 5.5 用 Opus 子代理，Gemini 4 Neon 用 agy 线程。每位评委看作品的画面和题面要点，按人设写，不超过 100 字。模板开发阶段的样例先用占位评语。
6. **评委也是选手**：Opus 和 Gemini Neon 既参赛又当评委，点评按题目类别分配，不回避自己的作品。
7. **音色设计**：用 Qwen3-TTS 的 VoiceDesign 模型按文字描述给每位评委设计一段参考音，再用 Base 模型以参考音合成全部台词，保证同一位评委音色前后一致。Qwen3-TTS 的环境和模型放在 `videos/runtime/tts/`。三位的描述：
   - GPT：二十六七岁的女性，音色清冷通透，吐字清晰利落，语速平稳，语气理性笃定、从容克制，像严谨而有远见的学者在陈述判断。
   - Claude：二十五岁左右的女性，音色柔和、略低而温润，语速舒缓，语气安静沉稳，带着温暖的笑意，像在书房里轻声讲给朋友听。
   - Gemini：十七八岁的少女，音色明亮清甜，元气十足，语速轻快，语调起伏自然，像真人聊天一样带着笑意和一点俏皮。
8. **字体**：视频和网站尽量用同一套；进网站的字体必须是开源或免费商用授权的。用户 11-24 指出第一版字体不对：标题字体要参照 `topics/审美全能/题面/字体与Logo设计/活动参考/` 里 1999 活动 Logo 的字体效果，找风格相近的通用字体来用。
9. **不用 1999 的素材**：skill 提炼的是设计语言。模板和网站里的图形、纹理、装饰全部原创，不使用 1999 的图标、立绘、界面截图和标志。
10. **下载包放哪**：放在站点自己的静态文件里。站点的自定义域名由阿里云 DCDN 代理，国内下载走的是 DCDN，不直连 GitHub；GitHub Releases 不走这条线，所以不用。单个包控制体积（GitHub Pages 单文件上限 100 MB）。
11. **存放位置**：

12. **网站只在本地**：站点做好后清单里的 `website_status` 先设为 `draft`，只在本地预览；上线要等用户发话。

## 七、质感返工（用户 11-24 提）

用户看了模板截图，觉得现在的模板充斥着比较廉价的效果，没有 1999 那种精致感。先派子代理调研质感差在哪：是缺了设计元素，是设计细节不到位，还是只学到了 1999 的皮毛。调研结论出来后再定怎么改。

调研方法（用户 11-24 定）：不要拿大量参考图逐页对照，也不要并行对比大量平行设计；选少数关键设计做参考，把其中的设计思路扩张开来。例如 `题面/字体与Logo设计/活动参考/` 里的 1999 活动 Logo 就是 1999 风格很对味的设计。

诊断之后怎么改（用户 11-24 定）：
- 先派子代理研究怎么把诊断里的质感贯穿整部片子，研究好后再派子代理修改、优化视频模板。
- 不是把 Logo 的设计层次全部照搬。Logo 的设计方式可以借鉴到部分主要文字上，比如每题的题名；主要文字的设计度要比次要小字高。
- 做视频模板的核心是美学、细节、层次、质感和品味的设计，不要把时间和额度浪费在纠结可调整的数值上。
- 网站也要一起改（用户 11-24 定）：和视频统一设计风格，质感也要做到方案里设计的层次和细节。
- **配色要多元**（用户 11-24 看了第一轮返工后定）：网页和各题的题名、排版普遍为了字面上统一风格，用了太多黑金配色。统一风格也可以允许多元化的配色和组合。1999 的活动 Logo 虽然发散很多，但看得出是自成一派的设计体系，要朝这个方向设计：每个方向有自己的配色和材质，统一靠同一套构成方法，不靠同一种颜色。
- **题名锁定要有鲜明特质**（用户 11-24 定）：在保留 1999 这套设计逻辑的同时，每题的题名 Logo 要做出鲜明的特征设计，用 Logo 的设计语言把主题的特质表现出来，设计的底层技巧依旧是 1999 的这一套。例如机甲题是硬质、冷峻、厚重；《壱雫空》PV 是清爽、晴朗、太阳雨（所以 PV 这一题从锁定到代表画面、片头那一格都改成亮的太阳雨调子，不再是雨夜）；玻璃温室是柔和、温暖、黄昏。
- **题名的配色层次参照 1999**（用户 11-24 定）：十个题名锁定的文字配色层次，都要参考 1999 活动 Logo，不只是 Logo 设计一题：能读的那层干净明确，题材色只落在主角字一处，前后层次分明，底子是比字暗得多、跟着字走的不规则暗渍，不是一块矩形色块，也不能显脏。
- **用户 11-24 看 Astra 样片后的意见**：
  - 题名锁定：1999 活动 Logo 虽然都做了艺术字处理，字的形体依旧锐利，不用圆滑的字体；很多字用了点缀色。这两点都要参考。
  - 英文字体：有些英文字体的细竖线太细，根本看不到，要换字体。
  - 片头起手页太单薄，把几个题目依次列出来也没有创意，要围绕星辰这个意象做文章。片头各段落里的方向名，用题名锁定做动画，不要简单排字。
  - 片头有几个镜头的素材没有出来（实现 bug，已查明是第一次出片内存不足、画布分配失败成了空白，并发已改，重渲后正常）。
  - 作品视频不能占满全屏，要像十项全能一样四周留边，放相应的信息，用运动背景和静态 SVG 装饰。
  - 评委点评页的角色排版感太弱，缺少装饰元素来交代评委在画面中的位置。
  - 题目内容的展示太简陋，要像十项全能那样，用装饰物衬托题干信息。
- **题名要做真正的艺术字**（用户 11-24 指出前几轮做偷懒了）：1999 活动 Logo 的字都做了艺术字处理，不是排字；配色不是给一笔换色，而是主色之外有其他点缀色做纹理扩散；装饰物不是简单的斜切，而是有鲜明的主体元素，并巧妙利用英文装饰字。先拿机甲题做试点，用户看过再铺开。参考局部在 `调研/审美全能/模板设计/艺术字试点/参考局部/`。
- 片头也要一起改（用户 11-24 定）：第二版骨架偏简陋，已做成的起手页、卡通渲染那一格和主题页也照方案重做；节拍表的时间结构不变。
