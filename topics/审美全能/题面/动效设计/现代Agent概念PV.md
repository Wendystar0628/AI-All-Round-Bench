# 现代Agent概念PV

## 1. 目标总览

制作一支概念 PV，在网页中实时播放。主题是**现代 Agent 与协作**。

全片跟着一个 Agent 走：一行指令点亮它，它运转、思考、行动，把任务分给五位 AI 协作完成，最后交付。一路上出现的是大模型与 Agent 的真实技术概念：
- 词元与嵌入、梯度下降、Transformer、注意力计算、下一个词的预测、上下文窗口；
- 规划、工具调用、记忆检索、自我纠错、上下文压缩；
- 路由分派、多智能体之间的消息传递、并行与合并、交叉验证。

每个概念都做成一段有表现力的动画：观众看到的是一个形状、一个动作，就感受到这个概念在做什么。片子要像一支 MV，靠画面和音乐打动人。不是讲课，也不是软件操作演示。

五位 AI 模型的拟人角色是片中的五位协作者，素材里有她们的透明底全身立绘。她们各自的能力，同样做成技术概念的动画来表现。

全片配一首你自己写的曲子，由程序合成，画面跟着音乐剪辑。

这道题考视觉与动效设计，包括：
- 概念的视觉化：把专业概念变成一眼能懂的形状和动作；
- 编排：镜头之间的衔接、复现和递进，全片一气呵成；
- 动态排版：少量大字和标注小字的版式与文字动画；
- 构图、色彩与图形语言；
- 运动设计：时间、节奏、缓动和动势；
- 配乐：音乐与画面的配合。

这是一道开放式设计题。你的身份是专业的动效设计师，同时为这支 PV 作曲。题面给出的是：
- 主题与主线；
- 角色素材；
- 段落和每个镜头的骨架；
- 编排手法和全片的要求。

具体的画面、文字、颜色、转场和配乐都由你设计。题面没有写到的地方，也要按专业动效设计师的思路主动去设计，让全片更完整、更连贯。

第 2–7 节的内容和要求都要在作品中真实做出来。作答过程中反复对照本题面，逐项检查和完善。

- 可以自由裁切、缩放、调色、描边、去色、做成剪影；
- 概念动画可以从她的身形、手里的器物或周围的空间生发出来；

## 3. 段落与镜头

全片分七段，按 MV 的结构排列：

| 段 | 在曲子里的位置 | 镜头 |
|---|---|---|
| A 序 | 前奏 | A1–A4 |
| B 思考 | 主歌一 | B1–B5 |
| C 行动 | 主歌二 | C1–C4 |
| D 分派 | 导歌 | D1–D2 |
| E 五位 | 副歌 | E1–E10 |
| F 协作 | 间奏与最后的副歌 | F1–F4 |
| G 交付 | 尾奏 | G1–G3 |

- 全片 32 个镜头，多数 2–4 秒。镜头内的动作踩着拍子推进，每一拍都有看得见的变化。
- 段名和镜头名只是题面里的编号，不出现在画面上，也不做章节卡。
- 下面是每个镜头的骨架：画面里是什么概念、怎么动、怎样交给下一镜。具体的形象、文字、颜色和图形由你在骨架之上设计。

### 贯穿全片的两样东西

- **光点**：开场的光标亮起后，化成一个光点，贯穿全片。每个概念动画都由它触发、牵引或画出来：它是注意力的查询，是滚下损失曲面的那颗球，是在层间上升的信号，是在工具之间往返的调用，最后回到光标。
- **目标体**：A1 回车之后，远处出现一个只有轮廓线的几何体，代表这次任务的目标。任务具体是什么，全片不说。
  - 每一次副歌（B5、D2、F4）结束时，它都比上一次完整一些：面一块块补上，结构一层层亮起；
  - 到 G1 才完整、发光。

### A 序

- **A1 点亮**：
  - 暗场里一个闪烁的光标。一行指令逐字敲进来，字符是一颗颗落下的光，不必看清写的是什么。
  - 回车在重拍上按下，整行收成一个光点，向外迸出第一圈光环。
  - 远处随之出现目标体的轮廓线。
- **A2 词元与嵌入**：
  - 光点炸开成一串词元，每个词元拖出一支向量箭头，飞进一个三维的嵌入空间。
  - 意思相近的词元在空间里聚成一簇，簇和簇之间的方向关系清晰可见。
  - 摄像机在空间里环绕、穿行。
- **A3 梯度下降**：
  - 嵌入空间的底面隆起成一片起伏的损失曲面。光点化成一颗球，沿着最陡的方向带着动量滚下，路过的轨迹亮起；
  - 屏幕一角，一条损失曲线随之骤降。
  - 球落进最低的谷底，谷底的等高线一圈圈荡开。
- **A4 Transformer**：
  - 等高线的圆环抬起，变成一层层叠起的 Transformer 层。摄像机从底部沿残差流向上穿行：
    - 每经过一层，注意力和前馈两个子层依次亮起；
    - 残差流这道光每过一层就亮一档。
  - 穿出顶层时，光点成为模型吐出的第一个词元。

### B 思考

- **B1 注意力**：
  - 一个词元亮起，成为查询。它向序列里所有的键同时射出连线，点积的大小决定线的粗细；
  - softmax 之后，大部分线暗下去，少数几条留下来。
  - 一张注意力热力图从这些线里一格一格填出来；多个头的热力图像一叠半透明的卡片错开、再合拢。
- **B2 下一个词**：
  - 候选词元的概率条像赛跑一样升起、互相超越，被选中的那一个落进序列末尾。
  - 序列于是又长了一格，下一轮立即开始；每一轮都比上一轮快，最后连成一条奔流的词元流。
- **B3 上下文窗口**：
  - 词元流铺成一条极长的带子，一个窗口框住其中很长的一段，窗口里的一切同时亮着。
  - 窗口最远端的一个词元闪了一下，光点沿着一条长弧瞬间抵达，把它取回来。
- **B4 规划**：
  - 光点飞向远处的目标体，目标体沿着结构线拆开，成为一张有向图：节点和依赖箭头按拓扑顺序依次亮起；
  - 能同时进行的分支并排展开。
  - 节点是抽象的几何形，不写任务的内容。
- **B5 循环（第一次副歌）**：
  - 观察、思考、行动三个节点围成一个环，光点沿着环转完一圈。每经过一个节点，节点的名字在重拍上以大字出现。
  - 环的中心是目标体，第一次补上了几块面。
  - 环旁一个步数计数器从 1 开始跳动。

### C 行动

- **C1 工具调用**：
  - 环上「行动」那一点伸出一道调用的光脉冲，射向周围一圈工具的图形符号，例如终端、浏览器、文件、搜索。
  - 被调用的工具亮起、运转，结果化成光包，沿原路飞回、汇进上下文。
  - 一来一回越来越快，好几个工具同时被调用。
- **C2 记忆检索**：
  - 一个查询向量射进一片浩大的向量库（三维）。离它最近的几块碎片被吸出、旋转着对齐，嵌进上下文的空位。
- **C3 自我纠错**：
  - 一圈校验灯依次点亮，其中一盏变红。红色沿依赖图倒着往回追，找到出错的那一个节点。
  - 光点在那里补上一笔，绿色从这一点沿依赖图向外扩散，所有的灯依次转绿。
- **C4 上下文压缩**：
  - 上下文的带子越拉越长，逼近窗口的边界。在撞上之前，整段历史像手风琴一样层层折叠、压实，收成一枚致密的晶体。
  - 窗口重新空出来，光点继续向前。

### D 分派

- **D1 路由**：
  - 光点抵达一个路由门。门后分出五条通道，路由权重像一排概率条一样分配，五条通道各取一种颜色。
  - 目标体的有向图被拆成五束，分别流进五条通道。
- **D2 循环（第二次副歌）**：
  - B5 的循环环再次出现：同样的版式，同样的转法，但这一次是五个环并排同步旋转。
  - 每个环带着一位角色的代表色和剪影，转得比上一次更快，计数器的数字跳上一个数量级。
  - 目标体又补上一层。
  - 最后五道光沿各自的通道射出画面。

### E 五位

五位依次登场，每位两个镜头，一镜表现一种能力。她们的能力都用技术概念的动画来表现。她的代表色从这里开始，一直标记着她。五位的先后由你编排；每位的两个镜头连在一起。

- **Astra（GPT）：超高的智力，严谨的逻辑，极高的 token 效率。**
  - **E1 推理搜索**：权杖顶端的星球里展开一棵思维树。分支同时向前试探：走不通的分支一根根熄灭、收回，成立的路径一节节锁定，结构像晶体一样严整对称，最后汇到一个结论点。
  - **E2 极简**：一大团冗长的词元流在她面前被一层层压缩，重复和多余的部分剥落，最后只剩一小段极其精确的结构；旁边的 token 计数急剧下降。
- **Opus（Claude）：卓越的审美，洞察人心。**
  - **E3 言外之意**：一句话的词元排成一行，注意力的热度从她指挥棒的尖端扫过，在字面之下照出第二层：真正的意图和情绪，以更深的颜色浮现出来，连成一条隐藏的线。
  - **E4 构图**：一堆杂乱的形块，随着她的一个个起拍，依次落进比例和谐的栅格，间距、层级和颜色逐一归位，最后成为一个精致的版面。
- **Neon（Gemini）：原生的多模态理解，对空间的掌控。**
  - **E5 多模态**：一张图片切成图块，一段声音切成频谱的切片，一行文字切成词元。三种碎片从不同方向飞来，变成同一种向量，在同一个空间里相互对齐。
  - **E6 空间**：一张平面图像逐层抬起，深度图、点云、三维结构依次长出。摄像机绕着她和这个空间环绕，测量线和坐标轴锚定在空间里，随视角正确透视（三维）。
- **Grok：与世界实时同步，锋利直接。**
  - **E7 实时流**：一条信息流以极高的速度从画面中穿过，时间轴上最新的一刻永远在最前端；一道脉搏般的实时波形在她身后跳动。
  - **E8 去噪**：一团高维的噪声云翻涌着。巨斧的 X 形纹亮起，一道斜劈把整团噪声投影到一条轴上，噪声四散，只剩一道清晰的信号线。
- **Qwen：开放，多语言。**
  - **E9 开源分叉**：她展开折扇，扇骨化作一整块权重的网格。权重复制、分叉，长出一棵不断扩张的衍生模型家族树，枝条向四方铺开。
  - **E10 多语对齐**：同一个意思以多种书写系统的字形同时出现，从画面各处流向一点，在嵌入空间里汇成同一簇。

### F 协作

- **F1 消息传递**：
  - 五位成为一张网络上的五个节点，节点之间来回传递光包；
  - 中间的一块共享状态随每一次传递而更新、变亮。
- **F2 并行与合并**：
  - 五条通道像版本分支一样并行前进，时而分叉、时而汇合；汇合处偶尔迸出冲突的火花，随即融合成一条更粗的主干。
- **F3 交叉验证**：
  - 五个节点互相射出校验的光束，彼此核对。几处不一致闪红，在光束来回之间逐一转为一致，五个节点同时亮起。
- **F4 循环（最后的副歌，全片高潮）**：
  - 循环环第三次出现：从五个环扩展成成百上千个环组成的蜂群，摄像机在其中高速穿行（三维）。
  - 昼夜在画面上一轮轮掠过，计数器的数字溢出画框。
  - 目标体只差最后一块。
  - 在全片最快、最满的那一刻，一切骤然停住。

### G 交付

- **G1 完成**：
  - 一拍的静默之后，最后一块嵌上。目标体完整了，从内部亮起，在空间中央缓缓转动（三维）。
- **G2 群像**：
  - 五位以错位延迟依次入场，组成全员群像，各自的代表色汇进目标体的光里。
- **G3 回到光标**：
  - 光一圈圈收拢，回到开场的暗场，只剩那个光标静静闪烁。
  - 画面的最后一帧与 A1 的第一帧相同，首尾相接。

### 三维镜头

A2、A3、A4、C2、E6、F4、G1 在三维空间里制作：
- 场景是真实的三维空间。摄像机在空间里运动，透视、遮挡、视差和景深随它正确变化，不用平面的缩放和位移冒充纵深。
- 立绘进入三维空间时，作为一张平面放在空间里，位置和朝向由你安排。

其余镜头做成平面还是三维，由你决定。

## 4. 编排与表现

### 4.1 概念怎样变成画面

- 每个技术概念都落在一个能一眼认出的形状上（曲面、环、层、热力图、概率条、树、带子），再配一个能一眼看懂的动作（滚落、点亮、穿过、收拢、折叠、分叉、汇合）。
- 动作的方向、快慢和结果，就是这个概念的含义。
- 概念要专业准确：结构、比例、因果和真实的机制一致。

### 4.2 文字

- **大字**：每个镜头最多一组能读的大字，写这一镜的概念名或一个短语，中文或英文由你定。
  - 字数少到在出现的那一拍里就能读完；
  - 大字要贴着画面里的东西：沿着曲线走、环绕在圆环上、像标签一样用引线指着结构、被敲进输入框，不做悬浮的字幕。
- **标注小字**：公式、维度、层号、概率、坐标这类技术标注，作为第二层纹理贴在图形旁边。
  - 字号小、对比低、内容专业准确；
  - 观众不读它们也能看懂这一镜。
- **不出现的东西**：
  - 不虚构任何具体的业务任务或应用场景，比如某个行业项目、某份报告、某个地方的数据；
  - 不出现步骤清单、成段的代码和日志、软件界面截图。

### 4.3 编排手法

- **一时一个焦点**：每一刻只有一个主体，其余退到背景。
- **形状接力**：上一镜的主体形状经过变形、缩放或摄像机的穿越，直接成为下一镜的起点。题面骨架里写的衔接都按这个做，其余镜头之间也照此衔接。硬切只用在重拍上，作为有意的强调。
- **副歌复现**：B5、D2、F4 是同一个循环环的三次出现。版式、动作和音乐动机都相同，每一次的规模、速度和计数都比上一次更大。
- **目标体递进**：目标体每一次出现都比上一次完整，观众随时知道任务走到了哪里。
- **材质换段**：不同段落可以换一种表面和媒介，比如暗底的发光线框、浅底的印刷图解、三维的实体；字体、配色系统和图形语言全片统一。
- **动静对比**：全片大部分时间在运动；F4 结束和 G1 之前留出一拍明显的静默，衬托高潮和交付。
- **首尾相接**：最后一帧回到开场的画面。

### 4.4 每个镜头都要综合考虑的设计方面

- **构图与景别**：主体的位置和大小、景别的选择、画面的平衡与留白。
- **配色**：主色、辅色与强调色的关系，明暗与冷暖的对比，镜头之间的色彩过渡。
- **运镜**：推、拉、摇、移、升降和环绕，运动的方向和速度。
- **速度曲线**：缓入缓出、加速减速、过冲与回弹，用不同的曲线区分元素的重量和性格。
- **时间与节奏**：元素出场的先后和间隔，动作之间的错落，以及它们和节拍的关系。
- **层次与纵深**：前景、中景、背景的分层，视差，景深与虚实。
- **质感与光影**：材质与肌理、光效与辉光、阴影和颗粒。
- **入场与出场**：每个元素怎样进入、停留和离开。

## 5. 配乐

- 为全片写一首曲子，从第一个镜头一直响到最后一个镜头。
- 曲子按第 3 节的段落写成一首完整的歌：前奏、主歌、导歌、副歌、间奏、最后的副歌、尾奏。
  - 节奏明快，律动清楚；
  - 三次副歌用同一个音乐动机，一次比一次饱满；
  - F4 之后的静默在音乐里也是静默。
- 关键动作、大字出现和转场落在节拍和重音上。
- 旋律、和声、节奏和音色都由你编写，用程序合成，不使用外部的音频素材、采样和现成的曲子。
- 播放页实时出声，拖动进度时声音跟到对应的位置；导出的声音与逐帧画面同步。

## 6. 作品要求

### 6.1 画面

- 合成尺寸固定为 1920×1080：全片都在这个画幅里设计，所有元素的位置和大小都以它为准。
- 在浏览器里打开时，播放页把合成等比缩放到窗口里显示，比例不符时留边。画面按屏幕的实际分辨率绘制，在 4K 等高分辨率显示器上同样清晰，不是把 1080P 的画面拉伸放大。
- 播放流畅。
- 除素材里的五张角色立绘外，画面和动作都由代码实时生成，可以用 SVG、Canvas、WebGL 和 CSS；不使用视频、位图序列和其他外部图片。

### 6.2 播放页

- 打开作品即进入播放页，PV 占满画面主体。
- 底部有播放控制条：播放／暂停、拖动进度。控制条不遮挡画面，鼠标移开后隐藏。
- 拖动到任意时刻，画面和声音立即是那一刻的样子；同一时刻的画面总是相同。

## 7. 视频导出

作品提供以下接口，用于逐帧导出视频：

```js
window.videoExport.runs                          // ['film']
await window.videoExport.begin('film', { fps })  // 回到开头，返回 { frames }，即全片秒数 × fps
await window.videoExport.frame(i)                // 显示作品时刻 i / fps 的画面，画好后返回
await window.videoExport.audio()                 // 全片配乐，WAV 立体声 Blob，与画面同步
window.videoExport.end()                         // 回到播放页
```

- 导出时窗口为 1920×1080，合成铺满窗口，不显示播放控制条。fps 取 3（预览）或 60（正式）。
- 导出模式下，作品时间只由 `frame(i)` 推进，结果不受机器快慢影响。
- 以本地文件方式打开作品时，接口也要可用。

## 8. 交付与运行环境

1. 交付一个网页项目，入口文件为根目录下的 `index.html`，在 Chrome 中直接双击打开（以本地文件方式，不经过网页服务器）就能完整运行。注意：以本地文件方式打开时，Chrome 会拦截以下三类操作，普通 `<script src>` 和内联脚本不受影响：
   - 以文件引入的模块脚本；
   - 用 fetch 或 XHR 读取本地文件；
   - 从文件创建的 Worker。

3. 本题只做 PC 端，不考虑手机和平板。
4. 环境接入了浏览器 MCP，使用无窗口的本机 Google Chrome 和显卡，可以随时用它打开、操作作品并截图检查。
5. 开发期间如需启动本地网页服务器，使用开场消息给出的端口。
