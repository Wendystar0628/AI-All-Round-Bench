# 艺术字与 Logo 设计：重新设计三款二次元游戏的 Logo

## 1. 目标总览

为三款二次元游戏重新设计 Logo，每款一枚，共三枚：《明日方舟：终末地》《崩坏：星穹铁道》《鸣潮》。

- Logo 的文字就是游戏名。**中文游戏名是主体，英文名是辅助。**
- 从这款游戏的世界观和主题出发，重新推导出字形。
- 再配上一个主体元素、英文和装饰，固定成一整块，用在游戏的主视觉、宣传片和启动画面上。

这是一道艺术字设计题，Logo 的核心是中文字本身。

| 节 | 内容 |
|---|---|
| 第 3 节 | 设计流程 |
| 第 4 节 | 各层的技巧 |
| 第 5 节 | 统一和可读的底线 |
| 第 6 节 | 在代码里处理字形的方法 |

每枚 Logo 用什么概念、改哪一笔、配什么颜色和材质，由你设计。每枚都要让人一眼读出这款游戏的世界和气质，三枚之间各有鲜明的特征。

要交付的有：三枚 Logo 的成品图和分层图、一个带展示片的展示网页，以及一份写明三张概念单的 `README.md`。

## 2. 主题与素材

### 2.1 三款游戏和 Logo 的文字

| 游戏 | 中文 | 英文 | 一句话 |
|---|---|---|---|
| 《明日方舟：终末地》（鹰角网络） | 主名「终末地」，系列名「明日方舟」 | Arknights: Endfield | 在行星塔卫二上拓荒建设的工业科幻 RPG |
| 《崩坏：星穹铁道》（米哈游） | 主名「星穹铁道」，系列名「崩坏」 | Honkai: Star Rail | 乘星穹列车穿行于各个世界的太空奇幻 RPG |
| 《鸣潮》（库洛游戏） | 「鸣潮」 | Wuthering Waves | 「悲鸣」之后的世界里，共鸣者与声骸的开放世界动作 RPG |

- **中文是主体。**
  - 主名是全枚最大、最醒目的字；系列名是次一级的字。
  - 两者都按这枚 Logo 的方言重新绘制。
- **英文是辅助。**
  - 英文名用作英文层，给中文补上大小和主次的层级，并负责收底和装饰。
  - 英文在体量和明度上让给中文主名：放大的英文退到中文后面，明度贴近底板；小号的英文贴着中文的结构线。
  - 具体用法由你设计（见 4.4）。
- **自行搜索游戏的资料**：这款游戏的世界观、故事、角色、美术风格和视觉资料，由你上网搜索，按设计需要取舍。
- **不参照官方现有的 Logo**：字形和构造从这款游戏的世界观和主题重新推导，做你自己认为好的设计。

## 3. 设计流程

每枚 Logo 都按下面的流程做。第 1 步在纸面上完成：概念单写全了再动手画。

1. **写概念单。** 动手之前，把这枚 Logo 的全部决定写成一张概念单（`README.md` 里交的就是它）：
   - **一句话概念**：把这款游戏最核心的东西，压成画面上的一个视觉现象。后面的每个元素都从这句话推出来，也都能说回这句话。
   - **三个气质词**、**一个具体物件**、**一个动作**。动作决定字的走势：往哪边倾斜，哪一笔伸出去。
   - **同源媒介**：这个主题在那个世界里，是用什么做出来、刻出来、印出来或者发出光来的。从它取一整套字形属性，比一项项单独调参数更统一。
   - **方言**：底字选哪一类；全组共用哪几条笔画规则（起笔收笔、粗细对比、转角、角度、点的形状、构造方式）；哪些部分保持不动。
   - **骨架**：
     - 字分几段、怎样排；
     - 主次和大小的层级，哪个字放大当签名字；
     - 重心往哪边走，全组用哪几个角度。
   - **母题落点**：高潮落在哪一笔，它和哪个物件同构；呼应落在哪一类笔画上。
   - **主体元素**：什么物件，处在哪个瞬间，放在整块的哪里，和高潮怎样呼应。
   - **英文分工**：选哪两三种用法，各放在哪里、承担什么。英文的内容和排法也尽量能说回概念。
   - **颜色角色**：字面、主题、阴影、高光、点缀、金属各用什么颜色。点缀色只给母题所在的地方。
2. **选底字，标笔画。**
   - 选一款横竖对比、字重和字怀离方言最近的现成字体作底字，它的骨架尽量沿用，改动集中在方言规定的部位。
   - 给全部字按笔顺标好笔画，出笔画标注图核对，做法见第 6 节。
3. **按顺序处理笔画：方言 → 高潮 → 呼应。**
   - 先把方言作为全组规则，一次执行到每个字；
   - 再在同构的那一笔上做唯一一处高潮；
   - 最后让同类笔画带上高潮的弱化特征。
4. **排成一整块。** 按概念单的骨架定每个字的位置和大小，看整块的外轮廓，在空出来的地方安排主体元素、英文、细线和底板。
5. **分层画出来，先黑白后颜色。**
   - 从后往前分层：底板、背景巨字、主体元素、细线、字、签名字、英文、星芒与高光。每层单独成图，叠回去严丝合缝。
   - 先用黑白定好形和明暗；黑白下成立了，再按颜色角色上色和材质。
6. **每一轮都出检查图，看过再改。**
   - 检查图包括：成品、黑白、去色、只剩字（拿掉底板、主体元素、英文和细线）、缩到小图、白底、黑底、分层展开、笔画标注图。
   - 出一轮检查图要很快，这样才能反复改、反复看。
   - 每一处改动都能用一句话说回概念。
7. **入场动画讲构造。** 各层按次序入场，每一层的入场讲出它自己的构造和母题：材质怎样出现，主体元素怎样动起来，高潮那一笔怎样落定。

三枚都要完整走完这个流程。先把第一枚从头到尾做完，把工具链跑顺，再做后两枚。三枚的打磨时间大致均匀，不要把最后一枚压成赶工。

## 4. 技巧

### 4.1 作用于全部字

- **方言来自源头**：先选定一类有来源的字形，用它带出整套属性，再在里面细调。
- **骨架**：字面率、重心、中宫、宽窄、倾斜、字距，作用在整组字上。
  - 横画对齐到几条共享的水平线。
  - 要倾斜的字，先在水平状态把结构做对，再整体斜切。
- **端头与对比**：每类笔画的起笔收笔、横竖粗细比，全组统一执行。同方向的笔画同粗，同类的收笔同形。
- **角度集**：全组只用几个角度，竖、横、撇捺点各取一个。所有斜笔、斜切和伸出去的线，都从这几个角度里取。
- **特征笔画**：挑这组字多数都有的一种笔画，比如点、撇捺或共同的偏旁，给它一个个性化的处理，并让它在每个字上都出现。
- **构造规则**：题材有明确的物理状态或工艺时，给全组一条“怎么做出来”的规则。
  - 每个字都做，强度可以有差别，结构不动。
  - 全组统一的轻改是底线，比如端头、对比、转角、点的形状；构造规则做多重，按题材定。
- **视觉修正**：以眼睛为准，而不是以几何为准。
  - 横略细于竖，重心略偏上；
  - 笔画多的字略放大、略减细，口字框往里收；首尾两个字笔画都少时，略加粗；
  - 按字与字之间的留白相等来定字距；
  - 眯眼看、换个大小看、倒过来看，各字的大小和灰度要均匀。

### 4.2 意象落在字上

**落点表**：哪些笔画和哪些形本来就像。

| 笔画或部件 | 可以同构的形 |
|---|---|
| 点 | 水滴、星光、火舌、叶片、圆珠、音符头 |
| 十字交叉 | 星芒 |
| 封闭框（日、口、月、田、囗） | 太阳、月、表盘、晶圆、眼、环 |
| 横（长横、顶横、底横） | 谱线、尺线、地平线、光束、走线 |
| 竖 | 雨丝、杆、柱、尖塔、剑 |
| 撇、捺 | 刀锋、羽、叶、尾 |
| 钩与收笔 | 卷须、螺旋、浪、藤、火焰尾、锚链 |
| 宀、穴、广这类“顶” | 屋顶、穹顶 |
| 象形部件（鸟、山、雨、水、火……） | 它本来画的那个东西 |
| 最外缘的长笔画 | 花饰、伸出去的线 |
| 字缝、两段之间的空 | 主体元素 |
| 英文首字母 | 轮廓和它相近的物件 |

**手法：**

- **同构置换**：把一笔或一个部件，换成和它本来就像的物件。
  - **同构才换**：只在同构的位置换。找不到同构的位置，就把母题放到主体元素或细线上。
  - **占位不越位**：新形占住原笔画的位置、走向和大致体量，骨架不变，读者仍然“看得见”那一笔。
  - **画法同族**：新形用这套字的方言重画，粗细对比、端头和材质都一样。
  - **形要点题**：选能讲出这款游戏的物件，最好一个物件同时画出主题的两层意思。
  - 完整的具象置换只做一处，作为高潮。
- **同族呼应**：同一母题的弱化形，落在同类笔画上，弱化到像这套字本来就长这样。
- **包裹与嵌入**：
  - 物件把一个字包在里面，被包的字缩小，但完整；
  - 或者字嵌进物件里；
  - 或者英文首字母兼作母题。
- **正负形**：让字内的留白、字与字之间的空隙形成有意义的形。负形读得出来，字也照样读得出来，几个字的负形分量接近。
- **整字体势**：不换部件，只让整个字的姿态和力的方向讲出主题，字仍然认得。

### 4.3 字与字的关系

- **主次与错落**：
  - 主名里可以有一个字放大，作为签名字；被放大的字要承担语义。
  - 首字定下全组的标准，首字的首笔可以夸张，后面的字用拉长、拖尾的笔画呼应它。
  - 系列名缩小，放在主名的上方、侧边，或嵌进空隙。
  - 字可以错开排，或者基线逐级升降。
  - 主次靠体量和位置拉开。大小、字重、字体类别、颜色、字距里，至少有两样拉开。
  - 高潮集中在一两处。
- **延伸与贯穿**：某一笔顺着自己的笔势拉长，收成发丝细线，指向主体元素或英文。
  - 延伸的是同一类笔画，只延几笔，方向一致；
  - 线和字的最细笔画同粗。
- **共笔与咬合**：相邻的字共用一条长笔画，或者在同一高度上连起来。
  - 只连能自然对接的笔；
  - 要么全组成系统地连，要么只连一处；
  - 连接处重新平衡灰度，和其余笔画一样匀。
- **截断**：一笔被切开、错位，或被别的东西遮掉一截，表达割裂、锋利、折射这类意思。
  - 断口形状统一，全件一处；
  - 断开的笔画，眼睛仍能补全。

### 4.4 字外的层

- **主体元素**：
  - 一个轮廓一眼认得的物件，用线稿或剪影画，和字是同一支笔：线宽取字的细笔画，形用平涂或这枚 Logo 的材质。
  - 和至少一个文字层同色同料，顶出整块外轮廓上的一处突起；体量服从中文主名。
  - 放法有五种：放在字后、插在两字之间、把一个字包住、当英文首字母、当连接件把几块串起来。
  - 放在字后时用线框或半透明，字的笔画完整地露出来。
- **英文**：
  - **风格配对**：英文和中文至少共享一种基因，比如同一种粗细对比、同一类收笔，或同一套颜色。宋体、明朝配衬线，黑体配无衬线，书法配有文化气质的罗马大写。
  - **用法**：英文给中文补上大小、主次的层级。常用的用法有六种：
    - 一行拉开字距的小号大写作底线；
    - 放大的首字母像括号一样抱住中文；
    - 小词塞进字与字之间的凹处；
    - 一条手写体斜穿主字；
    - 巨大的英文压在中文后面作背景，明度贴近底板，被中文挡住一部分；
    - 沿边缘竖排的小字。
  - 每枚选两到三种，英文最多两类字体。
  - **尺寸与对齐**：
    - 小号大写拉开字距，手写体保持原字距；
    - 装饰小字的字高在主字的三分之一以内；
    - 基线和字高对齐到中文的某条结构线：字面框的顶或底、某一横的高度、放大首字母的中线。
  - **和中文交叠**：
    - 明度、粗细、色相至少错开一样；
    - 手写线从中文的横画或细处穿过；需要时，上层字加一圈底色细边，把下层切开。
  - **字重与咬合**：英文的字重轻于中文，并和中文咬合在一起：嵌进中文的凹处、贴着中文的边线，或者被中文压住一部分。
- **细线与点**：线宽和字的最细笔画相同，端点用和母题同族的小形。伸出去的线，是某一笔的延伸。
- **花饰**：主题需要时使用。
  - 从最外缘的笔画顺着运动方向长出，走进外轮廓空出来的地方，回头托住英文，或者收住整块。
  - 以椭圆为基础，曲率连续；粗笔之间不交叉；首尾各一处为限。
- **底板**：主题色暗调的不规则色块，让 Logo 放在任何画面上都读得清。
  - 边缘带干笔、颗粒或撕边；
  - 轮廓可以取主题里某种形；
  - 只用一种主题色。

### 4.5 上色与材质

颜色按角色分工：

| 颜色角色 | 管什么 | 面积 |
|---|---|---|
| 字面色 | 读 | 中，全图明暗反差最大的一层 |
| 主题色 | 气质 | 大，底板和主体元素 |
| 阴影色 | 把字和底分开 | 只贴着字边，用主题色的暗调 |
| 高光 | 质感与精致感 | 极小，受光一侧的边和角 |
| 点缀色 | 记忆点 | 很小，一处为主，一两处呼应 |

- **点缀色**：只给母题的高潮、主字、首字母或一个英文词，并和主体元素同色。它可以像纹理一样，从主处在局部扩散开、渗进字面，越远越稀。
- **材质给谁**：两种做法，选一种。
  - 一种材质贯穿字面、主体元素和细线；
  - 或者签名字单独换料，这时它和主体元素同料，其余的字也带一层同样的细质感（颗粒、渐变、光晕），整块像一个物体。
- **派生的层**：一个光源。描边、投影、厚度、内线都从字形外扩、内缩、偏移得到，方向一致。
- **描边、投影与发光**：
  - 内层一道细暗边把字和底分开，外层用主题色或金属色描边；
  - 投影偏移的距离，看上去各处相等；
  - 发光用主题色；
  - 汉字内部的空白少，描边比西文节制，层数少而准，字怀保持通透。
- **材质**：
  - 画出它反射的东西和明暗分区，比如金属的天空带和地面带，玻璃的透光和边缘高光；
  - 渐变方向全组统一，最亮处留给关键词。
- **颗粒与做旧**：一层全局纹理压住所有层。它来自题材的工艺，全组一致，程度在那种工艺真实会出现的范围里。

## 5. 统一与可读的底线

- **一支笔**：全组一种起笔收笔、一个横竖粗细比、一种转角；局部的小细节，种类不超过两种。
- **一套**：一套线宽，一种主材质，一个光源，一个母题。
- **三级主次**：
  - 中文主名最亮、最大；
  - 主体元素和大号英文次之；
  - 细线、点、星芒、小字最弱。
- **可读**：
  - 拿掉主体元素、英文和细线，中文游戏名仍然完整可读；
  - 置换只换形和质地，字的结构保留；
  - 装饰放在字的周围，要读的笔画完整地露出来；
  - 整枚缩到高 64 像素时，主字还认得出；
  - 去色、白底、黑底都成立。

## 6. 字形的处理方法

字体里的汉字是一整块轮廓，没有“笔画”。全组规则、同构置换、呼应和延伸都以笔画为单位，所以处理字形的核心是：先把字变成笔画数据，再在笔画上执行规则。

1. **取底字**：从字体文件取出字的矢量轮廓作底字。选横竖对比、字重和字怀离方言最近的底字，改动最少。可变字体可以取任意字重。
2. **标笔画**：
   - 在坐标底图上读坐标，给每个字按笔顺标出每一笔：类型（横、竖、点、撇、捺、提、钩、折）、所属部件、中线、宽度。
   - 按中线把每一笔从整字里切出来，切剩的碎块归给最近的一笔。
   - 标完出一张笔画标注图核对。
3. **按查询批量执行规则**：
   - 方言写成作用在一类笔画上的操作，比如“所有的点”“收笔朝下、末端空着的竖”“最长的横”“某个部件”，查出来一次做完。
   - 同一条规则在各字上的强弱可以单独调。
4. **改一笔的三种方式**：
   - **做手术**：在原轮廓上切、削、移点、加厚收细、把曲线折成直段；
   - **重画**：按中线和宽度重新生成轮廓，端头和转角由方言决定，粗细沿中线变化；
   - **换成变体**：母题的形占原笔画的位置、走向和体量，替换后并回字里。
5. **骨架变换作用在中线和点上**：调宽窄、重心、中宫时，移动中线和控制点，再重画轮廓，笔画的粗细和端头保持原样。要倾斜时，结构做好后整体斜切。
6. **合并成干净的轮廓**：改好的笔画和字的其余部分，用布尔运算合成一个轮廓，接缝处没有细缝和重叠。
7. **派生层来自字形**：
   - 描边、投影、厚度、内线由字形外扩、内缩、偏移得到，沿同一个光源方向；
   - 延伸线从笔画的收笔顺着方向长出来。
8. **矢量为准，最后栅格化**：
   - 形全部在矢量上完成，最后按成品尺寸栅格化；
   - 所有层共用一张画布和一套坐标，层与层严丝合缝；
   - 展示片里要逐笔形变的部分，可以直接用导出的 SVG 路径。
9. **图层样式作用在字形上**：斜面、受光边、内阴影、发光、颗粒、撕边、颜色扩散，都在字形的覆盖率和距离场上计算，跟着笔画走。
10. **每一轮都看检查图**：黑白、去色、只剩字、缩小、白底、黑底，加上笔画标注图，看过再往下做。

`素材\字形底座\` 把这些处理用到的通用管道写好了：取字形、几何运算、笔画数据、画布、图层样式、出图和检查。它不带任何风格，可以直接用、改，或者只用其中一部分。字形和视觉怎么设计，由你决定。

## 7. 每枚 Logo 要有的

- 中文游戏名作主体（主名和系列名），英文名作辅助。
- 游戏名的全部汉字，都按这枚 Logo 的方言重新绘制。
- 一处同构的高潮，以及同类笔画上的呼应。
- 一个主体元素。
- 两到三种英文用法。
- 细线与点。
- 底板。
- 按角色分工的颜色和材质。
- 三枚之间，方言、母题、主体元素、配色和材质各不相同。
- 至少两处你自己构思的设计，在 `README.md` 里写明是哪几处。

## 8. 展示网页

- 打开 `index.html` 先看到三枚 Logo 并排，点进每一枚，有它自己的展示页：Logo 放在为它设计的背景上，背景由代码绘制，和主题相配。
- 网页里能播放第 9 节的展示片，可以暂停和拖动进度。
- 文字在 1920×1080 下清晰可读。
- 本题只做 PC 端。

## 9. 展示片

展示片 `show` 依次展示三枚 Logo，每枚约 30 秒。重点是展示设计怎样构成：每枚先给出成品，再拆回底字，一步步搭回成品。

每枚 Logo 是一个连续的镜头。所有变化都在同一枚 Logo 上发生，不切成一张张卡片：

1. **成品入场**：各层按次序入场，组成成品，每一层的入场讲出它的构造和母题（第 3 节第 7 步）。
2. **拆回底字**：颜色褪去，底板和装饰退场，字形变回底字原样，呈灰色；骨架的辅助线（共享的水平线、角度线）随之画出。
3. **方言**：方言的全组规则一条条执行。每执行一条，同一类笔画在所有字上同时形变成新形，配一行字幕写出这一条规则。
4. **高潮与呼应**：镜头推近高潮那一笔，物件形从原笔画里形变长出；镜头拉回，同类笔画上的呼应依次亮起，引线标出落点。
5. **组合**：底板、主体元素和英文滑入各自的位置，细线标出对齐关系：英文的基线和字高贴着中文的哪条结构线。
6. **黑白到上色**：先停在黑白稿，再按颜色角色逐层上色；材质上扫过一道光，点缀色从母题处扩散开。
7. **分层展开与定格**：整块沿纵深拉开成各层，标出每层是什么；合回之后，停在为它设计的背景上，只保留缓慢的光效。

- 三枚用同一套演法：段落顺序、字幕样式和辅助线的画法一致。
- 字幕只写这一步的设计动作，简短。完整的概念单留在 `README.md`，不上屏。
- 画面里不出现网页的导航和按钮，不需要声音。

作品提供以下接口，用于逐帧导出展示片：

```js
window.videoExport.runs                          // ['show']
await window.videoExport.begin('show', { fps })  // 回到开头，返回 { frames }，即全片秒数 × fps
await window.videoExport.frame(i)                // 显示作品时刻 i / fps 的画面，画好后返回
window.videoExport.end()                         // 回到正常的展示网页
```

- fps 取 3（预览）或 60（正式）。导出模式下，片中时间只由 `frame(i)` 推进，结果不受机器快慢影响。
- 画面适应调用方设置的窗口大小，最高到 3840×2160。
- 以本地文件方式打开作品时，接口也要可用。

## 11. 交付与运行环境

1. 展示网页在 Chrome 中直接双击 `index.html` 打开（以本地文件方式，不经过网页服务器）就能完整运行。以本地文件方式打开时，有这些限制：
   - 以文件引入的模块脚本，用 fetch 或 XHR 读取本地文件，以及从文件创建的 Worker，都会被拦截；普通 `<script src>` 和内联脚本不受影响。
   - 本地图片可以显示，也可以画进 2D 画布，但画过以后读不了画布的像素，也不能作为 WebGL 纹理上传。
2. 本机装有多种中、日、英文字体，字体文件在 `C:\Windows\Fonts`，可以读取。字形可以从字体文件取出轮廓再改造，也可以从零绘制。
3. 可以使用本机已有的编程语言、库和工具来绘制和导出 Logo。本机的 Python 装有 numpy、scipy、Pillow、fontTools、skia-pathops、opencv-python。
4. 可以联网搜索和查看资料。
5. 环境接入了浏览器 MCP，使用无窗口的本机 Google Chrome 和显卡，可以随时用它打开、操作作品并截图检查。
6. 开发期间如需启动本地网页服务器，使用开场消息给出的端口。

## 12. 规定

1. 所有文件只在工作目录（本题面所在的文件夹）内读取、创建和修改，不访问其他路径；运行编译器、解释器、库、浏览器等必需工具时必须访问的安装路径和临时目录除外，读取 `C:\Windows\Fonts` 里的字体文件也除外。截图等临时文件放在临时目录。
2. 全程独立作答，不开启子代理（subagent），不使用任何多代理或并行协作功能。
3. 不使用 `runas`，以及任何以其他账户身份登录、需要输入账户密码的命令。需要结束进程时，只按 PID 结束你自己启动的进程，不按进程名批量结束（`taskkill /IM`、`pkill`、`killall`、`Stop-Process -Name` 等）。
