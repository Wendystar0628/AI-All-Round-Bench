# AI模型考古

测试系列「AI模型考古」：把已经被新一代取代的旗舰模型请回考场，看 AI 编程智能体的能力怎样随时间变化。

系列按期进行。每一期请回同一年代的一批模型，按它们的水平单独出题，所以每期都是一个独立的专题，有自己的题目、参测名单、标识和成绩；成绩只在一期之内比较。各期共用一套视频模板、设计系统和网站栏目，总站上在 `/archaeology/` 下。

- 每期一个文件夹 `第<n>期-<年代>/`，专题标识为 `archaeology<n>`。题目定下来后，在文件夹里加专题清单 `专题.json`、参测登记 `参测.json` 和 `题面/`，格式与其他专题相同。
- 系列共用的设计系统放在 `设计/`。
