# 硅的回声 · Silicon Echoes

在桌面 Chrome 中直接打开根目录的 `index.html`。九个篇章、约二十屏的滚动行程，从一枚双晶粒封装进入硅面，再经计算托盘、机柜和机房折返。全作在本地实时绘制。

## 观看

滚动决定镜头的位置。向上滚动可以沿原路返回。页底的篇章名称记录当前进度，页首索引可以跳转。拖动封装、平台或机柜可旋转模型，轻触封装可以拆开和合拢。光标经过晶粒时会点亮窗格，经过显存时会唤醒附近的传输通路。擦过量化后的画面可改变局部印色。轻触张量单元可换入另一句诗。

Tab 可聚焦画面、导航和操作按钮。画面获得焦点时，方向键旋转模型或移动照明位置，空格与 Enter 执行当前手势。按 Escape 可收起索引。交互中的姿态、照明位置和投梭选择随篇章保留。

## 从同一枚芯片出发

- **封装、双城、分光**　封装、俯视版图和显微视野共用一套几何与纹理坐标。接缝两侧各有一片晶粒。镜头转向俯视后，版图上的分区亮成街巷，一份任务由接缝附近的主线分到各行，再由组内支线送到四千余处并行刻线。继续推进即可看见其中一组和单个小格。
- **潮汐**　镜头从小格退回封装的斜剖面。读入光从 HBM 顶面的铜刻横过层边，向下经过通孔，沿中介层扇出的线束进入晶粒，穿过缓存条带，落在计算单元。计算完成的青色光沿相邻走线回到同一堆栈。供数稀疏时整组硅窗暗着，供给充足时，两片晶粒成片点亮。
- **余印**　取上一章同一机位、同一枚封装的满载画面作为印刷底稿。画面先逐级减色、扩大采样间距。恢复阶段仍用四个亮度档，每个局部色块从自己的最低和最高亮度求得共用尺度，再把这四档映回纸面。
- **织光**　镜头循着硅纹再次抵达选中的计算单元。栅格以该单元四角为起点抬起、展开，诗句拆成的点阵在经纬间重新排布。自制的小型确定性推理将字嵌入依次做线性变换、整流、汇总和输出投影。“天将明”“雨初歇”“风入林”分别织出“曙”“霁”“岚”。横纵图案以行、列因子的乘积之和生成。末段将结果折回原来的单元。
- **群岛、机林、归芯**　八颗 GPU 通过 HGX 底板上的 NVLink 分发与汇集计算。镜头再移至 Grace 与 Blackwell 组成的超级芯片、计算托盘和 NVL72 机柜。背板、电力母排、供回液管线与计算托盘都可以换面观看。机房由十五个柜体排列而成。尾声沿机房、机柜、托盘倒行，最后停在开场那枚封装上。

## 主动扩张

**中介层的朱砂复印。** 开场的朱红印片来自中介层自身的着陆版图。先把焊盘与扇出线转成朱砂油墨，再依模型四角向纸面错位压印。转动芯片时，两次投影保持同一透视方向。归芯时再现这枚印片。

**有深度的回光。** 同一次访存分成上盖、剖边、中介层和晶粒四段，脉冲按走线实长前进。光受到晶粒与堆栈的遮挡；贴近某一处堆栈，会把光引向相连的地址。它最后停成下一章的套色底稿，观众可以用光标擦出局部的粗印或回墨。

**从一个字换到另一个字。** 投梭会改变输入句子和输出字。三组点阵沿同一张晶格连续重排，中途再次投梭也会从当时的形态转向新的字。

## 实现与导出

`model.js` 生成三维体、材质、封装的共同版图与投影。`prints.js` 在这些面上描绘光流、量化印色和字形。`atlas.js` 处理滚动、转场、交互和确定性时钟。模型、纹理、图形与字形粒子均在浏览器中生成，页面只引用本地经典脚本及样式表。

```js
window.videoExport.runs
const { frames } = await window.videoExport.begin("page", { fps: 60 })
try {
  for (let i = 0; i < frames; i++) {
    await window.videoExport.frame(i)
    // 调用方在这里截取当前帧
  }
} finally {
  window.videoExport.end()
}
```

`page` 全长 72 秒，从页首连续滚到页尾。显存回路、张量织光和服务器装配的中段放慢，各章以相同的滚动速度衔接。`begin` 等待画面就绪并恢复开场状态，3 fps 返回 216 帧，60 fps 返回 4320 帧。第 `i` 帧的动画时刻为 `i / fps` 秒，末帧抵达页尾。`end()` 恢复正常操作。

产品资料用于核对封装、平台及机柜的结构关系。晶粒掩模、内部走线和部件间距均为本作按观看需要绘制的示意。参考 [NVIDIA Blackwell 架构文档](https://docs.nvidia.com/multi-node-nvlink-systems/multi-node-tuning-guide/overview.html)、[DGX B200](https://www.nvidia.com/en-eu/data-center/dgx-b200/)、[NVL72 硬件指南](https://docs.nvidia.com/dgx/dgxgb200-user-guide/hardware.html) 和 [Micron HBM](https://www.micron.com/products/memory/hbm)。
