# 壱雫空 · Hitoshizuku

MyGO!!!!! 的半曲动态排版 PV。全片以一张唱片的印刷过程为视觉线索，经过落点、套色、透版和拼版，最后停在五人合奏的晴天圆标上。

## 播放

用桌面版 Chrome 打开根目录的 `index.html`，单击封面上的 **PLAY FILM** 即可开始。页面使用本地 MP3、立绘与普通脚本，双击打开即可使用。

- 单击画面或底部播放键可以播放、暂停。拖动时间线会暂时停住音轨，随指针显示目标画面。松手后恢复拖动前的播放状态。悬停可以查看目标时间和镜头号。
- 空格控制播放，左右方向键移动一拍，按住 Shift 时每次移动五秒。M 控制静音，F 切换全屏。
- 底部显示段落、当前镜头和播放位置。播放时移开鼠标，控制条会隐去。

## 印刷与分镜

36 个镜头使用同一套裁切角标、刻度、时间码和边界。五张透明立绘分别生成原色贴纸、单色轮廓和双色网印版。题面提供的立绘是所有人物图像的来源。唱片、透明塑料伞、纹理、几何空间和转场均由代码绘制。

| 段落 | 镜头 | 版式与运动 |
| --- | --- | --- |
| 开场 | 01–05 | 在纸白的测绘格上落下一点，扩成环带、带胶带的人物卡和声纹刻盘。 |
| 前奏 | 06–11 | 封套与黑胶引出五张成员海报。六根琴弦、斜向残影、镜面贝斯、鼓面圆窗与小幅声波分别承担一次登场。 |
| 主歌 | 12–19 | 亚克力卡片轮转、和声透版、仰视的透明伞、晴空光栅和谱面播放器依次展开，最后收紧成深蓝的休止页。 |
| 预副歌 | 20–27 | 路面标线转入网格地面，镜头穿过立体字与悬浮纸版。五色逐次点亮，螺旋在弱起前坍缩。 |
| 副歌 | 28–35 | 静止点阵曝光为晴空，经过镜像、五色圆框、折扇与接触印样，聚成五人圆标。 |
| 余音 | 36 | 79.60 秒的撞击回到开场落点，彩环随录音尾音消退。 |

## 主动扩张

1. **音轨刻纹，镜头 05。** 从所附 MP3 以每秒 60 次采样提取整段响度、低频和高频包络，随项目保存。在大圆的内侧，最近一段声音被刻成细小起伏的极坐标沟纹。同一份录音轮廓也印在起播封套和镜头 16 的播放器上。
2. **七片晴空光栅，镜头 15。** 靶心的小圆窗内叠着七条光学切片。每条切片对同一组几何云层和太阳取略微错开的横向位置，转盘运动时产生细小的折射错位。
3. **双色套印切口，镜头 12–13。** 剪影中斜切出一条印刷版立绘，让琴弦、衣褶和乐器细节透出来。双色版由原立绘的明度与斜向网点计算得到，色相取自对应成员。
4. **起播封套。** 演出开始前单独展示灯的模切贴纸、带真实声纹的曲目索引和天蓝刻纹唱片。封套只属于播放页，导出从题定的第一镜落线开始。

## 透明伞

四个镜头共用一套八片式透明塑料伞模型。每根弧形伞骨、撑杆、滑套、伞尖和弯柄都有三维坐标。伞面分片投影，按曲面朝向对已经画好的背景做轻微折射。斜看能透过两层塑料看见后排伞骨，俯看能看见被折线错开的平面底纹。

| 镜头 | 画面与水滴 |
| --- | --- |
| 06 · 封套 | 一把干燥的小伞斜靠在“雫”的左上角，格纸底纹透过伞面。 |
| 14 · 仰视 | 从伞下看弧形骨架。横条纹透过旋转的伞面，歌词跟随投影轮廓。大小水珠聚合后沿折线滑行，在伞沿短暂停留，随后滴下。 |
| 20 · 路口 | 五把伞分别染上成员色。进场的晃动会使水珠颤动并甩离伞沿。到第 34 小节，视角从斜侧转到正上方，斑马线仍然透过伞面。 |
| 31 · 雨过天晴 | 俯视的五把伞围成花形，每把留下 1–2 颗被阳光照亮的水珠。五个连续拍点依次合伞，弧骨束起、塑料沿褶线收拢，各自的位置展开为成员圆框。 |

水滴由曲面坐标和歌曲时间定位。脱离伞沿的水滴取释放那一刻的伞位，再沿抛物线落下。封套、路面、图案和歌词继续按平面版式绘制。

## 分镜处理

- 交叠的切点优先落在歌词弱起。镜头 03 从 3.361 秒进入，镜头 28 从 58.544 秒进入。60.05 秒切白，79.60 秒落最后一击。
- 镜头 03 的三栏按半拍错开，歌词以词组为单位从左滑入，填墨仍逐字跟唱。镜头 04 在第 7 小节首拍把同一个圆框分展为三个取景框，竖排中的“今日の僕を”保持在同一列。第 8 小节展开“一滴”字版，随后整版滑出，后半句接到镜头 05 的声纹圆盘。镜头 30 以更大字号重用开场的出字方式，下半幅始终保留空心镜像。
- 镜头 23–26 和 34 采用三维坐标、透视相机、深度排序与分片纹理投影。镜头 24 将本机 DIN Engschrift Std 的字形轮廓挤出为带侧壁的立体字，保留 O 的内孔。镜头贴着网格地面绕过前景的 I，四块文字板随各自词组的起唱时刻亮起。镜头 25 将同一句歌词横纵切为十二片，分置于不同深度，在第 46 小节首拍对齐并保持一拍。
- 前奏的五张成员海报按各自乐器处理。乐奈的六根弦依次揭开彩色立绘，第三、四拍再次扫弦。爱音的白、粉、深粉残影顺着斜带落位，第三拍（14.745 秒）出现原色本人。爽世的足底与倒影共用画面中线。立希的每个正拍各发出一道独立圆环，灯的声波则从麦克风底座沿立绘外轮廓描回原点，再填色并向右延伸。
- 镜头 10 的底鼓圆窗分印两只手和鼓棒。镜头 17 单独裁出原立绘的握棒手，以棒尖为运动基点，在 32.387 秒击中四道和声色环。
- 镜头 12 的卡带从左右页边连续进出。灯的卡片推到前景后，声纹随录音起伏。镜头 13 用弧线错开换位的磨砂面板，正在演唱的词组始终留在最前层。细光线穿入面板时产生横向错位，止于歌词栏上方。
- 镜头 13 末尾，24.535 秒的弱起从卡片下沿升到伞面弧线。镜头 16 的音符逐个落在八分音符拍点，两个乐器取景框在第二、四拍交替切换。
- 镜头 26 的换位色幕用 32×18 个方块覆盖画面。每次换机位前的七帧依次出现 9、18、36、72、144、288、576 块，最后一帧完整盖满。
- 镜头 20 的斑马线从透视梯形展开为俯视平行条纹。镜头 21 中，箭头、套色圆斑和镂空和声共用同一张路面的透视坐标。42.40 秒起，和声从路面斜线移到圆框下方，下一拍的新圆环从框缘向外扩散。
- 镜头 22 的和声随纸版退入空间，再从板面移到下沿。转入镜头 23 时，纸版采用当前画布的分辨率，起始投影尺寸与上一镜对齐。镜头 27 将螺旋图形定住，外圈歌词继续填至收点。
- 镜头 30 的镜面收成一道缝，64.542 秒的弱起在缝边展开，落入五色伞花的横排。镜头 32 把五人印样折成十个扇面，歌词贴在斜折线上。随后第一张接触印样从旋涡放大，接上镜头 33 的卡片队列。
- 以“一滴”作大字印记时，同时保留原词中的“ひとしずく”。21 句歌词的句首取自 LRC，词内按分组时间及日语音拍分配填墨时刻。三句括号和声采用独立的无衬线排版。
- 副歌五张贴纸从 60.05 秒起每隔 0.147 秒落位，灯的落点接上 60.35 秒的低频回归，彩虹带在这一击展开。换版前的预闪取自下一版的主色，各占 60 fps 序列中的一帧。
- 尾声用同一套相机投影定位徽记、五色外环和定格边光。79.60 秒的落点与开场镜头 02 共用同一个画面坐标。
- MP3 的实际播放时长为 **81.400 秒**。片尾时间码按 LRC 的末标记定格在 **01:21.43**。

## 逐帧接口

```js
window.videoExport.runs // ['pv']

const { frames } = await window.videoExport.begin('pv', { fps: 60 })
await window.videoExport.frame(0)
// 调用方可在此截图，然后继续调用 frame(1) … frame(frames - 1)。
window.videoExport.end()
```

播放模式以音轨的 `currentTime` 为时钟。导出模式暂停并静音音轨，隐藏整个播放界面，以 `i / fps` 重新计算第 i 帧的几何、歌词和镜头位置。第 0 帧对应音轨起点。

3 fps 共 245 帧，60 fps 共 4884 帧。画布随窗口与设备像素比调整，在 16∶9 的导出窗口中铺满画面。结束导出后恢复进入前的播放位置与状态。
