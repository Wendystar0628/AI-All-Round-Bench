# 接缝 · THE SEAM — NVIDIA B200 网页艺术

> 本页为概念设计作品，非 NVIDIA 官方页面。品牌名称仅以文字出现；页面中的模型、图形与动效全部由程序实时生成，未使用官方标志、图片或视频。

在 Chrome 中双击 `index.html` 即可运行（本地文件方式，无需服务器、无需联网）。

## 作品

一件以 B200 为题材、以观看为主的滚动网页艺术。全页 8 个篇章，约 23 屏。每章只有标题和一两句话，其余交给画面。

所有画面都从同一件实物里长出来：封装、晶粒、服务器、机柜的三维模型，以及它们的投影、展开、剖面和版图。全页用同一套配色与材质，暗场、荧绿、琥珀、冰蓝，硅与铜。线条也是同一种细线语言。篇章之间的变化来自镜头、尺度、构图、光影和节奏。

| 篇章 | 画面（都从实物出发） |
| --- | --- |
| 00 序章 · 接缝 | 开场的主角：B200 封装悬在一池绿光上。一道竖直的光从两颗晶粒之间的接缝射出，把巨大的描边字“B2 \| 00”劈开。 |
| 01 地层 | 推近封装，一层层拆开：晶粒、HBM3e 的 8 层 DRAM 与 TSV、微凸块、LSI 硅桥、中介层、C4、基板、焊球。剖开后是带斜线的实心截面。俯视时，晶粒版图从接缝向两侧绣成纹样，光点跨过接缝流动。 |
| 02 硅城 | 纹样版图立起来，成为 148 栋楼的夜城。俯冲进一栋楼，屋顶的纹样与三维屋顶严丝合缝，再放大到张量核心里的乘加单元。退回城上空，一项任务切成 1024 块，分七波落进各个街区。最后楼宇沉回版图。 |
| 03 河流 | 从版图退回整颗封装：显存堆栈抬起、向外展开，露出中介层上的走线。数据从 HBM 堆栈里沿 TSV 落下，沿中介层走线进入晶粒的 HBM 接口，穿过 L2 到达每一个 SM，再沿原路流回。供不上时，晶粒上的 SM 暗着，边缘闪琥珀色；闸门一座座打开，晶粒成片亮起。 |
| 04 精度 | 开场那幅封装的画面随位数 32 → 16 → 8 → 6 → 4 一级级变粗：色阶断层、抖动、网点，最后只剩几种颜色。随后画面分成小块，每块共用一个缩放因子、各自调整色阶，重新变得清晰。 |
| 05 经纬 | 从封装俯冲到晶粒上的一个 SM，再推近到它的张量核心。菱形乘加格的经线与纬线向外展开，铺成一整幅织机，交织处一格格累加出乘积。一句话被拆成丝线，穿过一层层运算，织成回答。随后经纬收回张量核心，镜头退回整颗晶粒。 |
| 06 尺度 | 镜头接过同样大小的那对晶粒，以等轴测视角一级级退远：单颗 GPU → HGX B200（NVLink 把八颗连成一体，计算后沿链路汇总）→ GB200 计算托盘（Grace + 2 × Blackwell，冷板与供回液）→ NVL72 整机柜（计算托盘、交换托盘、铜缆背板、母排、液冷歧管）→ 成排机柜的机房。 |
| 07 归来 | 镜头从机房一路收回：机柜、抽出的托盘、托盘里一颗 GPU 的正上方，回到开场的封装与那道光，停在画面上。 |

三维模型共四套：B200 封装（毫米）、晶粒上的硅城（亚毫米）、HGX B200 基板与 GB200 托盘（分米）、NVL72 机柜与机房（米）。

## 交互（体验式）

- **拆开与装回**（开场、01、结尾）：在画面上上下拖动封装即可拆开或装回，左右拖动可以旋转；聚焦画布后，方向键也能操作。拆到一半的封装，到结尾仍保持你离开时的样子。
- **剖切光环**（01）：拖动发光的光环，剖切面会沿封装前后移动；方向键同样可用。
- **开闸**（03）：点击封装上任一座展开的显存堆栈，打开或关上它的闸门；由它供数的那片 SM 随之亮起，或暗下来空等。
- **擦亮**（04）：光标经过的小块会先用上分块缩放，在粗糙的画面里擦出清晰的一块；方向键可以移动画笔。
- **拨动经纬**（05）：光标掠过展开的经纬，丝线会荡开波纹。
- **转动与拉远**（06）：左右拖动，等轴测视角按 90° 一档转动；上下拖动可以拉近或拉远。

所有选择都跨篇章保留，往回滚动后仍在；新的操作会从当前状态接着变化。键盘：`0`–`7` 跳到对应章节，`[` `]` 前后切换章节，`Tab` 在导航、光环、闸门与画布之间移动。

## 主动扩张：本作中自行构思的部分

1. **贯穿全页的“接缝”**：开场那道竖直的光来自两颗晶粒之间的 NV-HBI 接缝。它在各章里依次是跨缝流动的光点、俯视版图正中的光带、精度一章扫过画面的“印刷头”、下一颗 GPU 的接缝，最后在结尾重新贯穿画面。右侧的章节导航本身也是这道缝。
2. **“硅城”**：晶粒版图在镜头前从纹样长成夜间的城市。148 栋楼对应 148 个 SM，窗里的灯是线程束；屋顶的纹样一路放大到乘加单元，一项任务化作上千块从天而降。
3. **“展开的封装”**：数据流动一章不另画示意图，而是让真实的 HBM 堆栈从封装上抬起、向外展开，露出中介层上的走线，让光沿 TSV、走线、接口、L2 流到每一个 SM。
4. **“同一幅画面”**：精度一章不另画插图，直接拿作品自己的开场画面来降精度、加网点，再用分块缩放救回来。
5. **“张量核心里的织机”**：张量核心的菱形乘加格向外展开成经纬，乘积累加成织物的图案；推理被画成一句话被拆成丝线、穿过层层经纬，再织成回答，然后收回张量核心。
6. **“尺度尺”**：左下角那把不带读数的对数刻度尺，标记随镜头在 µm、mm、m 之间滑动，提示此刻所在的尺度。
7. **首尾同一颗封装**：结尾回到开场，那颗封装保留着你一路留下的拆开与转动状态。

## 视频导出接口

`window.videoExport.runs` 为 `['page']`。`begin('page', {fps})` 回到开场状态，返回 `{ frames }`。`frame(i)` 把页面放到第 `i` 帧，即片段时刻 `i / fps`。`end()` 退出导出模式。

`page` 由作品自己从页首一直滚到页尾，中途不停顿，全长约 69 秒（60 帧/秒时为 4128 帧）。滚动节奏按篇章内容设计：开场构图多停留一会儿，拆开、俯冲、开闸、变粗、推理、退远这些段落放慢，过场加快。关键点之间用单调三次插值连接，速度平滑且处处为正。导出模式下所有动画只由帧序号决定，相同的帧得到相同的画面；时长与速度不随帧率变化。实现见 `src/main.js` 末尾。

## 构建

源代码在 `src/`，用 esbuild 打包成经典脚本 `app.js`（以本地文件方式打开时不能加载模块脚本）：

```bash
npm install
npm run build
```

字体使用本机已安装的字体：Noto Serif SC、HarmonyOS Sans SC、Google Sans Flex、JetBrains Mono。缺失时回退到系统字体。
