# 浮空群岛传说 · Legend of the Floating Isles — 游戏 UI 原型

在 Chrome 中直接双击 `index.html` 打开即可运行（无需服务器、无外部资源，字体使用本机已安装字体）。

## 视觉语言「晨星航图」
深空蓝玻璃底板 · 香槟金细线 · 晨星四芒 · 星盘刻度 · 斜切角。
六属性用「六边形徽章 + 属性色 + 图形」区分，技能用八角形徽章，徽印用菱形纹章，稀有度用铜 / 银 / 金边框与菱形点数区分。

## 界面与流程
标题 → 剧情（对话 / 名词解释 / 章节标题卡）→ 任务柜台 → 编队与养成 → 战斗（含奥义与连锁奥义）→ 结算

左上角「界面目录」可直接跳到第 4 节的任意界面，也可以实时播放内置演示录像。

## 操作
| 场景 | 键位 |
|---|---|
| 通用 | 鼠标悬停 / 点击；方向键选择；Enter / Space 确认；Esc / Backspace / 鼠标右键 返回；画面上的按键提示也可以直接点击 |
| 标题 | 任意键开始；↑↓ 选择 |
| 剧情 | Enter / 点击 推进；A 自动；S 快进；← → / Tab 选择名词 |
| 任务柜台 | Q / E 切换难度；↑↓ 选择任务；Enter 选择 / 出发 |
| 编队 | ← → 选择编队位；Enter 更换角色；C 角色详情；F 出击 |
| 角色详情 | 方向键选择技能 / 徽印；Enter 打开替换列表（悬停即预览属性变化）；Q / E 或点击顶部徽记切换角色 |
| 战斗 | 1–4 技能（或点击技能格）；Q 奥义（或点击奥义按钮，攒满后触发连锁奥义）；Tab 锁定；Esc / 右上角暂停按钮 / 鼠标右键 暂停 |
| 结算 | Space 跳过演出；R 再来一次；Esc 返回 |

不操作时，战斗按编排自动推进：首领登场 → 交战 → 连携时刻 → 超载 → 连锁奥义 → 破防 → 讨伐成功。

## 视频导出接口
```js
window.videoExport.runs                         // ['tour']
await window.videoExport.begin('tour', { fps }) // → { frames }（约 96 秒 × fps）
await window.videoExport.frame(i)               // 第 i 帧对应作品内部时刻 i / fps
window.videoExport.end()
```
所有动效由内部虚拟时钟驱动：CSS 动画在导出模式下按虚拟时刻定格，画布特效与战斗事件使用固定种子，任意帧率下画面一致。

## 目录结构
- `index.html` 入口
- `css/` 基础视觉语言与各界面样式
- `js/core.js` 虚拟时钟、调度、导出同步、缩放、交互、转场、演示光标
- `js/icons.js` 成套图标（属性 / 武器 / 任务类型 / 技能 / 道具 / 界面）
- `js/data.js` 角色、技能、徽印、任务、道具、剧情数据
- `js/bg.js` 程序化背景（天空、云海、浮岛、火山竞技场、星空）
- `js/scene-*.js` 七个界面
- `js/tour.js` 演示录像编排与 `videoExport`
