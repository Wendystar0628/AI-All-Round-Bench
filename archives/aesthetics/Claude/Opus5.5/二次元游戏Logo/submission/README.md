# 三款二次元游戏 Logo · 重新设计

《明日方舟：终末地》《崩坏：星穹铁道》《鸣潮》各一枚。中文游戏名是主体（主名最大最亮，系列名次一级），英文名是辅助。每一枚都从这款游戏的世界观推出一套字形“方言”，把全部汉字按方言重新绘制，再配一处同构的高潮、一个主体元素、两到三种英文用法、细线与点、底板和按角色分工的颜色。

## 怎么看

- 双击 `index.html`（Chrome，本地文件方式即可，不需要服务器）：首页三枚并排，点进任意一枚是它的展示页——成品（代码绘制的主题背景 + 逐层入场动画）→ 概念单 → 方言示意 → 母题落点 → 黑白稿 → 分层展开 → 检查格。
- 展示片导出接口：`window.videoExport`（`runs = ['show']`，约 90 秒，三枚各 30 秒：入场、概念单、方言、母题落点、黑白稿、分层展开、检查格、成品定格）。片中时间只由 `frame(i)` 推进，第 i 帧 = `i / fps` 秒。

## 交付文件

| 路径 | 内容 |
|---|---|
| `index.html` | 展示网页入口（脚本与素材在 `web/`） |
| `logos/终末地/` `logos/星穹铁道/` `logos/鸣潮/` | `final.png`（透明底，宽 4300）、`mono.png`（黑白稿）、`layers/`（与成品同尺寸的透明分层，文件名写明是哪一层、z 序） |
| `src/` | 全部出图脚本：`strokes_data.py`（15 个字的逐笔标注）、`ef_glyphs.py`/`sr_glyphs.py`/`ww_glyphs.py`（三套方言）、`ef.py`/`sr.py`/`ww.py`（组合、上色、出图） |
| `work/` | 过程图：坐标底图、骨架图、笔画标注图、对照图、检查图、分层展开图 |

制作方法：用 `素材/字形底座` 取底字轮廓 → 在骨架图上按笔顺标出每一笔（类型、部件、中线、宽）→ 出笔画标注图核对 → 方言写成作用在一类笔画上的规则批量重画（由中线重画，端头、转角、粗细由方言决定）→ 高潮与呼应用变体替换 → 布尔合并 → 派生层（厚度、投影、受光边、发光）从字形外扩 / 偏移得到，同一个光源（左上）→ 在同一张画布上栅格化，出分层 PNG、黑白稿和检查图。

## 概念单一 · 明日方舟：终末地（Arknights: Endfield）

| 项 | 内容 |
|---|---|
| 一句话概念 | 在塔卫二的荒原上立起第一座中继塔——把电网和人一起，拉到地图的尽头。 |
| 三个气质词 | 硬朗、精确、拓荒 |
| 具体物件 | 中继塔（输电铁塔）。「末」的字形本来就是一座塔：一根竖穿过两道横，底下两条腿。 |
| 动作 | 立起、架线：塔身向上刺出整块外轮廓，电缆从塔头放向两侧。 |
| 材质 / 光 | 钢板上的模版喷漆：哑光、细颗粒、警示黄；一个光源在左上。 |
| 同源媒介 | 工程制图与钢构件——等轴测图纸的 30°/60° 角度、型钢的斜切口、模版喷涂留下的“桥”。 |
| 底字 | 思源黑体 CN Heavy（横竖等粗、字怀开阔，离方言最近） |
| 方言 | **角度集** 0°/30°/60°/90°：每一段笔画吸附到 30° 的整数倍，弯笔折成直段（像弯折的钢条）；**粗细** 横 108、竖 124、斜 116（横略细于竖）；**端头** 起笔切口贴网格（水平或竖直），自由端收笔一律斜切，切口与轴线成 60°；**转角** 尖角（焊接的折弯）；**点** 两端都贴网格切的平行四边形（等轴测方块的一个面）；**构造** 每一笔是一根独立的钢构件，T 字接头留 16 的拼缝（模版喷涂的桥）——转角与十字交叉不留；**特征笔画** 竖上开一小段 Warren 桁架孔。 |
| 骨架 | 字面撑满，重心居中略低（稳），中宫开阔；不倾斜；斜笔一律落在角度集上。系列名「明日方舟」同一套方言，缩小后减重孔省去（强度降低，结构不动）。 |
| 母题落点 | **高潮**：「末」的竖 → 中继塔塔身（实心竖条里开 Warren 桁架孔，腹杆 30°；塔顶收分、避雷杆、信标；两道横是横担，在塔身两侧让开拼缝；撇捺是先 60° 后 30° 的两折塔腿）。十字交叉与“竖 → 杆、塔”同构，字仍然是「末」（上横长于下横）。**呼应**：「地」的两根竖各开一小段桁架孔（同类笔画：竖），弱化到像钢件本来的减重孔。**为什么**：一座塔同时讲了“建设”（电网、集成工业）和“拓荒”（把基础设施钉进新的土地）。 |
| 主体元素 | 源石结晶——终末地工业要把它转化为能源。等轴测画法（棱线只用 30°/60°/90°，和方言同一支笔），立在「地」的右侧，顶部探出外轮廓；塔头的两根电缆接到它的顶上。 |
| 英文用法 | ① 巨大的 **ENDFIELD** 压在中文后面作背景，明度贴近底板；② **ARKNIGHTS : ENDFIELD** 拉开字距的小号大写作底线，左右对齐主名字面框，下面一道警示条；③ 沿底板左缘竖排的小字。字体 Bahnschrift（DIN 工业标识体；无衬线配黑体底的方言，共享“等粗、平切”的基因）。 |
| 颜色角色 | 字面色 暖白漆 `#EFEBE1`（全图反差最大）；主题色 警示黄 `#FFC20E`（结晶、塔身），暗调作底板 `#1E1C16`；阴影色 `#4B3C0C`（右下 30° 的厚度，主题色暗调）；高光 白（左上受光边、信标）；点缀色 警示黄：高潮塔身 + ENDFIELD 一词 + 绝缘子。材质：一种喷漆贯穿字面、塔身、结晶，全局同一层颗粒。 |
| 细线与点 | 电缆的线宽 = 塔身腹杆宽（全件最细的笔画），端点是六角绝缘子；「地」的竖弯钩顺着 30° 的笔势拉出一根渐细的线，指向结晶。 |

## 概念单二 · 崩坏：星穹铁道（Honkai: Star Rail）

| 项 | 内容 |
|---|---|
| 一句话概念 | 阿基维利在星海间铺下的银轨——每一个字都是一段铁路，最后一笔驶向远方的星。 |
| 三个气质词 | 浪漫、远行、优雅 |
| 具体物件 | 铁轨：两根钢轨 + 一排轨枕。 |
| 动作 | 前进：整体前倾 12°，铁轨向右上透视收窄，驶向一颗星。 |
| 材质 / 光 | 镀铬的银（天空带 · 地平线 · 地面带）+ 烫金；星光。 |
| 同源媒介 | 装饰艺术时代的铁路海报与机车铭牌：发丝线与粗柱的强对比、刻线的铬字、烫金车票。 |
| 底字 | 思源宋体 CN Heavy（横细竖粗，对比最接近方言） |
| 方言 | **对比** 横是发丝（30），竖是粗柱（150），横竖比约 1:5——横像钢轨，竖像轨枕；**构造** 粗笔中线刻一道 16 宽的细槽（内线），一根粗笔看上去是一对并行的轨；**端头** 竖与横平切，撇收成尖，捺由细到粗、捺脚切平，钩收尖；**转角** 方角：发丝横与粗竖相接，粗竖齐到横的外沿；**点** 短点一律换成四角星（星芒向内弯），长点（「穹」八的右点）按捺的笔法。 |
| 骨架 | 字面撑满、重心略高；结构做好后整体斜切 12°（列车前进的方向）。系列名「崩坏」同一套方言，印在车票上。 |
| 母题落点 | **高潮**：「道」的平捺 → 一段铁轨：从辶的底部驶出，钢轨与轨枕向右上透视收窄（近处轨距 66，远处收到两成），尽头是一颗金星。横、捺与“走线、轨道”同构，铁轨占住平捺的位置、走向和体量，「道」仍然认得。**呼应**：「铁」的捺上三道轨枕刻口；全组粗笔的内线是“轨”的弱化形。**为什么**：「道」同时是铁道，也是这款游戏里的“命途”——开拓的路。 |
| 主体元素 | 车票（星轨通票）：圆角票面、两侧半圆缺口、存根前一列打孔，票面印着系列名「崩坏」与 HONKAI，存根上一颗四角星；从左上角探出整块外轮廓，和铁轨同为烫金（同色同料）。 |
| 英文用法 | ① 巨大的意大利体 **Star Rail** 压在中文后面，明度贴近底板；② **HONKAI : STAR RAIL** 拉开字距的小号大写，落在铁轨尽头之下，跟着整体前倾；③ 车票上贴着系列名底线的 **HONKAI**。字体 Playfair Display（高对比衬线，和宋体底的发丝/粗柱对比同一个基因）。 |
| 颜色角色 | 字面色 镀铬银白 `#F3F0FF`（天空带、地平线、地面带）；主题色 星夜紫 `#2A1E63`（底板），辉光 `#6C5CFF`；阴影色 `#07051A`（贴着字边往右下）；高光 白（受光边、星芒）；点缀色 烫金 `#E9C36E`：铁轨（高潮）+ 车票 + 终点的星。 |
| 细线与点 | 发丝宽的星座线把「穹」「道」的星点连起来，节点是四角小星；铁轨尽头之外还有两颗渐小的星（航线）。 |

## 概念单三 · 鸣潮（Wuthering Waves）

| 项 | 内容 |
|---|---|
| 一句话概念 | 悲鸣之后，声音像潮水一样漫过世界——一支音叉在两字之间共鸣，把水的三点震成声波。 |
| 三个气质词 | 清冽、肃穆、共振 |
| 具体物件 | 音叉与它发出的声波。 |
| 动作 | 振动、向两侧扩散：同心的声波从音叉出发，穿过两个字。 |
| 材质 / 光 | 珠母（螺钿）的虹彩白 + 共鸣的青光；水墨的底。 |
| 同源媒介 | 钟声的包络 + 柳叶篆 / 悬针篆：古人把“声”铸进青铜时用的篆书，笔画两头尖、竖收成针。 |
| 底字 | 思源黑体 CN Medium（干净的骨架，方言靠包络起伏，不靠底字的对比） |
| 方言 | **笔形** 每一笔是一次钟鸣的包络：急起（水滴似的头，60 单位内涨到最宽）→ 长身 → 余音收成针尖，横竖撇捺折钩一律如此；**粗细** 横 74、竖 86、斜 82，几乎等粗；**转角** 圆转（钟声不断）；**竖** 悬针，最长的竖向下多垂一截；**点** 两头尖的柳叶。 |
| 骨架 | 修长：字面收窄到 0.9，重心上提；两字之间留出音叉的位置，左右对称。 |
| 母题落点 | **高潮**：「潮」的氵 → 三段声波弧：上点、中点、下提落在以音叉为圆心的同心圆上（上点与下提在外圈，中点在内圈），三段都朝外凸；弧的切线正好是原来三笔的方向（上点“\”、中点“\|”、下提“/”），所以字仍然认得。**呼应**：「鸟」的点弯成朝左凸的一小段弧，落在同一组同心圆上。**为什么**：氵是水，弧是声——一个部件同时画出“鸣”和“潮”。 |
| 主体元素 | 音叉：插在两字之间，叉齿探出主名的上沿，柄是一根悬针；“共鸣者”本来就是共振的器物，所有声波都从它出发。和高潮的声波弧同色同光。 |
| 英文用法 | ① 巨大的 **WAVES** 压在中文后面，明度贴近底板；② **WUTHERING WAVES** 沿一圈与音叉同心的声波排成下弧，两端各一段细线托住，这圈声波的半径对齐到中文字面框的底。字体 Trajan（罗马碑刻大写，配篆书底的方言）。 |
| 颜色角色 | 字面色 珠母白 `#EEF7F4`（白里透青、粉、金的虹彩）；主题色 深海青墨 `#0A1D20`（底板），共鸣青 `#7DF3E6`（音叉与辉光）；阴影色 `#010708`；高光 白（受光边、叉尖）；点缀色 共鸣青：声波弧（高潮），与音叉同色同光。 |
| 细线与点 | 同心的声波细环，只画在字外的空处，越外越淡；端点是落在细环上的小柳叶点（与声波弧同族）。 |

## 自己构思的设计

**终末地**
1. 「末」= 中继塔：不换部件，只按同构把竖、横、撇捺画成塔身、横担、塔腿——整字体势就是一座输电塔，横担在塔身两侧让开拼缝，像螺栓连接的钢构件。
2. 系列名「明日方舟」挂在塔头放出的一根电缆上，像线路上的铭牌；电缆端点是六角绝缘子。
3. 模版喷涂的“桥”被重新解释成钢构件之间的拼缝，只出现在 T 字接头（「日」的两横浮在两竖之间）。

**星穹铁道**
1. 发丝横 + 带刻槽的粗竖：字本身像一段铁路（轨与轨枕），高潮的铁轨是它“完整”的样子。
2. 短点都换成四角星，再用发丝宽的星座线把它们连起来，「星穹」挂在字的上方。
3. 底板做成向终点收窄的透视楔形，整块 Logo 是一段旅程：车票（出发）→ 铁轨 → 星（目的地）。

**鸣潮**
1. 音叉放在两字之间作圆心：同一组同心圆把左右两个字都“震”起来，「鸟」的点和氵的三点都落在圆上。
2. 氵的三点按原来的方向落在同心圆的切线上，所以既是声波也仍是氵。
3. 英文不另起一行，而是排在一圈与音叉同心的声波上，被两段细线托住。

## 检查

每一枚都按题面看过：去色、两档黑白、只留字（拿掉底板、主体元素、英文与细线）、整枚缩到高 64 像素、白底、黑底（`work/*_检查图.png`，网页“检查格”一节同样可看）；笔画标注图在 `work/stroke_map_*.png`，方言前后对照在 `work/*_big.png`。
