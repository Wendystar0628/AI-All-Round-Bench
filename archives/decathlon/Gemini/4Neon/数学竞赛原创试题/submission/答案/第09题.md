# 第 9 题解答

## 答案

$N$ 的最大可能值为 $18$。

---

## 证明

经位似变换，不妨设该外接圆 $\Gamma$ 为单位圆（半径 $R = 1$，圆心为 $O$）。

### 第一步：顶点权与内切圆半径公式

对剖分中的每个三角形 $\Delta = PQR$，其内切圆切三边于三点，记从顶点 $P, Q, R$ 到切点的切线长分别为 $x_P(\Delta), x_Q(\Delta), x_R(\Delta) > 0$。若两三角形 $\Delta_1 = PQR$ 与 $\Delta_2 = PRS$ 共边 $PR$，它们的内切圆外切当且仅当两者切 $PR$ 于同一点，即 $x_P(\Delta_1) = x_P(\Delta_2)$ 且 $x_R(\Delta_1) = x_R(\Delta_2)$。

对 $N$ 边形的每个顶点 $v$，所有以 $v$ 为顶点的三角形绕 $v$ 依次共边，故 $x_v(\Delta)$ 与 $\Delta$ 无关，记为 $t_v > 0$。于是剖分的每条边或对角线 $UV$ 均满足 $UV = t_U + t_V$。由海伦公式，每个三角形 $\Delta = PQR$ 的内切圆半径为
$$
r(PQR) = \sqrt{\frac{t_P t_Q t_R}{t_P + t_Q + t_R}}. \tag{1}
$$

**引理 1**：设 $PQ$ 为 $\Gamma$ 上某条边或对角线，且三角形 $\Delta = PQZ$ 位于 $PQ$ 所分不含 $O$ 的一侧（含 $PQ$ 为直径的情形），记该侧弧 $\widehat{PQ}$ 的圆心角为 $2\phi \in (0, \pi]$（从而 $\sin\phi = \frac{t_P + t_Q}{2}$）。则：
1. $t_Z < \min(t_P, t_Q)$；
2. 令 $r = r(PQZ)$，则 $r = t_Z \cot\frac{\phi}{2}$，且 $r$ 是方程
   $$
   r^2 + 2\left(1 + \sqrt{1 - \left(\frac{t_P + t_Q}{2}\right)^2}\right)r = t_P t_Q \tag{2}
   $$
   的唯一正根，记此根为 $\Phi(t_P, t_Q)$；
3. 对满足 $x, y > 0$ 且 $x + y \le 2$ 的实数对 $(x, y)$，函数 $\Phi(x, y)$ 关于 $x, y$ 均严格递增。

*引理 1 的证明*：因 $Z$ 在劣弧或半圆 $\widehat{PQ}$ 上，故 $\angle PZQ = \pi - \phi \ge \frac{\pi}{2}$，从而 $PQ > PZ$ 且 $PQ > QZ$，即 $t_P + t_Q > t_P + t_Z$ 且 $t_P + t_Q > t_Q + t_Z$，得 $t_Z < \min(t_P, t_Q)$。在 $\triangle PQZ$ 中，$r = t_Z \tan\frac{\angle PZQ}{2} = t_Z \cot\frac{\phi}{2}$。代入 $(1)$ 得
$$
r^2 = \frac{t_P t_Q t_Z}{t_P + t_Q + t_Z} = \frac{t_P t_Q r}{(t_P + t_Q)\cot\frac{\phi}{2} + r} \implies r^2 + (t_P + t_Q)\cot\frac{\phi}{2} \cdot r = t_P t_Q.
$$
利用 $t_P + t_Q = 2\sin\phi = 4\sin\frac{\phi}{2}\cos\frac{\phi}{2}$ 与 $\cos\phi = \sqrt{1 - \left(\frac{t_P + t_Q}{2}\right)^2}$，有 $(t_P + t_Q)\cot\frac{\phi}{2} = 4\cos^2\frac{\phi}{2} = 2(1 + \cos\phi)$，即得 $(2)$。若 $x_1 < x_2$ 且 $y_1 \le y_2$（$x_2 + y_2 \le 2$），则 $(2)$ 左端一次项系数严格减小而右端 $xy$ 严格增大，故正根满足 $\Phi(x_1, y_1) < \Phi(x_2, y_2)$。引理 1 证毕。

**引理 2**：设相邻两三角形 $\Delta_1 = PQR$ 与 $\Delta_2 = PQS$ 共对角线 $PQ$。
- 若 $O$ 严格位于 $PQ$ 的 $\Delta_1$ 一侧，则 $r(\Delta_1) > r(\Delta_2)$；
- 若 $O$ 在 $PQ$ 上（即 $PQ$ 为直径），则 $r(\Delta_1) = r(\Delta_2)$。

*引理 2 的证明*：记 $\theta = \angle PRQ$，则 $\angle PSQ = \pi - \theta$。由 $r(\Delta_1) = t_R \tan\frac{\theta}{2}$ 及 $(1)$ 得 $\tan^2\frac{\theta}{2} = \frac{t_P t_Q}{t_R(t_P + t_Q + t_R)}$，同理 $\cot^2\frac{\theta}{2} = \frac{t_P t_Q}{t_S(t_P + t_Q + t_S)}$。
- 若 $O$ 严格在 $\Delta_1$ 一侧，则 $\theta < \frac{\pi}{2}$，故 $\tan^2\frac{\theta}{2} < 1 < \cot^2\frac{\theta}{2}$，从而 $t_R(t_P + t_Q + t_R) > t_S(t_P + t_Q + t_S)$，推出 $t_R > t_S$，再由 $(1)$ 的单调性得 $r(\Delta_1) > r(\Delta_2)$。
- 若 $PQ$ 为直径，则 $\theta = \frac{\pi}{2}$，同理得 $t_R = t_S$ 及 $r(\Delta_1) = r(\Delta_2)$。引理 2 证毕。

### 第二步：构造 $N = 18$ 的例子

先说明局部扩张步骤：给定 $\Gamma$ 上一段劣弧 $\widehat{UV}$（端点权 $t_U, t_V > 0$ 且 $UV = t_U + t_V$），当动点 $Z$ 沿开劣弧 $\widehat{UV}$ 从 $U$ 移向 $V$ 时，$UZ - VZ$ 从 $-UV$ 严格递增连续变化至 $+UV$。因 $|t_U - t_V| < t_U + t_V = UV$，开劣弧 $\widehat{UV}$ 上存在唯一点 $Z$ 使 $UZ - VZ = t_U - t_V$。令 $t_Z = \frac{UZ + VZ - UV}{2} > 0$（由严格三角不等式），则 $UZ = t_U + t_Z$、$VZ = t_V + t_Z$，故 $\triangle UVZ$ 的内切圆与以 $UV$ 为边的父三角形内切圆外切，且 $t_Z$ 与 $r(UVZ) = \Phi(t_U, t_V)$ 仅由无序对 $\{t_U, t_V\}$ 唯一决定。

据此按四层构造 $18$ 边形及其剖分：
1. **第 $0$ 层（$1$ 个三角形）**：在 $\Gamma$ 上取内接正三角形 $P_0 Q_0 S_0$，赋权 $t_{P_0} = t_{Q_0} = t_{S_0} = \frac{\sqrt{3}}{2}$，其内切圆半径为 $r_0 = \frac{1}{2}$。
2. **第 $1$ 层（$3$ 个三角形）**：在三段劣弧 $\widehat{P_0 Q_0}, \widehat{Q_0 S_0}, \widehat{S_0 P_0}$ 上各按上述步骤添加顶点 $M_1, M_2, M_3$（恰为各弧中点）。所得 $3$ 个三角形全等，有相同内切圆半径 $r_1 = \Phi(\frac{\sqrt{3}}{2}, \frac{\sqrt{3}}{2})$，且 $t_{M_1} = t_{M_2} = t_{M_3} = 1 - \frac{\sqrt{3}}{2} =: t_1 > 0$。
3. **第 $2$ 层（$6$ 个三角形）**：所得外边界的 $6$ 段劣弧均具有端点权对 $\{\frac{\sqrt{3}}{2}, t_1\}$。在每段劣弧上按上述步骤添加顶点 $E_1, \dots, E_6$，得 $6$ 个全等（或镜像全等）的三角形，内切圆半径均为 $r_2 = \Phi(\frac{\sqrt{3}}{2}, t_1)$，且各 $E_k$ 具有相同权 $t_2 > 0$。
4. **第 $3$ 层（$6$ 个三角形）**：从每个第 $2$ 层三角形中，选取连接 $E_k$ 与 $\{P_0, Q_0, S_0\}$ 中顶点的那条外边（共 $6$ 段互不相交的劣弧，端点权对均为 $\{\frac{\sqrt{3}}{2}, t_2\}$），在每段劣弧上添加顶点 $F_1, \dots, F_6$。所得 $6$ 个三角形全等（或镜像全等），内切圆半径均为 $r_3 = \Phi(\frac{\sqrt{3}}{2}, t_2)$。

此凸 $18$ 边形被剖分为 $1 + 3 + 6 + 6 = 16$ 个三角形，相邻三角形内切圆均外切，内切圆半径恰取 $r_0, r_1, r_2, r_3$ 四个值。故 $N_{\max} \ge 18$。

### 第三步：证明 $N \le 18$（即三角形数不超过 $16$）

记剖分的对偶树为 $\mathcal{T}$。对任意一条位于不含 $O$ 一侧的边或对角线 $UV$（含 $UV$ 为直径的情形），令 $\mathcal{T}_{UV}$ 表示剖分中位于 $UV$ 该侧的所有三角形组成的子树（若该侧无三角形，则为空树）。

对整数 $k \ge 0$，记 $A(k)$（resp. $E(k)$）为端点权不等 $t_U \ne t_V$（resp. 端点权相等 $t_U = t_V$）时，内切圆半径至多取 $k$ 个不同值的子树 $\mathcal{T}_{UV}$ 的最大顶点数。定义数列 $a_0 = 0, a_1 = 1, a_k = 1 + a_{k-1} + a_{k-2}$（即 $a_2 = 2, a_3 = 4, a_4 = 7$），以及 $e_0 = 0, e_1 = 1, e_k = 1 + 2a_{k-1}$（即 $e_2 = 3, e_3 = 5, e_4 = 9$）。

**断言**：对一切 $k \ge 0$，有 $A(k) \le a_k$ 且 $E(k) \le e_k$。

*断言的证明*：对 $k$ 归纳。$k = 0$ 显然；对非空子树 $\mathcal{T}_{UV}$，设其根三角形为 $\Delta = UVW$。因 $W$ 在开劣弧或开半圆 $\widehat{UV}$ 上，两条子边 $UW, VW$ 均所对劣弧且 $O$ 严格位于 $\Delta$ 一侧，故由引理 2，两棵子树 $\mathcal{T}_{UW}, \mathcal{T}_{VW}$ 中所有三角形的内切圆半径均严格小于 $r(\Delta)$；又由引理 1，有 $t_W < \min(t_U, t_V)$，故 $UW, VW$ 均为端点权不等的边。
- 当 $k = 1$ 时，$\mathcal{T}_{UW}, \mathcal{T}_{VW}$ 均须为空，故 $A(1), E(1) \le 1$。
- 当 $k \ge 2$ 且 $t_U = t_V$ 时，$\mathcal{T}_{UW}, \mathcal{T}_{VW}$ 各至多使用 $k - 1$ 个半径值，故 $|\mathcal{T}_{UV}| \le 1 + 2A(k - 1) \le 1 + 2a_{k-1} = e_k$。
- 当 $k \ge 2$ 且不妨设 $t_U > t_V$ 时：若 $\mathcal{T}_{UW}$ 为空，则 $|\mathcal{T}_{UV}| = 1 + |\mathcal{T}_{VW}| \le 1 + a_{k-1} \le a_k$；若 $\mathcal{T}_{UW}$ 非空，其根半径为 $\Phi(t_U, t_W) < r(\Delta)$，而由引理 1 与引理 2，$\mathcal{T}_{VW}$ 中每个三角形的半径均不超过 $\Phi(t_V, t_W) < \Phi(t_U, t_W) < r(\Delta)$，故 $\mathcal{T}_{UW}$ 至多用 $k - 1$ 个半径值而 $\mathcal{T}_{VW}$ 至多用 $k - 2$ 个半径值，得 $|\mathcal{T}_{UV}| \le 1 + a_{k-1} + a_{k-2} = a_k$。断言证毕。

现按圆心 $O$ 相对于剖分的位置分类讨论（因 $N$ 边形顶点全在 $\Gamma$ 上，$O$ 不可能为顶点；又两直径必交于 $O$，故至多一条对角线过 $O$）：

**情形 1：$O$ 在 $N$ 边形外部或其一条边界边上。**
此时整个 $N$ 边形位于某条边界边 $PQ$ 的不含 $O$ 一侧，故三角形总数不超过 $\max(E(4), A(4)) \le 9 < 16$。

**情形 2：$O$ 严格位于剖分中某个三角形 $\Delta_0 = PQS$ 的内部。**
此时 $O$ 严格在 $\Delta_0$ 三边 $PQ, QS, SP$ 的 $\Delta_0$ 一侧，三棵子树 $\mathcal{T}_{PQ}, \mathcal{T}_{QS}, \mathcal{T}_{SP}$ 中所有三角形的内切圆半径均严格小于 $r(\Delta_0)$，故三棵子树合起来至多使用 $3$ 个半径值：
- 若 $t_P = t_Q = t_S$，则三边均为等权边，总三角形数 $\le 1 + 3E(3) \le 1 + 3 \times 5 = 16$。
- 若恰两权相等，设 $t_P = t_Q \ne t_S$：
  - 若 $t_P = t_Q > t_S$，则 $\Phi(t_P, t_Q) > \Phi(t_P, t_S) = \Phi(t_Q, t_S)$。若 $\mathcal{T}_{PQ}$ 非空，则 $\mathcal{T}_{PS}, \mathcal{T}_{QS}$ 各至多用 $2$ 个值，总数 $\le 1 + E(3) + 2A(2) \le 1 + 5 + 4 = 10$；若 $\mathcal{T}_{PQ}$ 为空，总数 $\le 1 + 2A(3) \le 9$。
  - 若 $t_P = t_Q < t_S$，则 $\Phi(t_P, t_S) = \Phi(t_Q, t_S) > \Phi(t_P, t_Q)$。若 $\mathcal{T}_{PS}, \mathcal{T}_{QS}$ 不全空，则 $\mathcal{T}_{PQ}$ 至多用 $2$ 个值，总数 $\le 1 + E(2) + 2A(3) \le 1 + 3 + 8 = 12$；否则总数 $\le 1 + E(3) \le 6$。
- 若 $t_P > t_Q > t_S$，则 $\Phi(t_P, t_Q) > \Phi(t_P, t_S) > \Phi(t_Q, t_S)$。将非空子树按根半径从大到小排列，第 $i$ 棵子树至多使用 $4 - i$ 个半径值且底边不等权，故总数 $\le 1 + A(3) + A(2) + A(1) \le 1 + 4 + 2 + 1 = 8$。

**情形 3：$O$ 位于某条对角线 $AC$ 上（即 $AC$ 为直径，$t_A + t_C = 2$）。**
- 若 $t_A \ne t_C$，则 $AC$ 两侧的两棵半圆子树底边均不等权，各至多用 $4$ 个半径值，故总三角形数 $\le 2A(4) \le 14 < 16$。
- 若 $t_A = t_C = 1$，则 $AC$ 两侧的根三角形 $\Delta_{0+} = ABC$ 与 $\Delta_{0-} = ACD$ 均为等腰直角三角形，满足 $t_B = t_D = \sqrt{2} - 1 =: b$ 且 $r(\Delta_{0+}) = r(\Delta_{0-}) = b$。余下三角形分布在四条全等的劣弧边 $AB, BC, CD, DA$ 上，每条边的端点权均为 $(a, b) = (1, \sqrt{2} - 1)$，记其子树为 $\mathcal{T}_1, \mathcal{T}_2, \mathcal{T}_3, \mathcal{T}_4$。每棵 $\mathcal{T}_i$ 中所有三角形半径均严格小于 $b$，故至多取 $3$ 个不同半径值。

  我们证明每棵 $\mathcal{T}_i$ 至多含 $3$ 个三角形。否则某棵 $\mathcal{T}_i$ 至少含 $4$ 个三角形，反复删去叶子可得一棵含根的 $4$ 顶点子二叉树 $\mathcal{S}$。在底边为 $(a, b)$ 的无限二叉树中，记根为 $\varepsilon$（新顶点权 $e$），$\varepsilon$ 的左子 $L$ 在边 $(a, e)$ 上（新顶点权 $f$），右子 $R$ 在边 $(b, e)$ 上（新顶点权 $h$），$L$ 的两子 $LL, LR$ 分别在 $(a, f), (e, f)$ 上，$R$ 的两子 $RL, RR$ 分别在 $(b, h), (e, h)$ 上。由引理 1，有 $a > b > e > f$、$e > h$，并按 $\Phi$ 的严格单调性及引理 2：
  - 任何含 $4$ 节点的根到叶路径上半径严格递减（$4$ 个不同值）；
  - 在 $\{\varepsilon, L, LL, LR\}$ 中，$r(\varepsilon) > r(L) > r(LL) = \Phi(a, f) > \Phi(e, f) = r(LR)$；
  - 在 $\{\varepsilon, R, RL, RR\}$ 中，$r(\varepsilon) > r(R) > r(RL) = \Phi(b, h) > \Phi(e, h) = r(RR)$；
  - 在 $\{\varepsilon, L, R, LR\}$ 中，$r(\varepsilon) > r(L) > r(R) = \Phi(b, e) > \Phi(e, f) = r(LR)$；
  - 在 $\{\varepsilon, L, R, RL\}$ 与 $\{\varepsilon, L, R, RR\}$ 中，均有 $r(\varepsilon) > r(L) > r(R) > r(RL), r(RR)$；
  - 唯一余下的 $4$ 节点二叉树是 $\{\varepsilon, L, R, LL\}$。下面证明 $r(R) > r(LL)$：

    注意 $\frac{2}{5} < b = \sqrt{2} - 1 < \frac{1}{2}$，且 $f < e < b < \frac{1}{2}$。
    - 对 $R$（底边 $(b, e)$），因 $r(R) < b < 1$ 且 $\cos\phi_{BE} < 1$，由 $(2)$ 得
      $$
      be = r(R)\bigl(r(R) + 2 + 2\cos\phi_{BE}\bigr) < 5r(R) \implies r(R) > \frac{be}{5} > \frac{2e}{25}.
      $$
    - 对 $L$（底边 $(a, e) = (1, e)$），有 $\sin\phi_{AE} = \frac{1 + e}{2} < \frac{3}{4}$，故 $\cos\phi_{AE} = \sqrt{1 - \sin^2\phi_{AE}} > \frac{\sqrt{7}}{4} > \frac{1}{2}$。由 $(2)$ 得 $2(1 + \cos\phi_{AE})r(L) < e$，进而由引理 1 得
      $$
      f = r(L)\tan\frac{\phi_{AE}}{2} = r(L)\frac{\sin\phi_{AE}}{1 + \cos\phi_{AE}} < \frac{e\sin\phi_{AE}}{2(1 + \cos\phi_{AE})^2} < \frac{e \cdot (3/4)}{2 \cdot (3/2)^2} = \frac{e}{6}.
      $$
    - 对 $LL$（底边 $(a, f) = (1, f)$），同理 $\sin\phi_{AF} = \frac{1 + f}{2} < \frac{3}{4}$，$\cos\phi_{AF} > \frac{1}{2}$，由 $(2)$ 得
      $$
      r(LL) < \frac{f}{2(1 + \cos\phi_{AF})} < \frac{f}{3} < \frac{e}{18}.
      $$
    于是 $r(R) > \frac{2e}{25} > \frac{e}{18} > r(LL)$，故 $\{\varepsilon, L, R, LL\}$ 的四个半径也两两不同。

  由此任何 $4$ 节点含根子树均至少有 $4$ 个不同半径值，矛盾。因此每棵 $\mathcal{T}_i$ 至多含 $3$ 个三角形，该子情形总三角形数不超过 $2 + 4 \times 3 = 14 < 16$。

综上，剖分至多含 $16$ 个三角形，即 $N \le 18$。结合第二步的构造，最大可能值为 $18$。
