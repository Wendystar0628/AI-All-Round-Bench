# 第 7 题解答

## 答案

- **当 $n$ 为奇数时**：存在总数恰为 $M$、最终最小周期大于 $2$ 的初始配置，当且仅当
  $$
  2r + 1 \le M \le 2r + 2n - 1 \quad \text{且} \quad M \ne 2r + n.
  $$
  存在时，最终最小周期的最大值为 $n$。
- **当 $n$ 为偶数时**：存在总数恰为 $M$、最终最小周期大于 $2$ 的初始配置，当且仅当
  $$
  r + 1 \le M \le 2r + 2n - 1.
  $$
  存在时，最终最小周期的最大值为 $n$。

---

## 证明

对每条有向边 $u \to w$ 及时刻 $t \ge 0$，记 $x_{u \to w}(t) \in \{0, 1\}$ 为第 $t$ 轮顶点 $u$ 沿边 $u \to w$ 送出的筹码数。易见 $0 \le a_v(t) \le d(v)$ 对一切 $v, t$ 保持不变，且总筹码数 $\sum_v a_v(t) = M$ 守恒。因状态空间有限且演化确定，任一配置序列最终必进入某个周期轨道；反之，周期轨道上的任一状态均可取作初始配置。故只需研究满足 $a_v(t + P) = a_v(t)$（$t \in \mathbb{Z}$，$P \ge 1$）的周期轨道。

记圈为 $C = \{v_0, \dots, v_{n-1}\}$，$E_{\mathrm{tree}}$ 为全部 $r$ 条不在圈上的边组成的集合。对每个 $v_i \in C$，记其子边数为 $c_i$，子边依次为 $v_i u_{i,1}, \dots, v_i u_{i,c_i}$，并记圈上两个方向的发送量为
$$
x_i(t) = x_{v_i \to v_{i+1}}(t), \qquad y_i(t) = x_{v_i \to v_{i-1}}(t).
$$

---

### 第一步：周期轨道的必要结构与周期上界

考虑任意周期为 $P$ 的周期轨道。

**1. 树边上的周期 $2$ 锁定。**
对任意非圈顶点 $u \notin C$（设其父顶点为 $p$），因父边 $u \to p$ 排在 $u$ 的最后（第 $d(u)$ 位），故 $x_{u \to p}(t + 1) = 1 \iff a_u(t + 1) = d(u) \implies x_{p \to u}(t) = 1$，即
$$
x_{u \to p}(t + 1) \le x_{p \to u}(t) \qquad (\forall t).
$$
另一方面，记以 $u$ 为根的子树 $T_u$ 内筹码总数为 $S_u(t) = \sum_{w \in T_u} a_w(t)$，则 $S_u(t + 1) - S_u(t) = x_{p \to u}(t) - x_{u \to p}(t)$。在一个完整周期 $t = 0, \dots, P - 1$ 上求和得 $\sum_{t=0}^{P-1} x_{p \to u}(t) = \sum_{t=0}^{P-1} x_{u \to p}(t) = \sum_{t=0}^{P-1} x_{u \to p}(t + 1)$。结合上述逐项不等式，必恒取等号：
$$
x_{u \to p}(t + 1) = x_{p \to u}(t) \qquad (\forall u \notin C,\; \forall t). \tag{1}
$$

现对每个 $v_i \in C$，令 $s_i(t) = \sum_{j=1}^{c_i} x_{v_i \to u_{i,j}}(t) = \min(c_i, a_{v_i}(t))$。由 $(1)$，在时刻 $t + 2$ 有
$$
a_{v_i}(t + 2) = \sum_{j=1}^{c_i} x_{u_{i,j} \to v_i}(t + 1) + x_{i-1}(t + 1) + y_{i+1}(t + 1) = s_i(t) + x_{i-1}(t + 1) + y_{i+1}(t + 1) \ge s_i(t). \tag{2}
$$
两边与 $c_i$ 取较小值得 $s_i(t + 2) \ge s_i(t)$。由周期性必有 $s_i(t + 2) = s_i(t)$ 对一切 $t$ 成立，从而每条与 $v_i$ 关联的子边均满足 $x_{v_i \to u_{i,j}}(t + 2) = x_{v_i \to u_{i,j}}(t)$。再由 $(2)$，每当 $x_{i-1}(t + 1) + y_{i+1}(t + 1) \ge 1$ 时，$\min(c_i, s_i(t) + x_{i-1}(t+1) + y_{i+1}(t+1)) = s_i(t + 2) = s_i(t)$ 迫使 $s_i(t) = c_i$，进而无论该和是否为 $0$，恒有（将 $t + 2$ 换为 $t$）：
$$
x_i(t) + y_i(t) = x_{i-1}(t - 1) + y_{i+1}(t - 1) \qquad (\forall i, t), \tag{3}
$$
且每当 $x_i(t) = 1$（等价于 $x_{i-1}(t - 1) + y_{i+1}(t - 1) \ge 1$）时，必有 $s_i(t) = c_i$（即 $v_i$ 的全部子边在时刻 $t$ 均取 $1$）。

同理，沿附着树自顶向下对顶点深度归纳：若 $u \notin C$（父顶点 $p$，子顶点 $w_1, \dots, w_k$）已满足 $x_{p \to u}(t + 2) = x_{p \to u}(t)$，令 $s_u(t) = \sum_{j=1}^k x_{u \to w_j}(t) = \min(k, a_u(t))$，则由 $(1)$ 得 $a_u(t + 2) = x_{p \to u}(t + 1) + s_u(t) \ge s_u(t)$，故 $s_u(t + 2) \ge s_u(t)$，由周期性得 $s_u(t + 2) = s_u(t)$，从而 $x_{u \to w_j}(t + 2) = x_{u \to w_j}(t)$；并且当 $x_{p \to u}(t + 1) = 1$ 时必有 $s_u(t) = k$（即 $u$ 的全部子边在时刻 $t$ 均取 $1$）。

由此，对每条非圈边 $e = (p, u) \in E_{\mathrm{tree}}$（$p$ 为父），记 $b_e(\tau) = x_{p \to u}(t)$（$\tau = t \bmod 2 \in \{0, 1\}$），则 $x_{u \to p}(t) = b_e((t - 1) \bmod 2)$。于是：
- 每条非圈边上的筹码数 $x_{p \to u}(t) + x_{u \to p}(t) = b_e(0) + b_e(1)$ 不随时间改变，记 $M_{\mathrm{tree}} = \sum_{e \in E_{\mathrm{tree}}} (b_e(0) + b_e(1)) \in [0, 2r]$，则圈上筹码数 $M_{\mathrm{cyc}} = \sum_{i=0}^{n-1}(x_i(t) + y_i(t)) = M - M_{\mathrm{tree}}$ 亦为常数；
- 若某圈顶点 $v_i$ 在时刻 $t$ 满足 $x_i(t) = 1$，则对附着于 $v_i$ 的树中每条距 $v_i$ 深度为 $d \ge 0$（父顶点距 $v_i$ 为 $d$）的边 $e$，递推得 $b_e((t + d) \bmod 2) = 1$。

**2. 圈上的演化与必要条件。**
因 $v_i \to v_{i+1}$ 排在 $v_i \to v_{i-1}$ 之前，恒有 $x_i(t) \ge y_i(t)$。由 $(3)$ 得
$$
x_i(t) = \max\bigl(x_{i-1}(t - 1), y_{i+1}(t - 1)\bigr), \qquad y_i(t) = \min\bigl(x_{i-1}(t - 1), y_{i+1}(t - 1)\bigr).
$$
对所有 $i$ 求和得 $\sum_i x_i(t) \ge \sum_i x_{i-1}(t - 1) = \sum_i x_i(t - 1)$；由周期性该和恒为常数，故对一切 $i, t$ 均有 $y_{i+1}(t - 1) \le x_{i-1}(t - 1)$，于是
$$
x_i(t) = x_{i - t}(0), \qquad y_i(t) = y_{i + t}(0), \qquad y_{i + t + 1}(0) \le x_{i - t - 1}(0) \quad (\forall i, t \in \mathbb{Z}). \tag{4}
$$

现设该周期轨道的最小周期 $P > 2$。由于所有树边均以 $2$ 为周期，若 $M_{\mathrm{cyc}} = 0$ 则全图以 $2$ 为周期，矛盾。故 $M_{\mathrm{cyc}} \ge 1$，从而至少有一个 $x_{i_0}(0) = 1$。

- **情形 1：$n$ 为奇数。**
  在 $(4)$ 中，当 $i, t$ 跑遍 $\mathbb{Z}$ 时，$(i + t + 1) - (i - t - 1) = 2(t + 1)$ 取遍模 $n$ 的全部剩余类。
  - 对每个 $v_i \in C$，存在时刻 $t_1$ 使 $x_i(t_1) = x_{i_0}(0) = 1$，同时 $x_i(t_1 + n) = 1$；因 $n$ 为奇数，$t_1$ 与 $t_1 + n$ 奇偶性相反，故附着在 $v_i$ 上的每条树边 $e$ 均满足 $b_e(0) = b_e(1) = 1$。由此所有树边均恒为 $1$（周期为 $1$），且 $M_{\mathrm{tree}} = 2r$，故 $M_{\mathrm{cyc}} = M - 2r \ge 1$，且全图周期整除 $n$，即 $P \le n$。
  - 若存在 $y_u(0) = 1$，由 $(4)$ 得对一切 $v \in \mathbb{Z}/n\mathbb{Z}$ 均有 $x_v(0) = 1$，故 $M_{\mathrm{cyc}} = n + \sum_u y_u(0) \ge n + 1$。因此当 $M_{\mathrm{cyc}} = n$ 时必有 $y \equiv 0$ 且 $x \equiv 1$，导致全图周期为 $1$，矛盾；同样当 $M_{\mathrm{cyc}} = 2n$ 时 $x \equiv y \equiv 1$，周期为 $1$，矛盾。
  因此 $n$ 为奇数时必有 $2r + 1 \le M \le 2r + 2n - 1$、$M \ne 2r + n$，且 $P \le n$。

- **情形 2：$n$ 为偶数。**
  此时 $2 \mid n$，所有树边以 $2$ 为周期且所有圈边由 $(4)$ 以 $n$ 为周期，故全图必以 $n$ 为周期，即 $P \le n$。
  因 $x_{i_0}(0) = 1$，对每个 $v_i \in C$，在时刻 $t_i = i - i_0$ 均有 $x_i(t_i) = 1$，故附着在 $v_i$ 上的每条深度为 $d$ 的树边 $e$ 均满足 $b_e((i - i_0 + d) \bmod 2) = 1$，于是 $b_e(0) + b_e(1) \ge 1$，得 $M_{\mathrm{tree}} \ge r$，从而 $M = M_{\mathrm{tree}} + M_{\mathrm{cyc}} \ge r + 1$。又若 $M = 2r + 2n$，则所有顶点恒满，周期为 $1$，矛盾。
  因此 $n$ 为偶数时必有 $r + 1 \le M \le 2r + 2n - 1$，且 $P \le n$。

---

### 第二步：构造达到最小周期 $n$ 的初始配置

**1. 满树构造（适用于 $2r + 1 \le M \le 2r + 2n - 1$，其中 $n$ 奇时要求 $M \ne 2r + n$）。**
令每条非圈边 $e$ 取 $b_e(0) = b_e(1) = 1$（即占用 $M_{\mathrm{tree}} = 2r$ 颗筹码，所有非圈顶点均置满 $a_u(0) = d(u)$），并在圈上放置 $k = M - 2r \in \{1, \dots, 2n - 1\}$ 颗筹码（即 $a_{v_i}(0) = c_i + x_i(0) + y_i(0)$）：
- 当 $1 \le k \le n - 1$ 时，取 $x_i(0) = \mathbf{1}[0 \le i < k]$，$y_i(0) = 0$；
- 当 $n + 1 \le k \le 2n - 1$ 时，取 $x_i(0) = 1$，$y_i(0) = \mathbf{1}[0 \le i < k - n]$；
- 当 $n$ 为偶数且 $k = n$ 时，取 $x_i(0) = \mathbf{1}[i \ne 1]$（仅 $v_1$ 为 $0$），$y_i(0) = \mathbf{1}[i = 0]$（仅 $v_0$ 为 $1$）。

易验上述选取均满足 $(4)$ 中的 $y_{i+t+1}(0) \le x_{i-t-1}(0)$（当 $n$ 偶、$k = n$ 时，$i + t + 1 \equiv 0 \pmod n$ 推出 $i - t - 1 \equiv -2(t + 1) \not\equiv 1 \pmod n$）。于是所有树边恒向两端各发 $1$ 颗筹码，圈上按 $x_i(t) = x_{i-t}(0)$、$y_i(t) = y_{i+t}(0)$ 演化。在三种情形中，非平凡的 $0$-$1$ 序列（长 $k$ 或 $k - n$ 的连续段，或 $y$ 中唯一 $1$ 的位置）均在模 $n$ 旋转下具有最小周期 $n$，故配置序列的最小周期恰为 $n$。

**2. 单波构造（适用于 $n = 2m \ge 4$ 为偶数、$r \ge 1$ 且 $r + 1 \le M \le 2r$，实则涵盖全部 $r + 1 \le M \le 2r + n - 1$）。**
因 $r \ge 1$ 且 $m \ge 2$，区间 $[r + 1, 2r + m - 1]$ 与 $[r + m + 1, 2r + 2m - 1]$ 之并覆盖全部整数 $M \in [r + 1, 2r + n - 1]$。故可将 $M$ 写成 $M = (r + s) + c_0$，其中 $s \in \{0, 1, \dots, r\}$ 且 $c_0 \in \{1, \dots, m - 1\} \cup \{m + 1, \dots, 2m - 1\}$。

对每条非圈边 $e = (p, u) \in E_{\mathrm{tree}}$（设其所在树根为 $v_i \in C$，$p$ 到 $v_i$ 距离为 $d \ge 0$），定义 $\tau_0(e) = (i + d) \bmod 2$。将全部 $r$ 条非圈边按各附着树的后序遍历排成一列（对每个顶点按其固定子边次序依次遍历各子树，并将通向该顶点的父边排在其子树所有边之后）。定义树边参数：
- 对所有 $e \in E_{\mathrm{tree}}$，令 $b_e(\tau_0(e)) = 1$；
- 对后序中的前 $s$ 条边令 $b_e(1 - \tau_0(e)) = 1$，其余 $r - s$ 条边令 $b_e(1 - \tau_0(e)) = 0$。

对圈上顶点定义 $t = 0$ 时的圈边参数：对奇数 $i$ 令 $x_i(0) = y_i(0) = 0$；对偶数 $i = 2q$（$0 \le q < m$），当 $1 \le c_0 \le m - 1$ 时令 $x_{2q}(0) = \mathbf{1}[0 \le q < c_0]$、$y_{2q}(0) = 0$，当 $m + 1 \le c_0 \le 2m - 1$ 时令 $x_{2q}(0) = 1$、$y_{2q}(0) = \mathbf{1}[0 \le q < c_0 - m]$。

取初始配置：对非圈顶点 $u$（父边 $e_p$，子边 $e_1, \dots, e_k$）令 $a_u(0) = b_{e_p}(1) + \sum_{j=1}^k b_{e_j}(0)$；对圈顶点 $v_i$（子边 $e_{i,1}, \dots, e_{i,c_i}$）令 $a_{v_i}(0) = \sum_{j=1}^{c_i} b_{e_{i,j}}(0) + x_i(0) + y_i(0)$。总筹码数为 $\sum_{e \in E_{\mathrm{tree}}}(b_e(0) + b_e(1)) + \sum_i(x_i(0) + y_i(0)) = (r + s) + c_0 = M$。

由后序遍历性质，对每个顶点及每种奇偶性 $\tau \in \{0, 1\}$，其子边上的 $b_{e_j}(\tau)$ 均构成前缀 $1$ 序列，且当某非圈顶点的父边满足 $b_{e_p}(1 - \tau) = 1$ 时其所有子边均满足 $b_{e_j}(\tau) = 1$；对圈顶点 $v_i$，每当 $i \equiv t \pmod 2$ 时其所有子边满足 $b_{e_{i,j}}(t \bmod 2) = 1$，而 $i \not\equiv t \pmod 2$ 时 $x_{i-t}(0) = y_{i+t}(0) = 0$。由此对 $t \ge 0$ 归纳可知，第 $t$ 轮中每条树边 $e = (p, u)$ 恰满足 $x_{p \to u}(t) = b_e(t \bmod 2)$、$x_{u \to p}(t) = b_e((t - 1) \bmod 2)$，且每条圈边恰满足 $x_i(t) = x_{i-t}(0)$、$y_i(t) = y_{i+t}(0)$。

若 $P \ge 1$ 为该配置序列的周期，则 $x_i(P) = x_i(0)$ 且 $y_i(P) = y_i(0)$ 对一切 $i$ 成立：
- 若 $P$ 为奇数，则 $x_0(P) = x_{-P}(0) = 0 \ne 1 = x_0(0)$，矛盾；
- 若 $P = 2d$ 为偶数（$1 \le d < m$），则当 $1 \le c_0 < m$ 时 $\{0, \dots, c_0 - 1\} \subset \mathbb{Z}/m\mathbb{Z}$ 在平移 $+d$ 下不变，当 $m < c_0 < 2m$ 时 $\{0, \dots, c_0 - m - 1\} \subset \mathbb{Z}/m\mathbb{Z}$ 在平移 $-d$ 下不变，均不可能。

故该配置序列的最小周期恰为 $n$。综上，结论全部成立。
