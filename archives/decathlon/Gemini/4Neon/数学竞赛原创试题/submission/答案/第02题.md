# 第 2 题解答

## 答案

全部满足条件的四元组函数 $(F_0, F_1, F_2, F_3)$ 为
$$
F_j(d) = (-1)^j f(d) + c_j \qquad (j = 0, 1, 2, 3,\; d \in \mathcal{D}_n),
$$
其中 $f : \mathcal{D}_n \to \mathbb{R}$ 为任意偶函数（即对一切 $d \in \mathcal{D}_n$ 满足 $f(-d) = f(d)$），$c_0, c_1, c_2, c_3 \in \mathbb{R}$ 为任意满足
$$
(n - 2)(c_0 + c_3) + 3n(c_1 + c_2) = 0
$$
的实常数。

---

## 证明

对任意满足题设一般位置条件（两两不同、无三点共线、无四点共圆）的 $n$ 红 $n$ 蓝点集 $S$ 及任意三元子集 $T \subset S$，记 $j = j(T)$，则 $S \setminus T$ 含 $n - j$ 个红点和 $n - 3 + j$ 个蓝点，故
$$
\delta(T) = \bigl(r_{\mathrm{in}}(T) - b_{\mathrm{in}}(T)\bigr) - \bigl((n - j - r_{\mathrm{in}}(T)) - (n - 3 + j - b_{\mathrm{in}}(T))\bigr) = 2\bigl(r_{\mathrm{in}}(T) - b_{\mathrm{in}}(T)\bigr) + 2j - 3. \tag{1}
$$
由此可见 $\delta(T) \in \mathcal{D}_n$ 恒成立。记 $\Sigma(S) = \sum_{T \subset S,\, |T|=3} F_{j(T)}(\delta(T))$。

---

### 第一步：必要性

设 $(F_0, F_1, F_2, F_3)$ 满足题意。

**1. 证明每个 $F_j$ 为偶函数。**
固定 $j \in \{0, 1, 2, 3\}$ 与 $d \in \mathcal{D}_n$。由 $(1)$，存在整数 $r \in [0, n - j]$ 与 $b \in [0, n - 3 + j]$ 使 $2(r - b) + 2j - 3 = d$。

取 $A = (-1, 0)$、$B = (1, 0)$、$C_0 = (0, 0)$，为其赋予颜色使 $T_0 = \{A, B, C_0\}$ 恰含 $j$ 个红点。依次在平面内选取其余 $2n - 3$ 个点组成集合 $S'$，使其中恰有 $r$ 个红点和 $b$ 个蓝点位于上半平面 $\{y > 0\}$，其余位于下半平面 $\{y < 0\}$，且每选一个新点时均避开 $x$ 轴以及所有已选点（含 $A, B, C_0$）两两所决定的直线和三三所决定的圆（有限条直线与圆之并无内点，故总可选取）。这样，在 $S' \cup \{A, B, C_0\}$ 中无四点共圆，且唯一共线三元组为 $\{A, B, C_0\}$。

对充分小的 $\varepsilon > 0$，将 $C_0$ 替换为 $C_{\pm\varepsilon} = (0, \pm\varepsilon)$ 得两个一般位置点集 $S_{+\varepsilon}$、$S_{-\varepsilon}$。
- 对一切 $T \ne T_0$，在 $\varepsilon = 0$ 时 $T$ 不共线且其余点均不在 $T$ 的外接圆上，由连续性知对充分小的 $\varepsilon > 0$，每个 $T \ne T_0$ 在 $S_{+\varepsilon}$ 与 $S_{-\varepsilon}$ 中的 $\delta(T)$ 相同。
- 对 $T_0 = \{A, B, C_{\pm\varepsilon}\}$，其外接圆方程为 $x^2 + y^2 + \frac{1 - \varepsilon^2}{\pm\varepsilon} y - 1 = 0$。当 $\varepsilon \to 0^+$ 时，对 $S'$ 中每个点 $(x, y)$（均有 $y \ne 0$），点在圆内当且仅当上式左端为负：故在 $S_{-\varepsilon}$ 中 $S'$ 位于圆内的恰好是上半平面的点（此时 $\delta(T_0) = d$），而在 $S_{+\varepsilon}$ 中位于圆内的恰好是下半平面的点（此时 $\delta(T_0) = -d$）。

于是 $0 = \Sigma(S_{-\varepsilon}) - \Sigma(S_{+\varepsilon}) = F_j(d) - F_j(-d)$，故每个 $F_j$ 均为 $\mathcal{D}_n$ 上的偶函数。

**2. 利用四点翻转型扰动确定函数间的关系。**
记 $\mathcal{E}_n = \{-(2n-4), -(2n-6), \dots, 2n-4\}$。对每个 $j \in \{0, 1, 2, 3\}$ 与 $e \in \mathcal{E}_n$，定义差分
$$
g_j(e) = F_j(e + 1) - F_j(e - 1).
$$

任取 $m \in \{1, 2, 3\}$（因 $n \ge 3$，有 $m \le n$ 且 $4 - m \le n$）以及任意 $e \in \mathcal{E}_n$。为四个点 $A = (1, 0)$、$B = (0, 1)$、$C = (-1, 0)$、$D_0 = (0, -1)$ 赋予颜色，使 $Q_0 = \{A, B, C, D_0\}$ 恰含 $m$ 个红点与 $4 - m$ 个蓝点。记点 $X$ 的颜色符号 $s(X)$ 为 $+1$（红）或 $-1$（蓝）。由 $2(R_1 - B_1) + 2m - 4 = e$ 可取整数 $R_1 \in [0, n - m]$ 与 $B_1 \in [0, n - 4 + m]$；依次选取其余 $2n - 4$ 个点构成 $S'$，使其中恰有 $R_1$ 个红点、$B_1$ 个蓝点在单位圆盘 $\{x^2 + y^2 < 1\}$ 内，其余在圆盘外，且每选一点均避开单位圆及此前所有点（含 $Q_0$）确定的直线与圆。于是 $S' \cup Q_0$ 无三点共线，且唯一共圆四元组为 $Q_0$。

对充分小的 $\varepsilon > 0$，将 $D_0$ 替换为 $D_{\pm\varepsilon} = (0, -1 \pm \varepsilon)$ 得一般位置点集 $S_{+\varepsilon}$、$S_{-\varepsilon}$。
- 对任意不全含于 $Q_{\pm\varepsilon} = \{A, B, C, D_{\pm\varepsilon}\}$ 的三元子集 $T$，由连续性知在充分小的 $\varepsilon > 0$ 下其 $\delta(T)$ 在 $S_{+\varepsilon}$ 与 $S_{-\varepsilon}$ 中相同。
- 记 $Q_{\pm\varepsilon}$ 中的四个三角形为 $T_A = \{B, C, D_{\pm\varepsilon}\}$、$T_B = \{A, C, D_{\pm\varepsilon}\}$、$T_C = \{A, B, D_{\pm\varepsilon}\}$、$T_D = \{A, B, C\}$。直接计算它们的外接圆方程：
  - $C(T_D)$：$x^2 + y^2 - 1 = 0$，代入 $D_\eta = (0, -1 + \eta)$ 得 $\eta(\eta - 2)$；
  - $C(T_B)$：$x^2 + y^2 - \frac{\eta(2 - \eta)}{1 - \eta} y - 1 = 0$，代入 $B = (0, 1)$ 得 $-\frac{\eta(2 - \eta)}{1 - \eta}$；
  - $C(T_A)$：$x^2 + y^2 + \eta x - \eta y - 1 + \eta = 0$，代入 $A = (1, 0)$ 得 $2\eta$；
  - $C(T_C)$：$x^2 + y^2 - \eta x - \eta y - 1 + \eta = 0$，代入 $C = (-1, 0)$ 得 $2\eta$。
  当 $\eta \to 0$ 时这四个圆均趋于单位圆，故对充分小的 $\varepsilon > 0$，$S'$ 中各点关于四个圆的内外关系与关于单位圆相同，对每个三角形的 $\delta$ 贡献均为 $e = 2(R_1 - B_1) + 2m - 4$。而 $Q_{\pm\varepsilon}$ 中余下一点对各三角形的贡献为：在 $S_{-\varepsilon}$（$\eta = -\varepsilon < 0$）中，$A, C$ 在圆内、$B, D_{-\varepsilon}$ 在圆外；在 $S_{+\varepsilon}$（$\eta = +\varepsilon > 0$）中，$B, D_{+\varepsilon}$ 在圆内、$A, C$ 在圆外。

注意到 $F_j(e + s(X)) - F_j(e - s(X)) = s(X) g_j(e)$，由 $0 = \Sigma(S_{-\varepsilon}) - \Sigma(S_{+\varepsilon})$ 得
$$
s(A) g_{j(T_A)}(e) + s(C) g_{j(T_C)}(e) - s(B) g_{j(T_B)}(e) - s(D) g_{j(T_D)}(e) = 0. \tag{2}
$$
对 $(A, B, C, D)$ 取三种着色：
- $(R, R, R, B)$（$m = 3$）：$g_2(e) + g_2(e) - g_2(e) + g_3(e) = 0 \implies g_3(e) = -g_2(e)$；
- $(B, B, B, R)$（$m = 1$）：$-g_1(e) - g_1(e) + g_1(e) - g_0(e) = 0 \implies g_0(e) = -g_1(e)$；
- $(R, B, R, B)$（$m = 2$）：$g_1(e) + g_1(e) + g_2(e) + g_2(e) = 0 \implies g_2(e) = -g_1(e)$。

故对一切 $e \in \mathcal{E}_n$ 均有 $g_j(e) = (-1)^j g_0(e)$（$j = 0, 1, 2, 3$）。令偶函数 $f = F_0$，则对每个 $j$，函数 $d \mapsto F_j(d) - (-1)^j f(d)$ 在相邻奇数 $e - 1, e + 1 \in \mathcal{D}_n$ 处取值相等，因而必为常数 $c_j$，即 $F_j(d) = (-1)^j f(d) + c_j$。

---

### 第二步：充分性与常数条件

设 $f : \mathcal{D}_n \to \mathbb{R}$ 为任意偶函数，对任意一般位置点集 $S$，定义
$$
\Phi(S) = \sum_{\substack{T \subset S \\ |T| = 3}} (-1)^{j(T)} f\bigl(\delta(T)\bigr).
$$

**断言**：对一切满足题设条件的点集 $S$，均有 $\Phi(S) = 0$。

*断言的证明*：先证明单点移动保持 $\Phi(S)$ 不变。设 $S' = S \setminus \{P\}$ 为固定的一般位置 $2n - 1$ 点集，记 $\mathcal{B}(S')$ 为 $S'$ 中两点所决定的全部直线与三点所决定的全部圆之并，记 $\mathcal{V}(S')$ 为 $S'$ 与 $\mathcal{B}(S')$ 中任意两条不同曲线的全部交点之并（显然为有限点集）。对任意两点 $P_{\mathrm{start}}, P_{\mathrm{end}} \in \mathbb{R}^2 \setminus \mathcal{B}(S')$，总存在 $M \in \mathbb{R}^2 \setminus \mathcal{B}(S')$，使折线 $\Gamma = P_{\mathrm{start}} M \cup M P_{\mathrm{end}}$ 避开有限集 $\mathcal{V}(S')$，且不与 $\mathcal{B}(S')$ 中任何圆相切。

让动点 $P$ 沿 $\Gamma$ 连续运动，它仅在有限个互异点处横截穿过 $\mathcal{B}(S')$ 中的单条曲线，每次穿过要么使唯一三元组 $\{P, A, B\}$ 共线，要么使唯一四元组 $\{P, A, B, C\}$ 共圆：
- 当 $P$ 在非 $A, B$ 处横截穿过直线 $AB$ 时，仅有 $T_0 = \{P, A, B\}$ 的外接圆退化为直线并反转内外（在以 $AB$ 为 $x$ 轴且中点为原点的坐标系中，$A=(-a,0), B=(a,0)$，外接圆 $x^2+y^2+\frac{a^2-x_P^2-y_P^2}{y_P}y-a^2=0$ 在 $y_P$ 变号时内外对调），故 $\delta(T_0) \mapsto -\delta(T_0)$ 而其余三角形的 $\delta$ 不变。因 $f$ 为偶函数，$\Phi$ 不变。
- 当 $P$ 在点 $P_0 \notin \{A, B, C\}$ 处横截穿过圆 $C(A, B, C)$ 时，仅有 $Q = \{A, B, C, P\}$ 内的四个三角形可能改变 $\delta$。将 $A, B, C$ 重标号使 $A, B, C, P_0$ 沿 $C(A, B, C)$ 依次排列，则在 $P_0$ 充分小邻域内 $ABCP$ 为凸四边形。由圆内接四边形对角互补知，$P$ 从圆 $C(A, B, C)$ 外部穿过到内部时，角和 $\angle ABC + \angle APC$ 由小于 $180^\circ$ 变为大于 $180^\circ$，从而 $P, B$ 分别从 $C(ABC), C(ACP)$ 外部进入内部，同时 $A, C$ 分别从 $C(BCP), C(ABP)$ 内部进入外部；而 $S' \setminus \{A, B, C\}$ 中各点关于这四个圆的内外关系均保持不变（与关于 $C(A, B, C)$ 相同，记其共同贡献为 $e$）。记 $Q$ 中红点数为 $m$，则对每个 $X \in Q$：若 $X$ 为红点，有 $s(X) = 1$、$j(Q \setminus \{X\}) = m - 1$；若 $X$ 为蓝点，有 $s(X) = -1$、$j(Q \setminus \{X\}) = m$；故恒有 $s(X)(-1)^{j(Q \setminus \{X\})} = (-1)^{m-1}$。于是 $\Phi$ 的改变量为
  $$
  \sum_{X \in \{A, C\}} s(X)(-1)^{j(Q \setminus \{X\})} \bigl(f(e+1)-f(e-1)\bigr) - \sum_{X \in \{B, D\}} s(X)(-1)^{j(Q \setminus \{X\})} \bigl(f(e+1)-f(e-1)\bigr) = 0,
  $$
  其中 $D = P$。故 $\Phi$ 仍不变。

由此，对任意给定的一般位置点集 $S = \{P_1, \dots, P_{2n}\}$（前 $n$ 个红、后 $n$ 个蓝），将各点逐一移至抛物线 $y = x^2$ 上的点 $Q_k = (t_k, t_k^2)$：在第 $k$ 步，因 $\mathcal{B}(\{Q_1, \dots, Q_{k-1}, P_{k+1}, \dots, P_{2n}\})$ 与抛物线仅交于有限个点，故可选取 $t_k > \max(0, t_1, \dots, t_{k-1})$ 使 $Q_k$ 避开该坏集，并将 $P_k$ 沿上述折线移至 $Q_k$。记最终点集为 $S_0 = \{Q_1, \dots, Q_{2n}\}$（$0 < t_1 < \dots < t_{2n}$），则 $\Phi(S) = \Phi(S_0)$。

对 $S_0$ 中任意三元子集 $T = \{Q_a, Q_b, Q_c\}$（$a < b < c$），令 $t^* = -(t_a + t_b + t_c) < 0$，则多项式 $(t - t_a)(t - t_b)(t - t_c)(t - t^*)$ 的 $t^3$ 项系数为 $0$，从而可写成 $t^4 + (\beta + 1)t^2 + \alpha t + \gamma$。于是 $x^2 + y^2 + \alpha x + \beta y + \gamma = 0$ 即为 $T$ 的外接圆方程。对 $k \notin \{a, b, c\}$，因 $t_k - t^* > 0$，有
$$
Q_k \text{ 在 } T \text{ 外接圆内} \iff (t_k - t_a)(t_k - t_b)(t_k - t_c) < 0 \iff k < a \text{ 或 } b < k < c.
$$
考虑对合映射 $\sigma(k) = 2n + 1 - k$，它交换红点与蓝点。对每个三元子集 $T = \{Q_a, Q_b, Q_c\}$，令 $T' = \{Q_{\sigma(c)}, Q_{\sigma(b)}, Q_{\sigma(a)}\}$。显然 $j(T') = 3 - j(T)$（故 $T' \ne T$ 且 $(-1)^{j(T')} = -(-1)^{j(T)}$），且 $\sigma$ 将 $T$ 外接圆内的点集双射到 $T'$ 外接圆外的点集、圆外的点集双射到圆内的点集，同时互换红蓝两色，因此
$$
\delta(T') = \bigl(b_{\mathrm{out}}(T) - r_{\mathrm{out}}(T)\bigr) - \bigl(b_{\mathrm{in}}(T) - r_{\mathrm{in}}(T)\bigr) = \delta(T).
$$
从而 $(-1)^{j(T)} f(\delta(T)) + (-1)^{j(T')} f(\delta(T')) = 0$。将全部三元子集按 $\{T, T'\}$ 配对求和即得 $\Phi(S_0) = 0$，断言证毕。

最后，对形如 $F_j(d) = (-1)^j f(d) + c_j$（$f$ 偶）的四元组，由上述断言，对一切一般位置点集 $S$ 均有
$$
\sum_{\substack{T \subset S \\ |T| = 3}} F_{j(T)}\bigl(\delta(T)\bigr) = \Phi(S) + \binom{n}{3}(c_0 + c_3) + n\binom{n}{2}(c_1 + c_2) = \frac{n(n - 1)}{6}\Bigl[(n - 2)(c_0 + c_3) + 3n(c_1 + c_2)\Bigr].
$$
由于 $n \ge 3$，该式恒为 $0$ 当且仅当 $(n - 2)(c_0 + c_3) + 3n(c_1 + c_2) = 0$。证毕。
