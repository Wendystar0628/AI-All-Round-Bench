# 第 11 题解答

## 答案

- 每个 $c_N$ 均有限。
- 生成函数为
  $$
  \sum_{N \ge 1} c_N t^N = \frac{t^4(2 - 2t + 3t^2 - 2t^3 + t^4 - t^5 - t^6 + 2t^7 - t^8)}{(1 - t)^2 (1 - t^2) (1 - t^4)^2}.
  $$
- $c_{12} = 72$。

---

## 证明

### 第一步：群结构与全部实不可约正交表示

考虑由生成元与关系定义的 $12$ 阶二循环群
$$
G = \langle a, b \mid a^6 = 1,\; b^2 = a^3,\; bab^{-1} = a^{-1} \rangle = \{a^i, a^i b : 0 \le i < 6\}.
$$
题设条件恰等价于给出 $G$ 的一个忠实正交表示 $\rho : G \to SO(N)$（即 $A = \rho(a), B = \rho(b) \in SO(N)$ 且 $\ker\rho = \{1\}$），等价关系即 $SO(N)$-共轭。

直接给出 $G$ 的五个两两非同构的实不可约正交表示（记 $R(\theta) = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}$，$S = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}$）：
1. **$V_0$**（$1$ 维）：$a \mapsto (1)$，$b \mapsto (1)$；$\det A = 1,\; \det B = 1$；$\ker V_0 = G$。
2. **$V_1$**（$1$ 维）：$a \mapsto (1)$，$b \mapsto (-1)$；$\det A = 1,\; \det B = -1$；$\ker V_1 = \langle a \rangle$。
3. **$V_2$**（$2$ 维）：$a \mapsto R(2\pi/3)$，$b \mapsto S$；$\det A = 1,\; \det B = -1$；$\ker V_2 = \langle a^3 \rangle$。
4. **$U_2$**（$2$ 维）：$a \mapsto -I_2$，$b \mapsto R(\pi/2)$；$\det A = 1,\; \det B = 1$；$\ker U_2 = \langle a^2 \rangle$。
5. **$W_4$**（$4$ 维）：$a \mapsto \begin{pmatrix} R(\pi/3) & 0 \\ 0 & R(\pi/3) \end{pmatrix}$，$b \mapsto \begin{pmatrix} 0 & -S \\ S & 0 \end{pmatrix}$；$\det A = 1,\; \det B = 1$；$\ker W_4 = \{1\}$。

验证不可约性与完备性：
- $V_0, V_1$ 显然 $1$ 维不可约；$V_2$ 中 $R(2\pi/3)$ 无实特征值，故实不可约；$U_2$ 中 $R(\pi/2)$ 无实特征值，故实不可约。
- 对 $W_4$，它在 $\mathbb{C}$ 上分解为两份同构的 $2$ 维复不可约表示 $\rho_1$（其中 $\rho_1(a) = \operatorname{diag}(\zeta, \zeta^{-1})$，$\rho_1(b) = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$，$\zeta = e^{i\pi/3}$）。若 $W_4$ 在 $\mathbb{R}$ 上可约，则必含一个 $2$ 维实不变子空间 $W'$，其复化为 $\rho_1$，从而存在 $A_0, B_0 \in GL_2(\mathbb{R})$ 满足 $A_0^3 = B_0^2 = -I_2$、$B_0 A_0 B_0^{-1} = A_0^{-1}$ 且 $A_0$ 特征值为 $e^{\pm i\pi/3}$。在适当实基下 $A_0 = R(\pi/3) = \frac{1}{2}I_2 + \frac{\sqrt{3}}{2}R(\pi/2)$，则 $B_0 R(\pi/2) = -R(\pi/2) B_0$ 迫使 $B_0 = \begin{pmatrix} x & y \\ y & -x \end{pmatrix}$，于是 $B_0^2 = (x^2 + y^2)I_2 \ne -I_2$，矛盾。故 $W_4$ 实不可约。
- 复化上述五个实不可约表示所含的互异复不可约表示共有六个：四个 $1$ 维表示（由 $V_0, V_1$ 及 $U_2 \otimes \mathbb{C}$ 给出）和两个 $2$ 维表示（由 $V_2 \otimes \mathbb{C}$ 与 $\rho_1$ 给出）。它们的维数平方和为 $1^2 + 1^2 + 1^2 + 1^2 + 2^2 + 2^2 = 12 = |G|$。由有限群复表示论的维数平方和定理（$\sum \dim^2 = |G|$），这已是 $G$ 的全部复不可约表示。因为任意实不可约表示复化后必含上述某复不可约表示且唯一决定原实不可约表示，所以 $V_0, V_1, V_2, U_2, W_4$ 构成 $G$ 的全部实不可约表示。

---

### 第二步：有限性、$O(N)$-等价与 $SO(N)$-分裂条件

由 Maschke 定理（有限群在 $\mathbb{R}$ 上的有限维表示完全可约），任意正交表示 $\rho : G \to O(N)$ 都同构于
$$
V(m_0, m_1, m_2, m_3, m_4) := V_0^{\oplus m_0} \oplus V_1^{\oplus m_1} \oplus V_2^{\oplus m_2} \oplus U_2^{\oplus m_3} \oplus W_4^{\oplus m_4},
$$
其中非负整数重数满足 $m_0 + m_1 + 2m_2 + 2m_3 + 4m_4 = N$，且重数组由 $\rho$ 的 $GL_N(\mathbb{R})$-共轭类唯一确定。

对两个正交表示 $\rho_1, \rho_2 : G \to O(N)$，若存在 $P \in GL_N(\mathbb{R})$ 使 $\rho_2(g) = P\rho_1(g)P^{-1}$，作极分解 $P = Q H$（$Q \in O(N)$，$H = (P^{\mathsf T}P)^{1/2}$ 正定对称）。由 $\rho_1(g), \rho_2(g)$ 正交得 $P^{\mathsf T}P$ 与所有 $\rho_1(g)$ 交换，作为 $P^{\mathsf T}P$ 的多项式，$H$ 也与所有 $\rho_1(g)$ 交换，故 $\rho_2(g) = Q\rho_1(g)Q^{-1}$。因此 $GL_N(\mathbb{R})$-共轭与 $O(N)$-共轭等价。

由于 $[O(N) : SO(N)] = 2$，每个 $O(N)$-共轭类至多分裂为 $2$ 个 $SO(N)$-共轭类；而对给定的 $N$，满足 $m_0 + m_1 + 2m_2 + 2m_3 + 4m_4 = N$ 的非负整数组只有有限个，故每个 $c_N$ 均有限。

现检验使 $\rho = V(m_0, m_1, m_2, m_3, m_4)$ 满足题设的充要条件：
1. **行列式条件（$A, B \in SO(N)$）**：五个不可约表示均满足 $\det A = 1$；而 $\det B = -1$ 仅出现在 $V_1, V_2$ 上，故 $A, B \in SO(N)$ 当且仅当
   $$
   m_1 + m_2 \equiv 0 \pmod 2.
   $$
2. **忠实性条件（$\ker\rho = \{1\}$）**：$G$ 的元素阶数除 $1$ 外均能被 $2$ 或 $3$ 整除，且唯一的 $2$ 阶元为 $a^3$、唯一的 $3$ 阶子群为 $\langle a^2 \rangle$，故 $\ker\rho = \{1\}$ 当且仅当 $a^3 \notin \ker\rho$ 且 $a^2 \notin \ker\rho$。对照各不可约表示的核可知，这等价于 $m_3 + m_4 \ge 1$ 且 $m_2 + m_4 \ge 1$，即
   $$
   m_4 \ge 1 \qquad \text{或} \qquad (m_4 = 0,\; m_2 \ge 1,\; m_3 \ge 1).
   $$
3. **$O(N)$-类分裂为 $SO(N)$-类的个数**：一个 $O(N)$-共轭类保持为 $1$ 个 $SO(N)$-类，当且仅当其中元素的正交中心化子 $Z_{O(N)}(A, B)$ 含有行列式为 $-1$ 的矩阵；否则分裂为 $2$ 个 $SO(N)$-类。

   由 Schur 引理（两两非同构的不可约表示之间无非零同态），任意 $T \in Z_{O(N)}(A, B)$ 保持上述五个同型分支不变，分块为 $T = \operatorname{diag}(T_0, T_1, T_2, T_3, T_4)$。注意到在后三个分支上分别存在与 $(A, B)$ 生成的代数元素给出的复结构 $J$（$J^2 = -I$）：
   - 在 $V_2^{\oplus m_2}$ 上，$J_2 = \frac{2A + I}{\sqrt{3}}$ 满足 $J_2^2 = -I$；
   - 在 $U_2^{\oplus m_3}$ 上，$J_3 = B$ 满足 $J_3^2 = -I$；
   - 在 $W_4^{\oplus m_4}$ 上，$J_4 = \frac{2A - I}{\sqrt{3}}$ 满足 $J_4^2 = -I$。

   由于 $T_k$ 与 $J_k$ 交换（$k = 2, 3, 4$），在由 $J_k$ 定义的复空间结构下 $T_k$ 是 $\mathbb{C}$-线性变换，故其实行列式 $\det_{\mathbb{R}}(T_k) = |\det_{\mathbb{C}}(T_k)|^2 \ge 0$；结合 $T_k$ 正交即得 $\det(T_2) = \det(T_3) = \det(T_4) = 1$。因此 $\det(T) = \det(T_0)\det(T_1)$。在 $V_0^{\oplus m_0}$ 与 $V_1^{\oplus m_1}$ 上中心化子分别为 $O(m_0)$ 与 $O(m_1)$，故 $Z_{O(N)}(A, B)$ 中存在行列式为 $-1$ 的元素当且仅当 $m_0 + m_1 \ge 1$。

综上所述，每个合法的重数组 $(m_0, m_1, m_2, m_3, m_4)$ 对 $c_N$ 的贡献为 $1 + \mathbf{1}[m_0 = m_1 = 0]$。

### 第三步：计算生成函数与 $c_{12}$

记 $C(t) = \sum_{N \ge 1} c_N t^N = F_{\mathrm{all}}(t) + F_{\mathrm{split}}(t)$，其中 $F_{\mathrm{all}}(t)$ 计所有合法重数组（每组计 $1$ 次），$F_{\mathrm{split}}(t)$ 计满足 $m_0 = m_1 = 0$ 的合法重数组（此时 $m_1 + m_2$ 为偶数等价于 $m_2$ 为偶数）。

**计算 $F_{\mathrm{all}}(t)$**：
满足 $m_1, m_2 \ge 0$ 且 $m_1 + m_2$ 为偶数的生成函数为
$$
\sum_{\substack{m_1, m_2 \ge 0 \\ 2 \mid (m_1 + m_2)}} t^{m_1 + 2m_2} = \frac{1}{(1 - t^2)(1 - t^4)} + \frac{t \cdot t^2}{(1 - t^2)(1 - t^4)} = \frac{1 + t^3}{(1 - t^2)(1 - t^4)},
$$
其中 $m_2 \ge 1$ 的部分减去 $m_2 = 0$（$m_1$ 偶）的 $\frac{1}{1 - t^2}$ 得 $\frac{t^3 + t^4}{(1 - t^2)(1 - t^4)}$。按 $m_4 \ge 1$ 与 $m_4 = 0$（$m_2, m_3 \ge 1$）拆开得
$$
F_{\mathrm{all}}(t) = \frac{1}{1 - t} \cdot \frac{1}{1 - t^2} \cdot \frac{t^4}{1 - t^4} \cdot \frac{1 + t^3}{(1 - t^2)(1 - t^4)} + \frac{1}{1 - t} \cdot \frac{t^2}{1 - t^2} \cdot \frac{t^3 + t^4}{(1 - t^2)(1 - t^4)} = \frac{t^4 + t^5 + t^6 + t^7 - t^9 - t^{10}}{(1 - t)(1 - t^2)^2 (1 - t^4)^2}.
$$

**计算 $F_{\mathrm{split}}(t)$**（$m_0 = m_1 = 0$ 且 $2 \mid m_2$）：
按 $m_4 \ge 1$ 与 $m_4 = 0$（$m_2 \ge 2$ 偶，$m_3 \ge 1$）拆开得
$$
F_{\mathrm{split}}(t) = \frac{1}{1 - t^4} \cdot \frac{1}{1 - t^2} \cdot \frac{t^4}{1 - t^4} + \frac{t^4}{1 - t^4} \cdot \frac{t^2}{1 - t^2} = \frac{t^4 + t^6 - t^{10}}{(1 - t^2)(1 - t^4)^2}.
$$

通分相加（乘以 $(1 - t)(1 - t^2) = 1 - t - t^2 + t^3$）：
$$
\begin{aligned}
C(t) &= \frac{(t^4 + t^5 + t^6 + t^7 - t^9 - t^{10}) + (t^4 + t^6 - t^{10})(1 - t - t^2 + t^3)}{(1 - t)(1 - t^2)^2 (1 - t^4)^2} \\
&= \frac{2t^4 + t^6 + t^7 - t^8 - 2t^{10} + t^{11} + t^{12} - t^{13}}{(1 - t)(1 - t^2)^2 (1 - t^4)^2}.
\end{aligned}
$$
分子与分母约去公因式 $1 + t$，即得
$$
C(t) = \frac{t^4(2 - 2t + 3t^2 - 2t^3 + t^4 - t^5 - t^6 + 2t^7 - t^8)}{(1 - t)^2 (1 - t^2) (1 - t^4)^2}.
$$

**计算 $c_{12}$**：
展开 $\frac{1}{(1 - t)^2(1 - t^2)} = \sum_{k \ge 0} \lfloor (k + 2)^2/4 \rfloor t^k = 1 + 2t + 4t^2 + 6t^3 + 9t^4 + 12t^5 + 16t^6 + 20t^7 + 25t^8 + \cdots$，再乘以 $\frac{1}{(1 - t^4)^2} = 1 + 2t^4 + 3t^8 + \cdots$ 得
$$
\frac{1}{(1 - t)^2(1 - t^2)(1 - t^4)^2} = 1 + 2t + 4t^2 + 6t^3 + 11t^4 + 16t^5 + 24t^6 + 32t^7 + 46t^8 + \cdots.
$$
提取 $C(t)$ 中 $t^{12}$ 的系数（即上式与 $2 - 2t + 3t^2 - 2t^3 + t^4 - t^5 - t^6 + 2t^7 - t^8$ 乘积的 $t^8$ 项系数）：
$$
c_{12} = 2(46) - 2(32) + 3(24) - 2(16) + 1(11) - 1(6) - 1(4) + 2(2) - 1(1) = 72.
$$
