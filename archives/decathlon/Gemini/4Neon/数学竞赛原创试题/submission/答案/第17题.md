# 第 17 题解答

## 答案

$\mathbb{E}D_\tau$ 的最大值为
$$
\frac{52}{21}.
$$

达到最大值的一条停止规则如下（记 $M_t = \max_{0 \le s \le t} S_s$，$m_t = \min_{0 \le s \le t} S_s$，所有抛币均彼此独立且与游走独立）：
1. 从 $S_0 = 0$ 出发不停，持续行进直到首次满足 $M_t - m_t = 2$（此时三元组 $(m_t, M_t, S_t)$ 必为 $(0, 2, 2)$、$(-2, 0, -2)$、$(-1, 1, -1)$ 或 $(-1, 1, 1)$ 之一）；
2. 若首次进入 $(0, 2, 2)$ 或 $(-2, 0, -2)$：以概率 $\frac{1}{7}$ 立即停止；以概率 $\frac{6}{7}$ 再走一步后立即停止；
3. 若首次进入 $(-1, 1, -1)$ 或 $(-1, 1, 1)$：继续行进，此后每当首次到达 $\pm 2$ 时立即停止，每当回到 $0$ 时以概率 $\frac{3}{4}$ 立即停止、以概率 $\frac{1}{4}$ 继续行进。

---

## 证明

### 第一步：证明 $\mathbb{E}D_\tau \le \frac{52}{21}$

设 $\tau$ 为任意满足题设的停止时刻（允许使用独立随机数，且 $\mathbb{E}\tau < \infty$），记自然扩张后的信息流为 $(\mathcal{F}_t)_{t \ge 0}$，其中第 $t + 1$ 步增量 $\xi_{t+1} = S_{t+1} - S_t$ 与 $\mathcal{F}_t$ 独立。

**1. 证明游走不会越出 $[-3, 3]$ 且触及 $\pm 3$ 必立即停止。**
对任意正整数 $N_1 < N_2$，因步长增量条件期望为 $0$、方差为 $1$，有
$$
\mathbb{E}\bigl[(S_{\tau \wedge N_2} - S_{\tau \wedge N_1})^2\bigr] = \mathbb{E}[\tau \wedge N_2 - \tau \wedge N_1] \xrightarrow{N_1, N_2 \to \infty} 0,
$$
故 $S_{\tau \wedge N} \to S_\tau$ 在 $L^2$（从而在 $L^1$）中收敛。令 $T_4 = \inf\{t \ge 0 : S_t = 4\}$。对固定正整数 $N$，事件 $A_N = \{T_4 \le \tau \wedge N\}$ 属于 $\mathcal{F}_{T_4 \wedge \tau \wedge M}$（$\forall M \ge N$），由有界停时的可选停时定理得
$$
\mathbb{E}[S_{\tau \wedge M}\mathbf{1}_{A_N}] = \mathbb{E}[S_{T_4 \wedge \tau \wedge M}\mathbf{1}_{A_N}] = 4\mathbb{P}(A_N).
$$
令 $M \to \infty$ 并利用 $L^1$ 收敛及 $S_\tau \le 3$ a.s.，得 $4\mathbb{P}(A_N) = \mathbb{E}[S_\tau \mathbf{1}_{A_N}] \le 3\mathbb{P}(A_N)$，故 $\mathbb{P}(A_N) = 0$。令 $N \to \infty$ 得 $\mathbb{P}(T_4 \le \tau) = 0$。若在某时刻 $t < \tau$ 有 $S_t = 3$，因 $\xi_{t+1}$ 与 $\mathcal{F}_t$ 独立，有 $\frac{1}{2}$ 条件概率在 $t + 1 \le \tau$ 处到达 $4$，故 $\mathbb{P}(\exists t < \tau : S_t = 3) = 0$。对称地，$\mathbb{P}(T_{-4} \le \tau) = \mathbb{P}(\exists t < \tau : S_t = -3) = 0$。

因此几乎必然地：对一切 $t < \tau$ 均有 $-2 \le m_t \le S_t \le M_t \le 2$；在 $t = \tau$ 时有 $-3 \le m_\tau \le 0 \le M_\tau \le 3$，且 $M_\tau = 3 \implies S_\tau = 3$，$m_\tau = -3 \implies S_\tau = -3$。

**2. 构造上鞅给出精确上界。**
定义对称函数 $\phi : \{-3, -2, -1, 0, 1, 2, 3\} \to \mathbb{R}$：
$$
\phi(0) = 1, \qquad \phi(\pm 1) = 1, \qquad \phi(\pm 2) = 0, \qquad \phi(\pm 3) = -2.
$$
注意到
$$
\mathbb{E}[\phi(S_\tau)] = \frac{1}{7}\bigl(1 + 2(1) + 2(0) + 2(-2)\bigr) = -\frac{1}{7}. \tag{1}
$$

在所有可达状态 $(m, M, x)$（即 $-2 \le m \le 0 \le M \le 2$ 且 $m \le x \le M$，外加终止边界状态 $(m, 3, 3)$（$-2 \le m \le 0$）与 $(-3, M, -3)$（$0 \le M \le 2$））上定义有界函数 $V(m, M, x)$，使其满足对称性 $V(m, M, x) = V(-M, -m, -x)$：
- 在以下几组特殊状态上规定：
  $$
  V(0, 0, 0) = \frac{7}{3}, \qquad V(0, 1, 0) = V(-1, 0, 0) = \frac{8}{3}, \qquad V(0, 1, 1) = V(-1, 0, -1) = \frac{7}{3}, \qquad V(0, 2, 0) = V(-2, 0, 0) = \frac{7}{2};
  $$
- 在其余一切可达状态（含终止边界状态）上规定 $V(m, M, x) = (M - m) + \phi(x)$。

直接逐项核对可知，对所有可达状态均有 $V(m, M, x) \ge (M - m) + \phi(x)$；并且对所有非终止状态（$-2 \le m \le 0 \le M \le 2$，$m \le x \le M$），定义一步后继的均值
$$
\mathcal{A}V(m, M, x) := \frac{1}{2}V\bigl(\min(m, x - 1), M, x - 1\bigr) + \frac{1}{2}V\bigl(m, \max(M, x + 1), x + 1\bigr),
$$
利用对称性只需验算以下 $18$ 个状态：
- $(0, 0, 0)$：$\mathcal{A}V = \frac{1}{2}(\frac{7}{3} + \frac{7}{3}) = \frac{7}{3} = V$；
- $(0, 1, 0)$：$\mathcal{A}V = \frac{1}{2}(3 + \frac{7}{3}) = \frac{8}{3} = V$；$(0, 1, 1)$：$\mathcal{A}V = \frac{1}{2}(\frac{8}{3} + 2) = \frac{7}{3} = V$；
- $(0, 2, 0)$：$\mathcal{A}V = \frac{1}{2}(4 + 3) = \frac{7}{2} = V$；$(0, 2, 1)$：$\mathcal{A}V = \frac{1}{2}(\frac{7}{2} + 2) = \frac{11}{4} < 3 = V$；$(0, 2, 2)$：$\mathcal{A}V = \frac{1}{2}(3 + 1) = 2 = V$；
- $(-1, 1, x)$（$x = -1, 0, 1$）：$V = 3$，两后继值均为 $3$，故 $\mathcal{A}V = 3 = V$；
- $(-1, 2, x)$（$x = -1, 0, 1, 2$）：$V$ 依次为 $4, 4, 4, 3$，两外边界值为 $V(-2, 2, -2) = 4$ 与 $V(-1, 3, 3) = 2$，故 $\mathcal{A}V$ 依次为 $4, 4, \frac{7}{2}, 3$，均有 $\mathcal{A}V \le V$；
- $(-2, 2, x)$（$x = -2, -1, 0, 1, 2$）：$V$ 依次为 $4, 5, 5, 5, 4$，两外边界值为 $V(-3, 2, -3) = V(-2, 3, 3) = 3$，故 $\mathcal{A}V$ 依次为 $4, \frac{9}{2}, 5, \frac{9}{2}, 4$，均有 $\mathcal{A}V \le V$。

由此，记 $Z_t = V(m_{t \wedge \tau}, M_{t \wedge \tau}, S_{t \wedge \tau})$，则对每个 $t \ge 0$ 有
$$
\mathbb{E}[Z_{t + 1} \mid \mathcal{F}_t] = Z_t \mathbf{1}_{\{\tau \le t\}} + \mathcal{A}V(m_t, M_t, S_t)\mathbf{1}_{\{\tau > t\}} \le Z_t \qquad \text{a.s.}
$$
故 $(Z_t)_{t \ge 0}$ 是有界上鞅。对一切 $t \ge 0$ 有 $\mathbb{E}[Z_t] \le \mathbb{E}[Z_0] = \frac{7}{3}$；因 $\tau < \infty$ a.s. 且 $Z_t$ 一致有界，由控制收敛定理得 $\mathbb{E}[Z_\tau] \le \frac{7}{3}$。再结合 $V(m_\tau, M_\tau, S_\tau) \ge D_\tau + \phi(S_\tau)$ 与 $(1)$ 得
$$
\mathbb{E}[D_\tau] - \frac{1}{7} = \mathbb{E}\bigl[D_\tau + \phi(S_\tau)\bigr] \le \mathbb{E}[Z_\tau] \le \frac{7}{3} \implies \mathbb{E}[D_\tau] \le \frac{7}{3} + \frac{1}{7} = \frac{52}{21}.
$$

### 第二步：验证所给停止规则合法且达到 $\frac{52}{21}$

按答案中的规则定义停时 $\tau$。
1. **第一阶段**（从 $0$ 出发直至 $M_t - m_t = 2$）：第一步以各 $\frac{1}{2}$ 的概率到 $+1$ 或 $-1$。若第一步到 $+1$，此后直至离开 $\{0, 1\}$（即触及 $+2$ 或 $-1$）是区间 $[-1, 2]$ 上从 $1$ 出发的对称赌徒破产问题：以概率 $\frac{2}{3}$ 先到 $+2$（进入 $(0, 2, 2)$），以概率 $\frac{1}{3}$ 先到 $-1$（进入 $(-1, 1, -1)$），期望步数为 $1 \times 2 = 2$。对称地，首次进入四状态的概率分别为
   $$
   \mathbb{P}\text{(进入 }(0, 2, 2)\text{)} = \mathbb{P}\text{(进入 }(-2, 0, -2)\text{)} = \frac{1}{3}, \qquad
   \mathbb{P}\text{(进入 }(-1, 1, -1)\text{)} = \mathbb{P}\text{(进入 }(-1, 1, 1)\text{)} = \frac{1}{6},
   $$
   且第一阶段期望步数为 $1 + 2 = 3$。
2. **第二阶段分支 A**（进入 $(0, 2, 2)$，概率 $\frac{1}{3}$）：
   - 以条件概率 $\frac{1}{7}$ 停在 $+2$（$D_\tau = 2$），贡献概率 $\frac{1}{21}$；
   - 以条件概率 $\frac{6}{7} \cdot \frac{1}{2} = \frac{3}{7}$ 停在 $+3$（$D_\tau = 3$），贡献概率 $\frac{1}{7}$；
   - 以条件概率 $\frac{6}{7} \cdot \frac{1}{2} = \frac{3}{7}$ 停在 $+1$（$D_\tau = 2$），贡献概率 $\frac{1}{7}$。
   条件期望额外步数为 $\frac{6}{7}$。进入 $(-2, 0, -2)$ 时的结果完全对称。
3. **第二阶段分支 B**（进入 $(-1, 1, \pm 1)$，总概率 $\frac{1}{3}$）：
   从 $(-1, 1, \pm 1)$ 出发，一步后以概率 $\frac{1}{2}$ 到达 $\pm 2$ 并立即停止（$D_\tau = 3$），以概率 $\frac{1}{2}$ 回到 $0$；在 $0$ 处以概率 $\frac{3}{4}$ 停止（$D_\tau = 2$），以概率 $\frac{1}{4}$ 再走一步回到 $(-1, 1, \pm 1)$。记从 $(-1, 1, \pm 1)$ 出发最终停在 $0$ 的条件概率为 $r$，条件期望额外步数为 $e$，则
   $$
   r = \frac{1}{2}\left(\frac{3}{4} + \frac{1}{4}r\right) \implies r = \frac{3}{7}, \qquad
   e = 1 + \frac{1}{2}\cdot\frac{1}{4}(1 + e) \implies e = \frac{9}{7}.
   $$
   于是分支 B 对 $0$（$D_\tau = 2$）贡献概率 $\frac{1}{3}\cdot\frac{3}{7} = \frac{1}{7}$，由对称性对 $+2$ 与 $-2$（均为 $D_\tau = 3$）各贡献概率 $\frac{1}{3}\cdot\frac{4}{7}\cdot\frac{1}{2} = \frac{2}{21}$。

合并各分支，检验全部条件：
- 期望停时有限：$\mathbb{E}\tau = 3 + \frac{2}{3}\cdot\frac{6}{7} + \frac{1}{3}\cdot\frac{9}{7} = 4 < \infty$；
- 终点分布：$\mathbb{P}(S_\tau = \pm 3) = \frac{1}{7}$，$\mathbb{P}(S_\tau = \pm 2) = \frac{1}{21} + \frac{2}{21} = \frac{1}{7}$，$\mathbb{P}(S_\tau = \pm 1) = \frac{1}{7}$，$\mathbb{P}(S_\tau = 0) = \frac{1}{7}$；
- 期望范围：
  $$
  \mathbb{E}D_\tau = 2\left(\frac{2}{21} + \frac{2}{7} + \frac{1}{7}\right) + 3\left(\frac{2}{7} + \frac{4}{21}\right) = \frac{22}{21} + \frac{30}{21} = \frac{52}{21}.
  $$
综上，$\mathbb{E}D_\tau$ 的最大值为 $\frac{52}{21}$。
