# 星际战舰编队 — 设计说明

## 舰队设计语言

**形态母题：向前分叉的层叠阶面。** 全队的轮廓都由同一个动作生成——一段向前的柱体在末端裂成两股，每股由一层层错开的体素阶面收细。旗舰把这个母题铺到最大尺度：舰身是一段段退叠的装甲带，舰首裂成两支前伸的叉爪，叉爪之间架起全舰最大的武器体量——光束主炮。母题在高度上再展开一层：背脊沿舰身中线堆出阶地与桅杆，腹部垂下退叠的龙骨鳍，于是从任何角度看过去，"分叉"都同时存在于平面上和垂直方向上。

**壳层做法：三层色阶 + 极少量高光。** 大面积主壳用中明度蓝钢承托结构；嵌进壳体的深槽、肋架与舱底用更暗、更吸光的蓝灰，让结构在明暗中分层；只有推进口、导能槽和金属棱线才允许出现锐利的亮边。暖色（琥珀）被严格留给危险物——脉冲炮口、导弹、命中闪光——冷色（青）留给能量与推进。二者从不混用，观众因此能一眼读出"这是能量"还是"这是弹丸"。

**同一套语言贯穿四类对象。**

| 对象 | 母题的收拢方式 |
|---|---|
| 旗舰"长弓级" | 母题满尺度展开：分叉舰首、抬升的主炮、退叠的推进喷口群 |
| 近卫舰 | 母题收成紧凑厚实的短柱：短翼叠层、前后急收，速射近防炮成组外伸 |
| 前卫舰 | 母题沿航行方向拉长：主体修长，外伸的导弹发射槽列形成方向性重复 |
| 小艇 | 只保留最简的三笔：前部、主体、喷口，翼面直接抄母题的折线 |
| 四种武器 | 主炮＝母题的"叉"，脉冲炮＝塔，近防炮＝短钉，导弹＝带翼的箭 |
| 四处舱内 | 同一套：层叠基座 + 深色夹层 + 发光内芯 + 悬置构件 |

**开火即语法演出。** 光束主炮先让炮身发光槽逐段亮起（从基部推向炮口），炮口聚集浓亮光团后才拉出持续束——这是"分叉"母题被点亮的瞬间。脉冲炮台以相邻错开半拍的方式送出一串串能量弹，近防炮打出密集短点射，前卫导弹拖着长尾弧线入靶。四种武器在光色上严格分区：主炮与脉冲为青，近防与导弹为琥珀，命中处两种光交汇成白。推进尾焰沿用同一条青线，于是全队的光在任何时刻都出自同一套配色规则。

**四处舱内是舰外的内化。** 舰桥、动力中庭、小艇机库与能量长廊都使用与外壳相同的蓝钢／暗件／发光内芯三段关系，只是把"层片"换成"平台与框架"：舰桥是悬置显示与侧层控制台围成的指挥中庭；动力中庭是贯通多层的环形平台与中央外构架核心；机库是两侧退让的停泊凹位与跨舱桥架；长廊是高大的装填装置阵列夹出的中央空隙。光线沿纵深后退，读者始终能感到自己身处一艘巨舰的体内，而不是另一个独立的场景。

**体素媒介统一。** 舰船、武器实体、导弹、小艇、陨石与实体碎块、全部舰内构件共用同一格距（1 单位）。远景靠舰列与尾焰组织，中景是成片装甲与重复炮台，近景才展开阶面、内腔与单个体素接缝。透明与发光构件同样保持颗粒，光束、尾焰、护盾与爆闪则不受格距限制，可以连续流动。
