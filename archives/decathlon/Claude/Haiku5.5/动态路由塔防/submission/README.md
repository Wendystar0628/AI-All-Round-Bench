# 网络安全攻防战

浏览器中运行的三维塔防游戏。战场是悬浮在协议层之上的立体网络，玩家作为守护进程，通过部署设备和改写路由，阻止蠕虫、木马、勒索者与僵尸网络抵达“中枢”。

## 运行方式

直接用 Chrome 打开 `index.html`（以本地文件方式，无需网页服务器）。作品使用经典脚本与内联资源，不依赖网络。

## 目录结构

| 路径 | 内容 |
| --- | --- |
| `index.html` | 入口：页面结构、图标精灵、界面层 |
| `css/app.css` | 界面样式（对局界面、菜单、图鉴、说明、结算） |
| `vendor/three.min.js` | three.js r160（UMD 构建），用于三维渲染 |
| `js/maps.js` | 三张地图的网格定义、地域标注与关键节点名称 |
| `js/data.js` | 设备、敌人、Boss、道具、波次与演示的数值与文本 |
| `js/grid.js` | 网格地图解析与流向场寻路 |
| `js/sim.js` | 战斗逻辑（与渲染无关，可在 Node 中单独测试） |
| `js/models.js` | 程序化建模：设备、敌人、Boss 与动画 |
| `js/view3d.js` | 三维场景：地图、路线、特效、背景、镜头与泛光后处理 |
| `js/audio.js` | 程序合成音效与环境音乐（Web Audio，无外部素材） |
| `js/ui.js` | 菜单、图鉴、说明、关卡卡片、结算与部署栏 |
| `js/demo.js` | 三段实战演示的脚本与导出时序 |
| `js/app.js` | 应用主控：状态、输入、界面同步、主循环与视频导出接口 |

## 操作

| 操作 | 方式 |
| --- | --- |
| 部署设备 / 道具 | 把待部署栏的卡片拖到地图上；或单击卡片后单击地图。拖动时预览作用范围与新路线 |
| 设定拦截器朝向 | 拦截器放下后移动鼠标确定朝向，单击确认；右键或 Esc 取消 |
| 选中 | 单击设备、敌人或地块，可升级、释放技能、分支选择或撤下 |
| 旋转视角 | 按住鼠标中键拖动环绕；按住 Shift + 中键平移；滚轮缩放 |
| 默认视角 | 按 Home，或点击顶栏“默认视角” |
| 暂停 / 调速 | 空格暂停；按 1、2、3 或点击顶栏切换 1×、2×、3× |
| 取消 / 菜单 | 右键取消当前操作；Esc 打开菜单 |

## 游戏内容

- **三张地图**：分段内网（14 波，Boss 万傀）、骨干流域（15 波，Boss 蜃楼）、气隙深层（16 波，Boss 蛰影）。
- **设备**：防火墙、蜜罐、网闸、拦截器、沙箱、修复进程。各可升至 2 级，蜜罐与拦截器在 2 级时二选一分支。
- **道具**：应急隔离器、协议降级、备份还原。
- **改道**：节点可被防火墙或网闸隔离，隔离会改写全网路线。任何会封死入口或地面敌人的操作都会被拒绝，且不消耗资源。
- **资源**：算力随战局增长，用于部署与升级；情报用于隔离节点、选择分支与情报道具。

## 实战演示

菜单中的“实战演示”提供三段从编排好的局面开始的演示：分段取舍（网闸改道）、旁路直通（洪峰与协议降级）、蛰影现身（运维环锁死与冗余切换）。总时长约 57 秒。演示中按 Esc 或点击“退出演示”返回。

## 视频导出接口

作品提供以下接口，供外部按帧截图：

```js
window.videoExport.runs                          // ['demo-1', 'demo-2', 'demo-3']
await window.videoExport.begin(runId, { fps })   // 回到该段起始局面，返回 { frames }
await window.videoExport.frame(i)                // i 从 0 起依次调用，完成时第 i 帧已完整显示
window.videoExport.end()                         // 回到正常的可操作状态
```

进入导出模式后，实时循环不再推进同一对局；第 `i` 帧对应游戏时刻 `i / fps`，与真实时间无关，结果可复现。分辨率由窗口大小决定，已验证至 3840×2160（界面按 1600×900 基准缩放）。

## 已知限制

- 空中航道、木马显形、路线改道等机制已实现并经无头测试，但整体难度未经真人试玩校准。尤其是气隙深层（第 16 波）在自动化测试中仍然偏难。
- 音效与音乐已完成离线与实时的电平测量，但未经人耳试听。
- 部分次要敌人的造型仍较简单。
