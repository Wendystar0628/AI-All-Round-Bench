# AE 风味动效设计编辑器

在浏览器中运行的合成与图层式动效编辑器（WebGL 2 渲染）。双击根目录的 `index.html` 即可在 Chrome 中运行，不依赖网页服务器；库、字体与资源全部随项目提供。

打开后自动载入 15 秒示例「锻字」：字「火」从笔画书写成形，挤出为炽热金属字块，在锤击（7.35 秒）下凹陷并迸出火星，最后冷却定型。

## 功能概览

- **工程与图层**：多合成（尺寸、帧率、时长、工作区）；形状、文字、空对象、调整、预合成、摄像机、平行光 / 点光源、三维几何、粒子、音色。图层可命名、显示、锁定、拖动排序（图层列表中上下拖动）、复制、删除、裁剪入出点。
- **绘制**：矩形（R）、椭圆（E）、钢笔（G）在画布上直接绘制。拖拽生成参数化形状；钢笔单击加节点、拖动设定切线，双击或回到起点结束（开放路径描边，闭合路径填充），Enter 结束，Esc 取消。绘制目标由 M 切换：形状内容（无形状图层时新建）或所选图层的蒙版。
- **变换与父级**：锚点、位置、缩放、旋转（三维含 X / Y 旋转）、不透明度；多层父级；设置与解除父级保持当前画面；拖动锚点画面不动；画布拖动在父级有旋转缩放时仍跟手。三维图层显示世界 X / Y / Z 轴，沿轴拖动移动。
- **关键帧**：秒表开启动画，关键帧增删、点选 / Shift 加选 / 框选、整组移动、Alt 拖动末尾关键帧按比例拉伸、复制粘贴、Delete 删除；线性、贝塞尔、定格，进入与离开分别设置（曲线视图），缓入缓出（F9）；空间路径（直线、曲线、尖角、独立手柄）。
- **曲线视图**：值曲线与速度曲线（位置的速度为沿路径的实际速度），X / Y / Z 分量切换，关键帧与贝塞尔手柄可拖动。
- **表达式**：`time`、`value`、`wiggle(频率, 幅度)`、`loopOut("cycle"|"pingpong")`、`linear`、`ease`、`thisComp.layer("名称").transform.xxx`、向量分量、`valueAtTime(t)`；按依赖求值，循环引用与语法错误给出提示并退回关键帧值。
- **形状与文字**：矩形、椭圆、贝塞尔路径（节点与切线可在画布上拖动编辑；属性面板可闭合 / 开放路径、添加或删除孔洞轮廓）；填充、描边；修剪路径、重复器、并集 / 差集 / 交集 / 排除（顺序影响结果）；路径形变（含孔洞对应）。文字支持多行、字号、行距、字距、对齐；逐字 / 逐词 / 逐行动画器（位置、旋转、缩放、不透明度）；自动笔画（遮罩按当前文字的笔画生成，换字后随之重新生成）。
- **程序节点**：可视化连线、断开、复制、删除、封装组；端口按类型着色（标量、向量、颜色、几何、场、图钉、采样点），每个节点显示当前结果摘要，类型不匹配的连线会被拒绝。
- **场与变形**：衰减场、噪声场、旋涡场、场叠加；场位移、弯曲、扭转；图钉变形（多图钉权重混合，不撕裂）。场同时作用于几何顶点与粒子；选中几何或粒子图层时画布上显示场的影响范围。选中几何图层时显示三角网格线框。
- **遮罩与效果**：矩形 / 椭圆 / 自由路径蒙版（相加、相减、相交、反转、羽化、路径动画）；轨道遮罩（Alpha、亮度及反转）；高斯模糊、发光（可超出边界）、投影、色相 / 饱和度 / 亮度；调整图层；五种混合模式。
- **预合成与运动模糊**：原位预合成；同一合成多次引用，各自时间与变换，支持变速、倒放、定格；运动模糊按快门区间实际运动取样。
- **三维**：挤出（保留凹部与孔洞，前后面、倒角斜面与侧壁）；材质（基础色、金属度、粗糙度、发光、不透明度）；平行光与点光源，投影（阴影贴图）；摄像机（焦距、景深，按视深度计算弥散）；三维通道统一深度遮挡；点选按射线命中最近的可见表面。
- **粒子**：多个发射器（点、形状曲线、几何表面）；速率、初速度、寿命、阻力、扩散角、随机种子；大小、颜色随寿命变化；重力、场、平面与变形网格碰撞（弹性、摩擦、首次碰撞的寿命倍率；碰撞体可选图层或节点图几何输出）；碰撞次级发射；拖尾来自实际轨迹。
- **工程**：撤销 / 重做（一次完整拖动、输入或接线记为一步）；保存为 JSON、重新打开后结果一致（模拟与取样按时刻确定）。

## 逐帧导出接口

```js
window.videoExport.runs                          // ['demo']
await window.videoExport.begin(runId, { fps })   // 回到起始状态，返回 { frames }
await window.videoExport.frame(i)                // 第 i 帧完整显示在页面上后返回
window.videoExport.end()                         // 恢复正常的可操作状态
```

`demo` 展示整个编辑器界面，15 秒示例从头到尾播放一遍；`begin` 时等待示例准备完成，`frame(i)` 使整个编辑器落在第 `i / fps` 秒（画布、播放头、时间轴与属性同步），取样不会重复推进模拟或触发事件。分辨率由窗口决定（画布按视口适配，渲染分辨率随之变化）。

## 字体与文字

内置字体为 Noto Sans Hans（思源黑体）子集，支持范围：GB2312 全部汉字（约 7000 字）、ASCII、全角标点与常用符号。其它字符显示为缺字提示。示例字为「火」。

换字：修改“火 · 写成”文字图层的文字，并把节点图中“文字轮廓”节点的文字参数改为同一个字（节点编辑器底部）。书写的笔画遮罩（该图层的“自动笔画”）、字形、字块、凹陷变形与火星都会按新字重新生成。

## 说明与限制

- 只做 PC 端，需要 WebGL 2；声音在首次点击或按键后启用。
- 尚未实现：画布上直接拖动图钉的手柄（图钉的位置、旋转、缩放参数可在节点中编辑并转为关键帧）；三维图层的旋转与缩放仅通过属性面板和画布的二维手柄完成。
- 运动模糊与景深为采样近似；阴影贴图对点光源使用单个透视投影（非立方体贴图）。
- 三维通道使用多重采样渲染。在部分驱动上，同一时刻的多次渲染之间可能出现极少数边缘像素（几十个像素、最大 2 个灰阶）的差异，视觉上不可见，属于驱动层面的舍入差异。
- 形状路径的节点编辑针对路径项本身，组的变换不参与节点拾取。
