# 嵌套操作系统（Nested OS）

一个桌面端（Windows，Electron 45.2.1）的嵌套图形操作系统：根系统提供日常桌面、电子表格、小组件、
浏览器（真实网页）等应用；每个系统可以创建直属子系统，子系统以三维直升机播放器、飞行排演与图表工作台为主要内容。

## 启动

```
npm install          # 安装 electron@45.2.1 与 three（本机已缓存时很快）
npm start            # 启动（启动前自动打包运行时与预编译系统程序）
```

启动参数（传给 `electron .`）：

- `--data-dir <目录>`：独立的数据目录（根系统磁盘保存在其中），默认为用户数据目录下的 nested-os-data。
- `--width <像素>` / `--height <像素>`：主窗口客户区尺寸，默认 1280×800。
- `--remote-debugging-port=<端口>`：调试端口（自动化使用 19106）。

根目录的 `automation.json` 记录了启动命令、主窗口标题、素材路径与自动化接口（window.bench）。

## 目录

- `src/main/`：Electron 主进程（窗口、nos:// 协议、磁盘持久化、模板加载、本机文件对话框）。
- `src/runtime/`：语言虚拟机、标准库、系统树（universe.js）、飞行物理库（sim-natives.js）。
- `src/renderer/`：宿主渲染（显示组合、输入、三维视图、主循环与 window.bench）。
- `assets/system/`：系统程序（内核 kernel.ns、窗口管理 wm.ns、编译器 compiler.ns、应用、公共库）。
- `assets/flight/`：飞控程序；`assets/demo/`：示例工作簿与三维场景；`assets/documents/`：文档与操作说明。
- `tools/`：构建与开发工具（引导编译器、自举校验、场景生成、预编译、调试脚本）。
- `tests/`：语言、内核与系统树的无界面测试。`npm test` 运行全部测试。
- `docs/DESIGN.md`：设计与接口约定。操作说明见 `assets/documents/使用说明.txt`（应用内可打开）。

## 说明

- 所有系统程序（包括内核、窗口管理与编译器）都是本系统文件中的程序，以本系统自定义的 Nest Script 编写，
  由系统内的编译器编译运行；编辑后重启对应子系统即生效。
- 宿主只提供执行环境、显示设备、输入、磁盘配额与网页视图；三维画面由宿主按提交的场景状态绘制。
- 子系统是运行时状态，应用重启后不保留；需要保存时使用快照（任务管理器）。根系统的文件与设置保存在数据目录中。
