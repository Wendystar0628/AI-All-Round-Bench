# 设计说明：裂首层片舰队

**形态母题——「裂首层片」**：舰首向前分叉成两支长叉，叉间的空腔里生长出发亮的炮身；壳体由层层错开的阶梯板片叠成，板片之间是深色槽带，冷青色光缝串起槽带、喷口与炮口。

**配色**：主壳为暖沙色（宽而柔和的反光）→ 深层构件为靛蓝黑（吸光）→ 青色发光（缝隙、推进、护盾、舱内显示）→ 少量琥珀色（炮口、导弹、导引灯）。陨石是灰褐色，爆裂时才显出橙色热光，与舰队冷青形成对照。

**各舰与武器**
- 旗舰（约 1150 格长）：分叉舰首夹着光束主炮（宽基部 → 带套环的炮身 → 深凹的发射口，炮身发光槽分段亮起）；侧部是羽状层片，上层是错落的塔群与舰桥塔，舰尾五组喷口嵌在逐层退让的尾部里；脉冲炮台分布在甲板边缘与悬浮在舰体周围。
- 近卫舰（约 200 格）：厚实紧凑，短叉鼻、叠层壳片，十二座速射近防炮成对布置在炮座上。
- 前卫舰（约 230 格）：细长主脊 + 向外张开的长叉，两侧伸出导弹吊舱，成列的槽位里是导弹实体。
- 小艇（约 30 格）：前叉、座舱、尾鳍与单喷口，是母题的最小版本。
- 半透明部件（座舱罩、传感圆罩、舰桥全息）同样由同格距体素构成；旗舰背脊塔群下留有能看穿的拱形通道。
- 所有实体（舰船、炮台、导弹、小艇、陨石与碎块、舱内构件，包括透明发光的全息体素）都用同一格距的体素搭建；光束、尾焰、护盾、爆闪、星云等光效不受体素限制。

**舱内与开火**
- 舰桥（旗舰上层塔）：中枢是层叠基座与悬起的显示环，成排控制台沿台阶式侧层向远处排开，前方观景开口外就是真实的舰列。
- 动力中庭、能量长廊：核心与环带、支撑、环形/分叉平台，以及一路后退的框架与装填装置，都沿用同样的“框架 + 深槽 + 青色冷光”语言。
- 机库：位于旗舰舷侧，泊位、桥架、维修构架与第二重舱口把长空间分成几段，远端是发光气闸。
- 开火顺序：主炮蓄势（炮身发光槽逐段亮起）→ 持续光束击穿大陨石 → 脉冲炮台分组错半拍 → 近卫近防炮点射 → 前卫导弹依次升空、弧线加速、延迟爆裂；陨石按预先生成的裂面分块，大块分离、中块翻滚、小块与体素碎屑飞散。随后各舰依次展开护盾，推进增强，整队加速并回到开头的航行状态。

**运行**：双击 `index.html` 即可（纯本地文件，无需服务器）。整轮 77 秒，所有状态都是全局时间的纯函数，因此 `window.videoExport`（`runs` / `begin` / `frame` / `end`）可以任意定位到指定帧。
