# 太阳雨中的小渔港堤岸（Three.js 三渲二微缩场景）

双击 `index.html`（`file://` 方式）即可运行，无需服务器；场景里没有任何 UI 元素。

## 操作
- 左键拖拽：旋转　右键 / Shift+左键拖拽：平移　滚轮：朝光标位置缩放　双击：聚焦到该点
- 推近时：停歇的海鸥会飞走、港猫会抬头看镜头、水下鱼群会散开，过一会儿再聚拢

## 资源
- 所有模型、贴图都由代码生成（顶点色合并几何 + 画布纹理 + 着色器），没有外部图片 / 字体 / 模型文件
- `vendor/three.bundle.js`：three r187 用 esbuild 打包成经典脚本（IIFE），以便 file:// 直接加载

## 代码结构（`js/`，按 index.html 中的加载顺序）
| 文件 | 内容 |
| --- | --- |
| `util.js` | 随机数 / 噪声、`Parts` 几何合并构建器、画布纹理 |
| `fx.js` | 全局 uniform、三渲二材质工厂（对 MeshToonMaterial 打补丁：混凝土 / 湿面 / 水下 / 雨珠 / 摆动） |
| `env.js` | 光照、天空与彩虹、云影、阵风、雨势，以及“同一时刻最多一件明显事件”的事件导演 |
| `water.js` | 平面反射、色块化水面、涟漪与航迹、水体剖面墙、水洼 |
| `post.js` | 主通道(MSAA) → 法线/深度 → 轮廓线 → 柔光 → 合成(调色/纸纹) → 移轴柔化 |
| `base.js` | 底座、码头与岸壁、海床、岸壁藤壶/海藻/系船环/铁梯 |
| `textures.js` / `fxobjs.js` | 告示牌、黑板、时刻表等画布贴图；光柱、水面反光、浪花带、雨珠 |
| `boat_parts.js` / `boats.js` | 船体放样、驾驶舱内部、系船柱与缆绳、绕缆 |
| `world_water.js` / `buildings.js` / `terrain.js` / `props.js` | 水面组装；渔协仓库、候船室、贩卖机；防波堤、灯塔、山坡与民家、消波块、台阶、滑道；港口道具 |
| `weather.js` / `creatures.js` | 雨丝、滴水、闪光；海鸥、港猫、鱼群、出港渔船 |
| `main.js` | 启动、相机控制、主循环 |
