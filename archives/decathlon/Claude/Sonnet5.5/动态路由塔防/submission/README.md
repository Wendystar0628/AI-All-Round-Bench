# 网络安全攻防战 · 动态路由塔防

浏览器三维塔防（three.js r160，全部美术与声音由程序生成）。直接双击 `index.html` 即可在 Chrome 中以本地文件方式运行，无需服务器。

## 玩法要点
- 守护进程（玩家）部署 6 种塔，抵御蠕虫、洪泛团、木马、勒索者、伪热点、加壳器与三位 Boss。
- 核心机制「动态改道」：把防火墙 / 网闸放到交换节点（或插入应急隔离器）会截断道路，各入口路线同步重新收敛；敌人从当前位置掉头。拖动时预览新路线，会封死入口的操作被拒绝且不消耗资源。
- 关卡选择页可切换难度（常规 / 困难 / 专家）；拖动卡片时会高亮所有可部署位置，节点候选以绿色光环标出。
- 三张地图：分段内网（14 波）、骨干流域（15 波）、气隙深层（16 波）；菜单中另有三段「实战演示」。

## 操作
- 镜头：中键拖动环绕，Shift+中键平移，滚轮缩放，H / Home 回到默认视角。左键只用于点选与拖放部署。
- 拖动底部卡片到地图部署；拦截器放下后移动鼠标设定朝向并点击确认。
- 数字键 1–6 选择塔，Q/W/E 道具，空格暂停，Tab 切换速度，N 发起下一波，U 升级，F 技能，Delete 撤下，Esc 取消/菜单。

## 目录
- `js/data.js` `js/maps.js`：塔、敌人、道具、状态、地图与波次数据
- `js/core.js` `js/sim.js`：逻辑内核（路径场、改道、连通保证、战斗模拟、Boss）
- `js/gfx.js` `js/terrain.js` `js/models.js` `js/fx.js` `js/world.js`：渲染、场景、建模、特效
- `js/ui.js` `js/screens.js` `js/input.js` `js/demo.js` `js/audio.js` `js/main.js`：界面、输入、演示、声音、主循环
- `test/`：Node 下的无头测试（`maps_test.js` 路线性质、`mech.js` 机制、`inv.js` 压力不变量、`boss.js`、`bot*.js` 平衡）

## 视频导出接口（供外部脚本使用）
`window.videoExport`：`runs`（`['demo-1','demo-2','demo-3']`）、`await begin(runId, { fps })` → `{ frames }`、`await frame(i)`（第 i 帧对应游戏时刻 i/fps，返回时已显示在页面上）、`end()`。
逻辑、界面、特效、定时器和 CSS 动画都由逐帧推进的虚拟时钟驱动，随机数使用固定种子，结果与机器快慢、帧率无关。实现见 `js/export.js` 与 `js/vtime.js`。

三段实战演示在 1 倍速下合计约 56 秒（约 18.6 + 18.8 + 17.9 秒），每段含开场、操作、战况与收尾；光标速度按真人移动估算，并留出预览与结果的停留时间。导出模式下真实输入与实时循环均不再推进对局。
