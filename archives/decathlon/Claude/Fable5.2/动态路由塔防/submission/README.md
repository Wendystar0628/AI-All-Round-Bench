# 网络安全攻防战 · 动态路由塔防

在 Chrome 中直接双击 `index.html`（本地文件方式）即可运行，不需要网页服务器，不联网。

## 目录

| 路径 | 内容 |
| --- | --- |
| `index.html` | 入口，按顺序以普通 `<script src>` 加载全部脚本 |
| `css/style.css` | “守护进程操作系统”界面样式（按 1920×1080 设计，随窗口等比缩放，最高 3840×2160） |
| `lib/three.bundle.js` | Three.js r170 及后期处理组件打包成的单文件（仅渲染库，模型、贴图、声音均为程序生成） |
| `js/core.js` `maps.js` `path.js` `data.js` | 工具、三张地图与波次、路由场（按通行时间的最短路）、塔 / 敌人 / 道具数据与说明文本 |
| `js/sim.js` `sim2.js` | 确定性固定步长对局模拟：部署、隔离、路由收敛、连通校验、战斗、Boss |
| `js/gfx_*.js` | 场景、模型与动作、特效与战场信息层、模拟到画面的同步 |
| `js/ui.js` `input.js` `icons.js` | HUD、流量预报、选中面板、图鉴、关卡选择、事件报告；Blender 式镜头与拖放部署 |
| `js/audio.js` | WebAudio 实时合成的环境声、音乐与音效 |
| `js/demo.js` | 三段实战演示与 `window.videoExport` 导出接口 |
| `_build/` | 打包 Three.js 的入口脚本、无头测试脚本和一次性补丁脚本（运行作品不需要） |

## 操作

- 镜头：中键拖动环绕，Shift + 中键平移，滚轮缩放，`H` 或顶栏按钮回到默认视角。
- 部署：把底部卡片拖到地图上（或点一下卡片再点地图）；拦截器落位后移动鼠标定朝向，左键确认、右键取消。
- 改道：在交换节点上部署网闸 / 防火墙或投放应急隔离器时，先显示各入口的预览路线（虚线）与确认气泡，确认后才执行；会封死道路的操作被拒绝，不消耗资源，并标出被封死的入口 / 敌人。
- 其他：`空格` 暂停，`Tab` 调速，`N` 立即开始下一波，`1–6` 拿起塔卡，`Z X C` 道具，`F` 技能，`U / I` 升级（分支 A / B），`Del` 撤下，`Esc` 取消 / 菜单。

## 视频导出

```js
window.videoExport.runs                         // ['demo-1', 'demo-2', 'demo-3']
await window.videoExport.begin('demo-1', { fps: 30 })   // -> { frames }
await window.videoExport.frame(i)               // i 从 0 起依次调用
window.videoExport.end()
```

三段演示时长 19.4 s + 20.0 s + 19.6 s = 59.0 s。导出模式下实时循环不再推进对局，第 `i` 帧对应游戏时刻 `i / fps`，战斗、自动操作、镜头、字幕与界面动效都按该时刻同步。

- `_build/test/maps.test.js`：三张图每个交换节点单独隔离后的改道与连通性。
- `_build/test/plan.js`：按固定方案布防的无头对局，三张图在正常经济下均可通关（分段内网 19/20，骨干流域 9/20，气隙深层 13/20）。拦截器对飞行目标伤害 +50%，伪热点不再是后两张图的主要失分来源。
- `_build/test/boss.js` / `seal.js`：三个 Boss 的预警与地形能力、封死拒绝、再次隔离间隔、撤下返还。
- 敌人被阻挡或冲击节点超过 8 秒会逐渐狂暴（伤害持续上升），避免“只挡不杀”的僵局。
