# 设计说明 · 「裂隙双叉」舰队

**形态母题**：两块向前伸出的叉齿，夹住一道发光的深槽；叉齿外侧再一层层退叠象牙色的装甲壳片，壳片之间露出暗色骨架。全片所有物体都由同一格距（1 格 = 1 单位）的体素搭成。

**色彩位置**：象牙白（上部）与石板蓝灰（下部）的大面积壳面承托结构；深石板蓝黑的内槽、骨架与喷口内腔作第二色调；少量青色能量光串起炮口、推进与缝隙，琥珀色只作标记灯、近防弹迹和导弹尾焰的点缀。

**各舰**
- **旗舰**（长 1120 格）：舰首是两根七级阶梯收束的长叉齿，中间的贯通空隙里悬着脊轴光束主炮（炮尾基座→带发光槽的炮身→深陷的炮口）；收腰之后是带装甲腰带与检修深槽的主体、阶梯式指挥堡、双尾鳍与腹部龙骨前叉；两侧机库舷舱自身也是一对小叉；舰尾为层层退让的矩形喷口井，口沿逐级发光。
- **近卫舰**（约 180 格，1/6）：把母题压短加厚——短钝双叉、叠层肩甲与短翼咬合，炮座上成组的速射近防炮。
- **前卫舰**（约 220 格，1/5）：把母题拉长摊开——细长双叉、后掠挂架外伸出导弹舱，舱面是成排发射槽与弹头。
- **小艇**（28 格，1/40）与**脉冲炮台**：只保留"双叉夹一道光槽"的最简形。

**武器与开火**：主炮沿叉隙蓄能——炮身光槽由后向前逐段点亮、炮口聚光，再拉出白芯青鞘的持续光束，把正前方的大岩体沿裂面劈成两半（裂面炽热发光、逐渐冷却）；脉冲炮台分组错半拍打出带短尾的能量弹，逐块崩落另一块岩体的边缘；前卫导弹依次弹出、点火、沿弧线拖出长尾迹，先后命中后引出大块分离翻滚；近卫近防炮以琥珀色的短促弹流清理小岩块。实体碎块始终是同尺寸体素。

**护盾与加速**：护盾是沿舰体中线留一道亮缝的两瓣壳面，阶梯状的肋纹向舰尾流动，展开亮波由舰首扫到舰尾；旗舰最大，其余各舰按距离依次点亮。随后尾焰由内层增强、拉长，全队从劈开的岩体之间前冲，镜头拉开接回开头的巡航。

**舱内**（同一母题与三色关系）
- **舰桥**：叠层八角基座与悬吊叉形显示架构成中枢，前方是舰队全息图与宽阔观景窗，两侧阶梯层排列控制台。
- **动力核心中庭**：上下两组爪形叉座夹住发光核心，四条环带绕核心反向旋转，五层环形/叉形平台与八条巨型支撑围合出跨层空腔。
- **贯通式机库**：沿舷舱纵贯约 380 格，两侧双层停泊凹位、跨舱桥架与吊爪、两道内闸，尽头是亮栅舱门。
- **能量装填与导能长廊**：连续门架之间排列夹层式装填柱（暗色夹层 + 亮芯），中空处悬着叉形导能架，能量块沿地槽分批前进，尽头是叉环形的发光炮尾腔口。

**镜头**：一轮 78 秒自动循环——巡航全景 → 贴近近卫与舰首的长镜头掠过舰身、绕过舰尾并跟随小艇进入机库 → 中庭 → 舰桥 → 长廊 → 主炮蓄能开火与四种武器交叠 → 全队开盾、加速穿过碎块并拉开，接回开头。`window.videoExport` 提供 `voyage / interior / attack / surge` 四个分块，全部来自同一条全局时间线，可按任意帧率逐帧定位。
