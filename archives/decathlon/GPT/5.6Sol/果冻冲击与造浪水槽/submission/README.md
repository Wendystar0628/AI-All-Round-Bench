# 介质实验室 · 果冻冲击与造浪水槽

直接用 Chrome 打开根目录的 `index.html` 即可运行；项目不需要服务器，不会在运行时请求网络资源。

## 操作

- 顶部可独立切换“果冻冲击”和“造浪水槽”。
- 右侧参数会参与材料约束、断裂、浮力与造浪计算。
- 底部支持暂停、继续、慢放、重置和四段预置演示。
- 鼠标拖拽旋转镜头，滚轮缩放；空格暂停，`R` 重置。

## 模拟与渲染

- 果冻内部是 320 个体素节点及结构/剪切连接，迭代 XPBD 距离和体积约束。连接按实时应变与材料阈值断裂；能量依次产生“仅变形、保持连通的裂口、分裂碎块”三级结果，碎块来自断裂图的连通分量。
- 水体以 1,536 个三维粒子和 16×8×8 网格执行 WebGPU 计算着色器 PIC 更新。粒子向网格收集质量与动量、网格速度再传回粒子；可视粒子会从 GPU 缓冲区抽样，飞溅、白水、拍壁和返回波按粒子事件生成。
- WebGL 2 负责体积软体、刚体、玻璃、水面重建、粒子与光照渲染。

## 逐帧导出

```js
window.videoExport.runs
await window.videoExport.begin('tank-full', { fps: 30 })
await window.videoExport.frame(0)
window.videoExport.end()
```

四段时长分别为 6、9、7、18 秒；每段会载入固定的材料、冲击或造浪参数。导出时正常实时循环停止，以固定 120 Hz 物理步推进并只显示三维画面；`end()` 会恢复导出前的场景与用户参数。
