# 逐项复查与本轮完善

依照题面的 5 个评分方向、23 个分项重新检查，并结合本地 Chrome 的实际画面修改。下表记录作品中的具体落点；它是验收记录，不是评分预估。

| 项目 | 本轮检查与落实 |
| --- | --- |
| 1. 统一设计语言 | 保留双叉、退叠壳叶与暗槽；为护卫舰补充凝练的叉形舰首，武器、泊位和装填框沿用青灰、黄铜、青色能量配色。 |
| 2. 旗舰大形与尺度 | 旗舰约 1100 格，护卫约 200 格量级、小艇约 33 格；外部近景改为沿敞开的侧舱观察小艇，直接建立体量级差。 |
| 3. 旗舰近景结构 | 将被肩部装甲遮住的机库改为真正凹入的开口，增加顶壳、侧缘、内泊位与停泊小艇；外伸壳叶和舰腹掠行仍保留。 |
| 4. 两类护卫 | 近卫保留厚实主体、短翼与六座转向炮；前卫保留舒展的侧架，补入槽内可见的导弹实体。 |
| 5. 舰阵层次 | 维持旗舰、18 艘近卫与 18 艘前卫；调整少量护卫的位置，让攻击镜头能接续看到不同发射舰。 |
| 6. 共同体素 | 所有实体仍经同一整数单位构建器生成，包括新增炮身、导弹、破片、数字标记和舱内框架；只让光与介质使用连续曲面。 |
| 7. 武器实体 | 炮台分为固定基座和可转向炮头，保留双管、炮口；主炮导能轨拆成独立的发光分段。 |
| 8. 四类发射光效 | 改为明确的发射、飞行和命中时间，消除弹丸在弹道中途突然出现；源点跟随实际炮口和舰船。主炮逐段蓄能，束身有流纹，停射时断开并前移；脉冲、近防和导弹保留不同速度、颜色与尾迹。 |
| 9. 陨石碎裂 | 将平直八分体改为相互嵌合的不规则裂面；加入不同大小的体素碎块与受击尘屑。脉冲和近防优先瞄准已分离的前部碎块，减少射向空心的问题。 |
| 10. 全队护盾 | 护盾由舰首向舰尾扫开，再扩张到完整包围；加入展开亮波对旗舰附近壳层的受光，保留各舰依次开启和轮廓透明度。 |
| 11. 航行与小艇 | 伴飞小艇改走周期闭合航线；侧舱新增实际离港、爬升、伴飞与返航路径。近处实体漂浮物随累计航程后掠，推进依次增强。 |
| 12. 舰桥 | 将整片亮屏改成暗底、分层的体素数据图形，保留中枢投影、错层台面和窗外舰列。 |
| 13. 动力中庭 | 保留跨六层的错转环架、核心流动节点和呼吸照明；补充上下端环架与支撑，让竖向空间有明确边界。 |
| 14. 贯通机库 | 新增跨舱高位步桥、栏杆、桥底暖光与泊位数字；桥架位于飞行和镜头通道上方，小艇继续离泊、驶出和返回。 |
| 15. 导能长廊 | 重新打开装填装置的外框，露出内部亮核；远端由单块亮面改为多重腔口和分开的发光构件，保留光块输送与夹架合分。 |
| 16. 宇宙与陨石环境 | 保留程序星空、星云和天体弧面；增加不同大小的近处实体漂浮物，未受击岩体仍有不规则外缘和空洞。 |
| 17. 基础与事件光 | 保留侧光、环境色和实时阴影；新增近防及脉冲发射处的短促局部照明，以及护盾扫过的柔和反光。 |
| 18. 材质与成像 | 保留主壳柔反光、暗构件与金属边缘的差异；继续采用 HDR 辉光、接触遮蔽及多重采样，强光外缘保留颜色。 |
| 19. 尺度与景别 | 外景在阵列全貌、主炮、侧舱、舰腹与推进器之间推进；四处舱内维持移动镜头，新增内容均位于实际镜头可见区域。 |
| 20. 路径与转场 | 调整侧舱取景高度，避免外伸壳叶挡住泊位；攻击结束至护盾镜头改为连续回望，并用位置、速度连续的曲线连接。 |
| 21. 攻击组织 | 镜头依次保留主炮及目标、近卫射击和前卫发射架，再靠近裂开的岩体；没有为每类武器重新等待起拍。 |
| 22. 结尾与循环 | 舰船微调、伴飞轨迹、尾焰与盾光光学相位改为周期运动；漂浮物使用累计速度积分，消除变速时跳位。首尾相机切线也作匹配，碎裂重建仍在视野之外。 |
| 23. 本地与导出 | 保留本地普通脚本、单一 `tour` 分块和 78 秒时间线；没有新增网络依赖或界面控件。 |

实际验证：本地 `file://` 运行；117 个时间点的中心视线采样未发现 5 格以内实体遮挡；逐段截图复核关键镜头；3840×2160 渲染无 WebGL 错误。对 0、13、21、32、42、50、58、61、64、67、69、73、77 秒，3 fps 与 60 fps 的场景变换及光学数值状态一致，随机跳帧重建一致；抽测脉冲发射瞬间，弹丸与炮口的起点距离为零。3 fps 返回 234 帧，60 fps 返回 4680 帧。

## 再次逐项复查：造型、内景层次与成像

继续依照上表 23 项核对，保留已完成的舰队规模、四类武器、碎裂、开盾和确定性时间线。本次新增与修正如下：

| 相关分项 | 具体改善 |
| --- | --- |
| 统一语言、旗舰轮廓、近景细节 | 将舰楼重构为双列退叠支承和挑空冠部；给旗舰和两类护卫加入整格分叉标记，减少安静装甲面中散乱的构件。 |
| 尺度揭示、舰阵层次 | 调整一艘前景前卫的高度与位置，让它先从画面边缘掠过，再显露中央旗舰和后方阵列；舰队仍为 37 艘。 |
| 推进器、运镜 | 保留侧舱与舰腹掠行，用连续曲线接入后方喷口近景，清楚展示五组主喷口的层叠口沿、发亮内腔与尾焰。 |
| 舰桥 | 投影图加入流动的立体航迹和发光节点，显示板加入扫描层；两侧透明实体面板透出后方投影，窗外舰列补上推进光。 |
| 动力中庭 | 收束发光内层轮廓、保留中央分叉，加入双向螺旋流光和沿支撑向外传递的能量节点；平台补充栏杆，镜头升高后拉远观察多层关系。 |
| 机库 | 门架底梁改为齐平结构，恢复贯通的飞行地面；保留高位步桥与泊位结构，增加轻薄的空间光，按纵深组织明暗。 |
| 装填与导能长廊 | 同样去除地面高梁；上方增加悬置导能头，能量块沿长廊朝远端腔口输送，形成与机库不同的装置节奏。 |
| 光、材质与成像 | 分别调整四处内景的环境光、主光与雾层，增强局部光源和暗部的层次；新增透明实体仍由整格体素构建，光锥和螺旋只作为光学介质。 |

验证记录：完整跑过 234 帧的 3 fps 预览；117 个中心视线采样未发现 5 格以内不透明实体遮挡。检查 2831 个实体网格所用的 1181 份独立几何，未发现偏离整数网格的顶点或被缩放的实体。对 18 个共同时间点比较 3/60 fps 的场景变换、光强、光学参数以及动态流光缓冲数据，状态一致，随机定位重建一致。已检查 3840×2160 的实际画面，未出现 WebGL 错误；时长和接口仍为 78 秒、234/4680 帧。

## 再次逐项复查：命中差异、完整包围与加速衔接

再次对照全部 23 项，重点修正攻击段和开盾加速段中仍不够清楚的关系：

- 主炮命中：先保持两片大岩体的整体形状，沿裂面逐渐撑开，再出现次级剥落和转动；裂面余热采用与光束呼应的冷色。
- 脉冲命中：改为分时剥落局部块体，并保留受损主体；后续脉冲继续照亮不同缺口。
- 近防命中：目标改为更小的岩体，连续点射会陆续打出小碎屑。新增的脉冲和近防碎屑共有 80 枚，均为整格实体，余光退去后仍继续运动。
- 导弹命中：先让受击处发亮，短暂延迟后施加分离冲量，不同块体错开炸裂和翻滚。后续导弹瞄准预测中的碎块位置；导弹离架后再点亮尾部，并出现独立的暖色短焰与长尾迹。
- 护盾包络：几何检查发现，原先两类护卫的尾部喷口边角超出盾面；已修正护盾长度和中心位置。逐一检查全队实体顶点，37 艘均处于完整展开的护盾内部，最大归一化半径平方约为 0.914（小于 1）。
- 展开反光：各舰壳面现在有随展开进度前移的柔和蓝色反光，保留原有体素表面与材质；旗舰的局部反光和推进照明跟随舰体移动。
- 加速衔接：各舰前冲和自身尾焰共用同一个加速相位，按前后编组接续增强；增加前冲幅度，同时保持循环首尾的姿态与运动连续性。

本轮验证：完整 234 帧预览、117 个中心视线采样通过；未发现偏离整数网格的实体顶点或被缩放的实体。20 个共同时间点的 3/60 fps 场景状态、发光强度及护盾反光参数一致，随机跳帧重建一致。预测命中点与对应碎块实际变换的误差约为 1.1×10⁻¹²。检查了 4K 攻击画面，无 WebGL 错误；时长与导出帧数保持 78 秒、234/4680 帧。
