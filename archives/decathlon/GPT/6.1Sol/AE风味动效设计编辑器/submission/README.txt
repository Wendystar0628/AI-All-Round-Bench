铸造 FORGE — 动效设计工作台
================================

运行
直接用 Chrome 打开根目录 index.html。所有脚本、字体、几何与音色均在本地，无需安装、构建、网络或服务器。

默认工程
「锻字 · 一字千锤」为 15 秒工程。首次打开停在成块阶段，便于查看材质；首次点击播放从第 0 秒开始。
四段章节按钮可跳到写成、成块、锻打、冷却。第一次播放会建立 Web Audio 音频。

编辑
1. 左侧素材或「图层」菜单创建图层；顶部新建工程可从空白开始。
2. 时间轴点击选择，Shift 多选；图层名称双击重命名，拖动排序。左侧眼睛与锁可切换显示和锁定。
3. 属性左侧时钟启用动画，菱形在当前时间记录关键帧。动画启用后，属性修改只更新当前帧。
4. 在画布拖动所选几何平移，W 旋转，拖动角点缩放，Y 移动锚点。
5. 曲线编辑器提供最终值和速度曲线，可拖动关键帧与进入/离开手柄。F9 缓入缓出。
6. 时间轴可 Shift 拖动框选关键帧、移动、复制粘贴、删除，更多菜单提供时间拉伸和工作区设置。
7. 表达式支持 time、value、wiggle、loopOut、linear、ease、跨图层引用和 valueAtTime。错误会回退并提示。
8. 内容页修改文字、文字动画范围、形状轮廓、修剪路径、重复器、布尔操作及图钉。路径工具 G 点击布点，Enter 完成。
9. 节点视图通过输出、输入端口接线，点击连线断开。标量端口为金色，几何为绿色，场为蓝色。节点组可双击展开。
10. Ctrl+Shift+C 将所选图层预合成；双击预合成图层或 Enter 进入，在左侧合成列表返回。
11. 材质页调整金属度、粗糙度、炽热和阴影；效果页提供效果、蒙版及轨道遮罩。摄像机属性可调整景深。
12. 粒子内容页选择点、轮廓曲线或几何表面发射，设置持续速率或爆发时刻、方向力、反弹、摩擦及寿命末端的大小与颜色。碰撞后可以真实生成次级粒子。

快捷键
空格 播放/暂停；方向键 逐帧；Shift+方向键 10 帧；Home/End 首尾；J/K 上下关键帧。
V 选择；W 旋转；Y 锚点；Q 矩形；G 路径；T 文字。
Ctrl+D 复制图层；Delete 删除；Ctrl+C/V 复制粘贴；Ctrl+Z 撤销；Ctrl+Shift+Z 或 Ctrl+Y 重做。
Ctrl+S 保存；Ctrl+O 打开。输入框内不会抢占编辑快捷键。

工程文件
「保存工程」下载 .forge JSON 文件；「打开」恢复工程。合成、图层、节点、材质、关键帧、表达式和模拟参数均保存在文件中。
内置 Forge Serif 为 Noto Serif SC 的字符子集：铸、锻、永、火、金、山、水、木、光。其余字符可使用系统字体轮廓回退。

逐帧接口
window.videoExport.runs                       // ['demo']
await window.videoExport.begin('demo',{fps:60}) // {frames:900}
await window.videoExport.frame(i)              // 精确取样到 i / fps 秒
window.videoExport.end()                       // 恢复交互
支持 3 fps 预览与 60 fps 输出，整个编辑器的时间和画面同步。模拟按工程参数与发射事件确定性计算，导出期间不会推进音频或播放时钟。

实现说明
Three.js 在 WebGL 2 上渲染实际挤出网格、PBR 材质、环境反射与几何阴影；OpenType 提取内置字体真实轮廓；polygon-clipping 处理轮廓布尔运算。
深度纹理用于景深，运动模糊在快门区间多次取样。粒子按面积在变形后网格表面取样发射，以 1/60 秒固定步长模拟，直接对渲染使用的世界空间三角形进行碰撞检测，计算运动表面的相对速度、反弹与摩擦。
拖尾由真实轨迹分段构成，碰撞转折也会保留。位置、颜色、尺寸与消退随寿命变化。几何、图钉、场、节点或模拟参数变化后重新建立轨迹缓存；首次计算新爆发时会有短暂计算开销。
所有界面图标、场景、材质环境、音色和示例均由项目中的代码生成。

随附第三方组件的许可证位于 vendor 目录。
