# 太阳雨中的小渔港堤岸

直接用 Chrome 打开根目录的 `index.html`。所有脚本均随项目提供，无须服务器或联网。

- 左键拖动：旋转观察。
- 右键或中键拖动，或 Shift + 左键拖动：平移。
- 滚轮：缩放，推近时聚焦鼠标所指的场景物体。
- 双击：回到全景。

场景中的模型、文字贴图、雨、水、植被与道具均由 `scene.js` 以几何体或 Canvas 程序制作。`vendor/three.min.js` 是随附的 Three.js r158 运行库。

视频接口：

```js
window.videoExport.runs; // ['overview', 'tour']
await window.videoExport.begin('overview', { fps: 30 }); // { frames: 150 }
await window.videoExport.frame(0); // 使用内部时刻 0 / 30 完成渲染
window.videoExport.end();
```

`overview` 为 5 秒静止全景，`tour` 为 20 秒连续运镜，从全貌进入水体剖面，随后经过候船室、船舱、渔协仓库和灯塔，最后回到全景。接口中的时间由帧号决定，支持调用方调整窗口大小至 3840 × 2160。正常浏览时，天气与港口生活以 100 秒为一个周期缓缓变化。

水面与水洼使用不同高度的实时镜面相机，再通过色阶、波纹和碎片遮罩概括倒影。水下包含摆动海藻、鱼群、藤壶与牡蛎、旧轮胎和锚链；建筑与船舱内有透窗光线及缓慢变化的水面焦散。所有这些效果均在本地文件方式下运行。

四艘船分别具有游钓装备、作业吊架、木座椅与敞舱舷外机；三间驾驶舱均可直接观察内部仪表和生活物件。渔协仓库与候船室保留开放视线，山坡民家设有窗檐、木门、信箱、盆栽和通向港口的石阶。滑道实际降到水边，倒扣舢板由木垫支撑，港猫在船下避雨。

天气周期中依次出现雨势转弱与猫外出、渔船绕防波堤航行、由海向岸推进的阵风、薄云与短暂灯塔亮灯、海鸥落水。猫的路线随周期变化；镜头靠近时，附近停歇海鸥、猫与水下鱼群会分别作出反应。
