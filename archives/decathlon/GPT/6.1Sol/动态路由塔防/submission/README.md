# 汐域 · 网络安全攻防战

双击根目录的 **index.html**，使用桌面 Chrome 即可完整运行。无需安装、构建、联网或启动服务器。

## 操作

- 选择一个防御域，部署设备，再点击“放行第 1 波”。三张地图直接开放，分别为 14 / 15 / 16 波。
- 拖动设备卡片到对应地块，或点击卡片（快捷键 1–6）后点击地块；先预览，再确认。拦截器可选择朝向。
- 中键拖动环绕，Shift + 中键平移，滚轮缩放，R 复位。
- 点选设备升级、选择分支、释放技能、旋转拦截器或撤下。点选敌人与地块查看状态。
- 空格暂停；右上角切换 1 / 2 / 3 倍速。H 打开设备、威胁与协议知识库。
- 三段实战演示位于主界面及系统菜单，可以随时退出。

## 视频接口

```js
window.videoExport.runs // ['demo-1', 'demo-2', 'demo-3']
await window.videoExport.begin('demo-1', { fps: 30 }) // { frames: 540 }
await window.videoExport.frame(0) // 随后按顺序调用，完成后即可截图
window.videoExport.end()
```

三段演示分别为 18、20、21 秒，1 倍速合计 59 秒，包含开场、连续操作、预览、战况与收尾。导出模式关闭实时推进，每帧同步推进战斗、操作、镜头和字幕至 `i / fps`，完成渲染后返回，不等待真实时间或下一次动画帧。可从本地文件调用。

## 实现

所有设备、威胁、建筑、材质、网络环境和图标均在项目内程序化制作；环境音乐和音效由 Web Audio 合成。唯一运行库为随项目存放的 Three.js 0.160.0（MIT），不使用远程资源。

路由采用带旧链路耗时的 Dijkstra。每次通行变化检查所有入口和地面威胁的连通性；节点旁路、临时故障与协议降级均触发全场重新寻路。

`node verify-routing.cjs` 可运行三张图的连通、节点改道、相邻步进和通行耗时回归检查。`node verify-game.cjs` 检查战斗、技能、状态、道具、胜负与重开；加上 `--campaign` 可运行三图连续波次的逻辑烟雾测试。

`node verify-campaign.cjs --require-win` 使用正常的 500 算力、90 情报，从第一波开始模拟实际花费、部署、升级、维修、道具和节点重建，并验证三张图均通过最后一波。该策略使用的开局布防可在战场右上角“布防参考”中查看。
