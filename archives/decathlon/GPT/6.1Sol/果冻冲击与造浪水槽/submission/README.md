# 物性之间 · 软体与流体实验室

直接用 Chrome 打开根目录的 **index.html**。无需安装、构建、服务器或网络；所有库和着色器均随项目交付。造浪水槽需要启用硬件加速、支持 WebGPU 的 Chrome。

## 自由实验

- 顶部切换果冻冲击 / 造浪水槽。
- 果冻：先选莓粉、紫晶或琥珀标本，再选择正中、偏心或连续冲击。软硬与结实程度作用于所选标本，各标本保留自己的材料设置；同一质量与落高可以直接比较三种材料。
- 水槽：释放九颗同尺寸的三组小球，可再次释放，最多同时 24 颗。各组密度独立可调；造浪幅度与频率控制左侧活塞。
- 鼠标拖动旋转，滚轮缩放；“默认视角”恢复镜头。
- 空格暂停 / 继续，S 切换四分之一速度，R 重置，1 / 2 切换场景，H 隐藏 / 显示界面。
- 声音默认关闭，点击右上角打开。声音在浏览器内合成。
- 预置实验会重设对应场景、参数和事件时序。重置后回到自由实验。

## 固定视频接口

```js
window.videoExport.runs
// ['jelly-center', 'jelly-multi', 'jelly-offset', 'tank-full']

const { frames } = await window.videoExport.begin('jelly-multi', { fps: 60 });
for (let i = 0; i < frames; i++) {
  await window.videoExport.frame(i);
  // 在这里截图；此时画面已经更新
}
window.videoExport.end();
```

单击与偏击各 7.5 秒、连击 9.5 秒、水槽 19 秒。接受任意正整数 fps；以固定演示时钟推进，并对相邻求解状态插值取样。导出期间停止实时推进，隐藏全部界面，按当前视口大小渲染。接口不输出声音，也不录制视频文件。`end()` 恢复界面并暂停在当前状态，可继续、重置或再次演示。

## 模拟实现

**果冻**（jelly.js）：每块初始标本为 448 个体积节点、1764 个四面体。XPBD 距离约束负责剪切与伸缩，四面体体积约束限制压缩；碰撞将冲击动量传入体积节点，重力、接触、摩擦和阻尼持续参与求解。达到由材料韧性、冲击能量与拉伸应变共同决定的阈值后，从接触位置生成断裂方向，重建四面体连接并复制裂面节点。碎片不是预制网格，断裂后继续使用原来的体积约束。表面从当前四面体边界提取；新裂面进行显示层的局部平滑。软体表面用空间哈希处理标本间、碎片间接触，金属球有球—球、球—软体和台面接触。

**水槽**（fluid.js）：约 1.6 万个三维流体粒子，44×20×19 欧拉网格。WebGPU 计算着色器依次执行整数原子 P2G 散射、网格动量归一化与外力、散度计算、Jacobi 压力迭代、投影以及 PIC/FLIP G2P 传递。移动活塞、槽壁、底部斜坡和球体均参与边界处理。球从粒子重建的局部液面与三维流速采样获得浮力、阻力和流体动量，球体边界再将动量反馈给流体。停机时提高 PIC 混合比例与粘性耗散，逐步消除余波。

自由液面由三维粒子密度场提取等值面，采用四面体多边形化生成连续表面，能够保留悬垂、空腔与分离的结构；低邻域密度的独立飞溅继续作为粒子渲染。表面法线、前后表面深度、水体厚度、环境反射与折射共同参与光学合成；白水还检查不透明物体深度，避免穿过活塞和球体显示。没有使用高度场、浅水方程或解析波形代替流体求解。白水从高速、低邻域密度的表面粒子产生，再随采样流场漂移、消散；入水气泡、下沉尾迹及槽底光影也在浏览器内更新。液面高度采样只服务于浮力与显示，不驱动主流体运动。

**渲染与交互**（app.js / style.css）：WebGL 三维渲染、程序化摄影棚环境反射、阴影、半透明物理材质与统一的简体中文界面。无外部字体、图片、模型或运行时网络请求。

## 已验证

- 通过 `file://` 在本机 Chrome 中直接运行，两个场景没有运行错误。
- 四段演示均完成逐帧检查，正中 / 偏击不裂，连击断裂；偏击球继续碰撞琥珀标本。
- 两个场景的 3840×2160 导出与界面隐藏均通过检查。
- 以 7、11、240 fps 导出的同一时刻，软体节点校验和、球位置与旋转状态完全一致。
- 参数对照中，同一冲击下，软标本的最大中心凹陷约 1.02 m，硬标本约 0.21 m；质量从 2 kg 增至 8 kg 时凹陷加深，降低结实程度后产生断裂。
- 小球重复释放达到 24 颗上限时保持稳定；水槽停止造浪后白水消散，三种密度组重新分层。

## 本轮逐项复查与改进

| 题面内容 | 落实的改进与检查 |
| --- | --- |
| 多种软体、同球不同结果 | 三标本可分别选中、修改材料与施加冲击；实际验证三个落点均命中对应软体。 |
| 大变形、回弹、体积保持 | 增加中心形变、真实四面体体积和冲击能读数；单击过程测得体积约保持在原体积的 99%～100%。 |
| 偏击与后续碰撞 | 复测偏击滑移约 0.58 m，球与第二块标本发生接触，结尾不裂。 |
| 由材料判据断裂 | 断裂方向取当前拉伸应变的主方向；过载程度决定两块或四块分离，连击最后一击实测形成四块，继续使用软体约束。 |
| 连贯液面、反射与折射 | 新增三维密度等值面、梯度法线与水体前后表面厚度；保留独立飞溅，减少原先密集粒子球的颗粒感。 |
| 入水、水冠、气泡 | 补上实际遗漏的气泡生成与尾迹逻辑；水冠强度随入水速度和密度变化，1 秒取样时可观察到气泡与飞溅。 |
| 可见装置推动水体 | 活塞相位连续积分，启停与幅度平滑变化；边界速度取实际位移差分，调频不再造成位置跳变。 |
| 三层运动与碰撞 | 修正实体槽底、斜坡与物理底面的高度差；碰撞按密度分配动量，加入流场加速度和近底升力。预置风浪中重球实测短暂离底约 9 cm。 |
| 停机、重置与重复释放 | 19 秒整段回归通过，停机后白水归零、球群收稳；24 颗上限保持三组各 8 颗。 |
| 独立控制、音效与中文 | 状态变更等待在途 GPU 求解完成，避免切换操作丢失；修复提示乱码，补齐球间、槽壁碰撞声音，并同步暂停、造浪和材料参数的界面状态。 |
| 演示编排与镜头 | 接触、断裂时推近，偏击时跟随第二次碰撞，风浪阶段保留三层球和水槽全貌；四段时长保持 7.5 / 9.5 / 7.5 / 19 秒。 |
| 逐帧与离线交付 | 补齐球旋转、活塞、气泡和白水的采样插值；7 与 11 fps 的水槽同一时刻粒子状态校验一致。再次验证 4K 水槽导出、界面隐藏、无 GPU 错误和本地文件运行。 |
