04创意网页设计CREATIVE WEB

所有画面都从一颗芯片长出/Every image grows from a single chip

以 NVIDIA B200 GPU 为题材的滚动网页艺术：从一颗芯片封装开场，钻进计算单元，拉远到整座数据中心，再回到这颗芯片。不放图表和参数，用画面说话。

  1. i.数据化作光，沿走线从显存流进芯片
  2. ii.精度一级级降低，画面变粗，又重新变清晰
  3. iii.从一颗 GPU 拉远到整座数据中心
  4. iv.每一章都接着上一章的画面长出来
