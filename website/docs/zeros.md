# 0分盘点 `/zeros/`

阅读页：按题列出拿 0 分的模型，每个用一句话说明为什么是 0 分。

## 数据

- 哪些是 0 分：`scores.json` 里题分正好是 0 的。本地预览含评测中的模型；正式站只含已确认的模型。
- 原因写在 `website/tools/zero-reasons.json`，按题名、型号存 `{ kind, zh, en }`。导出时只挑当前确实是 0 分的写进 `data/zeros.json`，所以原因跟着这份文件走，不随正式快照冻结；改了分、不再是 0 的自动不显示。
- 没写原因的 0 分显示评分员的异常备注，类别记「其他」。导出日志会列出缺原因的 0 分。
- 原因类别 `kind`：
  - `none` 未交付：没写出答案或作品，或只交了空壳、草稿；
  - `crash` 跑不起来：编译失败、崩溃、超时或启动卡死；
  - `wrong` 结果不对：能运行，但输出错误；
  - `slow` 未达门槛：结果对，但没达到计分门槛；
  - `rule` 违反规定：用了题目禁止的工具或做法。
- 原因由 GPT 6.1 Sol 查评分记录和作答写成（任务说明 `website/tools/zero-reasons-prompt.md`）：
  - 中文一到两句、50–80 字，讲清交了什么、具体卡在哪、为什么整题是 0；英文同义，最多 50 个词；
  - 不写型号名和题名，不写「因此得零分」；
  - 不透露评分指南、隐藏数据和参考答案。

## 版式

- **框架**：同题目详情。左栏是目录（有 0 分的题和个数，最后是「没有 0 分的题」）和统计（0 分总数、涉及题目、涉及模型、更新日期），右边是白纸。
- **页头**：
  - 眉标 `// ZERO SCORES`，标题「0分盘点」，右侧写总个数，横幅 `orbit/orbit-nested`；
  - 字段「9 / 13 道题有 0 分 │ 12 / 23 个模型拿过 0 分」，再接导语一句。
- **FIG.01「0 分分布」**：
  - **原因类别小块**：色块、名称、个数。点一个只看这一类，再点取消；地址带 `?kind=`。
  - **格子**：模型 × 13 题。0 分画该类色块（未交付斜线纹、跑不起来紫 600、结果不对青、未达门槛荧光绿加墨边、违反规定墨色）；有分的画小圆点；未出分的留空。
  - 每列表头从上到下是类别图标、题目简称、题号。简称中文竖排，英文转 90° 自下而上读。表头链到该题的分组；没有 0 分的题表头淡色。
  - 行按 0 分个数从多到少排。指向格子时，该列表头同时亮起，并显示浮签（模型、题、类别、原因）；点格子跳到下面那一条。
- **每道有 0 分的题一组**：
  - 组头是题号小块、英文眉标和题名，右边「6 / 23 个模型」和去题目页的小块；
  - 每个模型一行：厂商图标和全名（链到模型得分页）│ 原因类别 │ 原因。不到 1200 宽时，名字和类别在上，原因在下面占满整宽。
- **最后「没有 0 分的题」**：题目小块，链到题目页。按原因筛选时隐藏。
- **手机宽度**：行内模型名和类别在一行，原因在下面；分布图在框里横向滚动，模型名列固定在左边，整页不横向滚动。
- **暂停公示**：同其他成绩页，只显示提示。
