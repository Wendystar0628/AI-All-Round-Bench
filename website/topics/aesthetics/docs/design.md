# AI审美全能网站的设计

这个站是「AI审美全能」专题的展示网站，挂在正式域名的 `/aesthetics/`（英文在 `/aesthetics/en/`）。本文是网站的设计方案和写法说明：前五节讲站点是什么样，第六节讲交互，第七、八节讲版式、动效、图片和字体，第九节讲代码怎么组织、怎么写一页。开发和预览的命令见项目根目录的 [README](../README.md)。

设计的出发点是《质感贯穿方案》（`调研/审美全能/模板设计/质感贯穿/质感贯穿方案.md`）的第一、二节和第四节，以及它的增补《特质与配色》（同目录，冲突处以增补为准）：网站和视频是同一个世界、同一套底层、同一份锁定；骨架和明暗一样，每一题的皮（颜色、材质）各不相同。设计系统（颜色、令牌、字形、锁定、星座）以 `topics/审美全能/设计/设计系统.md` 为准，网站用它同步来的副本。数据字段见 [data.md](data.md)，下载包见 [downloads.md](downloads.md)，站点项目的七条约定见 `website/README.md`。

---

## 一、概念：一夜观测留下的图册

视频是某一个型号的「一夜」：一座老天文台，书架上十卷布面星图（十个创作方向），望远镜对准的天体是作品，三位轮值受测模型是评委；天文台夜里只点一盏灯——一颗用细线吊着的星。

**网站是这些夜晚合订成的图册。** 视频一部片只讲一个型号，网站把所有型号的「一夜」收在一起，按两种目录翻：按卷（方向，一题一页）翻，看同一道题各型号交了什么；按受测模型（型号）翻，看一个型号的整夜。

**只欣赏，不评判。** 页面上没有分数、名次、用时、开销，也不做任何对比工具。型号一律按参测登记的顺序排，写明「不分先后」。

**定下来的数**：十卷、三位评委。页面上写「十卷星图」「三位评委」的地方是定稿文案；方向数或评委数真要变时，改 `src/i18n/` 里这几句。会随数据变的数（作品件数、型号数、题面待定几卷）一律从数据里算。

## 二、和视频统一的底层

网站照搬视频的质感底层（方案第一节），只是光是静止的：

- **一盏光，有来源。** 每一页第一屏有一盏光：首页、卷目页是吊星，型号页和受测模型的窗里是那轮日，评委各自的灯，题目页是代表画面里的那盏灯。它照亮的那一片墙、光锥的边、日面，用预渲的点画贴图（`src/assets/light/`，由 `tools/textures.py` 画），不用 CSS 平滑渐变。点画只在过渡带里。
- **三种表面。** 夜：带一点藏青的近黑墙（`--wall`），上面一层灰泥一样极淡的斑驳和一层颗粒，两张瓦片都固定在视口上、压在字和图下面。纸：票、纸签、图版白边用同一张纸纹贴图（`.ae-sheet`），边上一圈极淡的吃色，落在墙上用短而实的接触阴影（`--contact`），不用 UI 卡片投影。箔：只给题名锁定的主角件，来自锁定文件本身。
- **颜色：公共的是夜，每一题有自己的一套。** 首页、受测模型、评委、关于是母版的夜；卷目页的书脊、题目页的页首按各题的配色。每一题一套颜色都取设计系统令牌（`tokens.json` 的 `directions[]`，字段见 `调研/审美全能/模板设计/质感贯穿/配色字段.md`；`design.mjs` 的 `skinOf`），网站不另写色值：世界色 `world`（大面积，色度压低）和它最深、最浅的两档，点亮色 `lit`（全屏唯一饱和的那一处），这一题能读的字 `ink`（暗底是它的纸白，亮底是它的墨），光色 `light`。
- **每屏只有一处真正饱和、被点亮的颜色**：首页是「审」上那颗锈橙星（十卷星座的十颗星各带一点自己的点亮色，极小），卷目页是主角卷垂下的书签带，型号页是那轮日，题目页是代表画面里的题材物，评委页是各自的灯色。
- **锈橙只属于这一夜本身**：字标那颗星、选手登场的日、导航的当前项。题目内部的部件（票根、书签带、当前星、页签短线、评语记号）都换成那一题的颜色；母版页上的票根是一块暖的深灰。
- **删掉的东西。** ✦、≫、◆◆、下划线、两色金渐变、墙和书脊的平行线纹理、圆角卡片。装饰用的星形只在吊星、星座里当前那一颗芒星、锁定里那一颗星芒；天上的星只是 1–2px 的点。
- **立绘进光。** 网页没法逐像素进光，用视频那套进光算法预先渲好的成品图（`topics/审美全能/设计/portraits/`：选手在日前、评委在各自的灯下）。成品图缺了的人退回数据里的原图，CSS 先压暗、染一层灯色、受光一侧一道窄边缘光、脚下化进雾（`img.is-raw`）。

### 文字分三等

| 等 | 是谁 | 网页上怎么做 |
|---|---|---|
| 一等：设计过的字 | 十个题名锁定、字标「AI审美全能」 | 用设计系统的同一份文件原样摆出来（锁定的图层和几何线、字形路径），网页不再模仿一遍 |
| 二等：排过的名字 | 型号名、评委名、「十卷星图」、各页标题、小节标题 | 只借两三样：放大一个字或字母、英文小型大写一档、一根三截发丝线 |
| 三等：次要小字 | 正文、点题短语、看点、评语、标签、星座的简称 | 常规字重（正文 400），干净，不加材质、描边、投影；几何线遇到它们断开 |

## 三、页面与网址

网址相对站内根路径（线上 `/aesthetics/`，开发服务器是 `/`）。英文页在 `en/` 下，路径相同。页面全部在构建时画好（静态 HTML），数据有了就自动多出页面。

| 页面 | 网址 | 内容 |
|---|---|---|
| 首页 | `''` | 一屏的标题卡和十卷星座，不滚动 |
| 卷目 | `volumes/` | 十卷星图：一摞书和当前那一卷的图版 |
| 受测模型 | `models/` | 参测型号的拱窗 |
| 评委 | `judges/` | 三位评委的登场，各一整屏 |
| 关于 | `about/` | 这一夜是怎么回事、怎么看下载的作品、出处 |
| 题目页 | `tasks/<key>/` | 一卷：页首是这一题的介绍页，下面是各型号的作品 |
| 型号页 | `models/<id>/` | 这个型号的一夜：十卷依次排开 |

- `<key>` 是题 key；题面还没出的两个方向（PV设计、字体与Logo设计）用展示文案里暂写的题 key，也有自己的页。`<id>` 是型号的网址标识。
- 题目页可带 `?m=<型号id>` 选定一个型号；任何页可带 `#shot=<型号id>/<题key>/<NN>` 直接打开那一张大图。评委页每位一个锚点 `#judge-<id>`，题目页、型号页的评委名链到这里。
- 页面之间怎么走：页头四项随时可达；首页的开卷票进卷目、星座的星进各题；卷目的书脊和图版进题目页；受测模型的窗进型号页；题目页的型号名进型号页，上一卷 / 下一卷和星座在卷之间走；型号页的每一卷进题目页（带 `?m=`）。

## 四、公共的骨架

**页头**（每页一样，`src/render/shell.mjs`）。固定在窗口顶上，往下滚也一直在（用户 11-24 定）：页首一屏里它是透明的、浮在画面上；离开页首后身后淡出一层夜色的底，底边一根细黄铜线，上下收窄，亮底题的页头字色也换回亮字（`shell.js` 给 `<html>` 加 `ae-scrolled`）。不是一条横栏，像一本书的目录：

- 左边「AI全能测评 ╱ AI审美全能」：前半回总站（中文页链 `/`，英文页链 `/en/`，不加站内根路径），后半回首页：中文页是字标的小字号形态（`logo/wordmark` 的 small：发丝加粗、不开观测缝、星放大一点），英文页是 Bodoni 的 AI Aesthetics。页脚的小吊星下面也是小字号字标。
- 右边四项：罗马数字斜体 + 宋体 600 的中文 + 拉开字距的小号英文（英文页只写英文）：**I 卷目 VOLUMES、II 受测模型 OBSERVERS、III 评委 JUDGES、IV 关于 ABOUT**。当前项下面一根锈橙短线；题目页算「卷目」，型号页算「受测模型」；首页没有当前项。
- 最右「中 / EN」：点了记住选择（`localStorage` 的 `octa.lang`，总站和各专题共用），并把本页的 `?…` 和 `#…` 带过去。第一次访问按浏览器语言跳，从站内点过来或地址带 `?stay` 不跳。
- 手机（<760）上四项收成一个「目录」按钮，点开是一整页的四项和语言切换（`<details>`，没有脚本也能用）。
- 页头占 `--head-h`：每页第一块自己让出这段高度（首页、满版页首的题目页和型号页本来就从页顶铺起）。纸底的题目页页头换墨色（`task.css`）。

**页脚**（首页没有）：一颗小吊星和字标、一句「一座老天文台，一夜观测。十卷星图摊在桌上，请慢慢翻看。」、四项和回总站、GitHub 仓库、「中 / EN」、更新日期和卷 / 受测模型 / 评委 / 作品数（为 0 的不写）、字体与厂商图标出处、ICP 备案。首页一屏放不下页脚，备案号贴在首页右下角。

**暂停公示**：正式发布时 `topic.notice` 打开的话，页底固定一条纸带写那句话；这时数据里没有型号和作品，各页按空状态画。

## 五、各页

### 5.1 首页：一屏，不滚动

首页就是片头主题页那张标题卡，再加一条能点的十卷星座（方案 4.2，样张四）。一屏里自上而下：

1. 吊星从页顶垂下、点亮，星身上一圈窄暖晕。
2. 字标「AI审美全能」（设计系统 `logo/wordmark/` 的大字形：铜版宋，「审」的屋顶开一道观测缝，锈橙星落在缝里，全屏唯一的锈橙；AI 浅金），直接落在夜上，背后不垫光锥、暗渍或光晕；下面短发丝线、AI AESTHETICS。
3. 一道倾斜的椭圆轨道套住那句话「同一份题面，各家模型的作品；今夜只欣赏，不评判。」，轨道上一颗小珠。
4. 一张开卷票：首屏唯一的主按钮，进卷目页；票根是一块暖的深灰（锈橙只留给字标的星）。
5. 十卷星座：一道低低的弧悬在地平线上方，星下是各题简称、星上是两位卷号，每一颗是一个入口，星点是那一题的点亮色（极小）。没有作品的卷是空心星、字更淡。悬停或聚焦一颗星，它变成芒星，上方浮出一张小纸签：迷你锁定（墨色那一档）和作品件数。
6. 地平线和小天文台，观测缝亮着朝向吊星；地平线下一行演职员表式的小字：几卷 · 几位受测模型 · 几位评委 · 几件作品 · 更新日期（为 0 的不写）。

- **一屏的做法**：整套构图画在一块「台」上，台高 = min(视口高, 视口宽 × 9/16)，贴着视口底边；台上所有竖向尺寸都按台高缩放（`--u`），横向按视口居中。窗口比 16:9 宽时台占满整个高度；比 16:9 窄时多出来的高度给上面的夜空，吊星的线一直从页顶垂下来。页面 `overflow: hidden`，没有滚动条。
- **矮窗口**：先收掉演职员表那一行，再把星座的简称收成只有卷号；矮到 420px 以下（横着的手机）才允许滚动，东西不被切掉。
- **手机竖屏、接近方形的窗口**：改成一列，开卷票在星座上面，星座两行五颗，仍是一屏。
- **动效**：只在本次访问的第一页放一次开场（星沿线放下、点亮一道长芒、字标对焦、轨道画出、星座的星从左到右依次点亮），之后只有吊星在摆。

### 5.2 卷目 `volumes/`：十卷星图

原首页往下滚才看到的书摞，按汇总页（方案 3.3）改：

- **左墙**：「十卷星图」二等标题（展示字体，「星」放大，一颗星芒），身后压一行只比墙亮一点的斜体幽灵字 *ten volumes of the night*；一句「灯熄之前，十卷都还来得及翻完。」和一句说明；下面是当前那一卷：封面图版、迷你锁定、一行编号 · 方向 · 件数 · 评委（编号是这一卷的点亮色）、点题短语。
- **书摞是一个有光的地方**（样张六）：吊星挂在书摞右上方，光从右上角照下来，离灯近的书亮、远的沉进夜里；整摞书搁在一条几乎是剪影的暗木桌沿上，桌沿顶上一根受光的细亮边。
- **书脊**：十本书各是自己那个世界的布色（`world`），亮的、暗的、中间调交替着摞起来，像一架真的书；书脊是圆的（上下两边暗一点），经纬布纹近看才出来，头尾两道压出来的线，没有圆角；长短、厚薄、手叠的错落都参差（带种子的随机）。编号是 Didone 斜体，类别是拉开字距的宋体小字，题名是锁定的迷你形态：铅印的纸白（暗布，`mini`）或墨（亮布，`mini-ink`），只有主角那个字用这一卷自己的材质烫上去。没有作品的卷：题名只淡淡压进布里，盖一枚长方的网点「云遮」印。
- **主角卷**：悬停（停 140ms，斜着移向图版时路过的书脊不会把图版换走）或聚焦哪一卷，哪一卷就抽出来一点、更亮，从左沿垂下它自己点亮色的书签带（这一屏唯一饱和的颜色）；左边换成那一卷。打开时第一卷就是主角卷（写在页面里，不等脚本）。亮布的书脊（墨字）编号也用这一卷的墨：水上乐园那种中间调的青上，最深的布色压不出字来。有作品还没有图时是一张空图版；一件作品都没有时是一扇云遮的夜窗。
- **手机**：书脊一列排下，没有左边的图版和吊星。

### 5.3 受测模型 `models/`

参测型号一人一扇拱窗（方案 4.3），一屏放下：窗是一条暗木的身子、内沿一根受光的细黄铜边；窗里是夜和那轮日（预渲的点画日面，下沿被窗台和暗角吃掉）；进光立绘站在日前，脚下化进雾，各人的头对齐在同一高度。窗下是二等的名字（Bodoni 常规的型号名、斜体小一档的推理强度坐在帽线上）、一根三截发丝线、厂商的小型大写（同时当评委的写「也是评委」）、作品件数和作答智能体。标题下一句「参加这一夜的型号，按登记顺序，不分先后。」点窗进型号页。手机上横着滑。

### 5.4 评委 `judges/`

评委登场的网页版（方案 3.4，样张三）。页首一个简短的标题和一句说明，下面三位各一整屏宽的一段，排法分开她们：

- **GPT 6.2 Sol：仪器铭牌，中轴对称。** 中线上一道笔直的观测缝，比墙亮，里面是冷的夜和远处一颗星；地平线在她眼睛的高度横贯全屏，刻度只在她两侧一小段，左端写 0°00′ HORIZON，右端停着最远的一颗星；身后对称的幽灵大字 S O L，她挡住中间的 O；名字是拉开字距的 Didone 大写，上面一行 GPT · 6.2。
- **Claude Opus 5.5：一张书页。** 左边是版心：首字母 O 很深，碗里收着 CLAUDE 的小型大写，后接斜体的 pus 和小号的 5.5；一根短发丝线、评委和她点评的方向；自我介绍像一段题记，前引号挂在版心之外；页脚一个页码 — ii —。版心和她之间一根竖直的订口线，顶上垂下一条松烟青的书签带（她的灯色）；她站在右边的拱窗前，窗里是松烟青的天，一盏读书灯从左上来。
- **Gemini 4 Neon：往一边倾。** 她在左，身后圆天窗里是琥珀色的光；右边 NEON 四个字母落在高低不同的基线上，那个 O 被拍歪、滚到基线下面；上方斜体 Gemini 4 和一笔琥珀色的手写 *hi there~*（全页唯一的手写）；自我介绍微微倾斜。
- **交接线**：同一根 1px 的线从上往下走——GPT 的地平线在她身后转成竖直（`--gx` 那一列），成了 Claude 那一页的订口，订口的下端再卷成 Gemini 的尾巴：从她身边起笔，打一个圈兜住那个 O，停在一颗星上（`src/client/judges.js` 按字的位置画）。
- **每段下面**：一句写给观众的人设、她点评的方向（编号、简称、题名，链到题目页）；同时参测的加一句链到她的型号页。中间给交接线留一道缝。
- 自我介绍和人设写在 `src/i18n/*/judges.json`（自我介绍和视频里她说的那句一致），不认识的评委退回数据里那句，排法用 Claude 那一种书页。
- **窄屏**：一段一列（画面在上、名字和介绍在下），交接线收起。

### 5.5 关于 `about/`

只剩阅读，全站最安静的书页：页首「关于这一夜」、一句话和本页目录（i. ii. iii.），一盏灯从左上照着这一页；下面三节——这一夜是怎么回事、怎么看下载的作品、出处。每节左边页边是小节标题（宋体 700 + 小型大写的英文一档），「这一夜」那一节的页边还有一列演职员表式的数目（卷目、受测模型、作品、评委、更新）；右边一栏正文，行距宽。评委的内容都搬到了评委页，这里只留一个链接。

### 5.6 题目页 `tasks/<key>/`

一页是一卷：页首就是视频的介绍页（方案 3.5、4.4），下面是各型号的作品。

**页首：这一题自己的颜色，一屏高**：

- **一块台**：静图、题名锁定、正文那一栏都在同一块 1920×1080 的「台」上，和视频的介绍页一样摆（`--px` 是一个舞台像素在网页上多大，台宽等于视口宽，台顶让开半个页头）。静图是代表画面的画面层（视频模板渲出，不带字，`topics/审美全能/设计/stills/<题key>.webp`）；锁定按视频的 `VX.ae.lockupPlace` 同一种算法摆（`design.mjs` 的 `lockupPlace`：字块左边对齐 x 100，英文小档的基线落在 y 422），几何线伸进画面接到丁给的落点（`linkOf`）。这样锁定的线和画面里的主角物接得上。几何线碰到字就断开，和视频一样按字实际占的地方算：点题短语、主要内容、每条看点、评委那一行各取每行字的外框合起来，外面留一圈 14 个舞台像素，在锁定的遮罩里挖洞（`task.js`，字体载入后、窗口改宽后重算）——网页的字号不跟着台缩放，窄一点的屏上字占的地方比视频宽，所以不能用一块写死的区域。
- 静图还没有时画缺省画面：这一卷的星座用黄铜线连在夜空里，上方吊着那颗星，一片灯光落在墙上。
- **颜色**：页首底下垫这一题的世界色，静图上沿化进页头那一条世界色、下沿化进世界色，再经过一段 `.tk-sink` 慢慢沉回夜。亮底的题（`ink` 是墨：PV、白模渲染、SVG动画、水上乐园、Logo）字和页头换成这一题的墨，字后面垫一团淡渍；暗底的题垫暗渍。
- 层次从后往前：画面 → 颗粒 → 字后面化开的渍 → 题名锁定（自带底版、几何线和星芒）→ 点题短语 → 主要内容、看点 → 观测卡。颗粒和渍都在台里、锁定之下，只压画面；锁定的各层原样叠放，不加滤镜、混合模式或叠色，也不被容器裁边（`.ae-lk` 的框就是锁定画布的大小，SVG 不裁），和视频里一样。暗底的题页头那一条压一层最深的世界色，纸白的页头字在亮一点的画面上也读得清。
- **题名锁定**：和视频同一份（`logo/lockups/` 的清单和网页用的 WebP 图层），编号小标按清单的位置贴（一行）。英文页、或这一题还没有锁定时，不按台摆：卷的小标和题名（设计系统的字形占位，英文页用 Didone）写在左上，字照常排。
- **点题短语**：中文在前、一道细斜线、斜体英文在后，共一条基线（英文页只写英文）；一行放不下时英文自成一行，去掉细斜线。**主要内容**一段，**看点**前面 Didone 斜体的 i. ii. iii.，都是常规字重；细斜线和看点的编号用这一题的颜色（暗底用点亮色，亮底用世界色最深的一档）。下面一行「评委 · 点评这一卷」和评委名（按她的排法缩小）。
- **观测卡**：躺在画面右下的光里，接触阴影落在背光一侧；票面是微型印刷（OBSERVATORY · ADMISSION、ADMIT ONE、No. 01/10 大号斜体数字、本卷星座的黄铜线、细线、3×2 点阵、一行 NIGHT OF THE TEN VOLUMES），票根是这一题世界色最深的一档，写这一题的动作（入画、点火……），亮底的题票面的微型印刷用这一题的墨（纸本身不变），进作品区。一件作品都还没有的卷不放卡，盖一枚云遮印。

**受测模型页签**：一排页签，一个型号一张：小封面图版 + 型号名。选中的那张受光（亮一档、上浮一点、底下一根点亮色的短线）；左右方向键在页签间移动（WAI-ARIA tabs）；选中写进地址 `?m=<型号id>`；没带 `?m=` 时选第一位；没有脚本时全部依次排开。

**一个型号的作品**：型号名（二等）、厂商小型大写、作答智能体、静帧数；右边一张取件票（下载，票根是世界色最深的一档）。作品图墙：每张图一圈纸边、接触阴影，横图封面单独占满一行，其余平均分行、按原比例等高；每张下一个图版编号；点开看大图。评语按点评页的样子排：前面一枚点亮色的小记号、评委名按她的排法、一根三截线、评语常规字重、说完一个 ▽；没有评语时写「点评稍后公布。」。最后是「这个型号的一夜」和「下一位」。

**页尾**：上一卷 / 下一卷两张书脊卡（和卷目页同一本书：那一卷的布色、迷你锁定、云遮印），下面一条横着的十卷星座（每颗星是它那一题的点亮色，当前那一颗是芒星）。

**空状态**（数据补上以后页面自己变）：

| 情况 | 怎么画 |
|---|---|
| 方向还没有题（PV设计、字体与Logo设计） | 页首照常（暂写的题名、点题短语、主要内容、看点，题名角上一个「暂定」纸签）；不放观测卡，盖一枚云遮印；作品区是一扇云遮的夜窗 |
| 题已登记、还没人作答 | 同上，没有「暂定」 |
| 作品还没有图 | 图墙换成一张空图版；页签上是空纸心；下载照常 |
| 方向不提供下载（白模渲染、PV设计） | 取件票是压暗的「仅展映」 |
| 方向提供下载但包还没打好 | 票的位置写一行「下载包整理中」 |
| 评语还没有 | 「点评稍后公布。」 |

### 5.7 型号页 `models/<id>/`

- **页首：选手登场的网页版**（方案 3.2），一屏：焦点是人，日只是她身后的光，字比画轻。穹顶内壁上只有日光在墙上的衰减和一层只比底亮一点的接缝；那轮日是预渲的点画日面，中心偏上暖橙、往外锈红，下沿被暗角吃掉；两道顶光从吊星落下，交叠在日的上半和她的头肩上；进光立绘站在日前，脚下化进雾。身后的系列大词（型号简称去掉数字：ASTRA、OPUS、NEON）放在腰的高度，人只挡住中间的字母，字母被日光染色——靠日的橙金、远的暗。卫星层：一条倾斜的点线轨道绕过她，轨道上一颗行星珠，几颗小金星和芒星，几粒往上飘的暖火星。右上一枚小圆章用竖直的点线吊下来，章里是观测台的标记和一圈微型字（日期、受测模型编号）。最下面是二等的名字：STARRING · 今夜主演、型号名、三截发丝线、厂商小型大写、作答智能体 · 测评日期 · 作品件数；同时当评委的加「也是这一夜的评委」，链到评委页她那一段。名字下面不放一排星（会被读成打分）。
- **目录**：一条十卷星座，点星跳到本页那一卷（`#v01`…）；这个型号没做的卷是空心的。
- **今夜节目单**：十卷按展示顺序，每卷一段：左边卷的小标、迷你锁定的题名（链到题目页 `?m=`）、点题短语、评语、取件票；右边封面图版（纸边，16:9 图框）和同一件作品的一排小图。这个型号没做的卷只占一行：卷的小标、题名、一枚云遮印。
- **页尾**：其他受测模型的小拱窗。

## 七、版式

**栅格**：页边 `max(32px, 3.9vw)`（手机 20px），内容最宽 1680px（`--margin`、`--max`，见 `src/styles/base.css`）。区块之间用留白和一根三截发丝线隔开，不加框。

**字号**（一屏最多四档）：正文 17px、行距 1.85–2；引言 20px；说明 14px；小型大写的标签 9.5–12px、字距 0.22–0.42em；名字 24–30px（Didone 常规）；小节标题 `clamp(30px, 2.6vw, 44px)`（宋体 700）；各页标题 44–68px（展示字 900）。首页、题目页页首、评委页按视口高度缩放。

**字体**（字体方案；`scripts/fonts.mjs`）：

| 家族 | 字体 | 用在 |
|---|---|---|
| AE Song | 思源宋体的同一设计 Noto Serif SC，400 / 600 / 700 | 正文 400；标签、名字、导航 600；小节标题 700 |
| AE Display CN | 同上，900 | 展示字：页头的「审美全能」、各页标题、字形没有时的纯文字退路 |
| AE Didone | Libre Bodoni（可变字重，正体和斜体；细线在小字号也看得清） | 型号名、评委名、编号、斜体短语、拉开字距的小型大写标签 |
| AE Script | Tangerine Bold | 只有 Gemini 的 *hi there~* 一笔 |

- 中文正文里的型号名用宋体自带的西文，Bodoni 不放在正文字体栈前面。斜体只用 Bodoni。英文要么比中文小一半（标签），要么大到变成纹理（幽灵字），不和中文同大并排。英文页标题用 Didone，正文仍是宋体的拉丁字，左对齐。
- 网页不用思源宋体本身：它的 OFL 带保留字名 “Source”，子集化算修改版要改字体内部名；Noto Serif SC 是同一设计、没有保留字名。

**颜色**：墙 `--wall`；正文 `--ae-text`、次文字 `--ae-text-2`、说明 `--ink-weak`（只给非必读）；黄铜 `--ae-brass` 给星座线和编号；各题的颜色只从令牌读（第二节）。锈橙只在字标的星、型号页的日和导航的当前项上。作品图不加滤镜、不加颗粒、不调色。

**断点**：

| 宽度 | 变化 |
|---|---|
| <1100 | 书脊各栏收窄 |
| <960 | 卷目单栏、收起图版区；题目页页首改上文下图、观测卡回到文字下面；型号页每卷改上下排；导航的小号英文收起 |
| <860 | 评委一段一列；关于页页边并进正文 |
| <760 | 页头收成「目录」按钮；首页一列；题目页页签横着滑；图墙按 150px 行高自然换行 |
| <600 | 页边 20px；受测模型横着滑；书脊两行 |

手机上不许出现整页横向滚动；能点的东西不小于 32px 高。

## 八、动效、图片与字体子集

**动效**：先空一下，再一下子出来，然后久久不动。

- 首页开场只在本次访问的第一页放（`<html class="is-first">`）；之后只有吊星以 5.6s 的周期摆 ±0.5°。卷目页、题目页缺省画面里的吊星也这样摆；型号页的暖火星慢慢往上飘。
- 悬停 0.3s：亮一档、上浮 2px 或抽出（书脊 16px）；不放大，不回弹。悬停的位移都乘 `--motion`。
- 系统开了「减少动态效果」：`--motion` 为 0，开场、摆动、入场全部关掉，过渡统一 0.15s。
- 不做视差滚动、滚动劫持、整页翻转、闪白。

**预渲的贴图**（`tools/textures.py`，带种子，`src/assets/light/`）：夜空 `sky.webp`、光锥 `cone.webp`、墙上的灯光 `pool.webp`、日 `sun.webp`、纸纹 `paper.webp`、夜墙的斑驳 `mottle.webp`。要换画法就改脚本重跑。

**图片加载**：作品图一律先用缩略图（长边 800，WebP），带宽高、懒加载；只有首屏那一张 `eager`。封面图版的图框固定 16:9（`object-fit: contain`）；页签的小图版铺满、取头肩那一截。看图器先放缩略图，大图下好再换上。图片和下载包的网址带 `?v=<大小+修改时间>`。

**字体子集化**（`scripts/fonts.mjs`）：开发时直接用原文件（可变字体整份，本机装了的先用本机的）。构建时把成品里所有页面、脚本、样式中出现的字收起来，每款字体只留这些字，做成 WOFF2（文件名带内容哈希），`@font-face` 写进每一页的 `<head>`。每款字体切成「基本」（拉丁、标点，中英文页共用）和「扩展」（汉字，按语言各一份），用 `unicode-range` 声明。Noto Serif SC 按 400 / 600 / 700 / 900 各切一个静态实例；900 和 Tangerine 只从带 `ae-dcn`、`ae-script` 的元素里收字。现在的成品：14 个子集共约 470 KB，一个中文页实际下载约 450 KB（宋体三个字重的汉字各约 120 KB），之后浏览器长缓存。

## 九、代码怎么组织

### 9.1 目录

```text
website/topics/aesthetics/
  scripts/sync.mjs        同步设计系统、字体、厂商图标到 src/vendor/（dev、build 前自动跑）
  scripts/site.mjs        Vite 插件：路由、开发时现画页面和读数据、构建后字体子集化并拷数据
  scripts/fonts.mjs       字体：文件从哪来 FONT_FILES、进成品的 FACES、开发用的 @font-face、构建做子集
  tools/textures.py       预渲的光和纸（写到 src/assets/light/）
  src/render/             页面在 Node 里画成 HTML
    index.mjs             路由表、渲染入口
    data.mjs              读数据目录、派生对象（字段说明写在文件开头）
    context.mjs           每页的 ctx：文案、链接、媒体地址、图标
    design.mjs            设计系统运行时（字形、锁定、星座、吊星）、令牌色、方向的皮（各题的配色）、锁定的摆法和落点、进光立绘和静图的查找
    shell.mjs             <head>、页头、页脚、图标集合、看图器骨架
    parts.mjs             公共部件
    pages/<页>.mjs        home、volumes、observers、judges、about、task、model
  src/styles/             site.css（令牌、纹理、base、shell、parts、lightbox）+ pages/<页>.css
  src/client/             site.js（公共）+ volumes.js、judges.js、task.js
  src/i18n/{zh,en}/       common、home、volumes、observers、judges、about、task、model
  src/assets/light/       预渲的贴图
  src/vendor/             同步来的副本（不进 git）
```

### 9.2 写一页

页面模块导出 `render(ctx, route)`，返回 `{ title, description, body, styles, script, gallery, bare }`，骨架由 `shell.mjs` 拼（`bare` 为真时不画页脚）。

- 类名：公共部件 `ae-` 前缀，样式在 `parts.css`；页面自己的类用页面前缀（首页 `hm-`、卷目 `vl-` / `sp-`、受测模型 `ob-`、评委 `jd-`、关于 `ab-`、题目页 `tk-`、型号页 `md-`）。
- 浏览器脚本：页面自己的脚本第一行 `import './site.js';`。页面内容在构建时就画全，脚本只切显隐、画随版面变的线；没有脚本时页面也完整可读。
- 文案写进自己命名空间的 JSON（`ctx.t('task.works.title')`），中英两份；数据里的字用 `ctx.L(x)`、`ctx.nameOf(x)`、`ctx.shortOf(cat)`（方向的简称）。
- 链接一律 `ctx.href('tasks/x/')`，图片和下载包一律 `ctx.media(path)`；同步来的设计素材用 `/src/vendor/…` 的地址，构建时 Vite 换成带哈希的成品地址。
- 不写分数、名次、用时、开销；型号顺序用数据的顺序。数据为空的地方都按 5.6 的表画，不为现在的数据写死任何东西。

### 9.3 读数据

只经过 `ctx.data`（`data.mjs`）：`categories`（10 个方向，`c.short`、`c.short_en` 是简称，`c.lead` 是页面上的那道题，`c.clouded` 表示一件作品都没有，`c.skin` 是这一题的配色，`c.cloth` 是书脊的布色即世界色）、`pages`、`entry(key)`、`models` / `model(id)`、`judges`、`counts`（`categories, models, judges, works`）。

### 9.4 公共部件（`src/render/parts.mjs`）

| 部件 | 说明 |
|---|---|
| `lockup(ctx, entry, { light })` | 题名锁定全量（题目页页首）：锁定清单的图层、几何线（伸到 `linkOf` 的落点；两层线共用一张遮罩，碰到字的洞由 `task.js` 填）、星芒、编号小标，按视频的摆法放在台上；没有锁定时用字形占位 |
| `miniLockup(ctx, entry, { form })` | 锁定的迷你和烫印形态：`mini`（暗底）、`mini-ink`（纸上）、`stamp`（烫箔）、`stamp-blind`（素压）；没有锁定时把主角件点上箔色 |
| `glyph`、`wordmark`、`displayText`、`volumesTitle` | 设计系统的字形、字标、展示字的纯文字（主角件放大） |
| `sectionHead`、`volumeLabel`、`modelName`、`modelBadge`、`judgeName` | 二等字：小节标题、卷的小标（01 — PV设计 PV DESIGN）、型号名、评委名的排法 |
| `starChart(ctx, { current, arc, href, clouded, count })` | 十卷星座（每颗星带那一题的点亮色） |
| `glint`、`star`、`constellation`、`hangingStar` | 芒星、四角星、方向的星座徽记、吊星 |
| `img`、`shot`、`wall`、`coverPlate`、`blankPlate` | 图、能看大图的一张、图墙、封面图版、空图版 |
| `obsCard`、`ticket` | 观测卡（入口）、取件票（下载） |
| `slip`、`cloudStamp`、`cloudedWindow` | 纸签、网点云遮印、云遮的窗 |
| `comment`、`figure` | 评语；立绘（先找进光成品图，没有时用原图加 `is-raw`） |
