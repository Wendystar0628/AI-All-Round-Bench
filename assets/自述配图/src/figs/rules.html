Ground Rules

核心规则Ground rules

所有专题、所有题都一样。各题自己的工具、联网和作品要求写在题面的“规定”一节。Same for every topic and task; each statement's rules section adds the task's own tool and network limits.

01

一题一个新会话A fresh session

作答目录只放这道题的题面和材料；智能体的记忆开测前清空，作答时关闭自动记忆。

Only this task's statement and materials in the folder; agent memories cleared before testing, auto-memory off.

02

独立作答Work alone

没有人回答问题，除系统故障说明外只发专题配置好的固定消息；不开子代理，不用多代理或并行协作功能。

Nobody answers questions; apart from failure notices, only fixed messages. No subagents or parallel agents.

03

开场不报时间No time in prompts

开场提示、叫回和提醒都不写限时和剩余时间；光追、电路两题题面写明限时，并给查看剩余时间的工具。

Prompts and reminders never give the time; the ray-tracing and circuit statements state the limit and ship a time-left tool.

04

只在作答目录里Stay in the work folder

只读写工作目录，必需工具的安装路径和临时目录除外；不换账户登录，只按 PID 结束自己启动的进程。

Only the work folder, plus paths required tools need; no other logins; end only your own processes, by PID.

05

到时中止Stopped at time

时间一到，智能体、命令、服务器和浏览器一并结束，不延长；作答目录里留下的就是提交。

Agent, commands, servers and browsers end together, no extension; what is left in the folder is the submission.

06

只评留下的内容The folder counts

评分一律看作答结束时的工作目录；作答目录不建 Git 仓库，文件名或格式略有出入照常评。

Graders read the folder as it was at the end; no Git repository; small slips in names or format are fine.
